## 这一节学什么

期望是按发生概率加权的平均值：$\mathbb E[X]=\sum_x x\,P(X=x)$，它可以不是任何一次实际出现的值。比如公平骰子的期望为 3.5，但骰子不会掷出 3.5。

>
> 为我讲解期望的线性性质，用指示变量和集卡分阶段等待说明怎样拆贡献，并引导我对独立性与等待时间提问。

## 线性性质不需要独立

$\mathbb E[X+Y]=\mathbb E[X]+\mathbb E[Y]$，$\mathbb E[cX]=c\mathbb E[X]$。即使 X、Y 有关联，只要期望存在，这些式子仍成立。

设 Iᵢ 为“第 i 题答对”的指示变量，答对时为 1，否则为 0。$\mathbb E[I_i]=P(\text{第 }i\text{ 题答对})$，所以期望答对题数就是这些概率之和。不需要枚举整张试卷的全部答案，也不要求每道题的对错独立。

但 $\mathbb E[XY]=\mathbb E[X]\mathbb E[Y]$ 一般需要额外条件，不能把“加法总能拆”误用到乘法。

## 例题精讲：[SP1026 FAVDICE — Favorite Dice](https://www.luogu.com.cn/problem/SP1026)

**题意简述：** 不断掷一个公平的 n 面骰子，各面等概率、各次独立，求所有点数至少出现一次所需次数的期望。第一行测试组数 t，每组一个 1≤n≤1000；每组仅输出一个保留两位小数的数。

自编输入：

```text
3
1
2
3
```

输出：

```text
1.00
3.00
5.50
```

### 先把思路讲清楚

已经见过 k 种点数时，下一次出现新点数的概率为 $\frac{n-k}{n}$。一次成功概率为 p 的重复试验，等到第一次成功的期望次数 E 满足 $E=1+(1-p)E$：先掷一次，失败后回到同样状态，因此 $E=\frac1p$。

于是从 k 种增加到 k+1 种的期望等待为 $\frac{n}{n-k}$。总次数拆成 n 个阶段，再用期望线性性相加，得到 $\frac nn+\frac n{n-1}+\cdots+\frac n1$。n=3 时各阶段为 1、1.5、3，总期望 5.5。最后一种最难等，因为成功概率仅为 1/n。

代码里的 remain 是还未见过的种数，循环每次加入一个阶段的期望。输出使用 `printf` 的 %.2f；不输出额外标题。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        double answer = 0;
        for (int remain = n; remain >= 1; remain--) answer += 1.0 * n / remain;
        printf("%.2f\n", answer);
    }
    return 0;
}
```

每组时间 $\mathcal{O}(n)$，额外空间 $\mathcal{O}(1)$。1.0*n/remain 使用浮点除法。集卡、集邮等“重复抽到已收集种类”的过程也能这样拆阶段，但若每次费用不同，要重新确定所求的随机量。

## 一个常用解题流程

先问总量能否拆成“每个位置的贡献”或“每个阶段的耗时”；为每份贡献单独求期望；最后利用线性性质求和。代码通常只剩一个循环，难点在拆分方式，不在循环怎么写。
