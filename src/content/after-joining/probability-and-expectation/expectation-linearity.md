## 这一节学什么

期望是按发生概率加权的平均值：E[X]=Σx·P(X=x)，它可以不是任何一次实际出现的值。比如公平骰子的期望为 3.5，但骰子不会掷出 3.5。

> **AI 伴学提示词**
>
> 为我讲解期望的线性性质，用指示变量和集卡分阶段等待说明怎样拆贡献，并引导我对独立性与等待时间提问。

## 线性性质不需要独立

E[X+Y]=E[X]+E[Y]，E[cX]=cE[X]。即使 X、Y 有关联，只要期望存在，这些式子仍成立。

设 Iᵢ 为“第 i 题答对”的指示变量，答对时为 1，否则为 0。E[Iᵢ]=P(第 i 题答对)，所以期望答对题数就是这些概率之和。不需要枚举整张试卷的全部答案，也不要求每道题的对错独立。

但 E[XY]=E[X]E[Y] 一般需要额外条件，不能把“加法总能拆”误用到乘法。

## 例题精讲：自编 · 收集全部卡片

**题意简述：** 一共有 n 种卡片，每次独立且等概率抽到其中一种，允许重复。输入 1≤n≤10⁷，求第一次集齐全部种类所需抽取次数的期望，输出六位小数。

输入 `3`，输出 `5.500000`。

已经有 k 种时，下一抽获得新种类的概率是 (n−k)/n。一次成功概率为 p 的独立重复尝试，等待成功次数的期望为 1/p：设期望为 E，先花一次；失败概率 1−p 时回到原状态，于是 E=1+(1−p)E。

因此，从 k 种到 k+1 种的平均等待为 n/(n−k)。把 n 个阶段的等待相加：

```text
总期望 = n/n + n/(n-1) + ... + n/1
       = n × (1 + 1/2 + ... + 1/n)
```

n=3 时三个阶段分别为 1、1.5、3，合计 5.5。最后一种最难等，是因为当时成功概率只有 1/n。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    long double harmonic = 0;
    for (int i = 1; i <= n; i++) harmonic += 1.0L / i;
    printf("%.6Lf\n", harmonic * n);
    return 0;
}
```

`1.0L` 让除法按 long double 进行，避免整数除法；`%.6Lf` 与 long double 参数对应。这里累计项很多，用 long double 减少累计误差。时间 O(n)，空间 O(1)，最大约一千万次浮点加法。

## 一个常用解题流程

先问总量能否拆成“每个位置的贡献”或“每个阶段的耗时”；为每份贡献单独求期望；最后利用线性性质求和。代码通常只剩一个循环，难点在拆分方式，不在循环怎么写。

## 练习：先拆贡献再算

先**独立重做例题**，手算 n=1、2、3；解释为什么不能把各阶段的成功概率直接相加当作总耗时。

### 推荐必做

1. **自编 · 随机答题：** 输入每题选项数，随机选一个，求期望答对题数；为每道题定义指示变量。
2. [P1297 单选错位](https://www.luogu.com.cn/problem/P1297)：答案循环错位后，求期望答对数；练习分别判断每一位置答对的概率，再求和。

### 选做巩固

- **自编 · 相邻相同次数：** 长 n 的独立均匀 k 色序列，求相邻两项颜色相同的对数期望；注意相邻事件之间有关联仍能相加。
- **自编 · 已有部分卡片：** 开始已有 k 种不同卡，求剩余等待期望，重新确定需要累加的阶段范围。
