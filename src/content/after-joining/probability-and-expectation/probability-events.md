## 这一节学什么

概率题的第一步是说清随机过程。两枚公平骰子的 36 个有序点数组合等可能，但“点数和为 2”和“点数和为 7”不等可能。不能把看起来不同的结果直接当成等可能事件。

> **AI 伴学提示词**
>
> 为我用骰子和随机到达时间讲解等可能、事件运算与几何概率，画图解释补集面积，并引导我对不理解的地方提问。

## 从结果集合到事件

样本空间 Ω 包含全部可能结果，事件 A 是其中一部分。有限且等可能时，$P(A)=\frac{|A|}{|\Omega|}$。两枚骰子和为 7 有 (1,6)…(6,1) 六种，概率为 6/36。

常用关系：$P(\overline A)=1-P(A)$，$P(A\cup B)=P(A)+P(B)-P(A\cap B)$。互斥表示二者不能同时发生；独立表示 $P(A\cap B)=P(A)P(B)$。二者不是同一概念：两个正概率且互斥的事件一定不独立。

连续均匀取点时，单个点的概率为 0，但一片区域的概率可以大于 0。几何概型用长度、面积或体积的比例计算；前提是题目确实给出了对应区域内的均匀分布。

## 例题精讲：[CF476B Dreamoon and WiFi](https://codeforces.com/problemset/problem/476/B)

**题意简述：** 原指令串只含 +、−，收到的同长度串还可能含 ?，每个 ? 独立等概率替换成 + 或 −。从 0 开始执行，+ 前进一步、− 后退一步，求最终到达原指令目标位置的概率。两串长度≤10，输入两行字符串，输出实数，误差≤10⁻⁹。

自编输入：

```text
+-+-
+-??
```

输出：

```text
0.500000000000
```

### 先把思路讲清楚

原串目标为 0，已知的 +− 也回到 0。两个问号有 ++、+−、−+、−− 四种等可能结果，其中两种使终点为 0，所以概率为 2/4。

等可能的是每个问号的完整赋值，而非最终位置：位置 0 对应两种赋值，±2 各一种。令 mask 的每位描述一个问号，枚举全部 2ᵏ 种赋值，满足终点要求的数量除以总量即可。没有问号时，空赋值仍有一种，答案为 0 或 1。

代码先累计已知位移，再用双层循环枚举未知位移，最后 `printf` 输出 12 位小数。分子乘 1.0，使整数计数转成浮点除法。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    string sent, received;
    cin >> sent >> received;
    int target = 0, known = 0, unknown = 0;
    for (char c : sent) target += c == '+' ? 1 : -1;
    for (char c : received) {
        if (c == '?') unknown++;
        else known += c == '+' ? 1 : -1;
    }
    int good = 0, all = 1 << unknown;
    for (int mask = 0; mask < all; mask++) {
        int position = known;
        for (int i = 0; i < unknown; i++) position += ((mask >> i) & 1) ? 1 : -1;
        if (position == target) good++;
    }
    printf("%.12f\n", 1.0 * good / all);
    return 0;
}
```

时间 O(长度+k2ᵏ)，额外空间 O(长度)。k≤10，最多 1024 种结果。

## 连续取值时，把计数换成面积

如果两人独立均匀在 `[0, 1]` 到达，将到达时间记为 (x,y)，全部结果落在单位正方形中。两人最多等 t（0≤t≤1），能见面对应 $|x-y|\le t$，也就是两条平行直线之间的带状区域。外侧两块直角三角形的总面积为 (1−t)²，因此见面概率为 $1-(1-t)^2$。

这个推导用于理解几何概型：有限等可能结果比较个数，连续均匀区域比较面积。不能把连续区域中的几个随手选点当成全部等可能结果。
