## 这一节学什么

概率题的第一步是说清随机过程。两枚公平骰子的 36 个有序点数组合等可能，但“点数和为 2”和“点数和为 7”不等可能。不能把看起来不同的结果直接当成等可能事件。

> **AI 伴学提示词**
>
> 为我用骰子和随机到达时间讲解等可能、事件运算与几何概率，画图解释补集面积，并引导我对不理解的地方提问。

## 从结果集合到事件

样本空间 Ω 包含全部可能结果，事件 A 是其中一部分。有限且等可能时，P(A)=|A|/|Ω|。两枚骰子和为 7 有 (1,6)…(6,1) 六种，概率为 6/36。

常用关系：P(非 A)=1−P(A)，P(A 或 B)=P(A)+P(B)−P(A 且 B)。互斥表示二者不能同时发生；独立表示 P(A 且 B)=P(A)P(B)。二者不是同一概念：两个正概率且互斥的事件一定不独立。

连续均匀取点时，单个点的概率为 0，但一片区域的概率可以大于 0。几何概型用长度、面积或体积的比例计算；前提是题目确实给出了对应区域内的均匀分布。

## 例题精讲：自编 · 两人能否相遇

**题意简述：** 两人各自独立、均匀地在 [0,L] 内到达。先到的人最多等 T 个时间单位，问能相遇的概率。输入实数 L、T，0<L≤10⁶，0≤T≤10⁶，输出六位小数。

输入 `60 15`，输出 `0.437500`。

把两人的到达时间作为横坐标 x、纵坐标 y，全部结果落在边长 L 的正方形内。能相遇等价于 |x−y|≤T。与其直接算中间斜带，不如扣除两侧三角形：当 T<L 时，每个三角形的直角边为 L−T，总面积为 (L−T)²。

```text
y
L +----------------+
  | 不相遇 /       |
  |       / 相遇   |
  |      / /       |
  |     / / 不相遇 |
0 +----------------+ x
  0                L
两条斜线：y=x+T 与 y=x-T
```

所以概率为 1−(L−T)²/L²。T≥L 时覆盖整个正方形，直接为 1；T=0 时只有对角线，面积为 0。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    double length, waitTime;
    cin >> length >> waitTime;
    double answer = 1;
    if (waitTime < length) {
        double ratio = (length - waitTime) / length;
        answer = 1 - ratio * ratio;
    }
    printf("%.6f\n", answer);
    return 0;
}
```

`%.6f` 输出六位小数，参数为 double。用比值再平方让式子更直接，时间、空间均 O(1)。边界是图形发生变化的位置，因此 T=0、T=L 都应手动核对。
