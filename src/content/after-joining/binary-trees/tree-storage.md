## 编号是地址，数据是内容

回到上一节的树：1 的孩子为 2、3，2 的孩子为 4、5，3 只有右孩子 6。

| 结点 u | 左孩子 lc[u] | 右孩子 rc[u] |
| --- | --- | --- |
| 1 | 2 | 3 |
| 2 | 4 | 5 |
| 3 | 0 | 6 |
| 4 | 0 | 0 |
| 5 | 0 | 0 |
| 6 | 0 | 0 |

约定结点编号从 1 开始，**0 表示这里没有结点**。例如 lc[3]=0 表示 3 没有左孩子，而不是存在一个编号为 0 的真实孩子。

如果结点还有分数、姓名等数据，另用 value[u] 保存。编号为 3 的结点可以保存分数 90：3 是编号，90 是内容。

```text
int lc[N], rc[N], value[N];
lc[1] = 2;
rc[1] = 3;
value[3] = 90;

int child = rc[1];    // child=3，取出右孩子编号
cout << value[child]; // 再用编号读取该结点的数据
```

你在数组章节学过：下标可以由程序计算。这里 rc[u] 的结果又能成为下一个下标，于是程序可以顺着树的连接关系继续前进。

### 需要向上走时，再保存父亲

读取 u 的孩子 v 后，如果 v 不为 0，就能设置 parent[v]=u。根没有父亲，可以令 parent[root]=0。

孩子编号不一定大于父亲编号。输入中先描述哪个结点，也不决定它处在第几层。层数来自连接关系，而不是编号大小。

## 为什么不能总写左孩子是 2u

如果按层从左到右给一棵完全二叉树编号，可以用 2u 和 2u+1 定位左右孩子。但题目给出任意编号时，必须保存输入中的真实关系。

即使按这种位置编号表示普通二叉树，长链也会使编号快速增大：一直走右孩子时，编号依次为 1、3、7、15……结点不多，却可能需要很大的数组。因此本章直接保存 lc、rc。

> **数组容量与空结点**
>
> 下标 1 到 n 至少需要 n+1 个位置。分配容量时预留余量；读取孩子后先判断是否为 0，再把它作为真实结点处理。越界和错误地把 0 入队，都可能导致答案错误或 RE（运行时错误）。

## 例题精讲：P4913 · 二叉树深度

**原题：** [P4913 · 二叉树深度](https://www.luogu.com.cn/problem/P4913)。

**题意简述：** 有 n 个结点，根编号为 1。输入第 i 个结点的左右孩子编号，0 表示不存在。求最多经过几层结点。n 最大为 10^6。

下面是本节自拟的输入输出，表示上面的 6 结点树。

输入：

```text
6
2 3
4 5
0 6
0 0
0 0
0 0
```

输出：

```text
3
```

### 思路：知道父亲的深度，就知道孩子的深度

令 depth[u] 表示结点 u 所在的层数。

- 根结点的 depth[1]=1。
- 如果 v 是 u 的孩子，depth[v]=depth[u]+1。
- 所有结点的 depth 最大值，就是答案。

这是一个沿树传播的计算过程。我们在第一板块学过队列：先处理根，再处理它的孩子，再处理下一层，恰好能保证计算孩子时，父亲的深度已经确定。

| 取出的结点 | 它的深度 | 新加入队列的孩子 | 处理后队列 |
| --- | --- | --- | --- |
| 1 | 1 | 2、3，深度为 2 | 2、3 |
| 2 | 2 | 4、5，深度为 3 | 3、4、5 |
| 3 | 2 | 6，深度为 3 | 4、5、6 |
| 4、5、6 | 3 | 没有孩子 | 逐步变空 |

这里输入保证是一棵树，每个非根结点只会从它的父亲处被加入一次。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1000000 + 5;
int lc[N], rc[N], depth[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> lc[i] >> rc[i];
    }

    queue<int> q;
    depth[1] = 1;
    q.push(1);
    int answer = 0;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        answer = max(answer, depth[u]);
        if (lc[u] != 0) {
            int v = lc[u];
            depth[v] = depth[u] + 1;
            q.push(v);
        }
        if (rc[u] != 0) {
            int v = rc[u];
            depth[v] = depth[u] + 1;
            q.push(v);
        }
    }
    cout << answer << '\n';
    return 0;
}
```

对照思路看代码：lc、rc 负责保存关系，depth 负责保存已经算出的层数，队列负责安排处理顺序，answer 负责记录目前见过的最大深度。

每个结点进出队列一次，时间复杂度 O(n)，数组与队列的空间复杂度 O(n)。三个 int 数组在 n=10^6 时约占 12 MB；把它们定义为全局数组，也避免把大数组放入函数的局部栈空间。

### 为什么这里使用队列

递归也能表达“树深度等于左右子树深度的较大者加 1”。但本题允许百万结点排成一条长链，递归会产生大量尚未返回的函数调用，可能耗尽调用栈而 RE。上面的队列实现处理同样的关系，不依赖递归层数。

## 练习：保存关系，再按关系计算

先**独立重做 P4913**。至少测试只有根、只有左孩子的链、只有右孩子的链和左右分支都有的树。

### 推荐必做

1. **自编：输出父亲与叶子。** 输入格式与 P4913 相同，输出所有结点的父亲编号，再按编号升序输出叶子。对本节 6 结点数据，两行结果分别为 `0 1 1 2 2 3` 和 `4 5 6`。练习把同一组连接关系用于不同统计。
2. [P4715 · 淘汰赛](https://www.luogu.com.cn/problem/P4715)：这次用数组保存每场比赛的胜者，逐层计算，最后比较根的两个孩子。练习把上一节的赛程图真正存入程序。

### 选做巩固

- **自编：根的编号不固定。** 输入仍是每个结点的左右孩子，但不再保证根为 1。先设置父亲数组，找出没有父亲的那个结点，再计算深度。练习从关系找起点。
- **自编：统计每一层的结点数。** 对上面的 6 结点输入，输出 `1 2 3`。练习利用 depth[u] 作为另一个数组的下标。
