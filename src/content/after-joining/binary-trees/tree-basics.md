## 这一节学什么

数组擅长把数据排成一列，树则用来表示层次关系。我们从已经熟悉的淘汰赛出发，认识树中的结点、父亲、孩子、叶子和子树，再用这些关系寻找亚军。

学习顺序：看懂一棵树 → 分清几个名称 → 手算淘汰赛 → 把找亚军的思路写成程序。

## 为什么要用树

四支队伍参加淘汰赛：1 和 2 比赛，3 和 4 比赛，两场的胜者再决出冠军。把“谁由谁晋级而来”画出来：

```text
                 决赛胜者
                /        \
         左半区胜者      右半区胜者
           /    \          /    \
         队1    队2      队3    队4
```

这一组数据存在层次和分支。单独列出队伍编号，无法直接表达这些关系；树把它们保存下来。以后表示文件夹、表达式、区间和分类时，也会遇到类似结构。

## 用一张图认识名称

```text
             1
           /   \
          2     3
         / \     \
        4   5     6
```

| 名称 | 含义 | 图中的例子 |
| --- | --- | --- |
| 结点 | 树中的一个对象 | $\{1,2,3,4,5,6\}$ |
| 根 | 整棵树最上面的起点，没有父亲 | 1 |
| 父亲与孩子 | 直接连接的上下两层关系 | 2 是 4 的父亲，4 是 2 的孩子 |
| 兄弟 | 父亲相同的结点 | 4 和 5 |
| 叶子 | 没有孩子的结点 | $\{4,5,6\}$ |
| 祖先 | 从根到当前结点途中经过的上层结点 | 5 的祖先有 $\{1,2\}$ |
| 子树 | 一个结点及它下面的全部结点 | 以 2 为根的子树含 $\{2,4,5\}$ |

一棵树中，根以外的每个结点恰有一个父亲。沿着父亲向上走，最终会到根；不会绕一圈又回到原来的结点。有 $n$ 个结点的树，连接它们的边有 $n-1$ 条。

**二叉树**要求每个结点最多有两个孩子，而且区分左孩子与右孩子。只有右孩子、没有左孩子，也是合法的二叉树。把一个结点的左右子树交换，通常就得到了另一棵二叉树。

## 深度：先约定从第几层开始

本章沿用后面例题的约定：**根在第 1 层，孩子的层数是父亲的层数加 1**。

上图中，1 的深度为 1，`2、3` 的深度为 2，`4、5、6` 的深度为 3。整棵树的深度是结点深度的最大值，因此为 3。

从 1 到 5 经过两条边，但经过三层结点。读题时要看要求计算的是边数，还是层数；程序里的初始值也要跟着题意确定。

若一棵二叉树的深度为 $h$：

- 第 1 层最多 1 个结点，第 2 层最多 2 个，第 3 层最多 4 个。
- 第 $h$ 层最多有 $2^{h-1}$ 个结点。
- 每一层都填满时，总结点数为 $1+2+4+\cdots+2^{h-1}=2^h-1$。
- 一条只有单个孩子的长链也属于二叉树。$n$ 个结点排成链，深度就是 $n$。

国内入门题通常把“每层都填满”的二叉树称为**满二叉树**。**完全二叉树**则允许最后一层没填满，但结点必须从左到右连续放置，前面的层全部填满。后面学习堆时，会继续用到完全二叉树。

## 例题精讲：P4715 · 淘汰赛

**原题：** [P4715 · 淘汰赛](https://www.luogu.com.cn/problem/P4715)。

**题意简述：** $2^n$ 支队伍参加淘汰赛，$n\le 7$。相邻队伍比赛，胜者继续按相同顺序比赛；能力值较高者一定获胜，各队能力不同。输出亚军队伍的编号。

### 先画赛程，再找需要的信息

用下面这组自拟数据模拟原题规则：

输入：

```text
2
5 9 7 3
```

输出：

```text
3
```

`1、2` 比赛，2 胜；`3、4` 比赛，3 胜；最后 2 战胜 3，亚军是 3。

```text
                 2号：9
                /      \
           2号：9       3号：7
           /   \        /   \
        1：5   2：9   3：7   4：3
```

能力最强的队伍会成为冠军。亚军却不一定是全体队伍中第二强的：第二强的队伍可能提前和冠军相遇。

从树的根往下看，决赛两位选手分别来自左半区、右半区。每个半区最终晋级的，都是这一半能力最强的队伍。于是只需要：

1. 找出前一半队伍中能力最大的队伍编号 $\mathrm{leftWinner}$。
2. 找出后一半的最大者 $\mathrm{rightWinner}$。
3. 两者比较，能力较低的一方就是亚军。

这就是“代码是思路的实现”：我们先确定决赛的两位选手来自哪里，代码再用两次扫描找出他们。无需为了出现“树”这个知识点，就把所有比赛结点都建出来。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int total = 1;
    for (int i = 1; i <= n; i++) {
        total *= 2;
    }
    int a[130];
    for (int i = 1; i <= total; i++) {
        cin >> a[i];
    }

    int half = total / 2;
    int leftWinner = 1;
    int rightWinner = half + 1;
    for (int i = 1; i <= half; i++) {
        if (a[i] > a[leftWinner]) leftWinner = i;
    }
    for (int i = half + 1; i <= total; i++) {
        if (a[i] > a[rightWinner]) rightWinner = i;
    }
    if (a[leftWinner] < a[rightWinner]) {
        cout << leftWinner << '\n';
    } else {
        cout << rightWinner << '\n';
    }
    return 0;
}
```

数组保存能力值，$\mathrm{winner}$ 变量保存编号，比较时再通过 `a[winner]` 取出能力值。输出要求的是编号，因此不能直接输出最大的两个能力值。

设参赛队伍数为 $K=2^n$，程序时间复杂度 $\mathcal{O}(K)$，数组空间 $\mathcal{O}(K)$。本题 $K$ 最大只有 128。
