## 这一节学什么

做一道依赖题，先要知道“下一步能处理谁”。树里每个非根结点只有一个父亲，图中的一个点却可能同时等多个前驱。我们先重新讲清拓扑排序怎样安排这个顺序，再把 DP 的更新放进同一个过程。

> **AI 伴学提示词**
>
> 为我从任务依赖讲解拓扑排序，手算入度、队列与顺序，再结合动图理解最长路更新和不可达点的处理，并引导我提问。

## 先讲拓扑排序：把所有“必须在前面”排好

有向边 u→v 表示 u 必须在 v 前面。**拓扑序**是所有结点的一种排列，使每条边的起点都在终点之前。能够排出这种顺序的有向图，恰好是有向无环图，简称 DAG。

例如 1→2、1→3、2→4、3→4：1 必须先于 2、3，4 要等 2、3 都结束。1、2、3、4 是合法顺序，1、3、2、4 也合法；拓扑序通常不唯一。

### 入度：还有多少个前驱没处理

indegree[v] 最初是指向 v 的边数。处理过程中，它表示 v 还有多少条依赖没释放。入度为 0 的点不用再等，可以放入队列。

Kahn 算法重复做这几步：

1. 先将**所有**入度为 0 的点加入队列。
2. 取出队头 u，写入拓扑顺序。
3. 遍历 u 的每条出边 u→v，把 indegree[v] 减 1，表示 u 这份前置依赖已处理。
4. 若 indegree[v] 恰好变成 0，将 v 加入队尾，等待之后处理。

这里说的“删边”是释放依赖，代码只修改入度，不需要真的把边从 vector 邻接表里删掉。队列只是管理已经就绪的点，不是在计算从某个起点出发的距离。

> **入度归零，表示全部前驱到齐**
>
> 看到一条边 u→v，不代表 v 已经可以处理。如果 v 还有别的前驱，它的入度仍大于 0，就必须继续等待。正是这个条件，让 DP 在处理 v 时可以确信所有来源的候选都已经送到。

## 例题精讲一：[B3644 拓扑排序 / 家谱树](https://www.luogu.com.cn/problem/B3644)

**题意简述：** 给每个人的后代关系，输出顺序，使每个人都在其后代前面。第一行 N≤100，随后 N 行，第 u 行列出 u 的后代编号，以 0 结束。输出任意一种合法拓扑序。

自编输入：

```text
4
2 3 0
4 0
4 0
0
```

输出：

```text
1 2 3 4
```

### 先把思路讲清楚

边 u→v 表示 u 必须在 v 前面。样例里 1 先于 2、3，2、3 又都先于 4；2 与 3 的相对次序没有限制。

入度是“还有多少个前驱没处理”。先把所有零入度点入队；取出 u 后输出它，沿 g[u] 给每个后代的入度减 1。只有减到 0，才表示它的全部前驱都已经处理，可以入队。

这段完整代码按原题读取每行末尾的 0。它没有输入边数 m，不能照搬另一种 n、m 后接边列表的格式。先独立完成这道拓扑排序题，再看下面动图如何在同样的处理顺序中加入 DP 转移。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> g(n + 1);
    vector<int> indegree(n + 1);
    for (int u = 1; u <= n; u++) {
        int v;
        while (cin >> v && v != 0) {
            g[u].push_back(v);
            indegree[v]++;
        }
    }
    queue<int> q;
    for (int u = 1; u <= n; u++) if (indegree[u] == 0) q.push(u);
    vector<int> order;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        order.push_back(u);
        for (int v : g[u]) {
            indegree[v]--;
            if (indegree[v] == 0) q.push(v);
        }
    }
    for (int i = 0; i < n; i++) cout << order[i] << (i + 1 == n ? '\n' : ' ');
    return 0;
}
```

设输入关系总数为 M，时间、空间 O(N+M)。原题的家谱关系可排出合法顺序。对一般有向图，还要检查已输出点数是否为 N：不足说明存在环，下面的动图会演示这种情况。

## 例题精讲二：P1807 · 最长路

**原题：** [P1807 · 最长路](https://www.luogu.com.cn/problem/P1807)。

**题意简述：** 给带权 DAG，求 1 到 n 的最长路线，不可达输出 −1。n≤1500、m≤50000，边权可负。

输入：

```text
4 4
1 2 3
1 3 5
2 4 4
3 4 -1
```

输出 `7`，路线 1→2→4 优于 1→3→4 的 4。

## 在拓扑排序里，多送一份“最长路候选”

f[u] 表示从 1 到 u 的最大路径权。初始 f[1]=0，其余不可达。对边 u→v，若 u 可达，尝试 f[v]=max(f[v],f[u]+w)。

u 出队时，它的全部前驱已经处理，所以 f[u] 已经是最终值。现在可以把这个值沿出边送给后继；v 会取所有候选中的最大者，等入度归零后再出队。

这不是“遇到一个候选，就马上确定 v”：本例点 4 的候选要分两次到达。

| 当前出队点 | 传给 4 的候选 | f[4] | 4 的剩余入度 | 是否就绪 |
| --- | --- | --- | --- | --- |
| 2 | f[2]+4=3+4=7 | 从不可达变成 7 | 1 | 还要等点 3 |
| 3 | f[3]−1=5−1=4 | 保持 7 | 0 | 入队，最大值已确定 |

回到动图选择“接上最长路 DP”，逐步对照这两行。**即使新候选没有改善 f[4]，也仍要把入度减 1**，因为这份依赖已经处理完了。

一般有环图中最长简单路径不能这样一次求解，正权环还可能使允许重复走的总权无限增加。DAG 没有回路，所有候选都会沿拓扑顺序结束，不需要反复松弛。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

struct Edge { int to, weight; };

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<Edge>> g(n + 1);
    vector<int> indegree(n + 1);
    for (int i = 0, u, v, w; i < m; i++) {
        cin >> u >> v >> w;
        g[u].push_back({v, w}); indegree[v]++;
    }
    const long long NEG = -(1LL << 62);
    vector<long long> f(n + 1, NEG);
    f[1] = 0;
    queue<int> q;
    for (int u = 1; u <= n; u++) {
        if (indegree[u] == 0) q.push(u);
    }
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (const Edge &e : g[u]) {
            if (f[u] != NEG) {
                f[e.to] = max(f[e.to], f[u] + e.weight);
            }
            indegree[e.to]--;
            if (indegree[e.to] == 0) q.push(e.to);
        }
    }
    cout << (f[n] == NEG ? -1 : f[n]) << '\n';
    return 0;
}
```

## 为什么不可达点也要处理

“从 1 能不能到达”和“前驱是否全部处理”是两件事。看动图中的五点例子：1→3、2→3、3→5、2→4、4→5。

最初 1、2 入度都为 0，都应入队。处理 1 后，3 得到一个可达候选，但它还在等点 2。虽然 2 从 1 不可达，仍必须出队并删除 2→3 这条依赖，3 才能入队；2 只是不能向 3、4 传播有效的最长路候选。

动图给 1→3 权重 2、3→5 权重 4，所以最终 1→5 最长路为 6；点 2、4 的 f 始终不可达，但它们的拓扑工作仍然正常完成。

> **可达判断只管 DP 更新，不包住入度更新**
>
> `if (f[u] != NEG)` 只保护候选的计算。`indegree[e.to]--` 放在判断外，所有边都要释放依赖。只把起点 1 入队，或直接跳过不可达点的全部出边，都会让后面的点继续等待已经不该等待的前驱。

不可达的 f 不能初始为 0，否则一条负权路线可能错误地被“凭空从中间开始”的方案超过。时间与空间 O(n+m)。

## 同样顺序，不同合并目标

路径计数把 max 改成来源方案数相加，起点 ways[1]=1；最早完成时间则在所有依赖完成后才能启动，取前驱完成时间的 max 再加当前任务耗时。目标不同，状态初值和合并运算也不同。

若原图有环，缩成 SCC 后得到 DAG，但分量内部的信息能否直接合并仍要依据题意证明。不能因为缩图无环，就把所有原图路径任务都简化成分量权值相加。
