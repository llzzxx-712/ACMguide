## 这一节学什么

序列、区间、树都提供了天然依赖顺序。一般有向无环图由拓扑排序给出这个顺序：处理一个点之前，它的所有前驱已经处理，便可以合并传来的候选。

> **AI 伴学提示词**
>
> 为我讲解 DAG 上的动态规划，用最长路对照拓扑排序、不可达与边松弛，再比较路径计数和任务完成时间，并引导我提问。

## 例题精讲：P1807 · 最长路

**原题：** [P1807 · 最长路](https://www.luogu.com.cn/problem/P1807)。

**题意简述：** 给带权 DAG，求 1 到 n 的最长路线，不可达输出 −1。n≤1500、m≤50000，边权可负。

输入：

```text
4 4
1 2 3
1 3 5
2 4 4
3 4 -1
```

输出 `7`，路线 1→2→4 优于 1→3→4 的 4。

## 最长路的可行性来自无环结构

f[u] 表示从 1 到 u 的最大路径权。初始 f[1]=0，其余不可达。对边 u→v，若 u 可达，尝试 f[v]=max(f[v],f[u]+w)。

一般有环图中最长简单路径不能这样一次求解，正权环还可能使允许重复走的总权无限增加。DAG 没有回路，所有候选都会沿拓扑顺序结束，不需要反复松弛。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

struct Edge { int to, weight; };

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<Edge>> g(n + 1);
    vector<int> indegree(n + 1);
    for (int i = 0, u, v, w; i < m; i++) {
        cin >> u >> v >> w;
        g[u].push_back({v, w}); indegree[v]++;
    }
    const long long NEG = -(1LL << 62);
    vector<long long> f(n + 1, NEG);
    f[1] = 0;
    queue<int> q;
    for (int u = 1; u <= n; u++) if (!indegree[u]) q.push(u);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (const Edge &e : g[u]) {
            if (f[u] != NEG) f[e.to] = max(f[e.to], f[u] + e.weight);
            if (--indegree[e.to] == 0) q.push(e.to);
        }
    }
    cout << (f[n] == NEG ? -1 : f[n]) << '\n';
    return 0;
}
```

所有入度为 0 的点都要参与拓扑过程，即使它从 1 不可达。只把 1 入队，可能让其他不可达前驱的入度永远不被删除，阻塞后面的可达点。

不可达的 f 不能初始为 0，否则一条负权路线可能错误地被“凭空从中间开始”的方案超过。时间与空间 O(n+m)。

## 同样顺序，不同合并目标

路径计数把 max 改成来源方案数相加，起点 ways[1]=1；最早完成时间则在所有依赖完成后才能启动，取前驱完成时间的 max 再加当前任务耗时。目标不同，状态初值和合并运算也不同。

若原图有环，缩成 SCC 后得到 DAG，但分量内部的信息能否直接合并仍要依据题意证明。不能因为缩图无环，就把所有原图路径任务都简化成分量权值相加。

## 练习：在每个点旁写出已到齐的前驱贡献

先**独立重做 P1807**，用小 DAG 枚举所有 1→n 路线，核对最大权，覆盖负边与不可达。

### 推荐必做

1. **自编 · DAG 路线数：** 统计固定起点到终点的路线数，对 10⁹+7 取模；平行边是否代表不同路线按给定模型处理。
2. **自编 · 工程完成时间：** 每个任务有耗时且必须等全部前置任务结束，求全部任务完成的最早时刻。

### 选做巩固

- **自编 · 最长路计数：** 同时保存最大值与达到它的方案数，更优时替换、相等时累加。
- **自编 · 恢复关键路线：** 更新最大值时保存前驱，输出一条最晚完成的依赖链。

对应题单：[自编入门题单](https://www.luogu.com.cn/training/1126196)、[树与图上的动态规划 #214](https://www.luogu.com.cn/training/214)。
