## 这一节学什么

上一节固定父点状态后，孩子答案可以直接相加。若整个子树只能选固定数量，就必须在不同孩子之间分配名额，这个合并过程就是树形背包。

>
> 为我讲解树形背包，用选课追踪每个孩子分到的名额，解释虚拟根和必须先选父亲的状态，并引导我提问。

## 例题精讲：P2014 · 选课

**原题：** [P2014 · 选课](https://www.luogu.com.cn/problem/P2014)。

**题意简述：** n 门课程，每门至多一个直接先修课，选择课程就必须选择全部先修课程。恰好选 m 门，最大化学分。n,m≤300，安排无环，学分为正。

输入：

```text
3 2
0 5
1 7
0 6
```

输出 `12`，选择 1、2。不能只选 2、3，虽然学分更高，但缺少课程 1。

## 用 0 号虚拟根连接所有起点

没有先修课的课程都接到 0，0 的学分为 0。把它也算作已选择的一门，最终求根子树里恰好 m+1 门的答案。这样原来多棵先修树就有了统一入口。

f[u][j] 表示从 u 子树选 j 门、且 j>0 时必须包含 u 的最大分数；f[u][0]=0 表示整棵子树不选。进入孩子合并前，只有 f[u][1]=score[u] 可达。

合并孩子 v 时，旧子树选 i 门，v 子树选 j 门，得到 i+j 门。只有 i≥1 时才允许接孩子，保证没有跳过先修父亲；j=0 表示这个孩子整棵不选。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> children(n + 1);
    vector<int> score(n + 1);
    for (int u = 1, p; u <= n; u++) { cin >> p >> score[u]; children[p].push_back(u); }
    vector<int> order(1, 0);
    for (int i = 0; i <= n; i++) for (int v : children[order[i]]) order.push_back(v);
    int need = m + 1;
    const int NEG = -1000000000;
    vector<vector<int>> f(n + 1, vector<int>(need + 1, NEG));
    vector<int> size(n + 1, 1);
    for (int at = n; at >= 0; at--) {
        int u = order[at];
        f[u][0] = 0;
        f[u][1] = score[u];
        for (int v : children[u]) {
            vector<int> next(need + 1, NEG);
            next[0] = 0;
            for (int i = 1; i <= min(size[u], need); i++) if (f[u][i] != NEG) {
                for (int j = 0; j <= min(size[v], need - i); j++) if (f[v][j] != NEG) {
                    next[i+j] = max(next[i+j], f[u][i] + f[v][j]);
                }
            }
            f[u] = next;
            size[u] = min(need, size[u] + size[v]);
        }
    }
    cout << f[0][need] << '\n';
    return 0;
}
```

next 单独保存合并结果，防止同一个孩子被重复使用。size 限制实际能选的数量，减少空状态扫描。这个直接实现可按 O(nm²) 估算上界，空间 O(nm)。

“恰好”意味着除 0 门、1 门初始状态外都应不可达，不能全设 0，否则不存在的选课数量也会参与转移。

## 选择边时，名额含义会变化

若题目要求从根出发保留若干条边，接入孩子子树还要花一条父子边，合并数量变成 i+j+1。先决定 j 数的是点、边还是费用，再写下标，不能凭模板默认相加。

## 练习：逐个孩子合并一张小表

先**独立重做 P2014**，画一棵分叉先修树，写出每次合并后的可达选课数量，再用子集枚举核对。

### 推荐必做

1. **自编 · 课程有不同费用：** 将“课程数量”换成预算，选择孩子前仍必须包含父亲，合并费用范围≤2000。
2. **自编 · 根连通的选边：** 选择恰好 k 条边，所有选边连成包含根的子树，最大化边权和，解释接入边的额外 1 个名额。

### 选做巩固

- **自编 · 恢复课程名单：** 保存孩子分配到的 j，逆向恢复每棵子树的选择数量。
- **自编 · 允许负学分：** 仍要求恰好 m 门，检查不能因为某些收益负就把状态错误初始化为 0。

对应题单：[自编入门题单](https://www.luogu.com.cn/training/1126196)、[树与图上的动态规划 #214](https://www.luogu.com.cn/training/214)。

## 本节验收

能说明虚拟根与 m+1 的关系；能保留先修依赖；能正确合并数量、处理不可达，并区分选点与选边的名额。
