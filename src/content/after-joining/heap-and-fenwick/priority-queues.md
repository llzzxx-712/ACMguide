## 这一节学什么

数据不断加入，又要反复取走当前最小值或最大值，没必要每次完整排序。堆只维护足以保证堆顶最优的局部关系，priority_queue 则把这些维护操作封装好供我们直接使用。

> **AI 伴学提示词**
>
> 为我讲解二叉堆与 priority_queue，画出数组对应的父子位置，模拟插入上浮和删除下沉，再对照最小堆代码，引导我提问。

## 堆不是把整个数组排好序

小根堆中，每个父亲的值都不大于自己的孩子，因此根一定是整棵树的最小值。大根堆方向相反，根是最大值。

```text
          1
        /   \
       4     2
      / \   /
     7   6 5
```

上面是合法小根堆。4 比旁边的 2 大，并不妨碍它成立：只要求父子之间满足大小关系，兄弟和不同分支不必整体有序。

形状上，从上到下、从左到右依次填满位置。用从 1 开始的数组保存时：

| 结点下标 i | 父亲 | 左孩子 | 右孩子 |
| --- | --- | --- | --- |
| i | i/2（根除外） | 2i | 2i+1 |

所以上图对应数组 {1,4,2,7,6,5}。不需要额外保存孩子指针，数组下标本身描述了结构。

## 插入上浮：只修复新元素到根的一条路

插入 0，先放到最后一个空位置。若它比父亲小，就与父亲交换，再继续向上比较：

```text
末尾加入 0：{1,4,2,7,6,5,0}
与父亲 2 换：{1,4,0,7,6,5,2}
与父亲 1 换：{0,4,1,7,6,5,2}
```

其他分支没有改变，只有新元素经过的路径需要修复。树高为 O(log n)，因此插入最多交换 O(log n) 次。

## 删除下沉：用末尾补根，再向下修复

取走堆顶 0 后，把最后的 2 搬到根，删掉末尾位置以保持形状。若根比孩子大，就与**两个孩子中更小的那个**交换，继续向下。

```text
末尾补根：{2,4,1,7,6,5}
与较小孩子 1 换：{1,4,2,7,6,5}
```

不能随便与一个孩子交换，否则可能仍比另一个孩子大。读取堆顶不需要移动，O(1)；插入与删除沿一条路径移动，O(log n)。

## priority_queue 的常用写法

```text
priority_queue<int> big; // 默认大根堆
priority_queue<int, vector<int>, greater<int>> small; // 小根堆

small.push(5);
small.push(2);
cout << small.top(); // 读取最小值 2，不删除
small.pop();         // 删除一个最小值，不返回它
int count = small.size();
bool noElements = small.empty();
```

三个类型参数依次表示元素类型、底层存储容器、比较规则。vector<int> 用来存元素，greater<int> 使较小元素位于堆顶。大根堆常用默认写法即可。

> **top 与 pop 都要求堆非空。**
>
> 需要“取出并使用”时，先用 top 保存值，再 pop。重复值会保留，pop 只删除其中一份。priority_queue 的名字中虽然有 queue，但它按优先级取元素，并不按普通队列的先来后到。

set 可以任意按值查找、删除并维护整体有序关系；堆适合不断插入和取堆顶，不直接提供按排名访问或按任意值删除。选择工具时看题目实际需要哪些操作。

## 例题精讲：P3378 · 堆

**原题：** [P3378 · 堆](https://www.luogu.com.cn/problem/P3378)。

**题意简述：** 初始为空，操作 1 x 插入 x，操作 2 输出最小值，操作 3 删除一个最小值。操作数≤10^6，按有效的取值、删除操作处理。

自拟输入：

```text
8
1 4
1 2
1 2
2
3
2
3
2
```

输出：

```text
2
2
4
```

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    priority_queue<int, vector<int>, greater<int>> heap;
    while (n--) {
        int op;
        cin >> op;
        if (op == 1) {
            int x;
            cin >> x;
            heap.push(x);
        } else if (op == 2) {
            cout << heap.top() << '\n';
        } else {
            heap.pop();
        }
    }
    return 0;
}
```

三种输入操作直接对应 push、top、pop。设操作总数为 m，最多保存 m 个数，总时间 O(m log(m+1))，空间 O(m)。百万级输入在开头关闭流同步。

## 练习：分清“读最值”和“删最值”

先**独立重做 P3378**，检查重复值、多次读取但不删除，以及删完一批后继续插入。

### 推荐必做

1. **自编 · 动态最大值：** 沿用例题操作格式，把操作 2、3 改成读取和删除最大值，使用默认 priority_queue<int>。比较底层维护规则与小根堆有什么不同。
2. **自编 · 按顺序取走：** 输入 n≤10^5 个整数，全部放入小根堆，再连续取出并输出。核对结果是否与 sort 一致，并解释它们在“动态加入数据”时的使用区别。

### 选做巩固

- **自编 · 保留最大的 k 个数：** 输入 n≤10^5、1≤k≤n 与数据流，始终只保留当前最大的 k 个元素。用大小至多 k 的小根堆，加入新数后超过 k 就删最小值，最后输出第 k 大值。
- **自编 · 手写小根堆：** 用 vector 从 1 开始保存位置，实现上浮、下沉，再用与例题相同的操作对照标准库结果。每次交换后检查父亲不大于孩子。
