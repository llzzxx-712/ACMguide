## 这一节学什么

模运算可以直接做加、减、乘，但不能直接把整数除法搬过来。例如 6/2=3，先模 5 再做整数除法却得到 1/2=0。逆元让“除以 a”变成“乘以一个能抵消 a 的数”。

## 什么时候能抵消一个数

如果 ax≡1 (mod m)，就称 x 为 a 的逆元。因为 ab·x≡b，乘上 x 等于撤销乘 a。上一节已经证明，这样的 x 存在当且仅当 gcd(a,m)=1。

模 7 下，3×5≡1，所以除以 3 可以乘 5。模 6 下，2 的倍数永远不会余 1，所以 2 没有逆元；不能只因为写出了分数就默认它可计算。

三种常用方式：

| 情况 | 计算方法 | 条件 |
| --- | --- | --- |
| 单个逆元，模数一般 | 扩展欧几里得解 ax+my=1 | gcd(a,m)=1 |
| 单个逆元，模数为质数 p | 快速幂 a^(p−2) mod p | a 不被 p 整除 |
| 求 1 到 n 的所有逆元 | 线性递推 | p 为质数，n<p |

第二种来自费马小定理 a^(p−1)≡1。它的指数不能随意用于合数模数。

## 线性公式怎样得到

令 p=q·i+r。模 p 下 q·i+r≡0，两边乘 i 和 r 的逆元，得到 inv[i]≡−q·inv[r]。当 1<i<p 且 p 为质数时，0<r<i，所需的 inv[r] 已算好。

以 p=7、i=3 为例，q=2、r=1，inv[3]≡−2×1≡5。代码把负号写成 p−q，再取模。

## 例题精讲：[P3811 模意义下的乘法逆元](https://www.luogu.com.cn/problem/P3811)

**题意简述：** 输入 n、质数 p，求 1…n 在模 p 下的逆元，每行一个。原题 n≤3×10⁶，n<p<20000528。

输入：

```text
3 7
```

输出：

```text
1
4
5
```

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, p;
    cin >> n >> p;
    vector<int> inv(n + 1);
    inv[1] = 1;
    for (int i = 2; i <= n; i++) {
        inv[i] = 1LL * (p - p / i) * inv[p % i] % p;
    }
    for (int i = 1; i <= n; i++) cout << inv[i] << '\n';
    return 0;
}
```

每项只依赖更小的下标，复杂度 O(n)，空间 O(n)。乘积可能超出 int，`1LL` 让乘法先按 long long 进行；只在最后赋值时缩回已取模的范围。大量输出用 `\n`，避免 `endl` 逐行刷新。

## 练习：先验证“乘回去等于 1”

先**独立重做例题**，把每个 i×inv[i] 对 p 取模，与 1 比较。

### 推荐必做

1. **自编 · 三种算法对照：** 对质数 101，分别用穷举、扩展欧几里得、快速幂求 1…100 的逆元，逐项核对。
2. **自编 · 模除法查询：** 给定质数 p 和若干 a/b，保证 b 不被 p 整除，输出 a·inv[b] mod p；注意先规范化负数 a。

### 选做巩固

- **自编 · 合数模数：** 对 m=12 的每个非零余数判断是否有逆元，观察它与互质的关系。
- **自编 · 阶乘逆元：** 先算 n! 的逆元，再从后向前推出全部阶乘逆元，为第二十二章组合数做准备。
