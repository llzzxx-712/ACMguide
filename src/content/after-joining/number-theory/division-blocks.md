## 这一节学什么

有些求和式写着 n 项，真正不同的值却只有约 √n 种。整除分块利用 floor(n/i) 在连续区间里保持不变，把逐项加法换成整段贡献。

> **AI 伴学提示词**
>
> 为我列出 floor(n/i) 的变化，推导相同商的右端点，再说明整除分块怎样与前缀和配合，并引导我提问。

## 商不变的一段有多长

固定左端点 l，令 q=floor(n/l)。当 floor(n/i)=q 时，有 i≤floor(n/q)。所以这一段最远到 r=floor(n/q)，下一个尚未处理的位置直接是 r+1。

n=10 时：

| 下标区间 | 商 | 这段贡献 |
| --- | --- | --- |
| [1,1] | 10 | 10 |
| [2,2] | 5 | 5 |
| [3,3] | 3 | 3 |
| [4,5] | 2 | 4 |
| [6,10] | 1 | 5 |

这里只计算五段，合计 27。代码里的 l、r、q 正是表格中的三列，不需要逐个访问 6、7、8、9、10。

## 例题精讲：自编 · 全部整除商之和

**题意简述：** 输入 1≤n≤10¹²，求 Σ(i=1…n) floor(n/i)。例如 n=5 时各项为 5、2、1、1、1，输出 `10`。

这个和也等于 1…n 每个数的约数个数之和：交换“枚举数再找约数”和“枚举约数再统计它的倍数”的顺序，就能看到二者相同。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    long long n;
    cin >> n;
    long long answer = 0;
    for (long long l = 1, r; l <= n; l = r + 1) {
        long long quotient = n / l;
        r = n / quotient;
        answer += quotient * (r - l + 1);
    }
    cout << answer << '\n';
    return 0;
}
```

前 √n 个下标最多产生 √n 段；后面的商小于约 √n，最多再有 √n 种。因此时间 O(√n)，空间 O(1)。n=10¹² 时约两百万段。答案不超过 n(1+ln n)，约 2.9×10¹³，long long 足够。

## 与前缀和组合

如果求 Σw[i]·floor(n/i)，同一段的商仍然不变。提前计算权值前缀和 S，就能把贡献写成 q·(S[r]−S[l−1])。下一步不再是死记新公式，而是问：我能否快速求这一段的权值总和？

若同时出现 floor(n/i) 与 floor(m/i)，这两个商必须都不变，右端点取 min(n/(n/l),m/(m/l))，循环到 min(n,m) 即可，超出后乘积为 0。结合上一节的 φ 前缀和，还能处理带互质计数的分块式子。

## 练习：先画出分段

先**独立重做例题**，打印 n=20 每段的 l、r、q，确认没有漏项或重叠，再与逐项求和比较。

### 推荐必做

1. **自编 · 两个商的乘积：** 求 Σ floor(n/i)·floor(m/i)，n,m≤10⁸；练习取两个右端点的较小者，答案用 long long。
2. **自编 · 加权求和：** 给出 n≤10⁶ 的权值数组，求 Σw[i]·floor(n/i)；练习用前缀和替代段内枚举。

### 选做巩固

- **自编 · φ 加权：** 预处理 φ 前缀和，计算 Σφ(i)·floor(n/i)，用小数据逐项核对。
- **自编 · 约数个数总和：** 分别用约数筛、逐项整除、整除分块实现同一目标，比较三种复杂度。
