## 这一节学什么

欧拉函数 φ(n) 表示 1…n 中与 n 互质的整数个数，例如 φ(6)=2，因为只有 1、5 符合要求。我们会把逐个求 gcd 的计数，变成一次线性筛中的递推。

> **AI 伴学提示词**
>
> 为我讲解线性筛为什么每个合数只处理一次，再推导欧拉函数的两种转移，说明欧拉定理的互质条件并引导我提问。

## 先理解 φ 的公式

若 n 的不同质因子是 p₁、p₂……，与 n 不互质的数恰好是这些质因子的倍数。排除它们得到 φ(n)=n·∏(1−1/p)。例如 12 的质因子是 2、3，所以 φ(12)=12×1/2×2/3=4，对应 1、5、7、11。特别规定 φ(1)=1。

## 线性筛为什么要 break

按 i 从小到大，维护已经找到的质数 p。用 i×p 标记合数，只允许 p 不大于 i 的最小质因子；当 i%p==0 时，处理完就停止。

例如 12 会由 6×2 处理。到 4 时先处理 4×2 就停止，不再由 4×3 重复处理 12。每个合数恰好由“除去一个最小质因子的剩余部分”与这个最小质因子生成一次。

顺便计算 φ：

- p 整除 i：质因子种类不变，φ(ip)=φ(i)·p。
- p 不整除 i：新添一个质因子 p，φ(ip)=φ(i)·(p−1)。

素数本身 φ(p)=p−1。这三个判断就是公式在代码中的实现。

## 例题精讲：[P2158 仪仗队](https://www.luogu.com.cn/problem/P2158)

**题意简述：** 从 N×N 方阵的左后角观察学生，同一射线只看见最近的一人，求看见的人数。输入 N，1≤N≤40000；输出整数。把观察点设为 (0,0)，考察 0…N−1 的整点，原点不计。

自编输入：

```text
3
```

输出：

```text
5
```

### 先把思路讲清楚

若 x、y 都为正，gcd(x,y)>1 时，(x/g,y/g) 位于同一射线且更近，会挡住 (x,y)；互质时中间没有别的整点。两条坐标轴各只有最近一点可见。

按较大坐标 i 分类，在 1≤j<i 的三角形里有 φ(i) 个与 i 互质的 j，对称后乘 2；还要单独计入 (1,1) 和两条轴。于是 N>1 时答案为 2·Σ(i=1…N−1)φ(i)+1，N=1 时为 0。

N=3 时能看见 (1,0)、(0,1)、(1,1)、(1,2)、(2,1)，共 5 人。先用上面线性筛求 φ，再累计贡献，这使筛出的数字真正回答了一道几何计数题。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n == 1) {
        cout << 0 << '\n';
        return 0;
    }
    vector<int> primes, phi(n);
    vector<bool> composite(n, false);
    phi[1] = 1;
    for (int i = 2; i < n; i++) {
        if (!composite[i]) {
            primes.push_back(i);
            phi[i] = i - 1;
        }
        for (int p : primes) {
            if (p > (n - 1) / i) break;
            composite[i * p] = true;
            if (i % p == 0) {
                phi[i * p] = phi[i] * p;
                break;
            }
            phi[i * p] = phi[i] * (p - 1);
        }
    }
    long long answer = 1;
    for (int i = 1; i < n; i++) answer += 2LL * phi[i];
    cout << answer << '\n';
    return 0;
}
```

时间 O(N)，空间 O(N)。乘法前用 p>(N−1)/i 检查上界；累计答案用 long long。

## 欧拉定理怎样用于幂

当 gcd(a,m)=1 时，a^φ(m)≡1 (mod m)。直觉是：把所有与 m 互质的余数乘 a 后取模，会得到同一组余数的重新排列；比较两边乘积并约去它们就得到结论。因此互质时指数可以对 φ(m) 取模。

不互质时不能直接这样做。例如 a=2、m=4，φ(4)=2，2² mod 4=0，而把指数 2 改为 0 得到 1。这也说明约去乘积需要逆元存在。
