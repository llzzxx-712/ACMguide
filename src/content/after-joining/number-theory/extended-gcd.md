## 这一节学什么

最大公约数只能告诉我们两个数共同包含多大的单位；扩展欧几里得还会找出“怎样把它们凑成这个单位”。这让我们能解 ax+by=c，也能把模方程转成整数方程。

## 从 30 和 18 开始倒推

欧几里得算法依次得到 30=1×18+12、18=1×12+6。倒过来代入：

```text
6 = 18 - 12
  = 18 - (30 - 18)
  = -1 × 30 + 2 × 18
```

于是 30x+18y=6 有解 x=−1、y=2。右边换成 12，两边乘 2 即可；换成 7 就不可能，因为左边一定是 6 的倍数。

裴蜀定理说明：设 g=gcd(a,b)，ax+by=c 有整数解当且仅当 g 整除 c。若 x₀、y₀ 是一组解，全部解为 x=x₀+t·b/g、y=y₀−t·a/g，其中 t 为任意整数。请代回原式，观察新增的两项怎样抵消。

## 递归代码对应哪一步

递归先求 b·u+(a%b)·v=g，再用 a%b=a−(a/b)·b 展开，得到 a·v+b·(u−(a/b)·v)=g。因此本层的 x=v、y=u−(a/b)·v。到 b=0 时，a×1+0×0=a 就是起点。

## 例题精讲：自编 · 找一组整数配比

**题意简述：** 输入正整数 a、b≤10⁹，以及 |c|≤10⁹。求 ax+by=c 的一组整数解；无解输出 `NO`。为方便核对，有解时要求 0≤x<b/g，y 可以为负数。

输入 `30 18 12`，输出 `1 -1`，因为 30−18=12。扩展欧几里得先给出 x=−2、y=4；把 x 对 b/g=3 取非负余数得到 1，再从原方程计算 y。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    long long u, v;
    long long g = exgcd(b, a % b, u, v);
    x = v;
    y = u - a / b * v;
    return g;
}

int main() {
    long long a, b, c, x, y;
    cin >> a >> b >> c;
    long long g = exgcd(a, b, x, y);
    if (c % g != 0) { cout << "NO\n"; return 0; }
    long long mod = b / g;
    x = x * (c / g) % mod;
    x = (x + mod) % mod;
    y = (c - a * x) / b;
    cout << x << ' ' << y << '\n';
    return 0;
}
```

`(x+mod)%mod` 把 C++ 中可能为负的余数移到要求的区间。模数为 1 时 x=0，仍然有效。本例乘积绝对值在约 10¹⁸ 以内，使用 long long；复杂度 O(log min(a,b))，递归深度同阶。

## 线性同余方程其实是同一个问题

ax≡c (mod m) 意味着 ax−c 是 m 的倍数，也就是 ax+my=c 对某个整数 y 成立。因此 gcd(a,m)|c 时才有解；x 的不同解按 m/g 为周期。逆元就是 c=1 的特殊情况，下一节继续使用这个结论。
