## 这一节学什么

做一个项目，常常要先完成准备工作，才能开始后续任务。我们把“必须先做”的关系画成有向边，用入度记录还剩多少项前置条件，通过拓扑排序找出符合依赖关系的执行顺序。

> **AI 伴学提示词**
>
> 为我讲解拓扑排序，用四项有先后关系的任务模拟入度、队列和最早完成时间，解释每行代码在实现哪一步思路，并引导我对不理解的地方提问。

## 先做谁：看剩余前置条件是不是零

有四项任务，耗时分别为 3、2、4、2。任务 2、3 都依赖 1；任务 4 依赖 2 和 3。

```text
         2（2）
        ↗     ↘
  1（3）       4（2）
        ↘     ↗
         3（4）
```

边从**前置任务指向后续任务**。g[1]={2,3}，g[2]={4}，g[3]={4}。初始入度分别为 0、1、1、2。

1. 1 的入度是 0，可以先处理。
2. 处理 1 后，删除它对 2、3 的限制，让二者入度各减 1。它们都变成 0，进入等待处理的队列。
3. 处理 2 后，4 的入度从 2 变成 1；还缺任务 3，不能开始。
4. 处理 3 后，4 的入度变成 0，才轮到 4。

实际代码无需删除边，只修改 indegree[v]。因此程序中的入度表示的是**还没有被处理掉的前置条件数**。

按这种方法得到 1、2、3、4，也可能得到 1、3、2、4。两种顺序都满足每条边 u→v 中 u 在 v 前面，这样的顺序叫**拓扑序**。能拓扑排序的图是 DAG，即有向无环图。

## 如果出现环，会发生什么

假如 1 依赖 2，2 又依赖 1，谁都不能先开始。队列最终会空，但没有处理完所有点。因此记录处理点数 count，若 count<n，就说明存在环。若把“存在拓扑序”当成题目的要求，这一步就能判断是否可行。

## 例题精讲：P1113 · 杂务

**原题：** [P1113 · 杂务](https://www.luogu.com.cn/problem/P1113)。

**题意简述：** n 项工作，每项给出编号、耗时和以 0 结尾的前置工作列表。工人充足，互不依赖的工作可以同时进行，求全部完成的最短时间。n≤10000，每项至多 100 个前置任务，题目保证前置任务编号更小。

自拟输入与输出：

```text
4
1 3 0
2 2 1 0
3 4 1 0
4 2 2 3 0
```

```text
9
```

### 不把任务串着做，而是等待最慢的前置任务

任务 1 在时刻 3 完成，任务 2、3 随后同时开始，分别在时刻 5、7 完成。任务 4 要等两者都完成，从时刻 7 开始，时刻 9 结束。

令 finish[v] 表示任务 v 最早完成时间。每个前置任务 u 都提出一个要求：“你至少要在我完成后，再花 duration[v] 时间”。因此：

```text
finish[v] = max(finish[v], finish[u] + duration[v]);
```

拓扑排序确保 v 出队时，它的所有前置任务已经提供过要求，最大值就是完整答案。没有前置任务的点从时刻 0 开始，finish 等于自身耗时。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 10000 + 5;
vector<int> g[N];
int indegree[N], duration[N];
long long finish[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        int id, pre;
        cin >> id;
        cin >> duration[id];
        while (cin >> pre && pre != 0) {
            g[pre].push_back(id);
            indegree[id]++;
        }
    }
    queue<int> q;
    for (int u = 1; u <= n; u++) {
        if (indegree[u] == 0) {
            q.push(u);
            finish[u] = duration[u];
        }
    }
    long long answer = 0;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        answer = max(answer, finish[u]);
        for (int v : g[u]) {
            finish[v] = max(finish[v], finish[u] + duration[v]);
            indegree[v]--;
            if (indegree[v] == 0) q.push(v);
        }
    }
    cout << answer << '\n';
    return 0;
}
```

题目的编号本身也符合依赖顺序；这里用队列把“所有前置条件完成，任务才能准备好”的过程直接实现出来。以后即使编号被打乱，仍能使用同样的处理方法。

每点入队一次，每条边处理一次，时间 O(n+m)，空间 O(n+m)，其中 m 是前置关系总数。finish 用 long long 保存累计耗时。

## 练习：先理解依赖，再决定转移什么

先**独立重做 P1113**，手算两条前置链耗时不同时，下游任务为什么取 max 而不是求和。

### 推荐必做

1. **自编 · 合法学习顺序：** 输入 n、m≤10^5 和 m 条先修关系 u→v，输出任意一个拓扑序；不存在时输出 `Impossible`。增加 count，检查是否处理完 n 个点。
2. **自编 · 最早开课学期：** 沿用上题输入，每门课用一个学期，先修课必须在更早学期完成。无环时输出每门课最早能在哪个学期修读，有环输出 `Impossible`。源点从第 1 学期开始，下游取前驱学期加 1 的最大值。

### 选做巩固

- **自编 · 拓扑序是否唯一：** 沿用上述输入，在无环时判断合法顺序是否唯一。每一步可选的零入度点若多于一个，会不会出现两种顺序？
- **自编 · 核对一份顺序：** 输入图后再给出 1 到 n 的一个排列，判断是否为拓扑序。记录每个点的位置，检查所有边的起点是否在终点之前，练习从定义反推代码。

## 本节验收

能解释入度减一表示去掉哪项限制；能用处理点数判断环；能把“取前置完成时间的最大值”与 finish 转移联系起来。
