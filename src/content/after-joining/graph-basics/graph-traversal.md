## 这一节学什么

搜索仍然是在枚举：来到 $u$，就从 `g[u]` 中枚举下一步 $v$。DFS 沿一条路线深入，BFS 先处理距离起点近的一层。图可能有环，也可能多条路线到达同一个点，因此要增加访问标记，保证每个点只处理一次。

## 从树走向图：为什么要记住“已经看过”

有边 $1\to 2$、$2\to 3$、$3\to 1$。若每次看到邻居就继续走，会在三点间绕圈。让 `vis[u]` 表示“$u$ 是否已经访问”，访问过就不再展开它。

还有另一种重复：$1\to 2$、$1\to 3$、$2\to 3$，3 可以从两条路线到达。**题目要看完所有能到达的点，每个点处理一次就够了；不是枚举所有路线。**先明确要枚举的是点还是路径，再设计访问标记。

## 例题精讲：P5318 · 查找文献

**原题：** [P5318 · 查找文献](https://www.luogu.com.cn/problem/P5318)。

**题意简述：** $n$ 篇文献、$m$ 条有向引用关系 $u\to v$，从文献 1 出发，分别输出 DFS 和 BFS 的访问顺序。遇到多个选择时先访问编号小的文献。$n\le 10^5$、$m\le 10^6$。

自拟输入：

```text
6 5
1 2
1 3
2 4
2 3
3 5
```

输出：

```text
1 2 3 5 4
1 2 3 4 5
```

6 无法从 1 到达，不输出它。先给每份名单排序，得到 $g[1]=\{2,3\}$、$g[2]=\{3,4\}$、$g[3]=\{5\}$，其余为空。

### DFS：栈保存尚待尝试的选择

递归 DFS 的思路是访问 $u$，然后按名单顺序逐个递归访问未访问的邻居。本题路径可以很长，我们用显式栈保存待处理的点，避免产生十万层函数调用。

栈后进先出，想先处理小编号，就把邻居**从大到小压栈**。下面栈的右端是栈顶：

| 动作 | 栈中待处理点 | 新访问的点 |
| --- | --- | --- |
| 压入起点 | 1 | — |
| 弹出 1，倒序压入 `3、2` | `3 2` | 1 |
| 弹出 2，倒序压入 `4、3` | `3 4 3` | 2 |
| 弹出 3，压入 5 | `3 4 5` | 3 |
| 弹出 5 | `3 4` | 5 |
| 弹出 4 | 3 | 4 |
| 弹出 3，已经访问，跳过 | 空 | — |

注意栈里会暂时有重复的 3。本写法在**弹出并正式访问时**标记。若 1 一压入 3 就把它标记，2 再想深入 3 时就会被挡住，访问顺序会改变。栈中的候选和已经访问的点，要区分开。

### BFS：队列保存等待扩展的点

先让 1 入队。处理 1 时，依次将 `2、3` 入队；处理 2 时，将 4 入队，3 已经排在队伍里；处理 3 时，将 5 入队。因此顺序为 `1 2 3 4 5`。

BFS 在**入队时就标记**，表示已经安排过访问，防止同一个点被多个前驱重复放入队列。它保证先访问一条边能到的点，再访问两条边能到的点；这里的距离是边数。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 100000 + 5;
vector<int> g[N];
bool vis[N];

void dfs(int start) {
    stack<int> st;
    st.push(start);
    while (!st.empty()) {
        int u = st.top();
        st.pop();
        if (vis[u]) continue;
        vis[u] = true;
        cout << u << ' ';
        int count = g[u].size();
        for (int i = count - 1; i >= 0; i--) {
            int v = g[u][i];
            if (!vis[v]) st.push(v);
        }
    }
}

void bfs(int start) {
    queue<int> q;
    q.push(start);
    vis[start] = true;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        cout << u << ' ';
        for (int v : g[u]) {
            if (!vis[v]) {
                vis[v] = true;
                q.push(v);
            }
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
    }
    for (int u = 1; u <= n; u++) sort(g[u].begin(), g[u].end());
    dfs(1);
    cout << '\n';
    fill(vis, vis + n + 1, false);
    bfs(1);
    cout << '\n';
    return 0;
}
```

倒序循环先把 `size()` 赋给 `int` 类型的 $\mathrm{count}$，再从 $\mathrm{count}-1$ 开始。名单为空时 $i=-1$，循环自然不执行。两次遍历之间清空 $\mathrm{vis}$，相当于给 BFS 一张新的访问记录表。

排序后，遍历时间 $\mathcal{O}(n+m)$，加上各名单排序的时间，整体上界可写 $\mathcal{O}(n+m\log(m+1))$。本写法 DFS 候选栈可能保存 $\mathcal{O}(m)$ 个条目，BFS 队列 $\mathcal{O}(n)$，图本身占 $\mathcal{O}(n+m)$ 空间。

## 连通块：一次遍历没有走完，就换个起点

对于**无向图**，从一个点出发能到达的所有点形成一个连通块。先访问 1 所在的块，再选一个尚未访问的点，启动下一次遍历：

```text
int blocks = 0;
for (int u = 1; u <= n; u++) {
    if (!vis[u]) {
        blocks++;
        bfs(u);
    }
}
```

统计时可以删掉 `bfs` 中的输出。不要在各次 `bfs` 之间清空 $\mathrm{vis}$：已经处理过的整块都要保留标记。孤立点也单独构成一个块。每点只展开一次、每条邻居记录只看一次，总时间仍是 $\mathcal{O}(n+m)$。

有向图里“$u$ 能到 $v$”和“$v$ 能到 $u$”可能不同；从某点访问到的点叫它的可达点，不能直接把上面的外层循环当成强连通块算法。
