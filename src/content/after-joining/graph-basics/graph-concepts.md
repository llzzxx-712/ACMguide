## 先想：每个路口需要记住什么

校园有 5 个路口，双向道路连接 1—2、1—3、2—4、3—4，5 暂时没有道路。

```text
    2
   / \
  1   4       5
   \ /
    3
```

从 1 出发可以直接走到 2、3；从 2 出发可以直接走到 1、4。**如果每个路口都有一份“下一步能去哪里”的名单，程序就记住了这张图。**

| 路口 u | 邻居名单 g[u] | 含义 |
| --- | --- | --- |
| 1 | 2, 3 | 从 1 可以直接走到 2、3 |
| 2 | 1, 4 | 从 2 可以直接走到 1、4 |
| 3 | 1, 4 | 从 3 可以直接走到 1、4 |
| 4 | 2, 3 | 从 4 可以直接走到 2、3 |

## 一组 vector 怎样变成这张图

之前的数组里，一个位置保存一个数。现在让每个位置保存一个可以增长的整数列表：

```text
const int N = 100000 + 5;
vector<int> g[N];
```

`vector<int>` 是一个保存整数的动态数组，`g[N]` 则创建了 **N 份相互独立的动态数组**。g[1] 是 1 的名单，g[2] 是 2 的名单；刚创建时每份都为空。我们用 1 到 n 作为结点编号，g[0] 暂时不用。

读到道路 1—2，就在两个名单中各记一次：

```text
g[1].push_back(2); // 1 的名单末尾添一个 2
g[2].push_back(1); // 2 的名单末尾添一个 1
```

push_back 的意思是“在末尾加入一个元素”。它不会自动修改另一份名单，所以双向道路要写两次。

| 读完哪条边 | g[1] | g[2] | g[3] | g[4] | g[5] |
| --- | --- | --- | --- | --- | --- |
| 尚未读入 | 空 | 空 | 空 | 空 | 空 |
| 1—2 | 2 | 1 | 空 | 空 | 空 |
| 1—3 | 2,3 | 1 | 1 | 空 | 空 |
| 2—4 | 2,3 | 1,4 | 1 | 2 | 空 |
| 3—4 | 2,3 | 1,4 | 1,4 | 2,3 | 空 |

**输入逐条给出关系，代码逐条把关系记进名单。**存完以后，原来的图画可以放在一边，后续算法只需读这些名单。

### 看懂 g[u][i]

对 g[1] = {2,3}，有 g[1][0]=2、g[1][1]=3。

- 第一层的 1 是**结点编号**，找到“路口 1 的名单”。
- 第二层的 0、1 是**名单中的位置**，vector 从 0 开始编号。
- 取出来的 2、3 才是**邻居的结点编号**。

例如 g[2][1]=4，意思是“结点 2 的名单里，第 1 号位置保存邻居 4”。位置 1 和结点 1 是两件事。可以把这行代码念成“到 2 的名单里，取出第二位邻居”。

## 有向、无向，以及边上的数

双向道路是**无向边**；文章 u 引用文章 v，是有方向的 **u→v**。引用关系只写 `g[u].push_back(v)`，不能因为 u 引用了 v，就认为 v 也引用了 u。

若道路还给出长度 7，这个 7 就是**边权**。边权也可以表示时间或费用，下一节会把目标和权值放在同一条记录里。

一个点关联多少条无向边，叫它的**度数**。上面的图中 1 的度为 2，5 的度为 0，5 叫**孤立点**。有向图分为入度和出度：指向它的边数是入度，从它出发的边数是出度。

沿边连续走得到一条路径，例如 1→2→4。绕一圈回到起点形成环，例如 1→2→4→3→1。上一章的树也可以看成图：无向树连通且没有环，因此两个点之间只有一条简单路径；一般的图可能有多条路线，也可能有些点彼此无法到达。

## 例题精讲：自编 · 校园道路的邻居名单

**题意简述：** 输入 n、m，然后输入 m 条双向道路 u、v。结点编号为 1 到 n，1≤n,m≤10^5，不含自环。按结点编号依次输出邻居名单，名单内保持输入的先后次序。每行以 `u:` 开头；没有邻居时输出 `u: -`。

输入：

```text
5 4
1 2
1 3
2 4
3 4
```

输出：

```text
1: 2 3
2: 1 4
3: 1 4
4: 2 3
5: -
```

### 完整代码：把刚才的记录过程写出来

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 100000 + 5;
vector<int> g[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    for (int u = 1; u <= n; u++) {
        printf("%d:", u);
        if (g[u].empty()) printf(" -");
        for (int v : g[u]) printf(" %d", v);
        printf("\n");
    }
    return 0;
}
```

`for (int v : g[u])` 表示依次取出 g[u] 里的每个数，当前取出的邻居编号放进 v。对于 g[1]={2,3}，循环先令 v=2，再令 v=3；空名单一次也不执行。

输入与输出共访问 n 个结点和 2m 条邻居记录，时间 O(n+m)，空间 O(n+m)。这里 cin 负责输入，格式化输出统一用 printf。

## 练习：先画图，再写名单

### 推荐必做

1. **自编 · 单向道路：** 沿用例题的输入规模和输出格式，把每条输入改为 u→v。用含 1→2、2→3 的输入检查：3 的名单应为空。练习方向与插入次数的对应。
2. **自编 · 路口度数：** 沿用无向图输入，每行输出一个结点的度。验证所有度数之和为 2m，感受一条边贡献了两份记录。

### 选做巩固

- **自编 · 手写名单：** 画 6 个点、7 条无向边，保留一个孤立点。手写每份名单，再用程序核对。
- **自编 · 出入度：** 输入有向图，按结点输出“入度 出度”。给出一条自环 u→u，观察两个计数各增加多少。
