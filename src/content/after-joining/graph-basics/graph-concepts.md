## 先认识 vector：长度可以变化的数组

普通数组 `int a[100];` 提前准备了 100 个位置。我们往里面读了多少个数，通常还要自己用 n 记录。如果一开始不知道需要保存多少个数，希望“来一个就往后添一个”，可以使用 vector。

```text
vector<int> a;       // 保存 int 的动态数组，开始没有元素
a.push_back(4);      // 现在是 {4}
a.push_back(1);      // 现在是 {4,1}
a.push_back(4);      // 现在是 {4,1,4}
int n = a.size();    // 现在有 3 个元素
cout << a[0];       // 输出 4，和普通数组一样通过下标取值
a[1] = 7;           // 修改已有位置，现在是 {4,7,4}
```

`vector<int>` 中的 int 表示元素类型，a 是容器名字。也可以写 `vector<long long>`、`vector<char>`、`vector<string>`，分别保存长整数、字符、字符串。前面创建 set<int>、map<string,int> 时，也是在尖括号中告诉容器要保存什么类型。

### 和普通数组有什么区别

| 想做的事 | 普通数组 | vector |
| --- | --- | --- |
| 准备 5 个整数位置 | `int a[5] = {};` | `vector<int> a(5);`，初始也都是 0 |
| 用给定初值创建 | `int a[3] = {4,1,4};` | `vector<int> a = {4,1,4};` |
| 按位置读写 | `a[i]` | `a[i]`，同样从 0 开始 |
| 记录当前元素个数 | 通常自己维护 n | `a.size()` |
| 在末尾添加一个数 | 自己检查空间，再维护个数 | `a.push_back(x)`，长度自动加 1 |
| 改变元素个数 | 创建后数组长度固定 | `a.resize(n)`，调整到 n 个元素 |

写 `vector<int> a(n);` 时，n 可以是刚从输入读到的数。已知需要 n 个位置，就这样创建，再用下标逐个读入；还不知道数量或准备边读边追加，就从空 vector 开始使用 push_back。

两种写法表达的是两种准备方式：

```text
vector<int> a(n);            // 已经有 n 个位置
for (int i = 0; i < n; i++) cin >> a[i];

vector<int> b;               // 开始没有位置
for (int i = 0; i < n; i++) {
    int x;
    cin >> x;
    b.push_back(x);          // 每次增加一个新元素
}
```

> **长度会变化，但 `[]` 不会替你增加元素。**
>
> `vector<int> a;` 的 size() 是 0，此时不能访问 a[0]；要先 push_back，或者创建为 `vector<int> a(n)`。有效下标始终是 0 到 size()−1，越界可能产生 RE。`a[i]=x` 修改已有位置，`a.push_back(x)` 才是在末尾新增一个位置。

### 常用操作：许多名字已经见过

set、map 和 vector 都有 size、empty、clear，含义也相近：查看成员个数、判断是否为空、清空。先把相同的部分对应起来，再记住各自保存的内容有什么不同。

```text
vector<int> a = {4,1,4};
int n = a.size();       // n=3
bool noElements = a.empty(); // false
cout << a.front();     // 第一个元素 4
cout << a.back();      // 最后一个元素 4
a.pop_back();          // 删除最后一个元素，现在是 {4,1}
a.resize(4);           // 扩展到 4 个元素，现在是 {4,1,0,0}
a.resize(1);           // 缩小到 1 个元素，现在是 {4}
a.clear();             // 现在为空，size()=0
```

front、back、pop_back 都要求容器非空。pop_back 只负责删除，不会返回被删除的数；需要这个数时，先用 back 读取，再删除。

### 同样是容器，保存顺序与 `[]` 的含义不同

把 4、1、4 依次加入：

| 容器 | 保存的内容 | 怎样理解 |
| --- | --- | --- |
| vector<int> | 4,1,4 | 保留添加顺序，也保留重复值 |
| set<int> | 1,4 | 自动按值排序，同值只留一份 |
| multiset<int> | 1,4,4 | 自动按值排序，重复值保留 |

vector 不会因为添加了一个更小的数就自动排序。要排序时，仍用熟悉的 sort：

```text
sort(a.begin(), a.end()); // 对 a 中的所有元素升序排序
```

begin 指向第一个元素，end 指向最后一个元素之后的位置，和 set 的迭代器名字一样。传给 sort 的范围是左闭右开，包含 begin，不包含 end。

map 的 `score["Alice"]` 根据**键**定位；vector 的 `a[2]` 根据**位置**定位。即使 a 中没有数值 2，也可以访问已有的第 2 号位置；访问 a[2] 不会去查找值为 2 的元素，也不会自动插入新成员。

按值查找时，vector 使用通用算法：

```text
auto it = find(a.begin(), a.end(), x);
if (it != a.end()) cout << *it;
```

找到就返回对应位置，找不到返回 end。它会依次检查元素，时间 O(n)；不像 set、map 的 find 利用内部查找结构。

删除也要分清参数的含义：`s.erase(x)` 删除 set 中值为 x 的成员；`a.erase(a.begin()+i)` 删除 vector 的第 i 号位置，要求该位置存在。后面的元素会向前移动，因此 vector 中间的删除是 O(n)，不是一次简单的末尾删除。

### 遍历：和数组、set 一样逐个取出来

```text
int n = a.size();
for (int i = 0; i < n; i++) cout << a[i] << ' ';

for (int x : a) cout << x << ' ';
```

第一种保留了下标 i，方便访问相邻位置；第二种只关心当前的值 x，写法和前面遍历 set 一样。这里 x 是取出来的一份值，修改 x 不会修改 a 中的元素；需要按位置修改时，可以先用第一种。

下标读写、size、empty 是 O(1)，末尾 pop_back 是 O(1)。连续做 n 次 push_back，总时间为 O(n)：偶尔需要扩容搬动已有元素，但把这些搬动合在一起，平均到每次添加仍为常数级。完整遍历 O(n)，sort 排序 O(n log n)。

## 上手例题精讲：自编 · 保存并排序一组数

**题意简述：** 输入 n（1≤n≤10^5）及 n 个整数，先输出保存的元素个数，再输出原顺序，最后输出升序结果，重复值全部保留。

输入：

```text
5
4 1 4 7 1
```

输出：

```text
5
4 1 4 7 1
1 1 4 4 7
```

思路很直接：每读一个数，就放到末尾；保存完后遍历输出；需要有序结果时，再排序同一个 vector。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        a.push_back(x);
    }
    int count = a.size();
    cout << count << '\n';
    for (int i = 0; i < count; i++) cout << a[i] << (i + 1 == count ? '\n' : ' ');
    sort(a.begin(), a.end());
    for (int i = 0; i < count; i++) cout << a[i] << (i + 1 == count ? '\n' : ' ');
    return 0;
}
```

时间 O(n log n)，空间 O(n)。先复制运行，再试着把 push_back 写法换成“创建 n 个位置后用下标读入”，核对结果是否相同。接下来，把“一份数列”换成“每个路口各一份邻居名单”，就能用它描述图。

## 先想：每个路口需要记住什么

地图上的路口、文章间的引用、课程间的先修要求，都在描述“对象之间有什么关系”。我们用**点**代表对象，用**边**代表关系，得到一张图。

校园有 5 个路口，双向道路连接 1—2、1—3、2—4、3—4，5 暂时没有道路。

```text
    2
   / \
  1   4       5
   \ /
    3
```

从 1 出发可以直接走到 2、3；从 2 出发可以直接走到 1、4。**如果每个路口都有一份“下一步能去哪里”的名单，程序就记住了这张图。**

| 路口 u | 邻居名单 g[u] | 含义 |
| --- | --- | --- |
| 1 | 2, 3 | 从 1 可以直接走到 2、3 |
| 2 | 1, 4 | 从 2 可以直接走到 1、4 |
| 3 | 1, 4 | 从 3 可以直接走到 1、4 |
| 4 | 2, 3 | 从 4 可以直接走到 2、3 |
| 5 | 空 | 从 5 没有一步能到达的其他路口 |

## 一组 vector 怎样变成这张图

之前的数组里，一个位置保存一个数。现在让每个位置保存一个可以增长的整数列表：

```text
const int N = 100000 + 5;
vector<int> g[N];
```

`vector<int>` 是一个保存整数的动态数组，`g[N]` 则创建了 **N 份相互独立的动态数组**。g[1] 是 1 的名单，g[2] 是 2 的名单；刚创建时每份都为空。我们用 1 到 n 作为结点编号，g[0] 暂时不用。

读到道路 1—2，就在两个名单中各记一次：

```text
g[1].push_back(2); // 1 的名单末尾添一个 2
g[2].push_back(1); // 2 的名单末尾添一个 1
```

push_back 的意思是“在末尾加入一个元素”。它不会自动修改另一份名单，所以双向道路要写两次。

| 读完哪条边 | g[1] | g[2] | g[3] | g[4] | g[5] |
| --- | --- | --- | --- | --- | --- |
| 尚未读入 | 空 | 空 | 空 | 空 | 空 |
| 1—2 | 2 | 1 | 空 | 空 | 空 |
| 1—3 | 2,3 | 1 | 1 | 空 | 空 |
| 2—4 | 2,3 | 1,4 | 1 | 2 | 空 |
| 3—4 | 2,3 | 1,4 | 1,4 | 2,3 | 空 |

**输入逐条给出关系，代码逐条把关系记进名单。**存完以后，原来的图画可以放在一边，后续算法只需读这些名单。

### 看懂 g[u][i]

对 g[1] = {2,3}，有 g[1][0]=2、g[1][1]=3。

- 第一层的 1 是**结点编号**，找到“路口 1 的名单”。
- 第二层的 0、1 是**名单中的位置**，vector 从 0 开始编号。
- 取出来的 2、3 才是**邻居的结点编号**。

例如 g[2][1]=4，意思是“结点 2 的名单里，第 1 号位置保存邻居 4”。位置 1 和结点 1 是两件事。可以把这行代码念成“到 2 的名单里，取出第二位邻居”。

## 有向、无向，以及边上的数

双向道路是**无向边**；文章 u 引用文章 v，是有方向的 **u→v**。引用关系只写 `g[u].push_back(v)`，不能因为 u 引用了 v，就认为 v 也引用了 u。

若道路还给出长度 7，这个 7 就是**边权**。边权也可以表示时间或费用，下一节会把目标和权值放在同一条记录里。

一个点关联多少条无向边，叫它的**度数**。上面的图中 1 的度为 2，5 的度为 0，5 叫**孤立点**。有向图分为入度和出度：指向它的边数是入度，从它出发的边数是出度。

沿边连续走得到一条路径，例如 1→2→4。绕一圈回到起点形成环，例如 1→2→4→3→1。上一章的树也可以看成图：无向树连通且没有环，因此两个点之间只有一条简单路径；一般的图可能有多条路线，也可能有些点彼此无法到达。

## 例题精讲：自编 · 校园道路的邻居名单

**题意简述：** 输入 n、m，然后输入 m 条双向道路 u、v。结点编号为 1 到 n，1≤n,m≤10^5，不含自环。按结点编号依次输出邻居名单，名单内保持输入的先后次序。每行以 `u:` 开头；没有邻居时输出 `u: -`。

输入：

```text
5 4
1 2
1 3
2 4
3 4
```

输出：

```text
1: 2 3
2: 1 4
3: 1 4
4: 2 3
5: -
```

### 完整代码：把刚才的记录过程写出来

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 100000 + 5;
vector<int> g[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    for (int u = 1; u <= n; u++) {
        printf("%d:", u);
        if (g[u].empty()) printf(" -");
        for (int v : g[u]) printf(" %d", v);
        printf("\n");
    }
    return 0;
}
```

`for (int v : g[u])` 表示依次取出 g[u] 里的每个数，当前取出的邻居编号放进 v。对于 g[1]={2,3}，循环先令 v=2，再令 v=3；空名单一次也不执行。

输入与输出共访问 n 个结点和 2m 条邻居记录，时间 O(n+m)，空间 O(n+m)。这里 cin 负责输入，格式化输出统一用 printf。
