## 这一节学什么

上一节把图存成每个结点的邻居名单，这种表示叫**邻接表**。现在练习怎样使用名单：枚举一个点的所有出边、记录带权边，以及处理多组数据。后面的图论教程都沿用 vector 存图。

> **AI 伴学提示词**
>
> 为我讲解 vector 邻接表的插入和遍历，再用 struct Edge 演示目标与权值怎样存成一条记录，并引导我对下标、方向或清空中不理解的地方提问。

## 从“取一个邻居”到“枚举所有下一步”

若 g[2]={1,4,7}，下面两种循环都依次得到邻居 1、4、7。

```text
for (int v : g[2]) {
    // v 依次是 1、4、7
}

int count = g[2].size();
for (int i = 0; i < count; i++) {
    int v = g[2][i];
}
```

大多数时候使用第一种：我们关心邻居是谁，无需关心它排在名单第几个位置。需要倒着遍历或按位置取元素时，再用第二种。

**遍历图的基本动作，就是“来到 u，打开 g[u]，逐个看看下一步可以去谁”。**以后 DFS、BFS、拓扑排序都会重复这个动作，差别在于怎样处理取出来的 v。

### 方向由插入位置决定

```text
g[u].push_back(v); // 原图 u → v：从 u 能去 v
rev[v].push_back(u); // 另建反图：从 v 能找到哪些点指向它
```

rev 也要声明成一组 vector。反图不是无向图：它是把原来所有箭头统一倒过来，原图和反图各自只记录一个方向。做题时先说清“我需要从谁找到谁”，再决定往哪份名单插入。

## 带权边：一个邻居变成一条记录

从 1 到 2 的路长 5，只有邻居编号 2 还不够。我们让一条记录同时保存目标和距离：

```text
struct Edge {
    int to;
    int weight;
};
vector<Edge> g[N];
g[1].push_back({2, 5});
```

现在 g[1] 里每个元素都是 Edge：`.to` 回答“去哪里”，`.weight` 回答“走这条边的代价是多少”。例如 g[1]={{2,5},{3,7}}，不是两个点分别叫 2、5，而是两条出边：去 2、长度 5；去 3、长度 7。

遍历也只需把元素类型改成 Edge：

```text
for (Edge e : g[u]) {
    int v = e.to;
    int w = e.weight;
    // 现在处理从 u 到 v、权值为 w 的这条边
}
```

## 例题精讲：自编 · 路口道路统计

**题意简述：** 有 n 个路口、m 条带权双向道路。每条输入 u、v、w 表示一条长度为 w 的路。对每个路口输出“关联道路条数 道路长度总和”。1≤n≤10^5，0≤m≤2×10^5，1≤w≤10^9；没有自环，允许同一对路口之间有多条道路，每条分别统计。

输入：

```text
3 3
1 2 5
1 3 7
2 3 4
```

输出：

```text
2 12
2 9
2 11
```

### 思路与代码怎样对应

路口 1 的名单为 {{2,5},{3,7}}，道路数就是名单长度 2；把每条记录的 weight 加起来得到 12。依次对每个路口做同样的事。单条权值能放进 int，总和可能超过 2,147,483,647，所以累加器用 long long。

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 100000 + 5;
struct Edge {
    int to;
    int weight;
};
vector<Edge> g[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }
    for (int u = 1; u <= n; u++) {
        int degree = g[u].size();
        long long sum = 0;
        for (Edge e : g[u]) sum += e.weight;
        printf("%d %lld\n", degree, sum);
    }
    return 0;
}
```

外层循环选名单，内层循环看名单中的每条路。所有内层循环一共执行 2m 次，所以时间 O(n+m)，不是 O(nm)。空间也是 O(n+m)：n 份名单，加上无向图的 2m 条边记录。

## 容量、边界和多组数据

> **第一层编号与第二层下标要分别检查。**
>
> g[N] 的有效第一层下标是 0 到 N−1，结点从 1 编号时要让 N 大于最大结点数。每个 vector 会随 push_back 增长，但 g[u][i] 仍要求 0≤i<g[u].size()；空名单不能取 g[u][0]。vector 的增长不会替你检查错误下标。

多组数据之间要清空上一张图：处理完当前图后，对 1 到 n 执行 g[u].clear()，再读取下一组。这样即使下一组 n 变小，也不会留下上组的边。访问标记、入度等辅助数组也要重新初始化。

同一条边输入两次，就会保存两次，叫**重边**。u→u 是**自环**。是否去重、是否允许自环，要按照题目含义决定；容器不会替我们判断。无向自环按两次插入会让度数增加 2，符合无向图中自环对度数的贡献。

## 练习：把需要的信息放进边

先**独立重做道路统计例题**，再用单个孤立点、两点间多条路、总权值超过 int 范围的数据检查。

### 推荐必做

1. **自编 · 邻居查询：** 输入无向图，再输入 q 个结点编号；每次按输入顺序输出该结点的邻居，无邻居输出 `-`。n、m、q≤10^5。练习先建图，再多次读取同一份名单。
2. **自编 · 收发统计：** 输入带权有向图，把权值视为一次转账金额，按编号输出每个人的“转出总额 转入总额”。n≤10^5、m≤2×10^5、w≤10^9。练习方向与 long long 累加。

### 选做巩固

- **自编 · 多组道路：** 输入 T 后，每组按例题格式给图，连续输出统计结果。用上一组边多、下一组边少的输入检查 clear。
- **自编 · 反向名单：** 输入有向图，分别输出每个结点能直接到达谁、哪些结点能直接到达它。对照原图和反图的插入位置。
