## 这一节学什么

前缀和擅长静态区间和，ST 表擅长静态区间最值，树状数组支持单点修改与前缀统计。现在希望用一套区间划分同时组织查询与修改，并让每个区间保存需要的信息，这就引出线段树。

> **AI 伴学提示词**
>
> 为我讲解线段树怎样划分区间，用长度 5 的数组手画建树和查询路径，解释结点编号与数组下标的区别，并引导我提问。

## 每个结点，负责一段连续的数组

线段树是一棵二叉树。根负责整个闭区间 [1,n]；负责 [l,r] 的结点，在 l<r 时分为 [l,mid]、[mid+1,r]，其中 mid=(l+r)/2；直到 l=r，每个叶子只对应一个数组元素。

长度 5 的数组可以这样分：

```text
                    p=1 [1,5]
              /                    \
        p=2 [1,3]                p=3 [4,5]
       /         \              /         \
 p=4 [1,2]    p=5 [3,3]    p=6 [4,4]    p=7 [5,5]
   /     \
[1,1]   [2,2]
p=8     p=9
```

沿用二叉树的数组编号：结点 p 的左孩子是 2p，右孩子是 2p+1。**p 是树上结点编号，l、r 才是它负责的原数组下标。** 例如 p=5 保存的是原数组第 3 项，并不是第 5 项。

递归函数每次带着 p、l、r，就能知道“我在哪里、我负责哪段”。普通线段树开 4n 大小的存储数组，给这种按完全二叉树位置编号的方式预留空间。

## 先决定维护什么，再决定怎么合并

若维护区间最小值，父结点的答案是两个孩子答案的 min；若维护区间和，就相加；若维护最大值，就取 max。

```text
最小值：mn[p]  = min(mn[p*2], mn[p*2+1])
区间和：sum[p] = sum[p*2] + sum[p*2+1]
```

把这个从孩子合并到父亲的步骤称为 pushUp。名字并不是新算法，它只是“重新算出当前区间答案”的函数。

## 例题精讲：P1816 · 忠诚

**原题：** [P1816 · 忠诚](https://www.luogu.com.cn/problem/P1816)。

**题意简述：** 给 m 笔账，回答 n 个闭区间的最小值查询。两者均≤10⁵，账目在 0 到 10⁵ 之间。原题第一项是数组长度 m，第二项是查询数 n；下面代码将它们命名为 n、q，按输入位置读取即可。

自拟输入：

```text
5 3
5 2 7 1 4
1 3
2 5
3 3
```

输出：

```text
2 1 7
```

### 建树：叶子读取元素，父亲取较小值

build(p,l,r) 到达 l=r 时保存 a[l]。否则先建好左右孩子，再 pushUp。以 [1,3] 为例，左侧 [1,2] 的最小值为 2，右侧 [3,3] 为 7，合并后仍为 2。

### 查询：能整体使用，就不要拆到叶子

查询 [2,5]：根 [1,5] 只被部分覆盖，继续访问左右孩子；右侧 [4,5] 整段包含在查询中，可直接取它的最小值 1；左侧再拆出 [2,2]、[3,3]。最后合并这几段的答案。

查询函数 query(p,l,r,ql,qr) 中，l、r 是当前结点的范围，ql、qr 是整次查询的目标范围。整个递归过程中，目标范围不变，只是当前负责的区间逐渐缩小。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 100000 + 5;
int a[N], mn[N * 4];

void pushUp(int p) {
    mn[p] = min(mn[p * 2], mn[p * 2 + 1]);
}

void build(int p, int l, int r) {
    if (l == r) { mn[p] = a[l]; return; }
    int mid = (l + r) / 2;
    build(p * 2, l, mid);
    build(p * 2 + 1, mid + 1, r);
    pushUp(p);
}

int query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return mn[p];
    int mid = (l + r) / 2;
    int answer = INT_MAX;
    if (ql <= mid) answer = min(answer, query(p * 2, l, mid, ql, qr));
    if (qr > mid) answer = min(answer, query(p * 2 + 1, mid + 1, r, ql, qr));
    return answer;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    for (int i = 1; i <= n; i++) cin >> a[i];
    build(1, 1, n);
    for (int i = 0; i < q; i++) {
        int l, r;
        cin >> l >> r;
        if (i) cout << ' ';
        cout << query(1, 1, n, l, r);
    }
    cout << '\n';
    return 0;
}
```

answer 初始为 INT_MAX，是因为它与任何有效答案取 min 都不会改变答案。求和时初始为 0；求最大值时应取足够小的值，不能对全负数组初始为 0。

两条子树判断必须独立：查询可能同时跨过 mid，所以不能写成 if/else。只有目标与子区间相交，才递归进入它。

建树每个结点处理一次，O(n)；一次连续区间查询每层只沿边界继续拆分，其余整段直接取值，总共 O(log n)，空间 O(n)。本题没有修改，ST 表也能完成；这里用它练习线段树的区间组织，下一节在同一结构中加入修改。
