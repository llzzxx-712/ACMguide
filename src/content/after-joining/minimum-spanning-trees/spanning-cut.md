## 这一节学什么

修建道路让所有城市连通，目标是所选道路的总代价最小。这里不要求每个城市到某个起点的路线最短，而是要用一组边把所有点连接起来。先明确生成树的条件，再推导选择最便宜边的理由。

## 生成树到底是什么

$n$ 个点全部保留，所选边连通且无环，就得到一棵生成树，边数恰好是 $n-1$。原图不连通时没有生成树；连通时通常有许多不同生成树。

最小生成树 MST 是边权总和最小的一棵。可以有多个边集不同、总权相同的 MST，不必为了唯一性人为规定一条题目没有要求的树。

例如三角形中 $1\text{—}2$、$1\text{—}3$ 权均为 2，$2\text{—}3$ 权为 1。以 1 为源的最短路树会选择两条权 2 的边，总权 4；MST 选择一条权 2、一条权 1，总权 3。

## 例题精讲：[P3366 最小生成树](https://www.luogu.com.cn/problem/P3366)

**题意简述：** 输入 $n$ 点 $m$ 边的带权无向图，选出连接全部点的 $n-1$ 条边，使总权最小；不连通输出小写 orz。$n\le 5000$、$m\le 2\times 10^{5}$、边权不超过 $10^{4}$。输入 $n$、$m$，再给每条边的两个端点和权值。

自编输入：

```text
4 5
1 2 2
1 3 3
2 3 5
2 4 4
3 4 2
```

输出：

```text
7
```

### 先把思路讲清楚

![最小生成树例题的割：左侧为 1、2，右侧为 3、4，绿色的 1—3 是跨割最小边](/ACMguide/diagrams/graphs/cut.svg)

将点分成 $S=\{1,2\}$ 与另一侧 $\{3,4\}$。跨过分界的边权分别为 `3 5 4`；不论内部怎样连接，要把两侧连起来，总要跨过这个割。先在图中找出最便宜的跨割边，再理解后面为何能安全选择它。

先看可行性：选出的边不能成环，且必须连接全部点。再考虑代价：从较小的边开始，只有当它连接两个不同连通块时才加入。样例先取 1—2 和 3—4，费用为 4；再取 1—3 连接两块，总费用为 7。

并查集回答“两端是否已连通”。若已经连通，再加这条边就形成环；否则合并两个块。每选一条边，连通块数减少 1，从 $n$ 块变成 1 块恰需 $n-1$ 条边。下面是这条思路的完整实现，下一节会继续比较 Kruskal 与 Prim。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;
struct Edge {
    int u, v, weight;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<Edge> edges(m);
    for (Edge &e : edges) cin >> e.u >> e.v >> e.weight;
    sort(edges.begin(), edges.end(), [](Edge a, Edge b) {
        return a.weight < b.weight;
    });
    vector<int> parent(n + 1), size(n + 1, 1);
    iota(parent.begin(), parent.end(), 0);
    auto find = [&](int x) {
        while (x != parent[x]) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    };
    long long sum = 0;
    int used = 0;
    for (Edge e : edges) {
        int a = find(e.u), b = find(e.v);
        if (a == b) continue;
        if (size[a] < size[b]) swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        sum += e.weight;
        used++;
    }
    if (used == n - 1) cout << sum << '\n';
    else cout << "orz\n";
    return 0;
}
```

按权排序 $\mathcal{O}(m \log  m)$，并查集合并的总开销接近线性，空间 $\mathcal{O}(n+m)$。图的无向边在这里作为一份边表保存，排序时每条边只需一条记录；若要从点枚举邻居，则仍使用 `vector` 邻接表。

## 割：把所有点分成两边

将顶点分成非空集合 $S$ 与其余点，连接两边的边称为跨割边。任何生成树必须有跨割边，否则两侧不能连通。

假设已经选了一片森林，并且存在一棵 MST 包含它；再选一个不切开任何已选边的割。取跨割最小边 $e$：若该 MST 已包含 $e$，直接保留；否则把 $e$ 加入会成一个环，环上还有另一条跨割边 $f$。删掉 $f$ 后仍是生成树，而且 $w(e)\le w(f)$，总代价不增加；割没有切开已选边，因此删掉 $f$ 也不会破坏之前的选择。

这说明可以把当前选择扩展成一棵包含 $e$ 的 MST。贪心每一步都需要这样的“不损失最优解”的理由，而不是因为边比较便宜就随意加入。

下一节的两种算法选割的方式不同：Kruskal 看当前连通块之间的最便宜边；Prim 看已加入点集与其余点之间的最便宜边。并查集、堆分别实现这些选择。

## 练习：同时检查连通与无环
