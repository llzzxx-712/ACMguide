## 这一节学什么

当点数不多、需要查询许多点对时，可以一次求出全源最短路。Floyd 不按起点遍历，而是依次允许更多点作为路径中间点：经过新点会不会得到更好的路线？

> **AI 伴学提示词**
>
> 为我讲解 Floyd 的中间点状态，手算加入一个中转点前后的距离矩阵，再把最短路转移改成可达性转移，并引导我提问。

## k 放最外层，是状态依赖决定的

处理完 k 之后，d[i][j] 表示中间点只允许来自 1…k 时的最短距离。最优路线要么不经过 k，要么拆成 i→k 与 k→j：

```text
d[i][j] = min(d[i][j], d[i][k] + d[k][j])
```

所以循环必须先枚举 k，再枚举 i、j。把 k 放内层会混用尚未完整建立的中间点集合，单轮扫描不再保证得到全部最短路。

一般图初始化 d[i][i]=0，有边时取最小直接边权，无边为 INF；只有两段都可达时才相加。有负边但无负环仍可求最短路，若 d[i][i]<0，则该点所在可达范围涉及负环，相关最短路线不能再视为有限最小值。

## 例题精讲：P2910 · Clear And Present Danger

**原题：** [P2910 · Clear And Present Danger](https://www.luogu.com.cn/problem/P2910)。

**题意简述：** 给 n≤100 个岛之间的有向直接代价矩阵，再给必须按顺序经过的地点序列，求总路线的最小代价。序列首项是 1，末项是 n；中间允许绕行。序列长度≤10000。

自拟输入：

```text
3 3
1 2 3
0 5 1
5 0 1
1 1 0
```

输出 `3`。必须先出现 1、2、3，但 1 到 2 可以先经过 3，走 1→3→2 费用 2，再走 2→3 费用 1。经过一个未来要求的点，并不妨碍以后再次按序经过它。

### 完整代码

本题直接输入矩阵，用二维 vector 保存。先求任意两岛最短代价，再将要求序列中相邻两项的代价相加。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, length;
    cin >> n >> length;
    vector<int> route(length);
    for (int &u : route) { cin >> u; u--; }
    vector<vector<long long>> d(n, vector<long long>(n));
    for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) cin >> d[i][j];
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
        }
    }
    long long answer = 0;
    for (int i = 1; i < length; i++) answer += d[route[i-1]][route[i]];
    cout << answer << '\n';
    return 0;
}
```

这里没有 INF 判断，是因为输入矩阵给出了每对岛屿的直接非负代价。一般邻接矩阵模板要保留不可达检查；有向矩阵也不能擅自将 d[i][j] 与 d[j][i] 设成相同。

Floyd 时间 O(n³)、存储 O(n²)，本题 n=100，约一百万次三重循环；n=10⁵ 时则完全不可行，要回到单源算法或分析图的特殊结构。

## 传递闭包：只问能不能到，不问花多少

若 can[i][j] 表示可达，把“取 min 与相加”换成“或与且”：

```text
for k = 1…n
    for i = 1…n
        for j = 1…n
            can[i][j] = can[i][j] || (can[i][k] && can[k][j])
```

含义仍是：不经过 k 已经能到，或者先到 k 再到 j。对角线是否初始为 true，取决于题目是否允许长度为 0 的路径；如果只统计至少走一条边的可达关系，应按题意初始化，不能把两个约定混用。

## 练习：把“中间点已处理到哪里”写出来

先**独立重做 P2910**，在三点图上记录每轮 k 后的矩阵，并用从每个点出发的 Dijkstra 核对非负图。

### 推荐必做

1. **自编 · 可达点对数：** n≤300，给有向边，允许长度为 0 的路径，计算有多少有序点对可达。初始化对角线为 true，再做传递闭包。
2. **自编 · 多次路线询问：** n≤300、q≤10⁵，有向边权非负，查询两点最短距离，不可达输出 −1。处理重边时取最小值，再统一预处理。

### 选做巩固

- **自编 · 是否处于有向环：** 传递闭包初始只登记真实边，不预设对角线，观察哪些 can[i][i] 最终为 true。
- **自编 · 保存中转点：** Floyd 改善时记录下一步或分割点，恢复一条最短路线，测试起终点相同与零权边。
