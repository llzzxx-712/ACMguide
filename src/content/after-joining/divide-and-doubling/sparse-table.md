## 这一节学什么

前缀和让区间求和变快；最值不能通过相减消去前缀，却可以把两个区间的最值合起来。本节借用倍增的长度划分，预处理 1、2、4、8 个元素的区间，再用两块覆盖任意询问，这就是 ST 表。

> **AI 伴学提示词**
>
> 为我讲解 ST 表，用长度为 5 的数组画出每层区间，解释查询时两块为什么允许重叠、为什么不能直接用同样方法求和，并引导我提问。

## 从跳跃次数换成区间长度

定义 mx[j][i] 为从 i 开始、长度为 2^j 的区间最大值。

```text
mx[0][i]：只包含 a[i]
mx[1][i]：a[i] 到 a[i+1]
mx[2][i]：a[i] 到 a[i+3]
```

长度为 2^j 的区间由前后两段长度 2^(j−1) 的区间组成，第二段从 i+2^(j−1) 开始：

```text
mx[j][i] = max(mx[j-1][i], mx[j-1][i + (1 << (j-1))]);
```

最小值表 mn 同理，把 max 换成 min。只建立右端点 i+2^j−1≤n 的有效区间。

对 {2,6,4,8,1}，最大值表为：

| 起点 i | 长度 1 | 长度 2 | 长度 4 |
| --- | --- | --- | --- |
| 1 | 2 | 6 | 8 |
| 2 | 6 | 6 | 8 |
| 3 | 4 | 8 | — |
| 4 | 8 | 8 | — |
| 5 | 1 | — | — |

## 用两块覆盖任意区间

查询 [l,r]，长度 len=r−l+1。找最大整数 j，使 2^j≤len，令 width=2^j。

- 第一块从 l 开始：[l,l+width−1]。
- 第二块在 r 结束：[r−width+1,r]。

width 不超过 len，而 2×width≥len，所以两块都在询问内部，合起来覆盖完整询问，中间可能重叠。

```text
查询 [1,5]，len=5，width=4
第一块：[1 2 3 4]
第二块：  [2 3 4 5]
```

重复看一遍中间元素，不会改变最大值或最小值：max(x,x)=x、min(x,x)=x。因此查询只需取这两块答案的 max 或 min。区间求和则不能这样做，重叠元素会被加两次。

### 用整数表求 j

预处理 lg[len]=⌊log2(len)⌋：lg[1]=0，lg[i]=lg[i/2]+1。查询时直接取 lg[len]，无需浮点对数和取整。

## 例题精讲：P2880 · Balanced Lineup G

**原题：** [P2880 · Balanced Lineup G](https://www.luogu.com.cn/problem/P2880)。

**题意简述：** n 头牛的身高保持不变，q 次询问某个连续区间内的最高身高减最低身高。n≤5×10^4、q≤1.8×10^5，身高≤10^6。

自拟输入：

```text
5 4
2
6
4
8
1
1 3
2 5
4 4
1 5
```

输出：

```text
4
7
0
7
```

第一问最高 6、最低 2；第三问只有一头牛，差为 0。每次分别查询最大值和最小值，再相减即可。

## 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 50000 + 5;
const int LOG = 17;
int mx[LOG][N], mn[LOG][N], lg[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    for (int i = 1; i <= n; i++) {
        cin >> mx[0][i];
        mn[0][i] = mx[0][i];
    }
    for (int i = 2; i <= n; i++) lg[i] = lg[i/2] + 1;
    for (int j = 1; (1 << j) <= n; j++) {
        int half = 1 << (j - 1);
        for (int i = 1; i + (1 << j) - 1 <= n; i++) {
            mx[j][i] = max(mx[j-1][i], mx[j-1][i+half]);
            mn[j][i] = min(mn[j-1][i], mn[j-1][i+half]);
        }
    }
    while (q--) {
        int l, r;
        cin >> l >> r;
        int j = lg[r - l + 1], width = 1 << j;
        int high = max(mx[j][l], mx[j][r-width+1]);
        int low = min(mn[j][l], mn[j][r-width+1]);
        cout << high - low << '\n';
    }
    return 0;
}
```

本题 n<2^16，准备 17 层足够。预处理 O(n log n)，每次查询 O(1)，空间 O(n log n)，两份 int 最值表约 6.8 MB。

ST 表的输入在建表后不再改变，这就是“静态”。若修改一个元素，覆盖它的许多预处理区间都可能需要更新；之后学习树状数组、线段树时，会进一步处理修改与查询交替出现的场景。

## 练习：先判断信息怎样合并

先**独立重做 P2880**，检查单元素区间、整段、长度恰好为 2 的幂，以及长度比 2 的幂多 1 的询问。

### 推荐必做

1. [P3865 · ST 表与 RMQ 问题](https://www.luogu.com.cn/problem/P3865)：只查询区间最大值。独立写最大值表，注意 n≤10^5、询问可达 2×10^6，按范围开数组并关闭流同步。
2. [P1816 · 忠诚](https://www.luogu.com.cn/problem/P1816)：只查询区间最小值。把状态、合并和查询一起改成 min，按题目要求在一行输出答案。

### 选做巩固

- **自编 · 区间 gcd：** 输入 n、q≤10^5 的正整数数组和区间询问，输出每段的最大公因数。利用 gcd(x,x)=x，判断重叠是否影响结果，再修改合并操作。
- **自编 · 最小值的最左位置：** 输入 n、q≤10^5，返回区间最小值的下标，相等取最左。表中保存候选下标，合并时先比较数值，再比较下标，让重叠时重复选中同一位置也不改变结果。

## 本节验收

能解释每层对应的区间长度；能画出一次查询的两块区间；能判断重叠是否会影响某种统计，并正确设置表的层数、区间终点和查询下标。
