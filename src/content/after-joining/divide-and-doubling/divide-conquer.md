## 这一节学什么

分治是一种组织解题思路的方法：把问题拆成同类小问题，求出各自答案，再把结果合起来。递归负责让程序进入更小的问题、返回后继续合并；关键仍是我们怎样划分所有可能的答案。

> **AI 伴学提示词**
>
> 为我讲解分治，用最大子段和画出递归区间，模拟左右子问题返回后怎样计算跨中点的答案，并引导我对不理解的地方提问。

## 先明确一个函数要解决什么

假设 solve(le,r) 的含义是“求 a[le..r] 中的答案”。取 mid=(le+r)/2，把区间分成 [le,mid]、[mid+1,r] 两段：

```text
solve(1,5)
├─ solve(1,3)
│  ├─ solve(1,2)
│  │  ├─ solve(1,1)
│  │  └─ solve(2,2)
│  └─ solve(3,3)
└─ solve(4,5)
   ├─ solve(4,4)
   └─ solve(5,5)
```

每次区间都缩小，最后只有一个元素，答案可以直接给出。左侧调用结束后，程序回到当前层，再求右侧，最后合并。调用没有凭空解决问题，它只是让相同的处理步骤在更小的输入上再次执行。

## 例题精讲：P1115 · 最大子段和（分治解法）

**原题：** [P1115 · 最大子段和](https://www.luogu.com.cn/problem/P1115)。

**题意简述：** 从 n 个整数中选择连续且非空的一段，使总和最大，输出最大和，n≤2×10^5。

自拟输入：

```text
5
-2 3 -1 2 -5
```

输出为 `4`，选择第 2 到第 4 项：3−1+2。

### 所有候选区间只有三种位置关系

对于当前 [le,r]，一个连续子段要么完全在左半边，要么完全在右半边，要么跨过 mid 与 mid+1 之间的分界线。

- 完全在左边的最优答案，交给 solve(le,mid)。
- 完全在右边的最优答案，交给 solve(mid+1,r)。
- 跨中线的子段，一定由“左半边的一段后缀”和“右半边的一段前缀”连接而成。

因此跨中线的最大和，就是左侧最大后缀和加上右侧最大前缀和。分别从 mid 向左累加、从 mid+1 向右累加，就能找到它们。

对例子中 mid=3 的划分：

```text
左半边：-2  3 -1   |   右半边：2 -5
最大后缀为 3-1=2  |   最大前缀为 2
跨中线答案为 2+2=4
```

左侧递归返回 3，右侧返回 2，跨中线为 4，当前层返回 max(3,2,4)=4。三类已经覆盖全部连续区间，因此比较它们不会漏解。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

vector<long long> a;

long long solve(int le, int r) {
    if (le == r) return a[le];
    int mid = le + (r - le) / 2;
    long long leftAnswer = solve(le, mid);
    long long rightAnswer = solve(mid + 1, r);
    long long sum = 0, suffix = LLONG_MIN, prefix = LLONG_MIN;
    for (int i = mid; i >= le; i--) {
        sum += a[i];
        suffix = max(suffix, sum);
    }
    sum = 0;
    for (int i = mid + 1; i <= r; i++) {
        sum += a[i];
        prefix = max(prefix, sum);
    }
    return max(max(leftAnswer, rightAnswer), suffix + prefix);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    a.resize(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];
    cout << solve(1, n) << '\n';
    return 0;
}
```

suffix、prefix 从很小的值开始，而不是从 0 开始，因为左右两段都必须至少取一个元素。全部为负数时，最大子段是其中最大的单个元素，不能选一个和为 0 的空段。两个扫描都至少执行一次，因此 LLONG_MIN 会先被实际和替换，再参与相加。

## 怎样估算分治的复杂度

每层所有区间互不重叠，扫描总长度为 O(n)；每次大约折半，递归层数 O(log n)，所以总时间 O(n log n)。数组 O(n)，同时存在的函数调用层数 O(log n)。

这道题也可以使用之前学过的线性 DP 或前缀最小值做到 O(n)。本次练习的重点是认识**分类拆分 → 子问题返回 → 跨边界合并**，并比较不同思路各自花了多少工作量。

### 推荐必做

1. [P1177 · 排序](https://www.luogu.com.cn/problem/P1177)：用归并排序将数组从小到大排列。明确每次递归返回的是哪段有序序列，再合并左右结果。
2. [P1923 · 求第 k 小的数](https://www.luogu.com.cn/problem/P1923)：找序列中第 k 小的值，最小值按第 0 小计。尝试按基准划分并只递归可能包含答案的一侧，注意重复值。

### 选做巩固

- [P1228 · 地毯填补问题](https://www.luogu.com.cn/problem/P1228)：一格不能覆盖，其余方格用 L 形地毯铺满。把大正方形分成四块，用中心一块地毯让每个子正方形都恰好有一个不能再覆盖的位置，练习构造同类子问题。
- [P1257 · 平面上的最接近点对](https://www.luogu.com.cn/problem/P1257)：按横坐标划分点集，分别处理左右内部最近距离，再考虑靠近分界线的跨侧候选。重点推导怎样减少合并时要比较的点对，输出按题意使用 printf 保留 4 位小数。
