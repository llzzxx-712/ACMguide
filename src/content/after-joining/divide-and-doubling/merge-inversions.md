## 这一节学什么

日常排序继续使用 `sort`。这一节拆开归并排序的过程，是为了利用“合并两个有序区间”时得到的信息：一次比较，就能知道一整批元素与当前数的关系，进而统计逆序对。

> **AI 伴学提示词**
>
> 为我讲解归并排序与逆序对，用含重复值的数组模拟左右排序和合并，解释为什么一次增加 mid-i+1，并引导我对不理解的地方提问。

## 怎样合并两份已经排好的数

左侧 {1,4,7}、右侧 {2,4,6} 都有序。用 i、j 分别指向两侧还没取走的第一个数，每次取较小者放进临时数组，再移动对应指针：

```text
比较 1、2，取 1
比较 4、2，取 2
比较 4、4，先取左侧的 4
比较 7、4，取右侧的 4
比较 7、6，取 6
右侧取完，把左侧剩下的 7 接上
结果：1 2 4 4 6 7
```

最小的未取元素一定在两个队头之一，所以不用再扫描两份列表内部。每个数只被取一次，合并总时间与两段长度之和成正比。

归并排序就是先递归排好左半段，再排好右半段，然后按这个规则合成一个有序区间。单个元素天然有序，作为递归边界。

## 例题精讲：P1908 · 逆序对

**原题：** [P1908 · 逆序对](https://www.luogu.com.cn/problem/P1908)。

**题意简述：** 统计原数组中 i<j 且 `a[i]`>`a[j]` 的位置对数，n≤5×10^5，数值不超过 10^9。

自拟输入：

```text
4
4 2 2 1
```

输出为 `5`：4 与后面三个数形成 3 对，两个 2 分别与 1 形成 1 对。相等的 2、2 不是逆序对。

## 把逆序对分成三类

与上一节一样，按原下标中点划分：两端都在左侧、都在右侧，或者左端在左侧而右端在右侧。

递归统计两侧内部的逆序对，并让两侧分别有序。虽然每侧内部顺序被排序改变，但**左组里的所有元素都来自原先的左半段，右组里的都来自原先的右半段**。因此跨组的原始位置关系 i<j 始终满足，只需要统计值的大小关系。

当合并时发现 `a[i]`>`a[j]`，左侧已经有序，所以 `a[i]` 到 `a[mid]` 都大于 `a[j]`。这一批元素有 mid−i+1 个，一次全部计入。

```text
左侧剩余：2 4 7    右侧当前：1
          ↑ i    ↑ mid
这三个数都大于 1，一次增加 3
```

反之，`a[i]`≤`a[j]` 时先取左侧：当前 `a[i]` 不会与右侧尚未取出的更大数形成逆序，不增加计数。相等时也走这一分支，保证只统计严格大于。

## 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

vector<int> a, temp;

long long mergeCount(int le, int r) {
    if (le >= r) return 0;
    int mid = le + (r - le) / 2;
    long long answer = mergeCount(le, mid) + mergeCount(mid + 1, r);
    int i = le, j = mid + 1, pos = le;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) {
            temp[pos++] = a[i++];
        } else {
            answer += mid - i + 1;
            temp[pos++] = a[j++];
        }
    }
    while (i <= mid) temp[pos++] = a[i++];
    while (j <= r) temp[pos++] = a[j++];
    for (int p = le; p <= r; p++) a[p] = temp[p];
    return answer;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    a.resize(n + 1);
    temp.resize(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];
    cout << mergeCount(1, n) << '\n';
    return 0;
}
```

temp 保存当前合并结果，避免一边写回 a、一边覆盖还没读到的数。合并完成后才整体复制回当前区间。两个递归调用完成后，这一层同时得到了“左右内部计数”和“两份有序区间”，再统计跨组部分。

每层合并 $\mathcal{O}(n)$，共有 $\mathcal{O}(\log  n)$ 层，总时间 $\mathcal{O}(n \log  n)$，临时数组和原数组占 $\mathcal{O}(n)$，递归深度 $\mathcal{O}(\log  n)$。严格递减数组有 $\frac{n(n-1)}{2}$ 个逆序对，50 万个数时约 1.25×10^11，计数和函数返回类型都要用 `long long`。
