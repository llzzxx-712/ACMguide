## 这一节学什么

向量可以先理解成有顺序的一组数；矩阵则把“新的一组数怎样由旧的一组数组合出来”写成表格。我们先看每个格子代表什么，再实现乘法。

> **AI 伴学提示词**
>
> 为我从二维向量和线性组合讲解矩阵，用行与列的配对手算乘法，并引导我理解维度、乘法顺序后提问。

## 一行就是一个新状态的计算规则

设旧状态列向量为 [x,y]ᵀ，想得到 x'=2x+y、y'=x−y，可以写成：

```text
[x']   [2  1] [x]
[y'] = [1 -1] [y]
```

矩阵第一行给 x' 的系数，第二行给 y' 的系数。几何上，这表示把向量变成另一个向量；列向量 [2,1]ᵀ、[1,−1]ᵀ 分别说明两个坐标轴单位向量变到哪里，任意向量的变化就是它们的线性组合。

本章统一采用**列向量放在右边**。因此先做 B，再做 A，整体写成 A·B·x。交换 A、B 往往得到不同结果，不能按普通数乘法随意交换。

## 行和列怎样配对

A 为 r×s，B 为 s×t，乘积 C 为 r×t：C[i][j]=Σ(k=0…s−1)A[i][k]B[k][j]。中间维度必须相同，因为 A 的一行要与 B 的一列逐项配对。

例如 [1,2] 乘 [5,7]ᵀ 得 1×5+2×7=19。单位矩阵主对角线为 1，其余为 0，相当于每个状态原样保留，是矩阵乘法中的“1”。

## 例题精讲：自编 · 计算矩阵乘积

**题意简述：** 输入 r、s、t，均为 1…100；再输入 r×s 的 A 和 s×t 的 B，元素为 0…10⁹+6，输出 A·B，每项对 10⁹+7 取模。

输入：

```text
2 2 2
1 2
3 4
5 6
7 8
```

输出：

```text
19 22
43 50
```

请先手算左上角和右下角，再把每一步找到代码里的 i、j、k。三层循环不是需要背的固定顺序，而是在枚举“答案哪一格”和“这格的哪一项贡献”。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const long long MOD = 1000000007;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int r, s, t;
    cin >> r >> s >> t;
    vector<vector<long long>> a(r, vector<long long>(s));
    vector<vector<long long>> b(s, vector<long long>(t));
    vector<vector<long long>> c(r, vector<long long>(t));
    for (auto &row : a) for (auto &x : row) cin >> x;
    for (auto &row : b) for (auto &x : row) cin >> x;
    for (int i = 0; i < r; i++) {
        for (int k = 0; k < s; k++) {
            for (int j = 0; j < t; j++) c[i][j] = (c[i][j] + a[i][k] * b[k][j]) % MOD;
        }
    }
    for (auto row : c) {
        for (int j = 0; j < t; j++) cout << row[j] << (j + 1 == t ? '\n' : ' ');
    }
    return 0;
}
```

循环按 i、k、j 排列，方便一段连续地访问 B 的第 k 行；含义与按 i、j、k 一样。每次乘加后取模，单个乘积加一个余数小于约 10¹⁸，long long 足够。时间 O(rst)，空间 O(rs+st+rt)。

## 练习：先检查维度

先**独立重做例题**，给每个矩阵标出行数和列数，再核对每一格的行列乘积。

### 推荐必做

1. **自编 · 单位矩阵：** 对方阵 A 验证 AI=IA=A，再用两个小矩阵找出 AB≠BA 的例子。
2. **自编 · 向量变换：** 输入若干二维向量，应用本节的 x'=2x+y、y'=x−y，分别直接计算和用矩阵相乘。

### 选做巩固

- **自编 · 两次规则：** 先交换 x、y，再把第一项乘 2，写出整体矩阵，核对顺序。
- **自编 · 固定长度走法：** 将有向图邻接矩阵的 A[u][v] 设为 u 到 v 的边数，解释 A²[u][v] 为什么统计恰好走两条边的方案。
