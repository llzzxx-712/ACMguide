## 这一节学什么

有些问题处理完一次选择后，留下的不是前缀，而是中间一段。此时用 `f[l][r]` 描述连续区间，比只记录“前 $i$ 项”更自然。状态里出现两维，并不意味着必须遍历所有两维顺序：先看它依赖哪些更短区间。

## 例题精讲：P1435 · 回文字串

**原题：** [P1435 · 回文字串](https://www.luogu.com.cn/problem/P1435)。

**题意简述：** 给非空字符串，只能插入字符，求最少插入多少个能成为回文，区分大小写。输入一个字符串，输出最少次数。

输入 `abca`，输出 `1`，可以在 `c` 后插入 `b` 变成 `abcba`；原本已经回文的 `aba` 输出 0。

## 先固定最外面一对字符

令 `f[l][r]` 为 `s[l…r]` 变成回文的最少插入数。

- `s[l] = s[r]`：两端可以配成一对，内部只需 `f[l + 1][r - 1]`。
- 不相等：在右侧补一个 `s[l]`，留下 $[l+1,r]$；或者在左侧补一个 `s[r]`，留下 $[l,r-1]$。取两者较小再加 1。

长度 1 已是回文，代价 0；空区间也不需要操作。当长度为 2 且两端相等时，内部为空，代码可直接使用已初始化为 0 的表格位置。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.size();
    vector<vector<int>> f(n, vector<int>(n));
    for (int length = 2; length <= n; length++) {
        for (int l = 0; l + length <= n; l++) {
            int r = l + length - 1;
            if (s[l] == s[r]) f[l][r] = f[l+1][r-1];
            else f[l][r] = min(f[l+1][r], f[l][r-1]) + 1;
        }
    }
    cout << f[0][n-1] << '\n';
    return 0;
}
```

长度从小到大，保证内部、删左端、删右端三个状态都已算好。时间与空间 $\mathcal{O}(n^{2})$，把原题最大字符串长度代入后，分别估算更新次数与 $n^2$ 个 `int` 的内存。

## 区间 DP 不一定都枚举分割点

本题按两端决策；合并石子通常枚举最后一次合并的分界 $k$；区间建树可以枚举根；它们共同的特征是由较小连续区间组成当前区间，而不是拥有一套完全相同的三重循环。

先问“最后一步把区间怎样处理”，再决定是否需要 $k$。空区间是贡献 `0、1` 还是不可达，也由合并运算决定，不能统一设为 0。
