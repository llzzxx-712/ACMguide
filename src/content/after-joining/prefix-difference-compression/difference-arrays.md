## 这一节学什么

前缀和擅长“先准备，再查区间”。差分把方向倒过来：先用少量标记记下每次区间修改，最后统一恢复结果。我们从“这一位比上一位多多少”推导一维差分，再推广到矩形修改。

> **AI 伴学提示词**
>
> 为我讲解一维与二维差分，用一次区间加和一次矩形加手动恢复数组，重点解释 r+1 与四个角的标记，并引导我对不理解的地方提问。

## 一维差分：保存相邻位置的变化

设 a[0]=0，d[i]=a[i]−a[i−1]。例如：

```text
a：3  3  5  2
d：3  0  2 -3
```

从左到右累加 d，就能恢复 a。现在要让 [2,3] 都加 4：

- d[2] 加 4：从位置 2 开始，后面所有前缀累计值都多 4。
- d[4] 减 4：从位置 4 开始，取消这份影响。

得到 d={3,4,2,−7}，恢复为 a={3,7,9,2}，正好只改变了第 2、3 位。于是任意 [l,r] 加 value 只需：

```text
d[l] += value;
d[r+1] -= value;
```

多次修改可以累加，因为加法可以交换顺序；等所有标记完成，再一次前缀累计恢复。**不是每次修改都恢复，否则又回到反复扫描数组。**

## 例题精讲一：P2367 · 语文成绩

**原题：** [P2367 · 语文成绩](https://www.luogu.com.cn/problem/P2367)。

**题意简述：** n 个学生有初始成绩，p 次操作将 [x,y] 每人成绩增加 z。全部修改结束后输出最低成绩，n≤5×10^6，p≤n。

自拟输入：

```text
4 2
3 3 5 2
2 3 4
1 4 1
```

最终成绩为 4、8、10、3，输出 `3`。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, p;
    cin >> n >> p;
    vector<long long> d(n + 2);
    long long previous = 0;
    for (int i = 1; i <= n; i++) {
        long long value;
        cin >> value;
        d[i] = value - previous;
        previous = value;
    }
    for (int i = 1; i <= p; i++) {
        int l, r;
        long long value;
        cin >> l >> r >> value;
        d[l] += value;
        d[r+1] -= value;
    }
    long long current = 0, answer = LLONG_MAX;
    for (int i = 1; i <= n; i++) {
        current += d[i];
        answer = min(answer, current);
    }
    cout << answer << '\n';
    return 0;
}
```

读初始成绩时直接构造差分，不必同时保留整个 a。current 累加到第 i 位，就是修改后第 i 个学生的成绩。时间 O(n+p)，空间 O(n)；long long 差分数组在最大 n 时约 40 MB。输入可能有数百万个数，开头关闭流同步。

## 二维差分：一个角开启影响，另外三个角控制范围

先考虑一个全零矩阵，对矩形 [x1,x2]×[y1,y2] 每格加 value。最后要对 d 做二维前缀和，得到每格数值。

只在 d[x1][y1] 加 value，恢复时它会影响**右下方整个区域**。为了只留下目标矩形：

1. 在 (x1,y1) 加 value，开启右下方的影响。
2. 在 (x2+1,y1) 减 value，取消下方多余区域。
3. 在 (x1,y2+1) 减 value，取消右方多余区域。
4. 右下角被取消了两次，在 (x2+1,y2+1) 加回 value。

```text
            y1          y2+1
     x1     +value      -value

   x2+1     -value      +value
```

二维差分记录的是“从这个角开始，让右下区域增加多少”。画出这四块右下区域，就能推导四个符号。

## 例题精讲二：P3397 · 地毯

**原题：** [P3397 · 地毯](https://www.luogu.com.cn/problem/P3397)。

**题意简述：** n×n 的地面，m 张矩形地毯，给出每张的左上角和右下角，输出每个格子被覆盖的次数。n、m≤1000。

自拟输入：

```text
3 2
1 1 2 2
2 2 3 3
```

输出：

```text
1 1 0
1 2 1
0 1 1
```

每张地毯就是一次矩形加 1。标记四个角后，用与上节相同的二维前缀和过程恢复覆盖次数：

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1000 + 5;
int d[N][N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= m; i++) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        d[x1][y1]++;
        d[x2+1][y1]--;
        d[x1][y2+1]--;
        d[x2+1][y2+1]++;
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            d[i][j] += d[i-1][j] + d[i][j-1] - d[i-1][j-1];
            cout << d[i][j] << (j == n ? '\n' : ' ');
        }
    }
    return 0;
}
```

时间 O(m+n²)，空间 O(n²)。这里在 d 上直接恢复，某个格子从“差分标记”变成“最终覆盖数”；按行扫描保证上、左、左上都已恢复。

> **取消影响的标记写在边界外一格。**
>
> 一维的 r+1、二维的 x2+1 和 y2+1 可能等于 n+1。数组必须为这些位置留空间，恢复答案时仍只遍历 1 到 n。n+1 的标记不是多余输出，而是记录“从范围之后停止增加”。写漏 +1 会让区间末尾少算一格，数组开小则可能越界并产生 RE。

## 练习：标记与恢复分开完成

先**独立重做 P2367、P3397**，在草稿纸上检查一次整段修改、单点修改和贴着最后一行列的修改。

### 推荐必做

1. **自编 · 批量修改后查询：** 输入 n、p、q≤10^5，初始数组，再给 p 次 [l,r] 加 value，最后给 q 次区间求和。数值绝对值≤10^9。先差分修改并恢复，再建前缀和回答查询。
2. **自编 · 带权地毯：** 沿用 P3397，每张地毯多一个整数 value，表示区域加 value，绝对值≤10^9。输出最终矩阵，n、m≤1000。修改标记量和数组类型，体会方法不依赖“每次只加一”。

### 选做巩固

- **自编 · 覆盖恰好 k 次：** 沿用 P3397，再给 k，输出覆盖次数恰好为 k 的格子数，恢复后再进行统计。
- **自编 · 环形区间加：** 输入长度 n 的全零环形数组和 p 次加法。l>r 时将修改拆成 [l,n] 和 [1,r]，最后输出所有元素，l=r 只改一个位置。

## 本节验收

能解释修改为何只需两个端点或四个角；能在全部修改后恢复结果；能正确安排边界外一格，并把差分与前缀查询接起来。
