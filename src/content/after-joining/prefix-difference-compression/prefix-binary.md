## 这一节学什么

工具往往要组合使用：差分降低一次检查的成本，二分减少检查次数。我们先得到正确的暴力思路，分别找出两层重复劳动，再把每个优化放回原思路中。

> **AI 伴学提示词**
>
> 为我讲解借教室中的差分与二分组合，手动检查前 k 个订单，解释失败条件的单调性，并用闭区间和 ans 模拟寻找第一个失败订单，引导我对不理解的地方提问。

## 例题精讲：P1083 · 借教室

**原题：** [P1083 · 借教室](https://www.luogu.com.cn/problem/P1083)。

**题意简述：** n 天中第 i 天有 capacity[i] 间教室。m 个订单按先后顺序处理，第 j 个订单在闭区间 [s[j],t[j]] 每天借 quantity[j] 间。求第一个不能满足的订单。全部满足输出 0；否则先输出 −1，再输出该订单编号。n、m≤10^6，教室数和借用量≤10^9。

自拟输入：

```text
3 3
3 2 4
1 1 2
2 2 3
1 1 3
```

输出：

```text
-1
2
```

第一个订单后，各天累计需求为 1、1、0，可以满足。前两个订单累计需求为 1、3、2，第 2 天需求 3 超过容量 2，所以第二单首先失败。

## 第一步：写出能想明白的暴力过程

按顺序处理每单，把对应区间每天的剩余教室减去借用量。一旦某天不足，就知道当前订单失败。这个思路正确，但每单可能修改 n 天，最坏 O(nm)，把百万级数据代入就会发现不可行。

重复劳动有两层：每次区间修改逐天处理；为了找失败位置，逐个订单试过去。我们分开优化它们。

## 第二步：固定 k，检查前 k 单能否全部满足

暂时不追问第一单失败在哪里，只问“前 k 个订单是否已经出现不足”。对每个订单做差分区间加，把借用量累计在对应天数上，再一次恢复每日总需求。

```text
d[s[j]] += quantity[j];
d[t[j]+1] -= quantity[j];
```

若任何一天需求大于 capacity，就返回 true；否则返回 false。我们把函数命名为 check(k)，并约定 **true 表示前 k 单已经失败**。这个约定要先讲清楚，再写二分方向。

检查前 k 单的时间为 O(n+k)，不需要让每个订单分别遍历所有天。

## 第三步：失败位置具有单调性

借用量非负，订单越多，每天总需求只会增加，不会减少。因此：

```text
订单前缀长度 k：1   2   3   4   5   6
check(k)：     假  假  假  真  真  真
                           ↑
                     找到第一个真
```

使用闭区间 [le,r] 和 ans：

- check(mid) 为真：mid 已是一个失败候选，先令 ans=mid；再往左寻找更早的失败，r=mid−1。
- check(mid) 为假：前 mid 单都成功，第一单失败只能在右边，le=mid+1。

找到“满足失败条件”的候选后，先记下来再尝试更优，和之前二分查找第一个≥x 的思路一致。ans 保持 −1 表示没有失败订单。

## 完整代码：各层分别表达一个想法

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1000000 + 5;
int n, m, s[N], t[N];
long long capacity[N], quantity[N], d[N];

bool check(int k) {
    fill(d, d + n + 2, 0);
    for (int j = 1; j <= k; j++) {
        d[s[j]] += quantity[j];
        d[t[j]+1] -= quantity[j];
    }
    long long need = 0;
    for (int i = 1; i <= n; i++) {
        need += d[i];
        if (need > capacity[i]) return true;
    }
    return false;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> capacity[i];
    for (int j = 1; j <= m; j++) cin >> quantity[j] >> s[j] >> t[j];
    int le = 1, r = m, ans = -1;
    while (le <= r) {
        int mid = le + (r - le) / 2;
        if (check(mid)) {
            ans = mid;
            r = mid - 1;
        } else {
            le = mid + 1;
        }
    }
    if (ans == -1) cout << 0 << '\n';
    else cout << -1 << '\n' << ans << '\n';
    return 0;
}
```

每次 check 都从空差分数组开始，表示重新检查“前 k 单”。二分下一次的 k 可能变大，也可能变小，不能把上次的标记继续叠加。数组留出了 n+1 这一停止标记的位置。

每日累计需求可能达到 10^15，quantity、d、need 使用 long long。总时间 O((n+m)log(m+1))，空间 O(n+m)，最大规模下主要数组约 32 MB；百万级输入在开头关闭流同步。

## 回看：代码是怎样一步步从思路长出来的

先问“前 k 单是否已超额”，得到 check；再问“怎样批量累计每天需求”，得到差分；最后问“失败前缀能否从少到多分成两段”，得到二分。不是看到题目就猜模板，而是让每段代码回答一个明确的问题。

同样，如果所有修改结束后才查询区间和，可以先差分恢复，再做前缀和；如果数值坐标很大但端点不多，可以先离散化，再记录变化。组合工具前，先写清每一阶段数组中的数代表什么。

## 练习：把检查与寻找答案分开

先**独立重做 P1083**，检查第一单就失败、最后一单失败、全部成功、需求恰好等于容量，以及借用量为 0。

### 推荐必做

1. [P3406 · 海底高铁](https://www.luogu.com.cn/problem/P3406)：相邻城市之间有铁路，按旅行顺序统计每段铁路被经过的次数，再比较每段两种付费方式。一次从城市 u 到 v，会经过编号 min(u,v) 到 max(u,v)−1 的铁路，先想清城市下标与铁路下标的区别。
2. [P1873 · 砍树](https://www.luogu.com.cn/problem/P1873)：求满足木材需求的最大锯片高度。先判断某个高度能否满足，再在闭区间中记录可行答案并向更高处寻找。

### 选做巩固

- [P1182 · 数列分段](https://www.luogu.com.cn/problem/P1182)：把数列分成指定段数，使各段和的最大值最小。先判断一个最大段和能否安排，再二分寻找最小可行值。
- [P1672 · Feed Accounting S](https://www.luogu.com.cn/problem/P1672)：根据每头牛来吃饲料的日期与剩余量，找最近一次运货的日期。先用区间变化统计每日消耗，再用累计消耗判断候选日期。

## 本节验收

能明确 check 的真假含义；能先记录 ans 再往更优方向缩小闭区间；能解释每次检查为何清空差分，并能从暴力瓶颈推导需要组合的工具。
