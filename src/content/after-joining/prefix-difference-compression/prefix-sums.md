>
> 为我复习一维前缀和，再用 3×3 方格推导二维前缀和与矩形求和，逐项解释为什么相加相减，并引导我对不理解的地方提问。

## 一维：先累计，再相减

定义 s[i] 为 a[1] 到 a[i] 的和，s[0]=0。则 s[i]=s[i−1]+a[i]，区间 [l,r] 的和为 s[r]−s[l−1]。

例如 a={2,4,1,3}，前缀和为 {0,2,6,7,10}，第 2 到第 4 项之和是 10−2=8。一次 O(n) 预处理后，每次查询 O(1)。[招新前的递推一节](/ACMguide/learn/recurrence/)已经接触过这个做法。

## 二维：让 s[i][j] 保存左上角的一整块

行编号从上到下，列编号从左到右；s[i][j] 表示第 1 到 i 行、第 1 到 j 列的总和。

```text
原矩阵 a                 前缀和 s
1  2  3                  1   3   6
4  5  6                  5  12  21
7  8  9                 12  27  45
```

例如 s[2][2]=1+2+4+5=12。s[0][j]、s[i][0] 设为 0，表示空区域。

计算 s[i][j] 时，先拿上方的整块 s[i−1][j]，再拿左侧的整块 s[i][j−1]。两者左上角重叠的 s[i−1][j−1] 被算了两次，要减掉一次，最后加上当前格子：

```text
s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j];
```

这是一个递推：当前值只依赖上方、左方、左上方，因此从上到下、从左到右计算即可。

## 怎样取出任意矩形

要第 x1 到 x2 行、第 y1 到 y2 列：

1. 先拿 s[x2][y2]，包含目标以及多余的上方、左方。
2. 减去上方 s[x1−1][y2]。
3. 减去左方 s[x2][y1−1]。
4. 左上角同时属于上方与左方，被减了两次，补回 s[x1−1][y1−1]。

```text
sum = s[x2][y2] - s[x1-1][y2]
    - s[x2][y1-1] + s[x1-1][y1-1];
```

对上面的第 2—3 行、第 2—3 列，得到 45−6−12+1=28，正好是 5+6+8+9。请在草稿纸上把四块区域涂出来，再对照公式；这样比背符号更容易写对边界。

## 例题精讲：P2004 · 领地选择

**原题：** [P2004 · 领地选择](https://www.luogu.com.cn/problem/P2004)。

**题意简述：** n×m 的地图，每格有一个可能为负的价值，选择边长为 c 的正方形，使价值和最大，输出左上角的行列坐标。n、m≤1000，题目保证最优解唯一。

自拟输入：

```text
3 3 2
1 2 3
4 5 6
7 8 9
```

输出：

```text
2 2
```

### 枚举位置，快速计算每个位置的价值

先想暴力思路：枚举正方形左上角 (x,y)，把内部 c² 个数相加。候选位置约 nm 个，时间 O(nmc²)。重复劳动在于不同正方形反复累计同一批格子。

前缀和把每次区域求和降为 O(1)，**枚举所有位置的思路仍然保留，只替换“怎样计算当前候选的和”**。左上角范围为 x≤n−c+1、y≤m−c+1，右下角是 (x+c−1,y+c−1)。

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1000 + 5;
long long s[N][N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, c;
    cin >> n >> m >> c;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            int value;
            cin >> value;
            s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + value;
        }
    }
    long long best = -(1LL << 60);
    int answerX = 1, answerY = 1;
    for (int x = 1; x + c - 1 <= n; x++) {
        for (int y = 1; y + c - 1 <= m; y++) {
            int x2 = x + c - 1, y2 = y + c - 1;
            long long sum = s[x2][y2] - s[x-1][y2] - s[x2][y-1] + s[x-1][y-1];
            if (sum > best) {
                best = sum;
                answerX = x;
                answerY = y;
            }
        }
    }
    cout << answerX << ' ' << answerY << '\n';
    return 0;
}
```

> **负数与第一行、第一列都要考虑。**
>
> 全部价值为负时，best 不能从 0 开始，否则所有候选都无法更新答案。全局数组的第 0 行、第 0 列初始为 0，让矩形贴着上边界、左边界时仍可直接套用公式。1000×1000 格的累计值可能超过 int，因此 s 用 long long。

建表 O(nm)，枚举 O(nm)，合计 O(nm)，空间 O(nm)。一百万格只需要各处理常数次。

## 练习：先减区域，再写下标

先**独立重做 P2004**，测试 c=1、c 等于矩阵边长、最优区域贴边和全负数。

### 推荐必做

1. **自编 · 矩形查询：** 输入 n、m、q（n、m≤1000、q≤10^5），给矩阵，再给 q 个 x1、y1、x2、y2，每行输出对应闭矩形之和。数值绝对值≤10^9。练习一次预处理、多次 O(1) 查询。
2. **自编 · 区间内有几个达标值：** 输入长度 n 的数组、阈值 k 和 q 次 [l,r] 查询，n、q≤10^5，求区间内有多少元素≥k。先把每个位置转成 0 或 1，再做前缀和，体会“前缀统计”不只统计原数之和。

### 选做巩固

- **自编 · 环形数组求和：** 输入 n、q 与数组，查询从 l 沿编号增加方向走到 r 的和；l>r 表示跨过 n 回到 1。把跨边界区间拆成两段，l=r 只含一个位置。
- **自编 · 挖去小矩形：** 查询一个大矩形减去其中一个小矩形后的总和，保证小矩形完全包含在大矩形里。练习用两次区域求和组合结果。
