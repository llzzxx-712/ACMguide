## 这一节学什么

编号或坐标很大，但真正出现的数并不多时，可以先收集所有需要的值，排序去重，再用它们在有序表中的位置作为新编号，这就是离散化。重点是想清楚：题目需要相对顺序，还是还要保留原来的距离。

> **AI 伴学提示词**
>
> 为我讲解离散化，用负数、大坐标和重复值模拟排序、去重、二分编号，再讲清编号间距为什么不能代替真实长度，并引导我对不理解的地方提问。

## 坐标很大，出现过的值却很少

输入值为 {1000000000,−5,42,−5}。如果直接拿这些值当数组下标，既有负数，又要开很大的数组。收集、排序、去重得到：

| 新编号（从 0 开始） | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 原值 | −5 | 42 | 1000000000 |

相同原值映射到相同编号，大小关系也保持不变：−5<42，对应 0<1。原来有多大并不影响新数组的长度。

```text
sort(xs.begin(), xs.end());
xs.erase(unique(xs.begin(), xs.end()), xs.end());
int id = lower_bound(xs.begin(), xs.end(), value) - xs.begin();
```

unique 会把相邻重复值合并到前段，返回有效部分的末尾；erase 删除后面的无效部分。lower_bound 找到第一个≥value 的位置，本节待查询的值都已收集，因此正好找到它的新编号。迭代器相减得到位置，赋给 int id 即可。

如果需要手写二分，也沿用闭区间与 ans：xs[mid]≥value 时先记录 mid，再向左找更小的位置；小于时向右找。这里用标准库把已经学过的查找步骤表达出来。

> **离散化保留顺序，不保留距离。**
>
> 编号 0、1 相差 1，但原值 −5、42 相差 47。只比较大小、判相等、给结点编号时可以用新编号；计算路程、长度、面积时要回到 xs 中的原值。

## 例题精讲：P1496 · 火烧赤壁

**原题：** [P1496 · 火烧赤壁](https://www.luogu.com.cn/problem/P1496)。

**题意简述：** 给 n 个着火区间 [a,b)，求被至少一个区间覆盖的总长度，重叠部分只算一次。n≤2×10^4，端点可能为负，范围在 32 位有符号整数内。

自拟输入：

```text
3
-2 2
1 5
8 10
```

输出为 `9`：前两段合起来覆盖 [−2,5)，长 7；第三段长 2。

### 为什么只保留端点就够了

所有端点排序为 −2、1、2、5、8、10。相邻端点之间没有任何区间开始或结束，所以**整段间隙的覆盖次数相同**。

| 间隙 | 覆盖次数 | 计入长度 |
| --- | --- | --- |
| [−2,1) | 1 | 3 |
| [1,2) | 2 | 1 |
| [2,5) | 1 | 3 |
| [5,8) | 0 | 0 |
| [8,10) | 1 | 2 |

把端点映射成编号后，区间 [a,b) 变成从 L 到 R 开始/停止影响：d[L]++、d[R]--。恢复到编号 i 时，累计覆盖次数对应的是 **[xs[i],xs[i+1]) 这段间隙**。若次数>0，加入真实长度 xs[i+1]−xs[i]。

这里右端 b 不属于区间，从 R 就应停止，不能照搬闭区间下标修改的 r+1。我们是根据区间含义推导停止位置，再写代码。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> left(n), right(n), xs;
    for (int i = 0; i < n; i++) {
        cin >> left[i] >> right[i];
        xs.push_back(left[i]);
        xs.push_back(right[i]);
    }
    sort(xs.begin(), xs.end());
    xs.erase(unique(xs.begin(), xs.end()), xs.end());
    int count = xs.size();
    vector<int> d(count + 1);
    for (int i = 0; i < n; i++) {
        int l = lower_bound(xs.begin(), xs.end(), left[i]) - xs.begin();
        int r = lower_bound(xs.begin(), xs.end(), right[i]) - xs.begin();
        d[l]++;
        d[r]--;
    }
    int cover = 0;
    long long answer = 0;
    for (int i = 0; i + 1 < count; i++) {
        cover += d[i];
        if (cover > 0) answer += xs[i+1] - xs[i];
    }
    cout << answer << '\n';
    return 0;
}
```

注意最后一个端点后没有下一段间隙，循环条件为 i+1<count。端点和长度差用 long long，确保减法本身不会在 int 中溢出。

最多 2n 个端点，排序与映射共 O(n log n)，恢复 O(n)，空间 O(n)。输入先全部收集，才能知道完整的编号表，这种提前准备的数据处理方式也叫离线处理。

## 练习：明确新编号要保留什么

先**独立重做 P1496**，检查重叠、相接、完全包含、重复区间以及负坐标。

### 推荐必做

1. [B3694 · 数列离散化](https://www.luogu.com.cn/problem/B3694)：对每个数输出比它小的不同数字个数加一。将数值排序去重，再查找每项编号；多组数据分别处理。
2. [P1955 · 程序自动分析](https://www.luogu.com.cn/problem/P1955)：判断相等与不等约束能否同时满足。收集所有大编号并离散化，先合并相等关系，再检查不等关系。

### 选做巩固

- [P1097 · 统计数字](https://www.luogu.com.cn/problem/P1097)：统计每个数字出现的次数并按数值升序输出。把不同数映射到连续编号后计数，再根据原数输出。
- [P8667 · 递增三元组](https://www.luogu.com.cn/problem/P8667)：统计三个数组中满足 A[i]<B[j]<C[k] 的三元组数。合并数值排序去重，再按编号计算 B[j] 两侧的数量，注意相等值不计入。
