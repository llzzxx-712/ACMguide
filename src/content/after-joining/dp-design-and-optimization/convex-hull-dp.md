## 这一节学什么

有些候选的优劣随当前 i 改变，不能仅按一个固定的 f[j] 排队。把公式展开后，若能写成“只与 i 有关的常数，加上关于 j 的直线取最值”，就可以用凸壳维护这些候选。

> **AI 伴学提示词**
>
> 为我讲解二次 DP 怎样展开为点与直线，手算候选交替和三点淘汰，解释单调性与整数乘法范围，并引导我提问。

## 例题精讲：自编 · 分段长度接近目标

**题意简述：** 给 n 个正整数长度，将序列划分为若干非空连续段，每段费用为“该段总长度−C”的平方，求最小总费用。n≤10⁵，所有长度之和≤10⁵，0≤C≤10⁵。输入 n、C，再输入各长度。

输入 `3 3` 和 `1 2 3`，输出 `0`，分为 [1,2]、[3]，两段长度都为 3。

## 先写 O(n²) 转移，再展开平方

令 X[i] 为前 i 项长度和，f[i] 为划分前 i 项的最小费用，f[0]=0：

```text
f[i] = min_j { f[j] + (X[i]-X[j]-C)² }，0≤j<i
令 t = X[i]-C，Y[j]=f[j]+X[j]²
f[i] = t² + min_j { Y[j]-2tX[j] }
```

每个前驱 j 对应点 (X[j],Y[j])；查询时比较 Y−2tX，等价于斜率为 2t 的直线从下方向上接触点集。上方永远碰不到的点不必保留，只维护下凸壳。

## 两种单调性分别用于两端

长度为正，因此 X[j] 严格递增，t 也递增。

- 队首两个候选中，后一项在当前 t 已经不差，未来更大的 t 会更偏向它，可以弹掉前者。
- 新点加入队尾时，若连续三点 a、b、c 的斜率满足 slope(a,b)≥slope(b,c)，中间点 b 不在下凸壳上，删除。

交叉相乘比较斜率，避免浮点除法与分母为 0。本例 X 严格递增，因此分母均为正。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long target;
    cin >> n >> target;
    vector<long long> x(n + 1), f(n + 1), y(n + 1);
    for (int i = 1; i <= n; i++) { long long a; cin >> a; x[i] = x[i-1] + a; }
    auto value = [&](int j, long long t) { return y[j] - 2 * t * x[j]; };
    auto bad = [&](int a, int b, int c) {
        return (y[b]-y[a]) * (x[c]-x[b]) >= (y[c]-y[b]) * (x[b]-x[a]);
    };
    deque<int> hull;
    hull.push_back(0);
    for (int i = 1; i <= n; i++) {
        long long t = x[i] - target;
        while (hull.size() >= 2 && value(hull[0], t) >= value(hull[1], t)) hull.pop_front();
        f[i] = t * t + value(hull.front(), t);
        y[i] = f[i] + x[i] * x[i];
        while (hull.size() >= 2 && bad(hull[hull.size()-2], hull.back(), i)) hull.pop_back();
        hull.push_back(i);
    }
    cout << f[n] << '\n';
    return 0;
}
```

每个点最多进出队一次，总时间 O(n)、空间 O(n)。先查询再加入 i，保证前驱严格为 j<i，不会使用空的新段。

> **展开后的中间量也要检查范围。**
>
> 本例可把所有前缀放一段，故 0≤f[i]≤10¹⁰；Y≤2×10¹⁰，X 差≤10⁵，交叉乘积不超过约 2×10¹⁵，long long 足够。更换范围后必须重新算这些乘积，不能只看最终答案。

如果 X 有相同值，要先合并同 X 下较小 Y；如果查询 t 不单调，不能继续永久弹队首，应在完整凸壳上查找；如果斜率与查询都无序，需要其他直线维护结构。先核对条件，再采用对应实现。

## 练习：让每个几何量回到原 DP 变量

先**独立重做本例**，写 O(n²) 版本对拍，覆盖 C=0、C 大于总长、所有长度为 1。

### 推荐必做

1. **自编 · 记录分段点：** 查询凸壳得到 j 时保存它，恢复所有最优段并核算平方费用。
2. **自编 · 每段增加固定费用：** 费用改为平方加 K，推导展开式，确认新增项放在哪里，比较分段数量怎样变化。

### 选做巩固

- **自编 · 相同横坐标：** 允许长度为 0，先处理同 X 候选，再维护凸壳，避免斜率分母为 0。
- **自编 · 随机打印壳：** 对 n≤20，逐次画出 (X,Y)，检查被删除点为何不会再成为最佳候选。
