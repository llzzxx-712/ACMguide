## 例题精讲：自编 · 跳跃范围内的最大收益

**题意简述：** 位置 0 出发，每步前进 L 到 R 格，落在 i 得分 a[i]，求恰好到 n 的最大总分，不可达输出 IMPOSSIBLE。n≤2×10⁵，1≤L≤R≤n，|a[i]|≤10⁹。输入 n、L、R，再输入 a[1…n]。

输入 `5 2 3`，得分为 `1 5 2 4 3`，输出 `8`，走 0→2→5，得 5+3；0→3→5 只能得 2+3。

## 朴素转移先确定候选是谁

f[i]=a[i]+max(f[j])，j∈[i−R,i−L]，且 j≥0。初始 f[0]=0，其余不可达。若逐个枚举 j，时间 O(n(R−L+1))。

i 每次增加 1，候选右端 i−L 也增加 1，左端 i−R 也增加 1，是滑动窗口最值。用单调队列保存下标，使对应 f 值从队首到队尾递减。

新候选 j 的 f 不小于旧队尾，并且 j 更晚过期，旧队尾就不可能再成为最优，弹出；队首小于 i−R 则过期。不可达状态根本不入队。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, L, R;
    cin >> n >> L >> R;
    vector<long long> a(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];
    const long long NEG = -(1LL << 62);
    vector<long long> f(n + 1, NEG);
    f[0] = 0;
    deque<int> q;
    for (int i = 1; i <= n; i++) {
        int enter = i - L;
        if (enter >= 0 && f[enter] != NEG) {
            while (!q.empty() && f[q.back()] <= f[enter]) q.pop_back();
            q.push_back(enter);
        }
        while (!q.empty() && q.front() < i - R) q.pop_front();
        if (!q.empty()) f[i] = f[q.front()] + a[i];
    }
    if (f[n] == NEG) cout << "IMPOSSIBLE\n";
    else cout << f[n] << '\n';
    return 0;
}
```

每个下标入队一次、最多从某端出队一次，时间 O(n)，空间 O(n)。答案可累计到约 2×10¹⁴，用 long long。队列为空时保持不可达，不能让负无穷与得分相加后变成假答案。

## 求和与非单调范围怎样处理

若转移是所有合法前驱方案数相加，可以令 P[x]=Σf[0…x]，用 P[i−L]−P[i−R−1]，负下标的前缀贡献视为 0，并按模数规范化。

若候选区间不能按单调方式前进，普通单调队列可能丢掉未来还需要的点；可以用线段树做区间最值。若候选含额外项，先把只与 j 有关的部分提出来，例如 f[j]−cost[j]，队列比较的应是这个完整候选值。

## 练习：将队列每次变化对应回一个前驱

先**独立重做本例**，和逐个枚举 j 的 O(nR) 版本对拍，测试 L=R、负得分、终点不可达。

### 推荐必做

1. **自编 · 范围跳跃计数：** 目标改成走法数量，对 10⁹+7 取模，用前缀和替代 max，初始化空路线 f[0]=1。
2. **自编 · 每个位置有不同合法范围：** 输入每个 i 的 [le[i],r[i]] 且都小于 i，使用线段树保存已求得的 f，查询范围最大值。

### 选做巩固

- **自编 · 恢复跳跃路线：** 计算 f[i] 时记队首为前驱，结束后回溯到 0。
- **自编 · 等值候选：** 让多个 f[j] 相等，比较保留较晚下标为何能更久服务未来窗口。
