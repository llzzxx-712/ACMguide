## 这一节学什么

经典数列的价值在于背后的分类方式。错排按“第一个人和谁交换”拆分；卡特兰数按“第一个左括号在哪里匹配”拆分。先说清分类怎样覆盖全部方案，再把它写成递推。

## 错排：没有人回到原位置

令 `D[n]` 为 n 个不同元素的排列中，没有任何元素留在原位置的方案数。$D_0=1$（空方案一种），$D_1=0$。

第 1 个元素去位置 j，有 n−1 种选法。再按元素 j 是否去位置 1 分两类：

- 若去，1 与 j 构成一个二元环，剩下 n−2 个元素错排，贡献 `D[n - 2]`。
- 若不去，把 1 到 j 这一步收缩，相当于剩下 n−1 个元素的错排，贡献 `D[n - 1]`。可以从排列的环表示理解：删去环中的元素 1，其前驱直接接到 j；反向插入能唯一还原。

因此 $D_n=(n-1)(D_{n-1}+D_{n-2})$。前几项为 1、0、1、2、9。

## 卡特兰数：第一个匹配把问题分成两边

令 `C[n]` 为 n 对合法括号的数量。第一个字符必须是左括号，若它的匹配右括号内部有 i 对，那么后面有 n−1−i 对；两部分都必须合法，且可以独立选择。

```text
( 内部 i 对 ) 后面 n-1-i 对
```

所以 $C_0=1$，$C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i}$。n=3 时五种是 `()()()`、`()(())`、`(())()`、`(()())`、`((()))`。

合法出入栈序列、以每个结点左右子树为空或非空来区分的二叉树形状，也可以按第一次匹配或根的两侧拆成同样的递推。

## 例题精讲一：[P1595 信封问题](https://www.luogu.com.cn/problem/P1595)

**题意简述：** n 封不同的信装入 n 个信封，要求全部装错，求方案数。输入 n，1≤n≤20，输出精确整数。

自编输入：

```text
3
```

输出：

```text
2
```

### 先把思路讲清楚

对三封信，合法排列为 `[2, 3, 1]` 与 `[3, 1, 2]`。考虑第一封信放入 j 的信封，有 n−1 种 j；再按 j 的信是否回到第一个信封分类，分别变成 n−2 或 n−1 个元素的错排，得到 $D_n=(n-1)(D_{n-1}+D_{n-2})$。

边界 $D_0=1$、$D_1=0$，代码从 2 开始递推。本题 n≤20，最大 `D[20] = 895014631192902121`，在 `long long` 范围内，不取模。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> d(max(n + 1, 2), 0);
    d[0] = 1;
    for (int i = 2; i <= n; i++) d[i] = (i - 1) * (d[i - 1] + d[i - 2]);
    cout << d[n] << '\n';
    return 0;
}
```

时间 $\mathcal{O}(n)$，空间 $\mathcal{O}(n)$。

## 例题精讲二：[P1044 栈](https://www.luogu.com.cn/problem/P1044)

**题意简述：** 1…n 按顺序入栈，中途可随时弹出，求不同出栈序列数量。输入 1≤n≤18，输出整数。

自编输入：

```text
3
```

输出：

```text
5
```

### 先把思路讲清楚

把一次入栈看作左括号，出栈看作右括号；任意前缀出栈次数不超过入栈次数，最终两者相同，所以操作序列对应合法括号串。由于入栈次序固定，操作序列也决定出栈序列。

与第一个左括号匹配的右括号，将剩下 $n-1$ 对分成内侧 $\ell$ 对和外侧 $n-1-\ell$ 对，贡献 $C_\ell C_{n-1-\ell}$。代码中的 `left` 对应这里的 $\ell$，枚举它并把贡献相加，边界为 $C_0=1$。

例如 $n=3$ 时：

$$
C_3=C_0C_2+C_1C_1+C_2C_0=2+1+2=5.
$$

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> c(n + 1);
    c[0] = 1;
    for (int i = 1; i <= n; i++) {
        for (int left = 0; left < i; left++) c[i] += c[left] * c[i - 1 - left];
    }
    cout << c[n] << '\n';
    return 0;
}
```

时间 $\mathcal{O}(n^{2})$，空间 $\mathcal{O}(n)$。两道题虽然都能递推，分类依据不同：一个看信件归属，一个看第一对括号。先说清不重不漏的分类，再写循环。
