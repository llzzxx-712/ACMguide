## 这一节学什么

经典数列的价值在于背后的分类方式。错排按“第一个人和谁交换”拆分；卡特兰数按“第一个左括号在哪里匹配”拆分。先说清分类怎样覆盖全部方案，再把它写成递推。

## 错排：没有人回到原位置

令 D[n] 为 n 个不同元素的排列中，没有任何元素留在原位置的方案数。D[0]=1（空方案一种），D[1]=0。

第 1 个元素去位置 j，有 n−1 种选法。再按元素 j 是否去位置 1 分两类：

- 若去，1 与 j 构成一个二元环，剩下 n−2 个元素错排，贡献 D[n−2]。
- 若不去，把 1 到 j 这一步收缩，相当于剩下 n−1 个元素的错排，贡献 D[n−1]。可以从排列的环表示理解：删去环中的元素 1，其前驱直接接到 j；反向插入能唯一还原。

因此 D[n]=(n−1)(D[n−1]+D[n−2])。前几项为 1、0、1、2、9。

## 卡特兰数：第一个匹配把问题分成两边

令 C[n] 为 n 对合法括号的数量。第一个字符必须是左括号，若它的匹配右括号内部有 i 对，那么后面有 n−1−i 对；两部分都必须合法，且可以独立选择。

```text
( 内部 i 对 ) 后面 n-1-i 对
```

所以 C[0]=1，C[n]=Σ(i=0…n−1)C[i]·C[n−1−i]。n=3 时五种是 `()()()`、`()(())`、`(())()`、`(()())`、`((()))`。

合法出入栈序列、以每个结点左右子树为空或非空来区分的二叉树形状，也可以按第一次匹配或根的两侧拆成同样的递推。

## 例题精讲：自编 · 两个经典计数一起算

**题意简述：** 输入 0≤n≤2000，输出 D[n] 和 C[n]，均对 10⁹+7 取模。输入 `3`，输出 `2 5`。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const long long MOD = 1000000007;

int main() {
    int n;
    cin >> n;
    vector<long long> derangement(n + 1), catalan(n + 1);
    derangement[0] = catalan[0] = 1;
    for (int i = 2; i <= n; i++) {
        derangement[i] = (i - 1) * (derangement[i - 1] + derangement[i - 2]) % MOD;
    }
    for (int length = 1; length <= n; length++) {
        for (int inside = 0; inside < length; inside++) {
            catalan[length] = (catalan[length] + catalan[inside] * catalan[length - 1 - inside]) % MOD;
        }
    }
    cout << derangement[n] << ' ' << catalan[n] << '\n';
    return 0;
}
```

数组初值使 D[1]=0；没有对 n=0 的数组越界赋值。时间 O(n²)，空间 O(n)，约两百万次卡特兰转移。每次乘积与加法均可放入 long long，且及时取模。

卡特兰数也可写为 C(2n,n)−C(2n,n−1)，等价于 C(2n,n)/(n+1)。模意义下使用后一个式子，需要 n+1 可逆；用阶乘预处理还要求相应阶乘非零，不能直接照搬普通除法。本节用递推让计算过程与划分思路完全对应。
