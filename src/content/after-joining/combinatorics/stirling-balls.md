## 这一节学什么

“把球放入盒子”不是一个固定公式。球是否不同、盒子是否编号、能否有空盒子，都直接改变答案。先把这些条件说清楚，再考虑排列组合、递推或容斥。

> **AI 伴学提示词**
>
> 为我比较不同球、相同球和有无编号盒子的区别，从最后一个球推导第二类斯特林数，再引导我提问。

## 四种常见模型

| n 个球、k 个盒子 | 允许空盒 | 每盒非空 |
| --- | --- | --- |
| 不同球、有编号盒子 | kⁿ | k!·S(n,k) |
| 不同球、无编号盒子 | Σ(j=0…k)S(n,j) | S(n,k) |
| 相同球、有编号盒子 | k≥1 时 C(n+k−1,k−1) | n≥k≥1 时 C(n−1,k−1) |
| 相同球、无编号盒子 | n 的至多 k 部分整数划分 | n 的恰好 k 部分整数划分 |

相同球、有编号盒子的情况是隔板法：每盒至少一个时，把 n 个球间的 n−1 个空隙中选 k−1 个放隔板。允许空盒时先给每盒补一个虚拟球，转成非空模型。无编号盒子则不能通过给所有方案统一除以 k! 解决，因为含有相同大小盒子的方案会产生不同数量的重复。

## 第二类斯特林数怎样递推

S(n,k) 把 n 个不同元素划成 k 个无编号、非空集合。考虑最后一个元素：

1. 自己单独成组，前 n−1 个元素分成 k−1 组，贡献 S(n−1,k−1)。
2. 加入已有组，前 n−1 个元素先分成 k 组，再选一组加入，贡献 k·S(n−1,k)。

因此 S(n,k)=S(n−1,k−1)+kS(n−1,k)，S(0,0)=1。n>0 时 S(n,0)=0，k>n 时也为 0。虽然组没有编号，但一个已经确定的划分确实包含 k 个不同的集合，所以第二类有 k 种加入位置。

## 例题精讲：[P1287 盒子与球](https://www.luogu.com.cn/problem/P1287)

**题意简述：** 输入 n、k，0≤k≤n≤10，将 n 个不同球放进 k 个不同盒子，每盒至少一个，输出精确方案数，原题保证答案小于 2³¹。先形成无编号集合，再把 k 个盒子标签分配给这些组，故答案为 S(n,k)·k!。

自编输入 `3 2`，输出 `6`：三个球任意选择一个单独成组有 3 种，再给两组分配编号有 2 种。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    if (k > n) { cout << 0 << '\n'; return 0; }
    vector<long long> s(k + 1);
    s[0] = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = min(i, k); j >= 1; j--) {
            s[j] = s[j - 1] + j * s[j];
        }
        s[0] = 0;
    }
    long long factorial = 1;
    for (int i = 1; i <= k; i++) factorial = factorial * i;
    cout << s[k] * factorial << '\n';
    return 0;
}
```

倒序 j 保证两项都来自前一行；每行结束后把 s[0] 设为 0，表示非空元素不能分成零组。n=k=0 时只有空放法，答案为 1；n>0、k=0 时为 0。时间 O(nk)，空间 O(k)。

## 与容斥核对

同一个答案也可以从全部 kⁿ 个放法中排除空盒，得到 Σ(j=0…k)(−1)^j C(k,j)(k−j)ⁿ。这里“指定哪些盒子为空”和“实际还可能有更多空盒”正是需要容斥纠正的重叠。小数据用两种办法互相核对，比孤立记住两个公式更有帮助。
