## 这一节学什么

计数题先要说清“哪些方案算不同”。选 3 人组成小组不区分顺序，选 3 人分别担任三个职务则区分顺序；这一步决定我们算组合数还是排列数。

>

## 公式来自怎样的选择过程

从 n 个不同元素里选 k 个排成一列，有 A(n,k)=n(n−1)…(n−k+1) 种；如果只要集合，每组被 k! 种顺序重复计算，故 C(n,k)=n!/[k!(n−k)!]。定义 C(n,0)=1，k<0 或 k>n 时为 0。

把第 n 个元素分成“选”和“不选”两类，得到 C(n,k)=C(n−1,k−1)+C(n−1,k)。这种证明同时说明两类互不重叠、没有遗漏，也直接给出杨辉三角的计算顺序。

其他恒等式同样可以问“我在数什么”：

- C(n,k)=C(n,n−k)：选中的集合与没选中的集合一一对应。
- ΣC(n,k)=2ⁿ：每个元素选或不选，也可以按集合大小分类。
- ΣC(a,k)C(b,r−k)=C(a+b,r)：从两组人中总共选 r 人，按第一组选了多少人分类。

展开 (a+b)ⁿ 时，每个括号选择 a 或 b。恰好选 k 个 b 的项共有 C(n,k) 个，所以对应系数为 C(n,k)·a^(n−k)·b^k。这就是二项式定理，不需要把展开式逐项乘出来。

## 例题精讲：[P2822 组合数问题](https://www.luogu.com.cn/problem/P2822)

**题意简述：** 给定 k，多次询问 0≤i≤n、0≤j≤min(i,m) 中，有多少个 C(i,j) 能被 k 整除。原题 n,m≤2000，k 为 2…21，询问最多 10⁴ 次。

自编输入：

```text
2 2
2 2
3 1
```

输出两行 `1`、`1`，唯一符合的都是 C(2,1)=2。

## 先标记，再数矩形

只关心是否整除，递推时保存 C(i,j) mod k 即可，不需要保存巨大的组合数。将合法位置且余数为 0 的格子标为 1，查询就是左上角矩形中的 1 的数量，可用二维前缀和 O(1) 回答。

当 j>i 时，这个位置根本不是题目要数的组合数，不能因为数组初值为 0 就误算成“整除”。j=0 的组合数恒为 1，因 k≥2，不会贡献答案。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q, k;
    cin >> q >> k;
    const int N = 2000;
    vector<vector<int>> c(N + 1, vector<int>(N + 1));
    vector<vector<int>> sum(N + 1, vector<int>(N + 1));
    c[0][0] = 1;
    for (int i = 1; i <= N; i++) {
        c[i][0] = 1;
        for (int j = 1; j <= i; j++) {
            c[i][j] = (c[i - 1][j - 1] + c[i - 1][j]) % k;
        }
        for (int j = 1; j <= N; j++) {
            int good = (j <= i && c[i][j] == 0);
            sum[i][j] = sum[i - 1][j] + sum[i][j - 1] - sum[i - 1][j - 1] + good;
        }
    }
    while (q--) {
        int n, m;
        cin >> n >> m;
        cout << sum[n][m] << '\n';
    }
    return 0;
}
```

最边上一项读取的 c[i−1][i] 在已分配数组内，含义是越出上一行三角形的 0。前缀和不超过约两百万，用 int 足够。预处理时间、空间 O(2000²)，全部询问 O(q)。这也演示了数学递推与前缀和怎样组合成完整解法。
