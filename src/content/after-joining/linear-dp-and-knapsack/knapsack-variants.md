## 这一节学什么

一件物品可能同时消耗体积和重量，附件可能必须跟主件一起购买，题目也可能要求数方案。这些变化都要回到状态与选择：保留多少资源信息，哪些组合合法，合并时是取最优还是相加。

## 例题精讲：P1507 · NASA 的食物计划

**原题：** [P1507 · NASA 的食物计划](https://www.luogu.com.cn/problem/P1507)。

**题意简述：** 每件食物最多一次，消耗体积 h、质量 t，获得卡路里 v。总体积不超过 H、总质量不超过 T，最大化卡路里。H、T≤400，n≤50。

输入：

```text
5 5
3
3 3 6
2 2 5
5 1 8
```

输出 `11`，前两件合起来体积和质量都为 5，优于只选第三件。

### 两种资源都必须进入状态

f[h][t] 表示体积上限 h、质量上限 t 时的最大收益。某件食物能选时，从 f[h−volume][t−mass] 转移。不能只按总体积记状态，因为同样体积下不同质量会影响后续选择。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int H, T, n;
    cin >> H >> T >> n;
    vector<vector<int>> f(H + 1, vector<int>(T + 1));
    for (int i = 0; i < n; i++) {
        int volume, mass, value;
        cin >> volume >> mass >> value;
        for (int h = H; h >= volume; h--) {
            for (int t = T; t >= mass; t--) {
                f[h][t] = max(f[h][t], f[h-volume][t-mass] + value);
            }
        }
    }
    cout << f[H][T] << '\n';
    return 0;
}
```

两维倒序表示来源仍是选当前物品之前的状态。时间 O(nHT)，最大约八百万次状态更新，空间 O(HT)。

## 依赖关系：不能只检查装不装得下

买附件必须买主件时，先枚举“主件”“主件+附件一”“主件+附件二”“主件+两附件”等合法组合，把同一主件的组合视为一组。附件单独出现不是合法选项，组内也只能选一个组合。

若依赖是一棵树，先选父亲才能进入孩子，则要在子树内分配名额或容量，第十八章会用树形背包完整实现。把父亲与孩子简单当作互不相关物品，会丢掉依赖条件。

## 计数：明确数的是什么

若求恰好重量 c 的子集数，ways[0]=1，其余为 0。每件物品倒序：`ways[c]+=ways[c-w]`。这个加法数的是不同子集，选或不选当前编号的物品形成互不重叠两类。

若求“达到最大收益的方案数”，同时维护 best、ways：候选更优时替换 best，并令 ways 等于来源方案数；候选相等时累加 ways；更差时不变。要明确容量是恰好还是至多，避免把同一子集因剩余容量不同重复计数。

一种稳妥写法是按**恰好使用的容量**初始化 best[0]=0、ways[0]=1，其余不可达；最后在所有不超过预算的容量中找最大 best，并只累计达到这个最大值的 ways。

## 练习：先写完整的状态定义

先**独立重做 P1507**，对 n≤18 枚举子集，同时核对两种资源，测试某一维恰好达到上限。

### 推荐必做

1. **自编 · 主件和附件：** 每个主件最多两个附件，容量≤5000。枚举合法组合后做分组背包，用反例检查是否允许了单买附件。
2. **自编 · 最优子集数量：** n≤100，正重量≤1000，容量≤5000、非负价值，输出最大收益与最优子集数，对 10⁹+7 取模。先按恰好重量记状态，再汇总预算内答案。

### 选做巩固

- **自编 · 恰好两种消耗：** 要求体积、质量都恰好用满，只有 (0,0) 可达，重新处理初始值。
- **自编 · 相同数值的不同物品：** 两件重量价值一样但编号不同，检查它们是否按题意算作不同子集，不能直接去重。
