## 这一节学什么

单人网格 DP 的当前位置通常只需行、列。两个人的收益互相影响时，分别求最优再相加可能重复取数，需要把两人的位置放进同一个状态。维数增加来自题目要求，并不是看到复杂题就多开数组。

> **AI 伴学提示词**
>
> 为我讲解双路径网格 DP，用同步步数减少一维，手算四种前驱与相遇时只取一次，并引导我提问。

## 例题精讲：P1004 · 方格取数

**原题：** [P1004 · 方格取数](https://www.luogu.com.cn/problem/P1004)。

**题意简述：** n×n 网格，部分格子有正数，其余为 0。从左上到右下走两次，每次只能向右或向下，同一个格子的数只能取得一次，最大化总和。n≤9，格值≤30。先输入 n，再输入若干行 x y value，输入 0 结束。

输入：

```text
2
1 1 1
1 2 2
2 1 3
2 2 4
0
```

输出 `10`。两条路线分别经过右上与左下，起终点虽然都经过两遍，但只取一次。

## 不先贪心固定第一条路

一条单独收益最大的路线，可能占用许多两条路都容易取得的格子，从而破坏整体最优。把两次行走看作两人同时出发，在每一步共同选择方向，才能比较完整方案。

如果直接保存 (r₁,c₁,r₂,c₂)，有四个位置下标。但第 k 条反对角线上，r₁+c₁=r₂+c₂=k，因此 c₁=k−r₁、c₂=k−r₂。只保留 k、r₁、r₂ 就够了。

## 四种前驱来自两次独立的方向选择

每个人上一格在上方或左侧，对应上一层行号为当前行−1 或当前行。因此枚举四种组合，取最大，再加本层两格收益。若 r₁=r₂，两人同在一个格子，只加一次。

```text
状态：f[k][r1][r2]
前驱：(r1,r2)、(r1-1,r2)、(r1,r2-1)、(r1-1,r2-1)
收益：a[r1][k-r1] + a[r2][k-r2]，相遇时去掉重复的一份
```

每个格子的行列和固定，因此两条路若经过同一格，必在同一个 k 相遇。这样扣除重复就不会漏掉不同时间的重叠。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> a(n + 1, vector<int>(n + 1));
    int x, y, value;
    while (cin >> x && x != 0) { cin >> y >> value; a[x][y] = value; }
    const int NEG = -1000000000;
    vector<vector<int>> previous(n + 1, vector<int>(n + 1, NEG));
    previous[1][1] = a[1][1];
    for (int k = 3; k <= 2 * n; k++) {
        vector<vector<int>> current(n + 1, vector<int>(n + 1, NEG));
        for (int r1 = max(1, k - n); r1 <= min(n, k - 1); r1++) {
            for (int r2 = max(1, k - n); r2 <= min(n, k - 1); r2++) {
                int best = max({previous[r1][r2], previous[r1-1][r2],
                                previous[r1][r2-1], previous[r1-1][r2-1]});
                if (best == NEG) continue;
                int gain = a[r1][k-r1];
                if (r1 != r2) gain += a[r2][k-r2];
                current[r1][r2] = best + gain;
            }
        }
        previous = current;
    }
    cout << previous[n][n] << '\n';
    return 0;
}
```

只初始化真正的起点，其他状态设不可达。第 0 行也保留 NEG，作为不合法前驱的边界。每层只依赖上一层，所以滚动为两个 n×n 表，时间 O(n³)、空间 O(n²)。

## 从两条路推广时先检查冲突规则

若题目改成两条路中间不能相交，应在非起终点处排除 r₁=r₂；若每个格子可重复收费，则相遇也要加两份。状态可以一样，收益与合法性判断却必须随题意改变。

## 练习：先在小棋盘画出两条完整路线

先**独立重做 P1004**，枚举 n≤4 时的所有单路径，再枚举路径对取并集收益，核对 DP。

### 推荐必做

1. **自编 · 禁止中间相交：** 沿用网格和两条路线，只允许起终点重合，修改合法性判断，测试 n=2。
2. **自编 · 长方形网格：** 扩展成 n×m，推导 k、行号范围与最终状态，不能继续把终止步数写成 2n。

### 选做巩固

- **自编 · 障碍格：** 某些格不可走，两人都必须避开；若终态不可达输出 IMPOSSIBLE。
- **自编 · 恢复双路径：** 对每层保存最优前驱组合，从最终状态还原两条路线，验证取数总和。

对应题单：[自编入门题单](https://www.luogu.com.cn/training/1126196)、[线性状态动态规划 #212](https://www.luogu.com.cn/training/212)。
