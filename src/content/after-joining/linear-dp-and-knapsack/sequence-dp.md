## 这一节学什么

子序列允许跳过元素，但保留原先顺序；子串必须连续。LIS 关注一个序列的递增关系，LCS 关注两个序列的共同顺序，编辑距离关注把一个串变成另一个串需要多少次操作。

> **AI 伴学提示词**
>
> 为我讲解 LIS、LCS 与编辑距离，按结尾和前缀定义状态，手填小表格，解释各个转移对应的实际操作，并引导我提问。

## LIS：为什么状态要说“以 $i$ 结尾”

`f[i]` 为以 `a[i]` 结尾的严格上升子序列最大长度。枚举之前的 $j$，若 $a[j]<a[i]$，可以接上：`f[i] = max(f[i], f[j] + 1)`，初值为 1，答案为所有 `f[i]` 的最大值，$\mathcal{O}(n^{2})$。

若只问长度，可令 `tails[len]` 为长度为 $\mathrm{len}$ 的递增子序列最小结尾。新数 $x$ 替换第一个不小于 $x$ 的位置；没有这样的位置就延长。结尾更小只会让后续更容易接上，因此每种长度只保留最小结尾，$\mathcal{O}(n \log  n)$。严格递增用 `lower_bound`；最长不下降改用 `upper_bound`。$\mathrm{tails}$ 本身不一定是一条真实子序列，恢复方案要额外记录前驱。

## LCS：两个前缀的最后字符怎样处理

`f[i][j]` 表示 $A$ 的前 $i$ 项与 $B$ 的前 $j$ 项的 LCS 长度。最后两项相等时可在 `f[i - 1][j - 1]` 后接一项；否则至少跳过一侧末项，取 `max(f[i - 1][j], f[i][j - 1])`。空前缀的 LCS 为 0。

一般时间 $\mathcal{O}(nm)$。如果两个序列恰好都是同一组互异元素的排列，可以把 $B$ 的元素映射成它们在 $A$ 中的位置，再求严格 LIS；有重复元素时不能直接用这一对一映射。

## 例题精讲：P2758 · 编辑距离

**原题：** [P2758 · 编辑距离](https://www.luogu.com.cn/problem/P2758)。

**题意简述：** 对小写字符串 $A$ 做插入、删除、替换，每次费用 1，求变成 $B$ 的最少操作次数。两串长度均不超过 2000。

输入两行 `abc`、`adc`，输出 `1`，只需把 `b` 替换为 `d`。输入 `abc`、`ab`，答案也是 1，这一次对应删除 `c`。

### 让状态含义直接说明每个候选

定义 `f[i][j]` 为 $A$ 的前 $i$ 个字符变成 $B$ 的前 $j$ 个字符的最少次数：

| 最后一步 | 候选 |
| --- | --- |
| 删除 $A$ 的第 $i$ 个字符 | $f[i-1][j]+1$ |
| 插入 $B$ 的第 $j$ 个字符 | $f[i][j-1]+1$ |
| 保留相同末字符或替换它 | $f[i-1][j-1]+\mathbf{1}_{A[i-1]\ne B[j-1]}$ |

其中指示符 $\mathbf{1}_{A[i-1]\ne B[j-1]}$ 在末字符不同时为 1，相同时为 0。空串变成长度 $j$ 的串需要插入 $j$ 次，所以 `f[0][j] = j`；长度 $i$ 的串变成空串要删除 $i$ 次，所以 `f[i][0] = i`。字符串用 0 起点访问，第 $i$ 个字符是 `A[i - 1]`，状态的“长度”和字符下标不要混淆。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    string a, b;
    cin >> a >> b;
    int n = a.size(), m = b.size();
    vector<vector<int>> f(n + 1, vector<int>(m + 1));
    for (int i = 0; i <= n; i++) f[i][0] = i;
    for (int j = 0; j <= m; j++) f[0][j] = j;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            f[i][j] = min({f[i-1][j] + 1, f[i][j-1] + 1,
                           f[i-1][j-1] + (a[i-1] != b[j-1])});
        }
    }
    cout << f[n][m] << '\n';
    return 0;
}
```

外层逐行、内层逐列，确保上方、左方、左上方都已计算。时间 $\mathcal{O}(nm)$，空间 $\mathcal{O}(nm)$，最大约四百万个 `int`，约 16 MB。若只要距离可滚动两行，若要恢复编辑过程则保留表格更直接。
