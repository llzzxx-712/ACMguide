## 这一节学什么

前面已经写过递推、记忆化搜索与简单 DP。现在把它们连起来：搜索在枚举方案，DP 则把后续任务完全相同的搜索状态合并，保存这个子问题的答案。关键不是代码里有没有数组，而是数组下标能否准确描述问题。

> **AI 伴学提示词**
>
> 为我复盘状态、转移、边界和计算顺序，用台阶计数比较搜索、记忆化与递推，并引导我提问。

## 哪些历史可以合并

若后续选择只取决于“还剩几级”，以前怎样走过来就不用放进状态；若要求不能连续走两个 2 级，剩余级数相同也不够，还要知道上一步是否走了 2 级。

判断状态是否充分，可以问：两段历史落在同一状态时，它们未来允许的选择和后续代价是否完全相同？若不同，应该补充信息；若相同，只保留题目需要的最优值或方案数。

## 例题精讲：自编 · 走上 n 级台阶

**题意简述：** 每次走 1 或 2 级，顺序不同视为不同方案，求走到第 n 级的方案数，对 10⁹+7 取模。0≤n≤10⁶。输入一个整数 n，输出方案数。

输入 `4`，输出 `5`：1111、112、121、211、22。输入 `0`，输出 `1`，表示不走任何一步的空方案。

### 先按最后一步分类

令 f[i] 表示恰好走到 i 的方案数。最后一步为 1，前面是到 i−1 的方案；最后一步为 2，前面是到 i−2 的方案。两类不重不漏，所以 f[i]=f[i−1]+f[i−2]。

边界 f[0]=1、f[1]=1。这里 f[0] 不是“没有方案”，而是能接上一段后续走法的空方案，设为 0 会让整个计数消失。

```text
搜索：solve(4) 需要 solve(3)、solve(2)
      solve(3) 又需要 solve(2)、solve(1)
记忆化：第一次算 solve(2) 后保存，之后直接使用
递推：按 0、1、2、3、4 的依赖顺序逐项算
```

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    const int MOD = 1000000007;
    vector<int> f(n + 2);
    f[0] = 1;
    f[1] = 1;
    for (int i = 2; i <= n; i++) f[i] = (f[i-1] + f[i-2]) % MOD;
    cout << f[n] << '\n';
    return 0;
}
```

时间 O(n)、空间 O(n)。每项只依赖前两项时还可滚动为 O(1) 空间；先把状态与顺序讲清楚，再压缩存储。两项模内值相加小于 2×10⁹+14，在 int 范围内。

## 记忆化不是把 0 当作未计算

有些子问题的合法答案就是 0，例如走到某个被封住的位置。应另外用 visited 标记是否已经计算，或选择不会与合法答案冲突的初值。搜索还必须沿无环依赖递归，互相调用但没有出口的状态不会因为加了缓存就自动正确。

递推则要先找到依赖顺序：序列可以按位置，区间按长度，树按孩子到父亲，DAG 按拓扑序。代码中的循环顺序就是这个依赖关系的实现。

## 练习：改要求时，先检查旧状态够不够

先**独立重做本例**，对 n≤15 枚举所有走法核对计数，再检查 n=0、1、2。

### 推荐必做

1. **自编 · 禁止连续走 2 级：** n≤10⁶，增加“上一跳是否为 2”的状态，分类讨论可接上的下一步。
2. **自编 · 最小费用上台阶：** 第 i 级有非负费用，落在该级支付费用，每步 1 或 2 级，求到 n 的最小总费用。将合并方式从加法改为 min，明确起点费用为 0。

### 选做巩固

- **自编 · 封闭台阶：** 某些位置不能停留，输入封闭集合后计数，区分合法答案 0 与未计算。
- **自编 · 对照调用次数：** 对 n≤25，分别记录普通搜索与记忆化求解各个子问题的次数，观察重复从哪里产生。
