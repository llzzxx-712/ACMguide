## 这一节学什么

前面已经写过递推、记忆化搜索与简单 DP。现在把它们连起来：搜索在枚举方案，DP 则把后续任务完全相同的搜索状态合并，保存这个子问题的答案。关键不是代码里有没有数组，而是数组下标能否准确描述问题。

> **AI 伴学提示词**
>
> 为我复盘状态、转移、边界和计算顺序，用台阶计数比较搜索、记忆化与递推，并引导我提问。

## 哪些历史可以合并

若后续选择只取决于“还剩几级”，以前怎样走过来就不用放进状态；若要求不能连续走两个 2 级，剩余级数相同也不够，还要知道上一步是否走了 2 级。

判断状态是否充分，可以问：两段历史落在同一状态时，它们未来允许的选择和后续代价是否完全相同？若不同，应该补充信息；若相同，只保留题目需要的最优值或方案数。

## 例题精讲：[P1192 台阶问题](https://www.luogu.com.cn/problem/P1192)

**题意简述：** 从 0 级出发，每次走 $1\ldots k$ 级，求到达第 $n$ 级的方案数，对 100003 取模。输入 $n$、$k$，$n\le 10^{5}$，$k\le 100$；输出一个整数。

自编输入：

```text
4 2
```

输出：

```text
5
```

### 先把思路讲清楚

到第 $i$ 级之前，不需要记整条路线，只需知道最后一跳之前在哪一级。最后一步跳 $\mathrm{step}$ 级的方案恰有 `f[i - step]` 种，因此 $f_i=\sum_{t=1}^{\min(k,i)}f_{i-t}$。代码中用 $\mathrm{step}$ 枚举这里的 $t$，把每种最后一步的贡献累加到 `f[i]`。按最后一步分组，不重不漏。

对 $n=4$、$k=2$，$f[0\ldots4]=[1,1,2,3,5]$。`f[0] = 1` 表示什么都没走的唯一空方案，它为第一步提供起点。外层 $i$ 从小到大，内层枚举最后一步，正好落实依赖先计算的顺序。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    const int MOD = 100003;
    vector<int> f(n + 1);
    f[0] = 1;
    for (int i = 1; i <= n; i++) {
        for (int step = 1; step <= k && step <= i; step++) {
            f[i] = (f[i] + f[i - step]) % MOD;
        }
    }
    cout << f[n] << '\n';
    return 0;
}
```

时间 $\mathcal{O}(nk)$，最大约 $10^{7}$ 次加法，空间 $\mathcal{O}(n)$。每次加法后取模，中间不到两倍模数，`int` 足够。不同跳跃顺序算不同方案，例如 $1+1+2$ 与 $2+1+1$ 是两条路线。

## 记忆化不是把 0 当作未计算

有些子问题的合法答案就是 0，例如走到某个被封住的位置。应另外用 $\mathrm{visited}$ 标记是否已经计算，或选择不会与合法答案冲突的初值。搜索还必须沿无环依赖递归，互相调用但没有出口的状态不会因为加了缓存就自动正确。

递推则要先找到依赖顺序：序列可以按位置，区间按长度，树按孩子到父亲，DAG 按拓扑序。代码中的循环顺序就是这个依赖关系的实现。

## 练习：改要求时，先检查旧状态够不够

先**独立重做本例**，对 $n\le 15$ 枚举所有走法核对计数，再检查 `f[0]` 的起始含义，以及 $n=1$、2 和 $k>n$。

### 推荐必做

1. [P1216 · 数字三角形](https://www.luogu.com.cn/problem/P1216)：从三角形顶端向左下或右下走到底部，使路径数字之和最大。按当前位置定义状态，比较两种前驱。
2. [P1048 · 采药](https://www.luogu.com.cn/problem/P1048)：每株草药采摘一次，求限定时间内能获得的最大价值。比较选与不选，并说明物品序号和已用时间为何足够描述状态。

- [P1434 · 滑雪](https://www.luogu.com.cn/problem/P1434)：每步只能滑向高度更低的相邻格，求最长滑行长度。以当前位置为状态，用记忆化搜索合并重复子问题。
