## 这一节学什么

set 保存有哪些成员，map 保存键对应的值。如果题目一直把两组人合为一组，并询问两人是否已经属于同组，就需要维护**分组关系**。并查集提供两个核心操作：查找所属组、合并两组。

## 从一人一组，到合并整个组

开始有 5 个人，各自一组：`{1} {2} {3} {4} {5}`。

1. 得知 1、2 是亲戚，合并为 `{1,2}`。
2. 得知 2、3 是亲戚，合并为 `{1,2,3}`。
3. 得知 4、5 是亲戚，合并为 `{4,5}`。
4. 查询 1、3，属于同组；查询 1、4，属于不同组。

若每次合并都把一整组成员重新标号，可能重复修改很多元素。并查集用一棵小树代表一组，**让根结点作为这组的代表**，合并时只需连接两棵树的根。

## f[x] 保存直接上级，find(x) 才寻找整组代表

令 f[x] 保存 x 的直接上级。开始每人一组，设置 f[i]=i，表示它自己就是根。

一种可能的合并结果：

```text
1 → 2 → 3       4 → 5
        ↑           ↑
      f[3]=3      f[5]=5
```

箭头表示“沿 f 向上找”。第一组代表为 3，第二组代表为 5。这里的上级只是程序为了维护分组建立的连接，不是现实中的父亲或直接亲戚关系。

find(1) 从 1 走到 2，再到 3，发现 f[3]=3，于是返回 3。find(2)、find(3) 也返回 3。

> **直接上级不一定是整组代表。**
>
> 判断同组使用 `find(x) == find(y)`，不能只比较 f[x] 和 f[y]。上图中 f[1]=2、f[3]=3 并不相等，但 1 和 3 属于同一组。

## 合并时，连接两组的根

要合并 x、y 所在的组：先求 fx=find(x)、fy=find(y)，如果不同，再设置 f[fx]=fy。

例如合并 1、4 时，fx=3、fy=5，连接 3→5，整个 `{1,2,3}` 就和 `{4,5}` 连起来了。

如果只写 f[x]=y，可能把树中间的一个分支单独搬走，而没有连接完整的两组。**思路是合并两组，代码就必须操作两组的代表。**

两个根已经相同时，它们原本就在同组，这次合并不改变任何关系。

## 路径压缩：找到了根，就把沿途结点接过去

对 `1→2→3→5` 执行 find(1)，第一次需要经过多个结点。既然已经知道它们的代表为 5，就可以改成：

```text
压缩前：1 → 2 → 3 → 5

压缩后：1 ───────→ 5
        2 ───────→ 5
        3 ───────→ 5
```

分组没有变化，但下次查询这些成员时，路径变短了。

### 用两次沿路径移动实现

第一趟用 root 找到根；第二趟从 x 重新沿旧路径前进，把沿途 f 都改为 root。

```text
int find(int x) {
    int root = x;
    while (f[root] != root) root = f[root];
    while (x != root) {
        int next = f[x]; // 改连接之前，先保存旧路径的下一站
        f[x] = root;
        x = next;
    }
    return root;
}
```

第二趟必须先保存 next。若先把 f[x] 改成 root，再写 x=f[x]，就会直接跳到根，漏掉尚未压缩的中间结点。

递归也能写成“先求上级的代表，再把结果保存为 f[x]”。本节完整代码使用循环形式，长链也不需要产生大量函数调用。

## 例题精讲：P1551 · 亲戚

**原题：** [P1551 · 亲戚](https://www.luogu.com.cn/problem/P1551)。

**题意简述：** n 个人，给出 m 对亲戚关系。亲戚关系可以传递；接着有 p 次询问，属于同一家族输出 `Yes`，否则输出 `No`。n、m、p 均不超过 5000。

自拟输入：

```text
5 3 4
1 2
2 3
4 5
1 3
1 4
4 5
2 2
```

输出：

```text
Yes
No
Yes
Yes
```

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 5000 + 5;
int f[N];

int find(int x) {
    int root = x;
    while (f[root] != root) root = f[root];
    while (x != root) {
        int next = f[x];
        f[x] = root;
        x = next;
    }
    return root;
}

void mergeGroup(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx != fy) f[fx] = fy;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, p;
    cin >> n >> m >> p;
    for (int i = 1; i <= n; i++) f[i] = i;
    for (int i = 1; i <= m; i++) {
        int x, y;
        cin >> x >> y;
        mergeGroup(x, y);
    }
    for (int i = 1; i <= p; i++) {
        int x, y;
        cin >> x >> y;
        cout << (find(x) == find(y) ? "Yes" : "No") << '\n';
    }
    return 0;
}
```

初始化对应“一人一组”，前 m 对输入对应“合并关系”，后 p 对输入对应“比较代表”。题目中的传递性，被树上沿路径寻找同一个根的过程表达出来了。

一次查找先沿父指针到根，再压缩路径，访问长度最坏可以达到 O(n)。本题即使按每次操作 O(n) 作较松的上界估算，也只有几千万量级；实际路径压缩会减少后续重复走的路径。数组空间 O(n)。下一节再加入按大小合并，进一步控制路径长度。
