## 这一节学什么

上一节会合并，但还没有决定两个根中谁接到谁。我们用集合大小决定连接方向，同时维护连通块数量，再学习怎样把更复杂的关系转化为“哪些对象必须同组”。

## 小集合的根，接到大集合的根

新增 sz[root]，表示这组有多少个结点。开始一人一组，所以 f[i]=i、sz[i]=1。

假设 x 所在组有 2 个成员，y 所在组有 5 个成员。合并时，让小组的根指向大组的根，大组大小从 5 变为 7。

```text
int fx = find(x), fy = find(y);
if (fx == fy) return;
if (sz[fx] < sz[fy]) swap(fx, fy);
f[fy] = fx;            // fy 现在是较小组的根
sz[fx] += sz[fy];      // 新根维护合并后的大小
```

### 为什么这样能控制树高

某个结点因为合并而多了一层上级，说明它原本在较小的一组。新组至少是原组的两倍大。经历 k 次这种增加后，组大小至少变成 2 的 k 次方，因此单靠按大小合并，树高就能控制在 O(log n)。

再配合路径压缩，一系列操作的均摊复杂度为 O(α(n))，α 是增长非常慢的反阿克曼函数。在竞赛的常见规模中，可以把它理解为接近常数的操作代价；这来自两种优化共同作用。

> **大小要从根读取。**
>
> 合并后，旧根的 sz 不再代表整组大小。询问 x 所在组有多少成员，写 `sz[find(x)]`。只有两个根确实不同时，才相加大小、减少组数；重复输入同一条关系不能重复统计。

## 连通块：暂时互相到不了的几组

将城镇看成结点，道路连接两个城镇。能够沿已有道路互相到达的城镇属于同一个**连通块**。

例如道路为 1—2、2—3、4—5，第 6 个城镇没有道路，目前有 `{1,2,3}`、`{4,5}`、`{6}` 三个连通块。

开始令 blocks=n。每次合并两个不同的根，blocks 减 1；两端本来就在同组，则不变。

## 例题精讲：P1536 · 村村通

**原题：** [P1536 · 村村通](https://www.luogu.com.cn/problem/P1536)。

**题意简述：** 给出城镇和现有道路，求最少还要修多少条道路，才能使所有城镇互相可达。有多组数据，n<1000；读到单独的 0 结束。同一对城镇可以有多条道路。

自拟输入：

```text
6 4
1 2
2 3
4 5
1 3
1 0
0
```

输出：

```text
2
0
```

第一组有 3 个连通块，已有道路 1—3 没有减少连通块数。第二组只有一个城镇，不需要新增道路。

### 为什么答案是连通块数减 1

一条新道路最多把两个块接成一个，使块数减少 1。从 k 个块变成 1 个，至少需要 k−1 条。

也确实可以做到：从第一个块选一个城镇，把它分别连到其他 k−1 个块。于是最少新增道路数就是 blocks−1。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1000 + 5;
int f[N], sz[N];

int find(int x) {
    if (f[x] == x) return x;
    f[x] = find(f[x]);
    return f[x];
}

bool mergeGroup(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx == fy) return false;
    if (sz[fx] < sz[fy]) swap(fx, fy);
    f[fy] = fx;
    sz[fx] += sz[fy];
    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    while (cin >> n && n != 0) {
        int m;
        cin >> m;
        for (int i = 1; i <= n; i++) {
            f[i] = i;
            sz[i] = 1;
        }
        int blocks = n;
        for (int i = 1; i <= m; i++) {
            int x, y;
            cin >> x >> y;
            if (mergeGroup(x, y)) blocks--;
        }
        cout << blocks - 1 << '\n';
    }
    return 0;
}
```

mergeGroup 返回“这次是否真的合并了两个块”，主函数据此更新 blocks。先读 n 并检查是否为 0，再读 m，符合题目结束格式。

这里 find 用递归展示路径压缩的另一种写法：先递归求上级的根，再把结果保存到 f[x]。由于按大小合并已经控制了树高，不会形成前一节那种未经控制的长链。每组时间 O((n+m)α(n))，空间 O(n)，每组数据都重新初始化。

## 进阶例题：P1892 · 团伙

**原题：** [P1892 · 团伙](https://www.luogu.com.cn/problem/P1892)。

**题意简述：** n≤1000，给出朋友 F、敌人 E 两类关系。题目给定两条推理规则：朋友的朋友是朋友，敌人的敌人是朋友。朋友必须同组，求最多能有多少组。

### 先按规则判断，哪些人必须合并

F 1 2 要求 1、2 合并。如果 E 1 3、E 2 3，那么 1、2 都是 3 的敌人，按规则也必须同组。

因此，对每个人 x，可以设立一个辅助连接点 enemy[x]，表示“已知与 x 为敌的人，应该连接到这里”。把 enemy[x] 的编号规定为 n+x：

```text
真实人物：1、2、……、n
辅助结点：n+1、n+2、……、2n

F p q：合并 p、q
E p q：把 p 接到 n+q，把 q 接到 n+p
```

例如 E 1 3、E 2 3 会把 1、2 都接到 n+3，于是自动同组。辅助结点是组织这些合并的工具，不是额外的人。

这里要忠实实现题目给出的规则：F p q 只要求 p、q 同组，不额外合并 n+p 与 n+q。题目没有规定“朋友的敌人也是敌人”，不能自行增加推理规则。

### 手算一组输入

```text
5
4
F 1 2
E 2 3
F 3 4
E 4 5
```

输出：

```text
3
```

已知朋友组为 `{1,2}`、`{3,4}`、`{5}`。两条敌人关系没有共同的原始敌人，不能据此额外推出 2、5 是朋友。这个例子帮助我们检查：代码有没有加入题目并未提供的规则。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 2000 + 5;
int f[N], sz[N];

int find(int x) {
    if (f[x] == x) return x;
    f[x] = find(f[x]);
    return f[x];
}

void mergeGroup(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx == fy) return;
    if (sz[fx] < sz[fy]) swap(fx, fy);
    f[fy] = fx;
    sz[fx] += sz[fy];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= 2 * n; i++) {
        f[i] = i;
        sz[i] = 1;
    }
    for (int i = 1; i <= m; i++) {
        char op;
        int p, q;
        cin >> op >> p >> q;
        if (op == 'F') {
            mergeGroup(p, q);
        } else {
            mergeGroup(p, n + q);
            mergeGroup(q, n + p);
        }
    }
    set<int> groups;
    for (int i = 1; i <= n; i++) {
        groups.insert(find(i));
    }
    cout << groups.size() << '\n';
    return 0;
}
```

最后只遍历真实人物 1 到 n，统计它们的不同根。根的编号可能恰好是辅助结点，这没有关系；我们统计的是“这些真实人物分到了多少个不同代表下面”，而不是根的编号范围。

本题 sz 统计的是并查集结点数，包含辅助结点，用于控制合并方向；不能把它直接当成真实团伙人数。合并部分时间 O((n+m)α(n))，最后用 set 去重根需要 O(n log n)，空间 O(n)。
