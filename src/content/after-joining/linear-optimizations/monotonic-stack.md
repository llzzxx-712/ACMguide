## 这一节学什么

普通栈只规定后进先出，单调栈还让栈中的数值保持某种大小顺序。我们用“右边第一个更大的数”和“奶牛能看到谁”理解它：先说明栈里保存的是哪些候选，再说明当前数为什么能让一些候选出栈。

> **AI 伴学提示词**
>
> 为我讲解单调栈，用含相等值的数组模拟每次入栈、出栈和答案变化，解释弹出条件为何使用严格或非严格比较，并引导我对不理解的地方提问。

## 例题精讲一：P5788 · 单调栈

**原题：** [P5788 · 单调栈](https://www.luogu.com.cn/problem/P5788)。

**题意简述：** 对每个位置 i，求右边第一个严格大于 a[i] 的元素的下标，不存在输出 0。n≤3×10^6，a[i]≤10^9。

自拟输入：

```text
5
2 1 2 4 3
```

输出：

```text
4 3 4 0 0
```

第 1 位的 2 遇到第 3 位的 2 时还不能结束寻找，因为题目要求**严格大于**；直到第 4 位的 4 才得到答案。

## 从反复向右找，改成让答案出现时主动通知

暴力方法对每个 i 逐个向右扫描，最坏 O(n²)。换一个角度：从左往右遇到 a[i] 时，看看之前哪些位置正在等一个比自己大的数，当前数能不能成为它们的答案。

用栈保存**尚未找到答案的下标**。每来一个新数：

1. 若栈顶对应的值比当前数小，当前下标 i 就是它的答案，记录并弹出。
2. 继续看新的栈顶，直到栈空，或栈顶的值≥当前数。
3. 当前 i 自己还没找到右侧答案，把 i 压入栈，等待后面的数。

### 为什么当前数是“第一个”，不是随便某个更大的数

假设下标 j 还在栈中，说明从 j+1 到当前 i−1 都没有出现能让它得到答案的数。现在第一次遇到 a[i]>a[j]，所以 i 就是它右边第一个更大的位置。**弹出是因为这个位置的问题已经解决。**

处理完当前数后，栈里对应数值从底到顶保持非递增，也就是前一个≥后一个。若栈顶还不小于当前值，下面的值只会更大，也都不能由当前数解决，可以停止检查。

### 把思路画成栈的变化

下面记为“下标:数值”，右端是栈顶：

| 当前 i 与 a[i] | 发生什么 | 处理后栈 |
| --- | --- | --- |
| 1，2 | 没有旧候选，压入 1 | 1:2 |
| 2，1 | 2 不小于 1，压入 2 | 1:2，2:1 |
| 3，2 | 1<2，弹出 2，令 answer[2]=3；相等的 2 保留 | 1:2，3:2 |
| 4，4 | 依次解决 3、1，答案均为 4 | 4:4 |
| 5，3 | 4 不小于 3，压入 5 | 4:4，5:3 |

扫描结束仍在栈中的位置没有更大的右侧元素，答案保留为 0。

## 完整代码：用 vector 当作栈

我们已经会用 vector 的 back、push_back、pop_back，正好对应栈顶、入栈和出栈。它保存的是下标，读取对应数值时再访问 a[下标]。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n + 1), answer(n + 1), st;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) {
        while (!st.empty() && a[st.back()] < a[i]) {
            int j = st.back();
            st.pop_back();
            answer[j] = i;
        }
        st.push_back(i);
    }
    for (int i = 1; i <= n; i++) cout << answer[i] << (i == n ? '\n' : ' ');
    return 0;
}
```

> **先看题目中的“严格”二字。**
>
> 本题找严格更大，弹出条件是旧值<当前值；相等时不能记录答案。若改成“第一个大于等于”，才改用旧值≤当前值。不要把某一个比较符号当成所有单调栈题目的固定写法。

这里 `!st.empty()` 放在前面，栈空时不会再读取 back。answer(n+1) 中 int 元素初始为 0，直接表示“尚未找到”。

## 为什么 for 里面还有 while，仍是 O(n)

每个下标只入栈一次，最多出栈一次。虽然某一次新数可能连续弹出很多旧下标，但这些下标以后不会再次入栈、出栈。把所有 while 加在一起，弹出总次数最多 n 次，所以总时间 O(n)，空间 O(n)。百万级输入要关闭流同步，数组也按实际 n 创建。

## 例题精讲二：P2866 · Bad Hair Day S

**原题：** [P2866 · Bad Hair Day S](https://www.luogu.com.cn/problem/P2866)。

**题意简述：** n 头牛排成一行，都看向右侧。牛 i 能看到右侧牛 j，当且仅当从 i+1 到 j 的每一头都严格比牛 i 矮。遇到不矮于自己的牛就被挡住，并且不能看到这头挡住自己的牛。求所有牛能看到的数量总和，n≤8×10^4。

自拟输入：

```text
5
5
2
2
4
1
```

输出为 `5`：第一头看到后面 4 头，第四头看到最后 1 头，其他牛看不到任何右侧牛。

### 按“谁能看到当前牛”计数

与其让每头牛反复向右看，不如从左到右，计算当前牛能被多少头旧牛看到。每一对“旧牛看见当前牛”只在当前牛出现时统计一次。

栈保存仍有机会看到后续牛的旧牛。当前高度为 h 时：

- 栈顶高度≤h：它看不到当前牛，后面也已被当前牛挡住，弹出。
- 弹完以后，剩下的旧牛都比 h 高，并且没有被中间的牛挡住，所以每头都能看到当前牛。
- 将剩余栈大小加到总数，再把当前牛压入栈。

| 当前高度 | 移除哪些旧高度 | 可以看到当前牛的旧牛数 | 处理后栈高度 |
| --- | --- | --- | --- |
| 5 | 无 | 0 | 5 |
| 2 | 无 | 1 | 5,2 |
| 2 | 弹出相等的 2 | 1 | 5,2 |
| 4 | 弹出 2 | 1 | 5,4 |
| 1 | 无 | 2 | 5,4,1 |

总数 0+1+1+1+2=5。相等的旧牛也要弹出，因为当前这头同高牛已经把它的视线挡住；这和上题相等时保留候选的原因不同。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> st;
    long long answer = 0;
    for (int i = 1; i <= n; i++) {
        int height;
        cin >> height;
        while (!st.empty() && st.back() <= height) st.pop_back();
        answer += st.size();
        st.push_back(height);
    }
    cout << answer << '\n';
    return 0;
}
```

这题只需要高度，不需要知道答案属于哪个下标，所以栈中直接保存高度。严格递减的一列牛会产生 n(n−1)/2 对可见关系，n=80000 时约 3.2×10^9，超过 int 上限，答案用 long long。时间 O(n)，空间 O(n)。

## 练习：先说出栈里到底保存谁

先**独立重做 P5788、P2866**，分别用全相等、严格递增、严格递减和只有一个元素的数据检查。对每次弹出，说清是“已经找到答案”还是“之后永远被挡住”。

### 推荐必做

1. **自编 · 左侧第一个更大值：** 输入 n≤10^6 与序列，输出每个位置左侧最近的严格更大元素的下标，不存在输出 0。处理当前数时，把不比自己大的旧候选弹出，再读取留下的栈顶；思考为何它是最近的。
2. [P3467 · PLA-Postering](https://www.luogu.com.cn/problem/P3467)：用最少矩形海报覆盖相邻建筑形成的墙面。维护仍能向右延伸的高度层，遇到更低高度就结束上方的层，遇到相等高度可以接着使用已有层。练习从“还能继续的候选”解释栈。

### 选做巩固

- [P4147 · 玉蟾宫](https://www.luogu.com.cn/problem/P4147)：求全是 F 的最大矩形，最后按题意输出面积的 3 倍。先逐行累计每列向上连续的 F 高度，把每行变成直方图，再利用左右第一个更矮位置确定矩形能延伸的宽度。
- **自编 · 等待了几步：** 沿用 P5788 的输入，存在更大元素时输出 answer[i]−i，否则输出 0。只改变记录的结果，检查栈中的下标为什么仍有用。

## 本节验收

能根据题意决定存下标还是存值；能说明单调性怎样形成；能独立推导相等值的处理规则，并用每项至多入栈、出栈一次说明线性复杂度。
