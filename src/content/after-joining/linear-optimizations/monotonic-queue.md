## 这一节学什么

普通队列按入队顺序处理所有元素；求滑动窗口最值时，我们只需要保存仍可能成为答案的候选。单调队列从队头移除过期下标，从队尾移除被新元素取代的候选，让队头始终给出当前窗口最值。

> **AI 伴学提示词**
>
> 为我讲解单调队列，用含重复值的滑动窗口逐步模拟过期、队尾删除和入队，解释为什么较新且更优的元素能取代旧元素，并引导我对不理解的地方提问。

## 从普通队列到双端队列 deque

先认识工具 `deque`。它可以从两端取出元素，名字可以理解为“双端队列”。常用操作如下：

| 操作 | 含义 | 对应到本节 |
| --- | --- | --- |
| `q.push_back(i)` | 从队尾加入 | 放入当前下标 |
| `q.front()` | 读取队头 | 获取当前最优候选 |
| `q.back()` | 读取队尾 | 检查最后一个旧候选 |
| `q.pop_front()` | 删除队头 | 移除已离开窗口的位置 |
| `q.pop_back()` | 删除队尾 | 移除已经不可能更优的候选 |
| `q.empty()` | 判断是否为空 | 读取 front/back 前检查 |

声明为 `deque<int> q;`。这里它保存整数下标，操作写法和上一节用 `vector` 作栈很接近，多了从队头删除的能力；无需每次把后面的元素整体前移。两端的这些添加、删除操作都是 $\mathcal{O}(1)$。

## 例题精讲：P1886 · 单调队列 / 滑动窗口

**原题：** [P1886 · 单调队列 / 滑动窗口](https://www.luogu.com.cn/problem/P1886)。

**题意简述：** 长度 n 的数组，长度为 k 的窗口从左向右每次移动一格，分别输出每个完整窗口的最小值、最大值。1≤k≤n≤10^6，元素可以是负数。

自拟输入：

```text
8 3
4 2 2 5 6 1 3 3
```

输出：

```text
2 2 2 1 1 1
4 5 6 6 6 3
```

### 暴力在哪一步重复了

枚举窗口位置本身只需 $\mathcal{O}(n)$，但每个窗口都扫描 k 个数寻找最值，总时间 $\mathcal{O}(nk)$，百万规模时不行。相邻窗口大部分重合，没必要把仍然有用的比较结果全部丢掉。

先只考虑最小值：当前右端为 i，窗口是 `[i - k + 1, i]`。未满 k 个元素时还不输出，只先维护候选。

## 删除理由一：下标已经不在窗口内

若队头下标 j<i−k+1，它已经在窗口左边，不能再作为答案，直接从队头删除。候选按下标从小到大入队，最早过期的总在队头。

这也是必须保存下标的原因：两个相等的 2 可能处在不同位置，会在不同时间离开窗口。只保存数值，就无法正确判断谁过期了。

## 删除理由二：新元素更小，而且更晚过期

假设一个旧候选 `a[j] = 5`，当前新元素 `a[i] = 2`，j<i。在之后的窗口里：

- 若旧位置 j 还在窗口中，新位置 i 也在，并且 2 比 5 更小。
- 旧位置 j 比 i 更早离开窗口；它消失以后，也无需再考虑。

所以旧的 5 永远不会比新的 2 更适合做最小值，可以从队尾移除。**候选被删除，是因为它之后不可能再赢，而不是因为它现在恰好不是答案。**

相等时也保留更新的那个：数值一样，新下标更大、有效期更长。因此求最小值时，队尾旧值≥新值就删除；维护后，队列中的数值从头到尾严格递增，最小值就在队头。

### 跟着例子模拟队列

下表仍用“下标:数值”表示候选，左端是队头：

| i | 窗口左边界 | 删除过期下标 | 删除较差队尾并加入当前数 | 当前输出 |
| --- | --- | --- | --- | --- |
| 1 | −1 | 无 | 1:4 | 未满 3 个 |
| 2 | 0 | 无 | 用 2:2 取代 1:4 | 未满 3 个 |
| 3 | 1 | 无 | 用较新的 3:2 取代 2:2 | 2 |
| 4 | 2 | 无 | 3:2，4:5 | 2 |
| 5 | 3 | 无 | 3:2，4:5，5:6 | 2 |
| 6 | 4 | 3:2 过期，移出队头 | 新的 6:1 让 5:6、4:5 依次从队尾移除 | 1 |
| 7 | 5 | 无 | 6:1，7:3 | 1 |
| 8 | 6 | 无 | 相等值保留新的 8:3，队列为 6:1，8:3 | 1 |

i<k 时算出的左边界可以小于 1，我们只拿它比较已入队的正下标，不会访问负下标。满 k 个元素后才读取队头输出窗口答案。

## 求最大值：比较方向反过来

新数更大、位置又更新时，会让旧的较小值失去竞争力，因此从队尾删除≤当前值的旧候选。维护后数值从头到尾严格递减，队头就是最大值。

| 要维护什么 | 队尾何时失去优势 | 维护后的数值顺序 |
| --- | --- | --- |
| 最小值 | 旧值≥新值 | 从头到尾严格递增 |
| 最大值 | 旧值≤新值 | 从头到尾严格递减 |

过期规则与求最小还是最大无关，始终依据下标；比较规则才依据数值。把这两种删除理由分开，代码就容易检查。

## 完整代码：每轮对应三个动作

先删除过期队头，再删除较差队尾，最后加入当前下标。两个函数分别输出最小值与最大值，只有队尾比较方向不同。

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1000000 + 5;
int a[N];

void outputMin(int n, int k) {
    deque<int> q;
    for (int i = 1; i <= n; i++) {
        int left = i - k + 1;
        while (!q.empty() && q.front() < left) q.pop_front();
        while (!q.empty() && a[q.back()] >= a[i]) q.pop_back();
        q.push_back(i);
        if (i >= k) {
            if (i > k) cout << ' ';
            cout << a[q.front()];
        }
    }
    cout << '\n';
}

void outputMax(int n, int k) {
    deque<int> q;
    for (int i = 1; i <= n; i++) {
        int left = i - k + 1;
        while (!q.empty() && q.front() < left) q.pop_front();
        while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
        q.push_back(i);
        if (i >= k) {
            if (i > k) cout << ' ';
            cout << a[q.front()];
        }
    }
    cout << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    for (int i = 1; i <= n; i++) cin >> a[i];
    outputMin(n, k);
    outputMax(n, k);
    return 0;
}
```

> **队列不是整个窗口，而是仍可能有用的候选。**
>
> 被队尾删除的元素可能仍在当前窗口里，但已经没有必要参与之后的最值竞争。窗口位置由 i 和 k 决定，不能用 `q.size()` 当作窗口长度。队列保存下标，输出答案时要写 `a[q.front()]`。

每个下标在一次扫描中入队一次，最多从队头或队尾被删除一次，两个 while 合计弹出 $\mathcal{O}(n)$ 次。两次扫描总时间仍为 $\mathcal{O}(n)$，队列最多保留 $\mathcal{O}(k)$ 个候选，保存输入的数组占 $\mathcal{O}(n)$ 空间。比较整数时直接用≥或≤，不通过相减来比较，`int` 极值也不会引起减法溢出。

## 练习：先写删除理由，再写不等号

先**独立重做 P1886**，测试 k=1、k=n、全相等、严格递增递减、负数和 `int` 的边界值。用草稿纸同时写下窗口区间与候选队列，观察它们为什么不同。

### 推荐必做

1. [P2032 · 扫描](https://www.luogu.com.cn/problem/P2032)：每个长度为 k 的窗口只输出最大值，每个答案单独一行。把本节思路独立实现一次，按照题目最大规模 2×10^6 调整存储范围。
2. [P1440 · 求 m 区间内的最小值](https://www.luogu.com.cn/problem/P1440)：对每个位置，输出它之前最多 m 个数的最小值，没有前项则输出 0。先回答当前位置，再将当前数加入队列，练习区分查询窗口与新候选。

### 选做巩固

- [P1714 · 切蛋糕](https://www.luogu.com.cn/problem/P1714)：连续非空子段长度至多 m，求最大和。令 s 为前缀和，固定右端 r 后需要在 `[max(0, r - m), r - 1]` 中维护最小 `s[j]`，再计算 `s[r] - s[j]`；先查旧候选，再加入 `s[r]`，避免选择空段。
- [P2216 · 理想的正方形](https://www.luogu.com.cn/problem/P2216)：找 n×n 区域，使区域最大最小差最小。先对每行做水平窗口最值，再对得到的结果按列做垂直窗口最值，把二维区域拆成两轮一维维护。
