## 这一节学什么

之前枚举一个区间，常会写两层 for，分别确定左右端点。若右端点增大时，合适的左边界也只会向右移动，就不用每次重新从头寻找。这一节用两个题目理解双指针：排序后的数值匹配，以及原序列上的连续窗口。

> **AI 伴学提示词**
>
> 为我讲解双指针和滑动窗口，用 $A-B$ 数对与逛画展逐步模拟边界、计数和答案，解释为什么指针不用退回，并引导我对不理解的地方提问。

## 双指针不是特殊语法，而是让两个位置协作

所谓指针，在本节中就是保存下标的整数，例如 $\mathrm{le}$、$r$。我们仍然使用数组或 `vector`、while 和 if；改变的是枚举顺序：**保留上次找到的位置，只移动已经需要改变的边界。**

要先回答两个问题：当前边界代表什么？为什么被跳过的位置以后也不会有用？想清楚后，循环条件才有依据。

## 例题精讲一：P1102 · $A-B$ 数对

**原题：** [P1102 · A-B 数对](https://www.luogu.com.cn/problem/P1102)。

**题意简述：** 给 $n$ 个数和正整数 $C$，统计满足 `A - B = C` 的数对个数。相同数值出现在不同位置，要分别计数，$n\le 2\times 10^{5}$。

自拟输入：

```text
6 2
1 3 1 3 5 3
```

输出为 `9`：两个 1 分别与三个 3 配对，产生 6 对；三个 3 分别与一个 5 配对，产生 3 对。

### 先把问题改写成“寻找 $B+C$”

固定 $B$ 后，需要找值为 $B+C$ 的 $A$。逐个 $B$ 再扫完整序列要 $\mathcal{O}(n^{2})$，最大规模约 $4\times 10^{10}$ 次，太多。我们先排序，使相同的值相邻：

```text
下标：0 1 2 3 4 5
数值：1 1 3 3 3 5
```

令 $\mathrm{le}$ 指向第一个不小于 $\mathrm{target}$ 的位置，$r$ 指向第一个大于 $\mathrm{target}$ 的位置，其中 `target = B + C`。那么相等值占据下标 $\mathrm{le}$ 到 $r-1$，个数就是 $r-\mathrm{le}$；若不存在，二者相等。

| 当前 $B$ | $\mathrm{target}$ | $\mathrm{le}$ | $r$ | 本次增加 |
| --- | --- | --- | --- | --- |
| 第一个 1 | 3 | 2 | 5 | 3 |
| 第二个 1 | 3 | 2 | 5 | 3 |
| 第一个 3 | 5 | 5 | 6 | 1 |
| 第二个 3 | 5 | 5 | 6 | 1 |
| 第三个 3 | 5 | 5 | 6 | 1 |
| 5 | 7 | 6 | 6 | 0 |

下标 $n$ 表示“已经越过最后一个元素”，只用来表示边界，不读取 `a[n]`。

### 为什么不用把 $\mathrm{le}$、$r$ 放回 0

排序后，枚举的 $B$ 不会变小，$\mathrm{target}$ 也不会变小。之前小于 $\mathrm{target}$ 的数，不可能重新成为之后更大 $\mathrm{target}$ 的匹配值；之前不大于 $\mathrm{target}$ 的数，也不会成为之后第一个大于 $\mathrm{target}$ 的位置。因此两个边界都只需向右走。

完整代码中的外层循环是在枚举 $B$，两个 while 是在更新对应的匹配范围：

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long c;
    cin >> n >> c;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    sort(a.begin(), a.end());
    int le = 0, r = 0;
    long long answer = 0;
    for (int i = 0; i < n; i++) {
        long long target = a[i] + c;
        while (le < n && a[le] < target) le++;
        while (r < n && a[r] <= target) r++;
        answer += r - le;
    }
    cout << answer << '\n';
    return 0;
}
```

这里没有手写二分：$\mathrm{le}$、$r$ 是跨多次查询保留下来的扫描位置。两个 while 在整个程序里各自最多移动 $n$ 次，因此排序后扫描 $\mathcal{O}(n)$，总时间 $\mathcal{O}(n \log  n)$，空间 $\mathcal{O}(n)$。例如 10 万个 1 与 10 万个 3、$C=2$ 时，有 $10^{10}$ 对，超过 `int` 上限，答案要用 `long long`。

## 滑动窗口：让 $[\mathrm{le}, r]$ 表示当前连续的一段

另一些题目必须保持原顺序，不能排序。例如要找一段连续的展品，排序会破坏它们原本相邻的关系。

让右端 $r$ 依次向右，每次把一个新元素加入窗口；再根据条件移动 $\mathrm{le}$，把左边不需要的元素移出去。我们同时维护窗口的信息，例如总和、不同种类数或某种值的出现次数。

窗口向右扩展时，更新进入的元素；窗口向左收缩时，更新离开的元素。**区间在变，但不必重新扫描整个区间。**

## 例题精讲二：P1638 · 逛画展

**原题：** [P1638 · 逛画展](https://www.luogu.com.cn/problem/P1638)。

**题意简述：** $n$ 幅画按顺序排列，每幅属于 1 到 $m$ 号中的一位画家。找最短连续区间，使 $m$ 位画家都至少出现一次；若有多个最短区间，取左端点最小者。保证有解，$n\le 10^{6}$，$m\le 2000$。

自拟输入：

```text
7 3
1 2 1 3 2 1 3
```

输出：

```text
2 4
```

### 维护出现次数，才知道能不能移走一幅画

令 `count[x]` 表示画家 $x$ 在窗口中的出现次数，$\mathrm{kinds}$ 表示窗口中已经出现了多少位画家。

- 加入画家 $x$：`count[x]` 从 0 变成 1 时，$\mathrm{kinds}$ 才加 1。
- 移走画家 $x$：`count[x]` 从 1 变成 0 时，$\mathrm{kinds}$ 才减 1。
- `kinds = m` 时，当前窗口覆盖了所有画家，可以更新答案，再尝试缩短左侧。

看右端 $r=4$ 时：

| 动作 | 窗口 | 画家 `1 2 3` 的次数 | $\mathrm{kinds}$ |
| --- | --- | --- | --- |
| 加入第 4 幅画 | $[1, 4]$：`1 2 1 3` | `2 1 1` | 3 |
| 记录 $[1, 4]$，移走第 1 幅 | $[2, 4]$：`2 1 3` | `1 1 1` | 3 |
| 记录更短的 $[2, 4]$，移走第 2 幅 | $[3, 4]$：`1 3` | `1 0 1` | 2 |

此时不再覆盖所有画家，停止缩左边，继续让右端加入新画。之后即使扩展 $r$，已经丢掉的更小左端点也不会产生更短答案：它们对应的有效区间在更早的右端点就已经被考察过，继续变长没有优势。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1000000 + 5;
int a[N], countArtist[2005];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int le = 1, kinds = 0, bestLength = n + 1;
    int answerL = 1, answerR = n;
    for (int r = 1; r <= n; r++) {
        if (++countArtist[a[r]] == 1) kinds++;
        while (kinds == m) {
            int length = r - le + 1;
            if (length < bestLength) {
                bestLength = length;
                answerL = le;
                answerR = r;
            }
            if (--countArtist[a[le]] == 0) kinds--;
            le++;
        }
    }
    cout << answerL << ' ' << answerR << '\n';
    return 0;
}
```

`++countArtist[a[r]] == 1` 表示先增加次数，再判断是否刚从 0 变成 1；删除时对应先减后判断。可以先拆成两行手写，理解后再合写。

$r$ 从左到右增加，$\mathrm{le}$ 也只向右移动。相同长度的窗口会按左端点从小到大的顺序被发现，只有严格更短时才更新，就保留了最小左端点。每幅画进入、离开各至多一次，时间 $\mathcal{O}(n+m)$，空间 $\mathcal{O}(n+m)$。

## 先判断单调性，再选择窗口条件

本题往窗口里加入画，只会保持或增加画家种类，不会让已有画家消失；删除则只会保持或减少种类，所以可以有规律地调整边界。

若维护的是区间和，则要结合数值范围：非负数序列中，扩展右端不会让和变小；含负数时就未必。例如 $\{5,-10,8\}$、上限为 3 时，读到 5 就因为超限删掉它，会错过总和为 3、长度为 3 的整个区间。**决定能否使用这种移动规则的是问题性质，而不是有没有连续区间。**

## 练习：先说明每次移动会改变什么

先**独立重做 P1102、P1638**。前者手算重复值的乘法计数，后者手算加入和移出时 $\mathrm{kinds}$ 是否变化。

### 推荐必做

1. [UVA11572 · 唯一的雪花](https://www.luogu.com.cn/problem/UVA11572)：找最长的连续不重复片段。右端加入后若产生重复，就移动左端，直到窗口重新没有重复；大编号可以用已学的 `unordered_map` 计数，每组数据重新初始化。
2. [P1147 · 连续正整数和](https://www.luogu.com.cn/problem/P1147)：输出所有和为 $M$ 的连续正整数段，且每段至少含两个数。维护当前区间和，按大小移动左右端点，练习保留符合要求的区间。

### 选做巩固

- [P3143 · Diamond Collector S](https://www.luogu.com.cn/problem/P3143)：两个展示柜各自要求最大最小差不超过 $K$，最大化总数量。排序后先用双指针处理一段，再考虑怎样把两段互不重叠的结果组合起来。
- [UVA1121 · Subsequence](https://www.luogu.com.cn/problem/UVA1121)：在正整数序列中求和不少于 $S$ 的最短连续子段，不存在时输出 0。满足条件时不断收缩左端；注意输入多组数据直到文件结束。
