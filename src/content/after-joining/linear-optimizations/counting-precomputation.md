## 这一节学什么

遇到重复计算时，可以先问：上次已经算出的信息，能不能保存下来供下一次直接使用？本节从成绩计数出发，学习小值域桶、预处理与空间换时间，再把前缀统计推广到多种累计信息。

> **AI 伴学提示词**
>
> 为我讲解计数、预处理和空间换时间，模拟分数桶与前缀和计数，解释为什么先查 sum-k 再记录 sum，并引导我对不理解的地方提问。

## 原始数据很多，不代表需要同样多种状态

如果 10 万个成绩都在 0 到 600 之间，可以用 count[score] 保存某个分数出现了几次。一共有 601 个可能分数，重复出现的成绩合在同一个桶里。

```text
输入：80 90 80 100
count[80]  = 2
count[90]  = 1
count[100] = 1
其他桶均为 0
```

之前的 map<int,int> 也能按分数计数；这里分数范围小而且连续，直接拿分数当下标就够了。**下标代表哪类数据，数组值代表这一类出现了多少次。**

若要按顺序输出这些成绩，从低分到高分扫描每个桶，每个分数输出 count[score] 次，就能得到有序结果。这也是桶排序思想的一种直接应用：数组下标本身就是顺序，不用反复比较所有成绩。

## 例题精讲：P7072 · 直播获奖

**原题：** [P7072 · 直播获奖](https://www.luogu.com.cn/problem/P7072)。

**题意简述：** 选手成绩依次公布，公布 p 人后，计划获奖人数为 max(1,⌊p×w/100⌋)，需要立即输出成绩从高到低第 k 名的分数，其中 k 为计划获奖人数。并列同分者一起获奖，但分数线仍是第 k 名的分数。n≤10^5，分数为 0 到 600 的整数，1≤w≤99。

自拟输入：

```text
5 40
80 90 80 100 90
```

输出：

```text
80 90 90 100 90
```

### 为什么不每公布一人就重新排序

如果对前 p 人都排序一次，总工作量会随前缀增长反复累加。其实我们只关心第 k 名的成绩，不需要每次都重排所有选手姓名和分数。

每收到 score，执行 count[score]++。随后从 600 往 0 扫，累计已经有多少人成绩至少达到当前分数；第一次累计人数≥k 的分数，就是当前分数线。

| 已公布人数 p | 计划人数 k | 从高分向下累计到哪里 | 分数线 |
| --- | --- | --- | --- |
| 1 | 1 | 80 分处累计 1 人 | 80 |
| 2 | 1 | 90 分处累计 1 人 | 90 |
| 3 | 1 | 90 分处累计 1 人 | 90 |
| 4 | 1 | 100 分处累计 1 人 | 100 |
| 5 | 2 | 100 分累计 1 人，90 分累计 3 人 | 90 |

第五步并列的 90 分都越过分数线，所以实际获奖 3 人。代码无需把 k 反复改大，只要找到第 k 名所在的分数桶。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int countScore[601];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, w;
    cin >> n >> w;
    for (int p = 1; p <= n; p++) {
        int score;
        cin >> score;
        countScore[score]++;
        int k = max(1, p * w / 100);
        int total = 0, line = 0;
        for (int value = 600; value >= 0; value--) {
            total += countScore[value];
            if (total >= k) {
                line = value;
                break;
            }
        }
        cout << line << (p == n ? '\n' : ' ');
    }
    return 0;
}
```

p×w 最大不到 10^7，用 int 足够。这里先做整数乘法再除以 100，整数除法对非负数直接向下取整；不要先写 w/100，因为整数除法会先得到 0。

每人只扫描至多 601 个分数，时间 O(nV)，其中 V=601，最大约 6×10^7 次简单累加，空间 O(V)。这是用 601 个桶保存统计，替换一次又一次处理全部已公布成绩。

> **数组范围跟着下标含义走。**
>
> 成绩包括 0 和 600，所以数组要有 601 个位置，下标为 0 到 600。若分数可能达到 10^9，就不能仍按分数直接开桶；可以用 map、离散化等方式，只保存实际需要的信息。

## 预处理：把之后反复需要的结果提前备好

前缀和就是已经学过的预处理：花 O(n) 建表，把每次求区间和的 O(n) 扫描变成 O(1) 相减。类似地，可以保存某个范围内的频数、某类元素的前缀个数、每个前缀的最小值。

选择保存什么信息，要从后面的询问反推：

| 后续要问什么 | 可以预先保存什么 | 怎样读取结果 |
| --- | --- | --- |
| 数 x 出现过几次 | count[x] | 直接读桶 |
| [l,r] 里有几个达标值 | 达标标记的前缀和 | s[r]−s[l−1] |
| 当前前缀的最小元素 | prefixMin[i] | 直接读 prefixMin[r] |
| 当前值与之前同类位置的总贡献 | 每类的个数、下标和、数值和 | 用统计量计算，不逐个枚举 |

例如预先记录 prefixMin[i]=min(prefixMin[i−1],a[i])，之后问前 r 个数的最小值就能直接读取。**但任意区间最小值不能像区间和一样，用两个前缀最小值相减得到**：求和能够消掉重复部分，最小值没有这样的减法性质。

空间换时间也需要估算数组大小。若有 n=10^5 个前缀、每个前缀统计 26 个字母，int 表大约占 10^5×26×4 字节，约 10.4 MB；如果每个前缀都保存整个前缀的副本，总量会达到 O(n²)，没有消除重复存储。

## 经典类型：有多少个区间的和等于 k

**先固定右端点，再统计它能配上几个左端点。**这是一种经常用到的枚举方式。

设 s[r] 是前 r 个数的和，s[0]=0。区间 [l,r] 的和为 k，就等价于：

```text
s[r] - s[l-1] = k
s[l-1] = s[r] - k
```

当我们枚举到右端点 r，当前前缀和记为 sum=s[r]。需要寻找的不是某个具体的左端点，而是：**此前的 s[0] 到 s[r−1] 中，有多少个值等于 sum−k？**每个这样的位置 j 都对应一个合法区间 [j+1,r]。

所以可以用桶或 map 记录以前出现过的前缀和及其次数。前缀和范围小、能安全映射为数组下标时用桶；可能出现负数或数值很大时，用 map<long long,long long> 记录更直接。

### 例题精讲：自编 · 区间和计数

**题意简述：** 输入 n、k 及 n 个整数，求和恰好为 k 的非空连续区间个数。n≤2×10^5，元素绝对值≤10^9，k 的绝对值≤10^14。

输入：

```text
3 0
1 -1 0
```

输出为 `3`，对应 [1,2]、[1,3]、[3,3]。

| 右端 r | 当前 sum | 要查 sum−k | 之前出现几次 | 新找到哪些区间 |
| --- | --- | --- | --- | --- |
| 1 | 1 | 1 | 0 | 无 |
| 2 | 0 | 0 | 1 | [1,2] |
| 3 | 0 | 0 | 2 | [1,3]、[3,3] |

开始就记录 s[0]=0 出现一次。因此 r=2 时能找到“从第一个数开始”的区间。到 r=3 时，值为 0 的旧前缀分别位于 0、2，虽然数值相同，却对应两个不同左边界，要保留次数。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long k;
    cin >> n >> k;
    map<long long, long long> countPrefix;
    countPrefix[0] = 1;
    long long sum = 0, answer = 0;
    for (int r = 1; r <= n; r++) {
        long long x;
        cin >> x;
        sum += x;
        auto it = countPrefix.find(sum - k);
        if (it != countPrefix.end()) answer += it->second;
        countPrefix[sum]++;
    }
    cout << answer << '\n';
    return 0;
}
```

查询使用 find，不存在时贡献为 0；更新使用 countPrefix[sum]++，第一次出现就从 0 开始累计。map 操作 O(log n)，总时间 O(n log n)，空间 O(n)。若换成合适范围的数组桶，查询与记录均为 O(1)；unordered_map 则是平均 O(1) 查询与记录。

> **先查询旧前缀，再记录当前前缀。**
>
> 当前右端 r 只能搭配 j<r 的前缀。若先加入 s[r]，当 k=0 时就会把 s[r]−s[r]=0 算进去，对应一个空区间。countPrefix[0]=1 则表示真正存在的初始空前缀，用它配上 r≥1 得到的是非空区间。全部元素为 0、k=0 时答案为 n(n+1)/2，n=2×10^5 时超过 int，所以前缀和、计数和答案都用 long long。

这套方法允许数组含负数，因为它依赖前缀和的代数关系，不要求窗口和随端点单调变化。

### 从“一个前缀和”推广到“一组前缀状态”

如果题目要求多类元素在区间内的次数相等，也可以尝试把条件改写成两个前缀状态相同。P1360 就是这样的练习：

1. 对每种能力 j，记录前 r 天的提升次数 c[j]。
2. 将状态写成 `{c[2]−c[1], c[3]−c[1], …, c[m]−c[1]}`。
3. 两个前缀状态相同，就表示它们之间的区间里，每种能力比能力 1 多出的次数都是 0，也就是所有能力提升次数相同。

这里题目要的是**最长长度**，因此 map 中保存状态最早出现的位置。相同状态再次出现在 r，就尝试用 r−最早位置更新答案，不覆盖原来的最早位置。初始全零状态的位置为 0；m=1 时状态没有差值分量，所有前缀状态相同，整个区间自然均衡。

对照两类目标：统计区间数量，保存出现**次数**；寻找最长区间，保存**最早位置**。先明确需要什么答案，再决定 map 的值保存什么。

## 再进一步：保存汇总信息，代替重复查看明细

假设当前数 a[i] 要与所有之前同类的 a[x] 配对，贡献为 a[x]+a[i]。直接枚举每个 x，会反复扫描同一批旧元素。

若提前维护同类元素个数 cnt 和数值和 sumValue，这次总贡献就是：

```text
所有旧 a[x] 的和 + 当前 a[i] 被加了 cnt 次
= sumValue + cnt * a[i]
```

先用统计量计算当前贡献，再把当前元素加入统计。这个顺序对应“只与之前的元素配对”，避免让自己与自己配对，也避免重复统计。

这与前面 map 中的 frequency[x]++ 是相通的：我们保存的不是完整的解题历史，而是之后计算真正需要的几个数。练习中的 P2671 会把这一思想用到下标与数值的组合贡献中。

## 练习：先问后续究竟需要什么信息

先**独立重做 P7072 与区间和计数例题**。前者检查同分和分数边界；后者检查负数、重复前缀、从第一个元素开始的区间，以及 k=0。

### 推荐必做

1. [P1360 · Gold Balanced Lineup G](https://www.luogu.com.cn/problem/P1360)：求每种能力提升次数相同的最长连续时期。将各能力相对能力 1 的前缀计数差作为状态，可用 map<vector<int>,int> 保存最早位置；输入数字的各个二进制位表示当天哪些能力提升，位的读取会在第 6.3 节讲解。练习从“前缀值匹配”推广到“前缀状态匹配”。
2. [P2671 · 求和](https://www.luogu.com.cn/problem/P2671)：端点 x<z 同色、同奇偶时，中点 y=(x+z)/2 是整数，三元组贡献为 (x+z)×(a[x]+a[z])。按“颜色、奇偶”分组，把贡献展开成 x×a[x]+x×a[z]+z×a[x]+z×a[z]，分别维护个数、下标和、数值和、下标乘数值之和，练习把成对枚举改成汇总统计，最后按题意对 10007 取模。

### 选做巩固

- [P1115 · 最大子段和](https://www.luogu.com.cn/problem/P1115)：固定右端 r 后，最大化 s[r]−s[l−1]，等价于找此前最小的前缀和。先用旧最小值更新答案，再纳入 s[r]，保证区间非空；初始 s[0]=0 也要参与。
- **自编 · 字母区间计数：** 输入长度≤10^5 的小写字符串和 q≤10^5 次询问 l、r、c，输出该区间中字母 c 的出现次数。建立每个字母的前缀计数，先估算空间再选择数组大小。
- **自编 · 值出现的区间：** 给 n≤10^5 个数，值在 0 到 10^6。预处理后回答 q≤10^5 个值 x 的“出现次数、首次位置、末次位置”，不存在输出 `0 -1 -1`。对每个值保存三个统计量，体会一次扫描准备多种答案。

## 本节验收

能根据值域选择数组计数或映射；能从区间和推导 sum−k，解释初始前缀和与查询顺序；能根据“数量、最长长度、总贡献”等目标决定保存次数、最早位置或累计统计量，并估算时间和空间。
