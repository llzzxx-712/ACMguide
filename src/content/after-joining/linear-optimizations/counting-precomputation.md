## 这一节学什么

遇到重复计算时，可以先问：上次已经算出的信息，能不能保存下来供下一次直接使用？本节从成绩计数出发，学习小值域桶、预处理与空间换时间，再把前缀统计推广到多种累计信息。

> **AI 伴学提示词**
>
> 为我讲解计数、预处理和空间换时间，模拟分数桶与前缀和计数，解释为什么先查 sum-k 再记录 sum，并引导我对不理解的地方提问。

## 原始数据很多，不代表需要同样多种状态

如果 10 万个成绩都在 0 到 600 之间，可以用 `count[score]` 保存某个分数出现了几次。一共有 601 个可能分数，重复出现的成绩合在同一个桶里。

```text
输入：80 90 80 100
count[80]  = 2
count[90]  = 1
count[100] = 1
其他桶均为 0
```

之前的 `map<int, int>` 也能按分数计数；这里分数范围小而且连续，直接拿分数当下标就够了。**下标代表哪类数据，数组值代表这一类出现了多少次。**

若要按顺序输出这些成绩，从低分到高分扫描每个桶，每个分数输出 `count[score]` 次，就能得到有序结果。这也是桶排序思想的一种直接应用：数组下标本身就是顺序，不用反复比较所有成绩。

## 例题精讲：P7072 · 直播获奖

**原题：** [P7072 · 直播获奖](https://www.luogu.com.cn/problem/P7072)。

**题意简述：** 选手成绩依次公布，公布 p 人后，计划获奖人数为 `max(1, ⌊p×w/100⌋)`，需要立即输出成绩从高到低第 k 名的分数，其中 k 为计划获奖人数。并列同分者一起获奖，但分数线仍是第 k 名的分数。n≤10^5，分数为 0 到 600 的整数，1≤w≤99。

自拟输入：

```text
5 40
80 90 80 100 90
```

输出：

```text
80 90 90 100 90
```

### 为什么不每公布一人就重新排序

如果对前 p 人都排序一次，总工作量会随前缀增长反复累加。其实我们只关心第 k 名的成绩，不需要每次都重排所有选手姓名和分数。

每收到 score，执行 `count[score]`++。随后从 600 往 0 扫，累计已经有多少人成绩至少达到当前分数；第一次累计人数≥k 的分数，就是当前分数线。

| 已公布人数 p | 计划人数 k | 从高分向下累计到哪里 | 分数线 |
| --- | --- | --- | --- |
| 1 | 1 | 80 分处累计 1 人 | 80 |
| 2 | 1 | 90 分处累计 1 人 | 90 |
| 3 | 1 | 90 分处累计 1 人 | 90 |
| 4 | 1 | 100 分处累计 1 人 | 100 |
| 5 | 2 | 100 分累计 1 人，90 分累计 3 人 | 90 |

第五步并列的 90 分都越过分数线，所以实际获奖 3 人。代码无需把 k 反复改大，只要找到第 k 名所在的分数桶。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int countScore[601];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, w;
    cin >> n >> w;
    for (int p = 1; p <= n; p++) {
        int score;
        cin >> score;
        countScore[score]++;
        int k = max(1, p * w / 100);
        int total = 0, line = 0;
        for (int value = 600; value >= 0; value--) {
            total += countScore[value];
            if (total >= k) {
                line = value;
                break;
            }
        }
        cout << line << (p == n ? '\n' : ' ');
    }
    return 0;
}
```

p×w 最大不到 10^7，用 `int` 足够。这里先做整数乘法再除以 100，整数除法对非负数直接向下取整；不要先写 w/100，因为整数除法会先得到 0。

每人只扫描至多 601 个分数，时间 $\mathcal{O}(nV)$，其中 V=601，最大约 6×10^7 次简单累加，空间 $\mathcal{O}(V)$。这是用 601 个桶保存统计，替换一次又一次处理全部已公布成绩。

> **数组范围跟着下标含义走。**
>
> 成绩包括 0 和 600，所以数组要有 601 个位置，下标为 0 到 600。若分数可能达到 10^9，就不能仍按分数直接开桶；可以用 `map`、离散化等方式，只保存实际需要的信息。

## 预处理：把之后反复需要的结果提前备好

前缀和就是已经学过的预处理：花 $\mathcal{O}(n)$ 建表，把每次求区间和的 $\mathcal{O}(n)$ 扫描变成 $\mathcal{O}(1)$ 相减。类似地，可以保存某个范围内的频数、某类元素的前缀个数、每个前缀的最小值。

选择保存什么信息，要从后面的询问反推：

| 后续要问什么 | 可以预先保存什么 | 怎样读取结果 |
| --- | --- | --- |
| 数 x 出现过几次 | `count[x]` | 直接读桶 |
| `[l, r]` 里有几个达标值 | 达标标记的前缀和 | `s[r] - s[l - 1]` |
| 当前前缀的最小元素 | `prefixMin[i]` | 直接读 `prefixMin[r]` |
| 当前值与之前同类位置的总贡献 | 每类的个数、下标和、数值和 | 用统计量计算，不逐个枚举 |

例如预先记录 `prefixMin[i] = min(prefixMin[i - 1], a[i])`，之后问前 r 个数的最小值就能直接读取。**但任意区间最小值不能像区间和一样，用两个前缀最小值相减得到**：求和能够消掉重复部分，最小值没有这样的减法性质。

空间换时间也需要估算数组大小。若有 n=10^5 个前缀、每个前缀统计 26 个字母，`int` 表大约占 10^5×26×4 字节，约 10.4 MB；如果每个前缀都保存整个前缀的副本，总量会达到 $\mathcal{O}(n^{2})$，没有消除重复存储。

## 经典类型：有多少个区间的和等于 k

**先固定右端点，再统计它能配上几个左端点。**这是一种经常用到的枚举方式。

设 `s[r]` 是前 r 个数的和，`s[0] = 0`。区间 `[l, r]` 的和为 k，就等价于：

```text
s[r] - s[l-1] = k
s[l-1] = s[r] - k
```

当我们枚举到右端点 r，当前前缀和记为 `sum = s[r]`。需要寻找的不是某个具体的左端点，而是：**此前的 `s[0]` 到 `s[r - 1]` 中，有多少个值等于 sum−k？**每个这样的位置 j 都对应一个合法区间 `[j + 1, r]`。

所以可以用桶或 `map` 记录以前出现过的前缀和及其次数。前缀和范围小、能安全映射为数组下标时用桶；可能出现负数或数值很大时，用 `map<long long, long long>` 记录更直接。

### 例题精讲：[CF1398C Good Subarrays](https://codeforces.com/problemset/problem/1398/C)

**题意简述：** 给一个由 0…9 组成的数组，统计元素和等于区间长度的非空连续区间。第一行测试组数 t，每组输入 n 和一个 n 位数字串；所有组总长度≤10⁵。每组输出区间数。

自编输入：

```text
1
3
120
```

输出：

```text
3
```

### 先把思路讲清楚

对 `[1, 2, 0]`，合法区间是 [1]、`[2, 0]`、`[1, 2, 0]`。枚举右端点 $r$，区间条件及移项结果为：

$
\begin{aligned}
S_r-S_{l-1}&=r-(l-1),\\
S_r-r&=S_{l-1}-(l-1).
\end{aligned}
$

这里的 $S_i$ 对应前缀和 `S[i]`。固定右端点后，只需统计此前有多少个位置满足 `S[j] - j == S[r] - r`。

于是把普通前缀和换成 `key[i] = S[i] - i`，只需数左边有几个与当前 key 相等的前缀。三个位置的 key 为 `[0, 1, 0]`，连同空前缀 `key[0] = 0`，逐步增加的答案为 1、0、2。

先把 `count[0] = 1` 放入 `map`，使从第一个元素开始的区间也能计入。处理 r 时先查询、后登记，保证左前缀严格在 r 左边，避免统计空区间。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        string a;
        cin >> n >> a;
        map<int, long long> count;
        count[0] = 1;
        int sum = 0;
        long long answer = 0;
        for (int r = 1; r <= n; r++) {
            sum += a[r - 1] - '0';
            int key = sum - r;
            answer += count[key];
            count[key]++;
        }
        cout << answer << '\n';
    }
    return 0;
}
```

最大答案为 $\frac{n(n+1)}{2}$，使用 `long long`。`map` 的每次操作 $\mathcal{O}(\log  n)$，总时间 $\mathcal{O}(n \log  n)$、空间 $\mathcal{O}(n)$。也可以把 key 的范围平移后用桶计数，统计流程不变。

## 练习：先问后续究竟需要什么信息

先**独立重做 P7072 与 CF1398C**。前者检查同分和分数边界；后者检查全 1、含 0、重复的 `S[i] - i`，以及从第一个元素开始的区间。

### 推荐必做

1. [P8649 · k 倍区间](https://www.luogu.com.cn/problem/P8649)：统计和为 K 的倍数的连续区间数。相同余数的两个前缀可以组成一个合法区间；先登记空前缀，再累计已有余数的次数，答案用 `long long`。
2. [AT_abc233_d · Count Interval](https://www.luogu.com.cn/problem/AT_abc233_d)：统计和恰好为 K 的连续区间数。数列可以包含负数，用 `map` 记录已出现的前缀和次数，先查询再插入当前前缀。
