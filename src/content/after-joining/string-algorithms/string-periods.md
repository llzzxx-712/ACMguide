## 这一节学什么

前缀函数不仅能寻找一个模式出现在哪里。相同的前后缀还意味着字符串在某个距离后重复；我们可以由此推导周期，也能寻找两串拼接时可共用的部分。

> **AI 伴学提示词**
>
> 为我讲解 border 与周期的关系，用 cabcabca 和 abababa 区分允许截断的周期与完整重复，再模拟两串的重叠拼接，并引导我提问。

## 一个 border 对应一次向后平移

若长度为 n 的字符串有长度为 b 的 border，就有：

```text
s[0..b-1] = s[n-b..n-1]
```

令 p=n−b，相同位置相隔 p：对所有 i≥p，都有 s[i]=s[i−p]。也就是说，从第 p 个位置开始，每个字符都重复前面 p 格的字符，p 就是一个周期长度。

反过来，若 p 是周期，前 n−p 个字符就与后 n−p 个字符相等，所以它们构成 border。因此：**周期越短，对应的 border 越长**，最短周期为：

```text
p = n - pi[n-1];
```

若没有非空 border，pi[n−1]=0，最短周期为 n，即整个串作为一轮。

## 例题精讲：P4391 · Radio Transmission 无线传输

**原题：** [P4391 · Radio Transmission 无线传输](https://www.luogu.com.cn/problem/P4391)。

**题意简述：** 一条消息不断循环播放，收到其中一段字符串，求原消息可能的最短长度。接收内容可以从循环中间开始，也可以在一轮尚未结束时停止，长度≤10^6。

自拟输入：

```text
8
cabcabca
```

输出为 `3`。用 cab 重复得到 cabcabcab……，前 8 个字符就是收到的内容。它也可以看作循环 abc 从 c 开始接收，旋转循环起点不影响最短长度。

### 手算最长 border

```text
前缀：c a b c a
全串：c a b c a b c a
后缀：      c a b c a
```

最长 border 长度为 5，所以 p=8−5=3。后面的字符都与前面相隔 3 的位置相同。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    string s;
    cin >> n >> s;
    vector<int> pi(n);
    for (int i = 1; i < n; i++) {
        int j = pi[i-1];
        while (j > 0 && s[i] != s[j]) j = pi[j-1];
        if (s[i] == s[j]) j++;
        pi[i] = j;
    }
    cout << n - pi[n-1] << '\n';
    return 0;
}
```

前缀函数 O(n) 时间，最后读取一次结果，空间 O(n)。仍是上一节的 pi 构造，只是问题要求的答案换成了“长度减去最长 border”。

## “允许最后一轮截断”与“完整重复”要分清

abababa 的最短周期为 2，用 ab 循环可以生成它，但长度 7 不是 2 的倍数，最后一轮只收到 a。

若另一个题目要求整个串必须是若干个完整循环节拼成的，则需要检查 n%p==0。满足时循环节长 p，否则只能把整串看成一轮，长度为 n：

```text
int p = n - pi[n-1];
if (n % p != 0) p = n;
int repeats = n / p;
```

例如 ababab 的完整循环节为 ab，重复 3 次；abababa 的完整循环节长度为 7。本题允许截断，不加整除检查，直接输出 2 或 3 等最短周期。

## 不止最长一个：沿 border 链往回找

如果想找全部 border，从 len=pi[n−1] 开始，再令 len=pi[len−1]，直到 0。

对 ababa：最长 border 为 aba，长度 3；aba 自己的最长 border 为 a，长度 1；再往下为 0。于是全部非空 border 长度为 1、3。

这条链和 KMP 失配时回退走的是同一条路：每次从当前可用前后缀，转到它内部更短的可用前后缀。若每个前缀都单独走到链尾，重复字符多时可能达到 O(n²)；进一步统计时，要继续寻找可以复用的累计信息。

## 应用：拼接两串时共用重叠部分

例如 A=abcab、B=abxyz。A 的末尾 ab 与 B 的开头 ab 相同，可以只保留一份，得到 abcabxyz。

需要寻找的是“A 的后缀与 B 的前缀”的最长相同长度。对小写字符串构造 `B + "#" + A`，其中 # 不会出现在原输入中。这个新串的最后一个 pi 值，就给出所需的重叠长度。

为什么不会把 B 之后的字符也误当成更长前缀？因为 # 只出现一次，真正相同的前后缀无法跨过这个独有分隔符。最后输出 A，再接 B 中尚未共用的后半段。

```text
string joined = b + "#" + a;
// 按相同规则计算 joined 的 pi
int overlap = pi.back();
cout << a << b.substr(overlap) << '\n';
```

substr(pos) 表示取从 pos 到结尾的字符串；这里原字符串仍从 0 开始，因此跳过 overlap 个字符，直接用 overlap 作为起点。

## 练习：先确认题目的“周期”定义

先**独立重做 P4391**，比较 cabcabca、abababa、ababab、abc 和单个字符，手算各自的最长 border 与最短周期。

### 推荐必做

1. **自编 · 完整重复次数：** 输入长度≤10^6 的非空小写串，输出最短完整循环节长度和重复次数。加入整除判断，区分“不完整末轮”和“一轮完整字符串”。
2. **自编 · 重叠拼接：** 输入两个长度≤10^5 的非空小写串，保留 A、B 内部次序且不删除各自字符，把 A 的后缀与 B 的前缀尽可能共用，输出最短拼接结果。使用分隔串求 pi，并检查完全重叠和无重叠。

### 选做巩固

- [P3435 · OKR-Periods of Words](https://www.luogu.com.cn/problem/P3435)：按题目给出的周期定义，求所有前缀的最大周期长度之和。沿 border 关系寻找最短非空 border，并思考怎样保存结果，避免每次重新走完整条链；没有对应周期时贡献为 0。
- [P1470 · 最长前缀](https://www.luogu.com.cn/problem/P1470)：若干短单词能反复使用，求能拼出的目标串最长前缀。定义可达位置 DP，用字符串匹配判断从一个可达位置能接上哪些短单词，把匹配结果变成状态转移。

## 本节验收

能从相隔 p 的字符相等推导 border；能区分两种重复要求；能把 pi 看作可继续使用的前后缀关系，并应用于周期和拼接。
