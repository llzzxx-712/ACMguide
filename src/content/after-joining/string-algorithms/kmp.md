## 这一节学什么

暴力匹配失败后，常会换一个起点，把刚比较过的字符再比较一遍。KMP 保存模式串的前后缀关系，让失配时能保留已经确定的匹配部分。重点是理解 j 表示多少个字符已经匹配，以及它为什么沿前缀函数回退。

> **AI 伴学提示词**
>
> 为我讲解前缀函数和 KMP，用 ABABAC 在 ABABABAC 中匹配的过程模拟失配回退，解释保留了哪段字符，并引导我对不理解的地方提问。

## 先认识 border：相同的真前缀与后缀

前缀从字符串开头开始，后缀在字符串结尾结束。若一个字符串既是某串的前缀，又是它的后缀，并且不是整个串本身，就称为它的 border。

例如 ABABA 的 border 有 A、ABA，最长长度为 3。这里允许前后缀重叠，ABA 分别占第 1—3 位和第 3—5 位。

本节使用从 0 开始的下标，定义 pi[i] 为模式串 p[0..i] 的最长 border 长度：

```text
p：     A B A B A C
下标：  0 1 2 3 4 5
pi：    0 0 1 2 3 0
```

pi[i] 保存的是**长度**，不是最后一个字符的下标。长度为 j 的前缀对应下标 0 到 j−1，下一个等待比较的位置是 p[j]。

## 怎样从前一个位置继续计算 pi

计算 pi[i] 时，先取 j=pi[i−1]：之前结尾已经与长度 j 的前缀相同，现在看新字符 p[i] 能不能与 p[j] 接上。

- 能接上，长度变成 j+1。
- 接不上，就寻找这段长度 j 前缀本身的更短 border，令 j=pi[j−1]。
- 继续尝试，直到接上或 j=0。

为什么可以这样缩短？之前匹配的后缀等于模式串开头长度 j 的前缀；它的更短可用后缀，正是这个前缀自己的 border。我们不是把 j 随便减一，而是在枚举**仍有可能继续匹配的前后缀长度**。

例如计算 ABABAC 最后一个 C：先有 j=3，C 与 p[3]=B 不同；回退到 pi[2]=1，仍与 p[1]=B 不同；回退到 pi[0]=0，与 A 也不同，最终 pi[5]=0。

## 匹配文本时，怎样利用这份信息

文本 s=ABABABAC，模式 p=ABABAC。先匹配了 ABABA，文本下一位是 B，而模式下一位是 C，失配：

```text
文本：A B A B A B A C
模式：A B A B A C
已匹配 ABABA，下一位 B 与 C 不同

保留末尾 ABA，对齐到新的模式前缀：
文本：A B A B A B A C
模式：    A B A B A C
```

已匹配长度 j=5，令 j=pi[4]=3，就保留了文本中最后的 ABA。当前文本字符 B 再与 p[3]=B 比较，成功后 j=4，文本继续向右走，最后在起点 3 找到完整匹配。

**文本下标不后退。** 我们回退的是模式已经匹配的长度，利用旧比较结果排除不可能的位置。

## 例题精讲：P3375 · KMP

**原题：** [P3375 · KMP](https://www.luogu.com.cn/problem/P3375)。

**题意简述：** 给出文本与模式，按顺序输出模式在文本中出现的全部起点，下标从 1 开始，允许重叠。最后输出模式每个前缀的最长 border 长度。两串长度都不超过 10^6。

自拟输入：

```text
ABABABAC
ABABAC
```

输出：

```text
3
0 0 1 2 3 0
```

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s, p;
    cin >> s >> p;
    int n = s.size(), m = p.size();
    vector<int> pi(m);
    for (int i = 1; i < m; i++) {
        int j = pi[i-1];
        while (j > 0 && p[i] != p[j]) j = pi[j-1];
        if (p[i] == p[j]) j++;
        pi[i] = j;
    }
    int j = 0;
    for (int i = 0; i < n; i++) {
        while (j > 0 && s[i] != p[j]) j = pi[j-1];
        if (s[i] == p[j]) j++;
        if (j == m) {
            cout << i - m + 2 << '\n';
            j = pi[j-1];
        }
    }
    for (int i = 0; i < m; i++) cout << pi[i] << (i + 1 == m ? '\n' : ' ');
    return 0;
}
```

完整匹配在文本下标 i 结束，0 起点是 i−m+1，题目要求从 1 开始，所以输出 i−m+2。

> **一次匹配结束后，仍要保留可继续使用的后缀。**
>
> 令 j=pi[j−1]，既让下一次读取 p[j] 时不越界，也允许重叠匹配。例如 AAA 中查 AA，第一次从 1 开始，保留长度 1 的 A 后，下一次还能找到起点 2；直接清零会漏掉它。

计算 pi 和匹配都是 O(n+m) 时间：每读一个新字符，j 最多加一；所有回退使 j 减小，总回退次数不会超过总增加次数。pi 数组占 O(m)，输入字符串占 O(n+m)。

## 练习：给 j 的每次变化说一个理由

先**独立重做 P3375**，检查不匹配、模式比文本长、单字符模式、重复字符与重叠出现。

### 推荐必做

1. **自编 · 匹配次数：** 沿用例题输入，只输出模式出现次数，仍允许重叠。每次 j=m 时计数，然后保留最长 border 继续匹配。
2. **自编 · 输出 border 链：** 输入非空字符串，输出它所有非空真前后缀的长度，从小到大。先得到最长长度 pi[n−1]，再反复跳到 pi[len−1]，收集后逆序输出，没有则输出 0。

### 选做巩固

- [P2375 · 动物园](https://www.luogu.com.cn/problem/P2375)：对每个前缀统计不重叠的 border 数量，再按题意组合结果。沿 pi 跳转时加入长度不超过前缀一半的限制，继续思考如何避免对每个前缀重新走整条链。
- **自编 · 从若干文本查同一模式：** 先输入模式，再输入若干非空文本，分别输出匹配次数，总文本长度≤10^6。模式的 pi 只建一次，每段文本开始时重新令 j=0。

## 本节验收

能解释 border 与 pi 的长度含义；能用已匹配后缀推导 j=pi[j−1]；能处理重叠匹配与 0、1 两种下标的转换，而不是只背两段相似循环。
