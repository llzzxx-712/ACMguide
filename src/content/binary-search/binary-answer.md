## 从“最高是多少”改成“这个高度行不行”

上一节在有序数组中查位置。现在考虑：锯片设得越高，锯下来的木材越少；如果需要至少 7 米木材，锯片最高能设到哪里？

直接求最高高度可能还没思路，但给定高度 15 米，就很容易检查：逐棵计算锯下的部分，加起来是否达到 7 米。

这就是二分答案的第一步：**把求最优值，转成判断一个候选值能不能做到。**

我们把判断封装成 `bool` 函数 `check(h)`，`true` 表示这个高度可行，`false` 表示不可行。然后再看候选值变大时，可行性怎样变化。

## 例题精讲：P1873 · 砍树

**原题：** [P1873 · 砍树](https://www.luogu.com.cn/problem/P1873)，来自[自编入门题单](https://www.luogu.com.cn/training/1126196)。

**题意简述：** 有 $n$ 棵树，需要至少 $m$ 米木材。锯片设在整数高度 $h$，高于 $h$ 的树被锯下高出的部分，其他树不动。求能够获得足够木材的最大 $h$。

$n\le 10^6$，$m\le 2\times 10^9$，树高不超过 $4\times 10^5$；全部树高之和大于 $m$。

输入：

```text
4 7
20 15 10 17
```

输出：

```text
15
```

### 固定高度，检查木材是否够用

一棵树高为 `a[i]`，锯片高度为 $h$，贡献是：

```text
max(a[i] - h, 0)
```

树比锯片高，就贡献差值；不高于锯片，贡献为 0，不会产生负木材。把所有树的贡献相加，与所需长度比较即可。

| $h$ | 高 20 的树 | 高 15 的树 | 高 10 的树 | 高 17 的树 | 总量 | 至少 7 米？ |
| --- | --- | --- | --- | --- | --- | --- |
| 14 | 6 | 1 | 0 | 3 | 10 | 是 |
| 15 | 5 | 0 | 0 | 2 | 7 | 是 |
| 16 | 4 | 0 | 0 | 1 | 5 | 否 |

$h=15$ 可行，$h=16$ 已不可行，答案为 15。

## 单调性：可行后，怎样继续找更好的

锯片升高时，每棵树贡献的木材只会减少或不变，总量也只会减少或不变。

因此：

- $h$ 可行，比它低的高度也可行。
- $h$ 不可行，比它高的高度也不可行。

从低到高排列候选高度：

```text
高度：0  1  2  ...  14 15 16 17 ... 400000
可行：是 是 是 ...  是 是 否 否 ...    否
```

这种只从“是”变成“否”、不会来回变化的性质，叫**单调性**。我们要找其中最大的可行高度。

树本身的输入顺序可以是乱的，不必排序；这里有顺序的是候选高度对应的可行性。

> **先写 `check` 的含义，再说明单调方向。**
>
> 本题 `check(h)` 表示“锯片设到 $h$，木材够不够”。高度越高，木材越少，所以可行值在左，不可行值在右。
>
> 每次找到可行的 $\mathrm{mid}$，先把它保存到 $\mathrm{ans}$，再尝试更高的高度。

## 闭区间与 $\mathrm{ans}$：和查找使用同一套写法

这里也先把思路说成一句话：“固定一个高度，算木材够不够；够就先记住这个高度，再尝试更高；不够就试更低。”`check` 实现“算木材够不够”，$\mathrm{ans}$ 实现“先记住”，两种边界更新实现“再尝试的方向”。代码中的每个部分，都能在这句话里找到对应的任务。

答案范围可以取 $[0,400000]$，因为树高不超过 400000。定义：

```text
int le = 0, r = 400000, ans = -1;
```

- $[\mathrm{le},r]$：还要尝试的整数高度，两端都包含。
- $\mathrm{ans}$：目前找到的最大可行高度，初始 −1 表示尚未记录。

每轮取 $\mathrm{mid}$，然后只做两种处理：

| `check(mid)` | 说明 | 处理 |
| --- | --- | --- |
| `true` | $\mathrm{mid}$ 是可行答案，还可以试更高 | `ans = mid`，`le = mid + 1` |
| `false` | $\mathrm{mid}$ 不可行，更高的也不行 | `r = mid - 1` |

循环条件仍是 $\mathrm{le}\le r$，每次都越过已经检查的 $\mathrm{mid}$。结束时直接输出 $\mathrm{ans}$。

**最大可行值不需要靠退出后的边界推算。** 只要发现可行值，就已经把它记进 $\mathrm{ans}$ 了。

### 从较小范围手算同样的过程

为方便在纸上观察，样例的最高树只有 20 米，我们手算时把初始范围缩到 $[0,20]$。使用 $[0,400000]$ 运行程序也会得到相同结果。

| 轮次 | $\mathrm{le}$ | $r$ | $\mathrm{mid}$ | 木材总量 | 操作后 $\mathrm{ans}$ | 边界更新 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 0 | 20 | 10 | 22 | 10 | `le = 11` |
| 2 | 11 | 20 | 15 | 7 | 15 | `le = 16` |
| 3 | 16 | 20 | 18 | 2 | 15 | `r = 17` |
| 4 | 16 | 17 | 16 | 5 | 15 | `r = 15` |

最后 $\mathrm{le}=16$、$r=15$，循环结束，输出 $\mathrm{ans}=15$。第 `3、4` 轮失败后，$\mathrm{ans}$ 仍保留上一轮找到的可行高度。

## 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1000007;
int n, m;
int a[N];

bool check(int h) {
    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += max(a[i] - h, 0);
    }
    return sum >= m;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);

    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    int le = 0, r = 400000, ans = -1;
    while (le <= r) {
        int mid = le + (r - le) / 2;
        if (check(mid)) {
            ans = mid;
            le = mid + 1;
        } else {
            r = mid - 1;
        }
    }

    cout << ans << '\n';
    return 0;
}
```

### 逐项检查

**每次 `check` 重新统计。** $\mathrm{sum}$ 是函数内的局部变量，每次从 0 开始。试新的高度时，不能沿用上次的累计量，也不能永久修改树高。

**等于所需长度也可行。** 题目要求至少 $m$，所以返回 $\mathrm{sum}\ge m$ 的判断结果。

**累计值用 `long long`。** 单棵树高能放入 `int`，但一百万棵树的总量可达 $4\times 10^{11}$，超过 `int` 的 2147483647。先定义 `long long` 类型的 $\mathrm{sum}$，再逐项相加。

**答案为 0 也要保留。** 题目保证 $h=0$ 时木材足够，因此 $\mathrm{ans}$ 最后至少会更新成 0。不能用 `if (ans)` 判断是否找到，因为 0 本身可以是合法答案。

**找到答案后还要继续。** 若可行就直接 `break`，只能得到某个可行高度，不能保证最高。保存 $\mathrm{ans}$ 后继续向右，才会找到更大的可行值。

## 一次 `check` 与总复杂度

一次 `check` 看 $n$ 棵树，是 $\mathcal{O}(n)$。高度范围大小约为 $H=400001$，二分需要 $\mathcal{O}(\log H)$ 轮，所以总时间为：

```text
O(n log H)
```

最大规模约为 19 轮、每轮一百万棵树，即一千九百万这个量级的处理。数组空间 $\mathcal{O}(n)$，`check` 的额外空间 $\mathcal{O}(1)$。

二分减少的是尝试的候选值数量，**每次 `check` 的成本仍要乘进去**。

## 最小可行值：保存后向左试

有些题目要求“最小容量”或“最小的最大段和”。候选值越大，限制越宽松，可行性可能是：

```text
否 否 否 是 是 是 是
```

这时找到一个可行 $\mathrm{mid}$，先保存 `ans = mid`，再向左试更小的值：

```text
int ans = -1;
while (le <= r) {
    int mid = le + (r - le) / 2;
    if (check(mid)) {
        ans = mid;
        r = mid - 1;
    } else {
        le = mid + 1;
    }
}
// 最后直接使用 ans
```

使用前，先给 $\mathrm{le}$、$r$ 选定包含答案的闭区间。若没有可行值，$\mathrm{ans}$ 保持 −1，再按题目要求处理无解输出。

| 目标 | 从小到大的可行性 | `check(mid)` 为真 | `check(mid)` 为假 |
| --- | --- | --- | --- |
| 最大可行值 | 是 → 否 | `ans = mid`，`le = mid + 1` | `r = mid - 1` |
| 最小可行值 | 否 → 是 | `ans = mid`，`r = mid - 1` | `le = mid + 1` |

两种写法都在可行时记录 $\mathrm{ans}$。**区别只在于：保存这个答案以后，是继续向右找更大值，还是向左找更小值。**
