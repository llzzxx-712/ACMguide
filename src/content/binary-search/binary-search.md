## 今天要完成什么

今天利用有序性，每次排除约一半候选位置。我们先找“第一个大于等于 $x$ 的位置”，统一使用闭区间和 $\mathrm{ans}$；再检查该位置是否等于 $x$，解决第一次出现的位置查询。

>

## 为什么可以每次排除一半

先看已经升序排列的一组数：

```text
编号：1  2  3  4  5  6  7
数值：1  2  2  2  5  7  9
```

要找数字 7，先看中间的第 4 个数，它是 2。因为数组有序，前 4 个数都不会大于 2，所以不可能是 7，可以一起排除。

只需要继续在第 5 到第 7 个数中查找，再取中点、再排除一半。这就是**二分查找**。

$n$ 个数大约需要 $\log_2 n$ 轮；一百万个数，减半约 20 次就能缩到很小的范围。有序性是这里的依据：若数组是乱的，中间的数小于目标，并不能说明左边都小于目标。

## 把目标改写成一个判断条件

若要找 2 第一次出现的位置，先问一个更统一的问题：**满足 $a[i]\ge 2$ 的位置中，编号最小的是多少？**

```text
编号：       1  2  3  4  5  6  7
a[i] >= 2： 否 是 是 是 是 是 是
```

条件从“否”变成“是”后不会再变回去，我们就能二分寻找最靠左的“是”。

中点满足 $a[\mathrm{mid}]\ge x$，说明它是一个**满足条件的候选答案**。但它左边可能还有更好的位置，所以先记下 `ans = mid`，再向左找。

| 判断 | 说明 | 本轮处理 |
| --- | --- | --- |
| $a[\mathrm{mid}]\ge x$ | $\mathrm{mid}$ 满足条件，左边可能有更小的编号 | `ans = mid`，`r = mid - 1` |
| $a[\mathrm{mid}]<x$ | $\mathrm{mid}$ 和左边都不满足条件 | `le = mid + 1` |

写代码前，先把这两种处理讲给自己听：“满足条件，先记住，再找更靠左的；不满足条件，这里和左边一起排除。”接着才写 $\mathrm{ans}$、$r$、$\mathrm{le}$ 的赋值。代码中的 `>=` 来自本次查找的条件，`r = mid - 1` 来自“更优位置在左边”；换一道题时，先重新判断这两件事。

> **满足条件，先记录，再尝试更优方向。**
>
> $\mathrm{ans}$ 表示已经找到的候选答案；找最小位置时，更优的方向就是左边。下一节二分答案也沿用这套思路：`check` 为真时先记录，再向可能更优的方向继续找。

## 闭区间与 $\mathrm{ans}$：每个变量都有直接的含义

本节把数据存放在 `a[1]` 到 `a[n]`，初始化：

```text
int le = 1, r = n, ans = -1;
```

- **$\mathrm{le}$、$r$：** 当前还要检查的最左、最右编号。
- **$[\mathrm{le},r]$：** 两端都包含，还没有检查完的位置。
- **$\mathrm{ans}$：** 已经找到的、满足 $a[i]\ge x$ 的候选位置；−1 表示暂时没有候选。

核心代码只有两个分支：

```text
while (le <= r) {
    int mid = le + (r - le) / 2;
    if (a[mid] >= x) {
        ans = mid;
        r = mid - 1;
    } else if (a[mid] < x) {
        le = mid + 1;
    }
}
```

$\mathrm{le}=r$ 时只剩一个元素，也要检查，所以循环条件有等号。每轮都排除已经检查的 $\mathrm{mid}$，边界使用 $\mathrm{mid}+1$ 或 $\mathrm{mid}-1$；当 $\mathrm{le}>r$ 时，候选范围为空。

中点写成 `le + (r - le) / 2` 可以避免 $\mathrm{le}+r$ 太大时溢出；在本题范围内，它与 `(le + r) / 2` 结果一致。

### 找到候选后，再确认是否恰好等于 $x$

例如查询 6，数组中第一个大于等于 6 的数是 7，位置为 6。这个位置满足我们二分时的条件，但**数组里并没有 6**。

因此要把“候选位置”与“目标是否存在”分清：

```text
if (ans != -1 && a[ans] == x) {
    return ans;
}
return -1;
```

先检查 $\mathrm{ans}\ne -1$，再访问 `a[ans]`。`&&` 左边为假时不计算右边，避免读取 `a[ -1]`。

### 与动图对应的完整程序

这份程序固定使用动图中的七个数，只需输入要查询的 $x$。复制运行后，分别输入 `2、6、9`，对照动图观察。

```cpp
#include<bits/stdc++.h>
using namespace std;

int a[8] = {0, 1, 2, 2, 2, 5, 7, 9};

int main() {
    int x;
    cin >> x;

    int le = 1, r = 7, ans = -1;
    while (le <= r) {
        int mid = le + (r - le) / 2;
        if (a[mid] >= x) {
            ans = mid;
            r = mid - 1;
        } else if (a[mid] < x) {
            le = mid + 1;
        }
    }

    if (ans != -1 && a[ans] == x) {
        cout << ans << '\n';
    } else {
        cout << -1 << '\n';
    }
    return 0;
}
```

`a[0]` 的 0 只用来占位，我们实际查找的是 `a[1]` 到 `a[7]`。输入 2 输出 2；输入 6 输出 −1；输入 9 输出 7。

### 把动图过程记成表

找 $x=2$：

| 轮次 | $\mathrm{le}$ | $r$ | $\mathrm{mid}$ | `a[mid]` | 本轮操作 |
| --- | --- | --- | --- | --- | --- |
| 1 | 1 | 7 | 4 | $2\ge 2$，满足条件 | `ans = 4`，`r = 3` |
| 2 | 1 | 3 | 2 | $2\ge 2$，满足条件 | `ans = 2`，`r = 1` |
| 3 | 1 | 1 | 1 | $1<2$，不满足条件 | `le = 2`，$\mathrm{ans}$ 保留 2 |

最后 $\mathrm{le}=2$、$r=1$，退出循环。`ans = 2` 且 `a[2] = 2`，返回 2。

如果查询 6，第一次检查的 2 太小，向右找；随后 $7\ge 6$，记录 `ans = 6` 并向左找；最后 $5<6$，退出。$a[6]=7$，验证不相等后返回 −1。

## 例题精讲：P2249 · 查找

**原题：** [P2249 · 查找](https://www.luogu.com.cn/problem/P2249)，来自[自编入门题单](https://www.luogu.com.cn/training/1126196)。

**题意简述：** 给出已经单调不减的数组，进行 $m$ 次询问。每次输出目标第一次出现的编号，从 1 开始；不存在就输出 −1。$n\le 10^6$，$m\le 10^5$，数值在 0 到 $10^9$ 之间。单调不减允许相等，题目已保证有序，无需再排序。

### 从一次查询，走到多次查询

把上面的二分过程写成 `findFirst(n, x)`。每次查询只改变 $x$，使用同一个有序数组，函数内部重新初始化 $\mathrm{le}$、$r$、$\mathrm{ans}$。

输入示例：

```text
5 5
1 2 2 2 5
2 4 1 6 5
```

输出：

```text
2 -1 1 -1 5
```

查 4 时，候选是位置 5，但 $a[5]=5$，因此返回 −1。查 6 时，整个数组都太小，没有候选，$\mathrm{ans}$ 保持 −1。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int a[1000005];

int findFirst(int n, int x) {
    int le = 1, r = n, ans = -1;
    while (le <= r) {
        int mid = le + (r - le) / 2;
        if (a[mid] >= x) {
            ans = mid;
            r = mid - 1;
        } else if (a[mid] < x) {
            le = mid + 1;
        }
    }
    if (ans != -1 && a[ans] == x) {
        return ans;
    }
    return -1;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    for (int i = 0; i < m; i++) {
        int x;
        cin >> x;
        if (i > 0) cout << ' ';
        cout << findFirst(n, x);
    }
    cout << '\n';
    return 0;
}
```

### 检查边界、答案与复杂度

- 数据使用 1 下标，初始闭区间为 $[1,n]$，$\mathrm{mid}$ 始终是本次数据的合法位置。
- $a[\mathrm{mid}]\ge x$ 时记录候选，继续向左寻找更小的编号。
- 找到最左候选后检查是否相等；无候选或不相等都返回 −1。
- 每轮越过 $\mathrm{mid}$，范围一定缩小；单元素也能正确结束。
- 每次查询 $\mathcal{O}(\log  n)$，总时间 $\mathcal{O}(n+m \log  n)$，空间 $\mathcal{O}(n)$。最大规模约两百万轮二分判断，输入达到百万级，先关闭流同步。

## lower_bound 与 upper_bound

理解手写二分后，可以用标准库完成常见查找。

```text
int pos = lower_bound(a + 1, a + n + 1, x) - a;
```

`lower_bound` 找第一个**大于等于 $x$**的位置，与前面手写二分的目标相同。返回位置减去数组开头 $a$，得到本节使用的 1 下标。

参数与 `sort` 一样表示 $[a+1,a+n+1)$，也就是从开头到结尾之前。这是标准库接口的区间约定；我们手写二分的待查范围仍是闭区间 $[\mathrm{le},r]$。

所有数都小于 $x$ 时，库函数返回 $n+1$。确认目标存在时，先检查范围：

```text
if (pos <= n && a[pos] == x) {
    // 找到了，编号是 pos
}
```

`upper_bound` 找第一个**严格大于 $x$**的位置：

```text
int pos = upper_bound(a + 1, a + n + 1, x) - a;
```

| 函数 | 返回的位置 |
| --- | --- |
| `lower_bound` | 第一个 $\ge x$ |
| `upper_bound` | 第一个 $>x$ |

对 `1 2 2 2 5` 查找 2，两个位置分别为 2 和 5，出现次数为 $5-2=3$：

```text
int first = lower_bound(a + 1, a + n + 1, x) - a;
int after = upper_bound(a + 1, a + n + 1, x) - a;
int count = after - first;
```

$x$ 不存在时，两者落在同一个插入位置，差为 0。单次调用在数组上为 $\mathcal{O}(\log  n)$。

> **标准库查找前，先保证数组升序。**
>
> 无序数组先用 `sort`；题目要求原输入编号或顺序时，先保存记录，再决定排序哪份数据。使用库函数返回的位置时先检查范围。
