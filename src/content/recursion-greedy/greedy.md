## 贪心在选什么

假设要从一些比赛里选出互不冲突的若干场，目标是参加的场数最多。我们每选一场，就会影响后面还能参加哪些比赛。

**贪心**就是在这样的过程中，每一步按一个规则选择当前看来最合适的方案，并继续处理剩下的部分。

理解时要分清：

- **目标：** 最后要最大化或最小化什么？这里是场数最多。
- **策略：** 每一步按什么规则选？例如结束最早、花费最少、单位收益最高。
- **依据：** 这样选为什么不会让最终答案变差？

策略不是看到题目里有“最大”“最小”就直接套出来的。先用小数据检验，再解释它与最终目标的关系。

## 用反例排除错误策略

先看一个自编的买硬币问题：有面值 `1 3 4` 的硬币，每种都可以使用多枚，要凑出 6，怎样用的枚数最少？

“每次拿不超过剩余金额的最大面值”会得到：

```text
4 + 1 + 1，共 3 枚
```

但实际可以：

```text
3 + 3，共 2 枚
```

这组数据就是**反例**：只要找到一个合法情况让策略不是最优，它就不能解决整道题。

找反例时，可以多试：

- 有一个选择很诱人，却挡住后面多个选择。
- 几个选择的数值相同。
- 最小规模、边界刚好相等的情况。
- 某个指标很小，但它与真正的目标并不一致。

我们接下来就用这种方式分析比赛安排。

## 例题精讲：P1803 · 凌乱的yyy / 线段覆盖

**原题：** [P1803 · 凌乱的yyy / 线段覆盖](https://www.luogu.com.cn/problem/P1803)。

**题意简述：** 有 $n$ 场比赛，每场给出开始时间和结束时间。参加一场就要完整参加，不能同时参加两场。求最多可以参加多少场。$1\le n\le 10^6$，时间满足 $0\le\mathrm{start}<\mathrm{finish}\le 10^6$。

一场结束时，另一场恰好开始，可以接着参加。也就是说，后面一场的开始时间**大于或等于**上一场的结束时间即可。

### 先比较几种看起来合理的选择

**方案一：优先开始最早的。**

```text
[0, 10)
[1, 2)
[2, 3)
[3, 4)
```

如果先选 $[0,10)$，只能参加 1 场；选后面三场，可以参加 3 场。因此“开始最早”不合适。

这里用 $[\mathrm{start},\mathrm{finish})$ 表示时间段，右端不包含，所以 $[1,2)$ 与 $[2,3)$ 不冲突。

**方案二：优先持续时间最短的。**

```text
[0, 3)
[3, 6)
[6, 9)
[2, 4)
```

最短的是 $[2,4)$，但它同时挡住前两场，最多只能再参加 $[6,9)$，共 2 场；选择前三场可以参加 3 场。因此“持续时间最短”也不合适。

**方案三：在可以接着参加的比赛中，优先选结束最早的。**

选完一场之后，越早空出时间，后面越有机会继续参加更多比赛。这是本题使用的贪心规则。

### 为什么“结束最早”一定成立

假设现在从某个时间开始有空，$E$ 是所有能参加的比赛中结束最早的一场。

再看一种最优安排，假设它第一场选的是 $O$。因为 $E$ 结束最早：

```text
E 的结束时间 <= O 的结束时间
```

把最优安排里的第一场 $O$ 换成 $E$：

1. $E$ 本来就可以参加，不会与已经参加的比赛冲突。
2. 原来排在 $O$ 后面的比赛，都在 $O$ 结束后才开始。
3. $E$ 结束得更早或一样早，所以后面的比赛仍然能参加。

因此，替换后场数不变，我们就得到了一个“第一场选 $E$”的最优安排。这叫**交换思路**：把某个最优方案中的选择，换成我们的贪心选择，结果不会变差。

选完 $E$ 后，剩下的仍是同样的问题：在结束时间之后，最多还能参加多少场。对剩余部分继续使用同样的规则即可。

> **把直觉补成一句能检查的理由。**
>
> “早结束更好”是直觉；“把最优安排的第一场换成最早结束的一场，后面的比赛仍全部可参加”说明了它为什么成立。
>
> 以后遇到新的贪心策略，也试着说明：与另一种选择相比，它怎样保留了后续机会？

### 用 sort 把选择顺序排出来

按照结束时间从小到大排序。维护 $\mathrm{lastEnd}$，表示最近一场已选比赛的结束时间。

然后从前到后扫描：

- 当前 $\mathrm{start}\ge\mathrm{lastEnd}$：可以参加，答案加 1，更新 $\mathrm{lastEnd}$。
- 当前 $\mathrm{start}<\mathrm{lastEnd}$：与已选比赛冲突，跳过它。

排序后，我们每次遇到的第一场可参加比赛，就是剩余比赛中结束最早的可参加比赛。

### 策略怎样落到程序里

先想清楚“每次选结束最早且不冲突的比赛”，再为这句话安排代码：`sort` 按结束时间排列候选；$\mathrm{lastEnd}$ 保存已选安排的结束时刻；$\mathrm{start}\ge\mathrm{lastEnd}$ 检查当前能否接上；选中后 `answer++`，并把 $\mathrm{lastEnd}$ 更新为这场的结束时间。

这里的排序键、判断条件和更新语句，都在实现同一个选择策略。遇到新题时，先说明为什么选它、选完以后留下什么状态，再写相应的排序和扫描。

### 手算一组完整数据

输入：

```text
6
1 3
2 4
3 5
0 6
5 7
7 8
```

这组数据已经按结束时间排列：

| 比赛 | 处理前 $\mathrm{lastEnd}$ | 能否参加 | 处理后 $\mathrm{lastEnd}$ | 已选场数 |
| --- | --- | --- | --- | --- |
| $[1,3)$ | 0 | 能 | 3 | 1 |
| $[2,4)$ | 3 | 不能 | 3 | 1 |
| $[3,5)$ | 3 | 能，边界相接 | 5 | 2 |
| $[0,6)$ | 5 | 不能 | 5 | 2 |
| $[5,7)$ | 5 | 能 | 7 | 3 |
| $[7,8)$ | 7 | 能 | 8 | 4 |

输出：

```text
4
```

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

struct Match {
    int start, finish;
};

Match matches[1000005];

bool cmp(Match a, Match b) {
    if (a.finish != b.finish) {
        return a.finish < b.finish;
    }
    return a.start < b.start;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> matches[i].start >> matches[i].finish;
    }

    sort(matches, matches + n, cmp);

    int lastEnd = 0;
    int answer = 0;
    for (int i = 0; i < n; i++) {
        if (matches[i].start >= lastEnd) {
            answer++;
            lastEnd = matches[i].finish;
        }
    }

    cout << answer << '\n';
    return 0;
}
```

### 逐项检查写法

- 用结构体把一场比赛的开始、结束时间放在一起，排序时整条记录一起移动。
- cmp 优先比较结束时间。结束时间相同时按开始时间排，保证比较规则明确；它们为后续留下的时间相同。
- 题目所有开始时间都不小于 0，所以 $\mathrm{lastEnd}$ 初始为 0，允许第一场从 0 开始。
- 判断使用 `>=`，允许前一场刚结束、下一场马上开始。
- 只有真正选中一场时才更新 $\mathrm{lastEnd}$；跳过的比赛不改变我们的安排。
- 最大输入达到百万场，把数组放在 main 外，并在读入之前给 `cin` 关闭流同步。

时间主要花在排序，复杂度 **$\mathcal{O}(n \log  n)$**；扫描是 $\mathcal{O}(n)$。$n=10^6$ 时，$n\log_2 n$ 约为两千万。保存比赛记录的数组需要 $\mathcal{O}(n)$ 空间。

## 排序之后，不同题目会有不同的贪心规则

学会 `sort` 后，许多贪心题的实现会变得简洁，但排序条件必须来自题目目标。

| 目标 | 可以考虑的顺序 | 要解释的关键 |
| --- | --- | --- |
| 参加最多场不冲突的比赛 | 结束时间升序 | 结束更早，后续安排仍能保留 |
| 让所有人的总等待时间最小 | 接水用时升序 | 用时短的人在前，后面的人总等待更少 |
| 物品能随意分割，容量内价值最大 | 单位重量价值降序 | 把同样重量换成单位价值更高的部分，价值不会降低 |

以排队接水为例，相邻两人的用时为 $a$、$b$，排在他们前面的总用时为 $S$。

- $a$ 在前：这两人的等待时间是 $S$ 与 $S+a$，总和为 $2S+a$。
- $b$ 在前：总和为 $2S+b$。

后面的人都要等 $a+b$，交换这两人的顺序不影响后面的人。如果 $a\le b$，就让 $a$ 在前，等待总和不会增加。这也是交换思路。

再看能分割的物品：单位价值低的部分占用了重量，就可以把同样重量替换为单位价值更高的部分。**能不能分割，是这里能按单位价值贪心的关键条件。** 第八章学习不能分割、每件只能取或不取的背包时，会使用另一种方法。

## 写完贪心后，怎样检验

按这个顺序做一次检查：

1. 用一句话说清目标和策略，避免把“当前指标好看”当作最终目标。
2. 手算一组会让其他策略失败的数据。
3. 尝试交换或比较，说明选择之后不会失去更好的答案。
4. 检查排序条件、相等情况、更新时机和累计值类型。

对 P1803，可以测试只有一场、全部重叠、全部首尾相接、结束时间相同，以及比赛输入顺序完全打乱的情况。
