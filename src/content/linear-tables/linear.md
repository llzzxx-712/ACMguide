## 线性表：数据排成一列

点名册、排队名单、等待执行的任务，都可以按先后顺序排成一列。**线性表**描述的就是这种一对一的顺序关系。

你用过的数组也是一种保存线性表的方式。今天关注两个问题：新元素放在哪里？处理元素时先取哪一个？

| 工具 | 放入与取出的规则 | 典型场景 |
| --- | --- | --- |
| 数组、vector | 可以按下标访问 | 成绩表、顺序扫描 |
| stack（栈） | 一端放入，同一端取出 | 括号匹配、撤销操作 |
| queue（队列） | 队尾放入，队首取出 | 排队服务、BFS |
| 链表 | 用连接关系记录前后元素 | 已知位置的插入、删除 |

先把最常用的栈与队列用起来，再回头比较它们与数组的区别。

## 栈：最后放进去的，最先拿出来

想象一摞盘子。新盘子放在最上面，要拿盘子，也从最上面拿。这个可以操作的一端叫**栈顶**。

依次放入 1、2、3，再依次取出，得到 3、2、1。这叫**后进先出**。

```text
操作       栈（左边是栈底，右边是栈顶）
push(1)   [1]
push(2)   [1, 2]
push(3)   [1, 2, 3]
top()     读到 3，栈不变
pop()     [1, 2]
```

### stack 的常用操作

```text
stack<int> st;
st.push(10);           // 把 10 放到栈顶
st.push(20);
int x = st.top();      // x=20，只读取，不删除
st.pop();              // 删除栈顶的 20
int n = st.size();     // n=1
bool noData = st.empty(); // false，栈里还有 10
```

类型写在尖括号里：stack<int> 保存整数，stack<char> 保存字符。变量名 st 可以自己取。

> **top() 负责读，pop() 负责删。**
>
> pop() 不会返回被删的元素，需要时先保存 top()。调用 top() 或 pop() 前，必须确认栈非空；常用写法是 if (!st.empty())。

## 例题精讲一：P1739 · 表达式括号匹配

**原题：** [P1739 · 表达式括号匹配](https://www.luogu.com.cn/problem/P1739)。

**题意简述：** 一段表达式以 @ 结束，包含数字、字母、运算符和小括号。判断小括号是否配对，输出 YES 或 NO。表达式长度小于 255。

### 为什么栈适合匹配括号

看 `(a+(b*c))@`。遇到最右边那个内层右括号时，应先匹配最近出现、还没有配对的左括号。**最近放入的左括号，最先配对**，正好对应栈。

从左到右扫描：

1. 遇到左括号，把它入栈，表示还有一个括号等待配对。
2. 遇到右括号，若栈为空，说明前面没有左括号，立即判为不匹配；否则弹出栈顶左括号。
3. 遇到其他字符跳过；到 @ 停止。
4. 扫描结束后栈还不为空，说明有左括号没被配对。

```text
字符     栈中未配对的左括号
(        (
a        (
+        (
(        ((
b*c      ((
)        (
)        空
@        结束，匹配
```

这里只出现一种括号，用“未匹配左括号的数量”也能判断。我们先使用栈，把“最近的括号先配对”这个过程写清楚；以后同时处理 ()、[]、{} 时，栈里保存的括号类型就派上用场了。

### 输入输出示例

输入：

```text
(a+(b*c))@
```

输出：

```text
YES
```

换成 `)(@`，右括号首先出现，输出 NO。即使左右括号总数相等，顺序不对也无法配对。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    stack<char> st;
    bool ok = true;

    for (char c : s) {
        if (c == '@') break;
        if (c == '(') {
            st.push(c);
        } else if (c == ')') {
            if (st.empty()) {
                ok = false;
                break;
            }
            st.pop();
        }
    }

    if (!st.empty()) ok = false;
    cout << (ok ? "YES" : "NO") << '\n';
    return 0;
}
```

代码中的 `for (char c : s)` 会依次把字符串中的字符取出来，放到变量 c 中；它相当于按下标从头到尾扫描，只是这里不需要使用下标。

每个字符看一次，括号至多入栈、出栈各一次。设表达式长度为 L，时间 O(L)，最坏空间 O(L)。

## 队列：先来的人，先被处理

队列像食堂窗口排队：新同学站到队尾，窗口先服务队首。依次放入 1、2、3，再依次取出，得到 1、2、3。这叫**先进先出**。

```text
队首 → [1, 2, 3] ← 队尾
push(4) 后：[1, 2, 3, 4]
pop() 后： [2, 3, 4]
```

### queue 的常用操作

```text
queue<int> q;
q.push(10);          // 队尾放入
q.push(20);
int x = q.front();   // x=10，读取队首
int y = q.back();    // y=20，读取队尾
q.pop();             // 删除队首，剩下 20
int n = q.size();    // n=1
bool noData = q.empty(); // false
```

queue 没有用下标访问队中任意元素的接口。想处理等待最久的任务，就读 front()，再 pop()；要随机访问第 i 个元素，则选数组或 vector。

stack 的 top() 和 queue 的 front()、back() 都只读取；两者的 pop() 都只删除。**空容器不能读取端点或执行 pop()。**

## 例题精讲二：P1540 · 机器翻译

**原题：** [P1540 · 机器翻译](https://www.luogu.com.cn/problem/P1540)。

**题意简述：** 翻译软件的内存最多保存 M 个单词，开始为空。依次处理 N 个单词：内存里已有就直接使用；没有就查词典，并把单词放入内存。如果内存已满，先移除最早进入的单词。求查词典的次数。

1≤M≤100，N≤1000，单词用 0 到 1000 的整数编号表示。

### 把两个问题分别交给合适的工具

- **哪个单词最早进入？** 用 queue 维护进入顺序，队首就是该移除的单词。
- **单词是否已经在内存里？** 用 bool 数组 inMemory[x] 直接查询。

这里的下标就是单词编号。你在数组一节学到的“下标可以参与解题”，现在又用了一次：不需要挨个扫描内存。

先按题目规则手算“命中、未命中、内存已满”三种情况，再选择工具实现：命中就跳过后续处理；未命中就增加查询次数；已满时先删除最早进入的单词，再加入新单词。队列和标记数组分别承担顺序、存在性这两项任务，程序里也要在加入、移除时同步更新它们。

有一次命中时，只使用已有单词，**不把它挪到队尾**。题目按照“进入时间”淘汰，不是按照“最近使用时间”淘汰。

### 手算一次

输入：

```text
3 7
1 2 1 5 4 4 1
```

| 读入 | 操作 | 内存中的队列（从早到晚） | 累计查词典 |
| --- | --- | --- | --- |
| 1 | 不在内存，放入 | 1 | 1 |
| 2 | 不在内存，放入 | 1、2 | 2 |
| 1 | 已有，顺序不变 | 1、2 | 2 |
| 5 | 不在内存，放入 | 1、2、5 | 3 |
| 4 | 已满，移除 1 后放入 4 | 2、5、4 | 4 |
| 4 | 已有，顺序不变 | 2、5、4 | 4 |
| 1 | 已满，移除 2 后放入 1 | 5、4、1 | 5 |

输出：

```text
5
```

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

bool inMemory[1005];

int main() {
    int m, n;
    cin >> m >> n;
    queue<int> q;
    int ans = 0;

    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (inMemory[x]) continue;

        ans++;
        int count = q.size();
        if (count == m) {
            int oldest = q.front();
            q.pop();
            inMemory[oldest] = false;
        }
        q.push(x);
        inMemory[x] = true;
    }

    cout << ans << '\n';
    return 0;
}
```

移除单词时，要同时修改队列和 inMemory；否则数组会误以为已经被移除的单词还在内存里。由于 M≥1，队列已满时一定非空，可以读取 front()。

每个输入单词处理一次，每次命中查询、入队、出队为 O(1)，总时间 O(N)。队列至多保存 M 个单词，标记数组覆盖 0 到 1000。

## 用数组模拟，看看容器内部的思路

日常做题可以直接使用 stack、queue。手写一次数组版，能帮助你理解“端点怎样移动”。

### 数组模拟栈

设数组容量足够，初始 top=0，表示空栈，st[1] 到 st[top] 是有效元素。

```text
// 入栈 x
st[++top] = x;

// 栈非空时读取栈顶、出栈
int x = st[top];
top--;
```

++top 先把 top 加 1，再作为下标。出栈只需移动 top，不必把旧格子清零；有效范围已经变了。

### 数组模拟队列

初始 head=1、tail=0，规定 [head,tail] 是当前有效队列：

```text
// 入队 x
q[++tail] = x;

// head <= tail 时读取队首、出队
int x = q[head];
head++;
```

head>tail 表示空队列，元素个数为 tail−head+1。出队后 head 往右移动，不能只写 q[head]=0：写入 0 并没有改变队首的位置。

> **数组容量按总入队次数估算。**
>
> 这种写法的 tail 只增不减，前面的格子不会自动复用。即使同时在队中的元素很少，累计入队次数很多时仍可能越界。后面的网格 BFS 会让每个格子只入队一次，因此可按格子总数分配；使用 queue 时由容器管理存储。

## 回头认识顺序表、vector 与链表

### 数组和 vector：顺序存放，按下标访问

数组在使用前确定容量；vector 可以随着 push_back 增长：

```text
vector<int> a;
a.push_back(10);
a.push_back(20);
cout << a[0] << '\n';  // 10
int n = a.size();      // 2
a.pop_back();          // 删除末尾的 20
```

vector 与 string 一样使用 **0 下标**，n 个元素的有效下标为 0 到 n−1。需要开 n+1 个位置、继续用 1 下标时，可以写 `vector<int> a(n + 1);`。

按下标访问是 O(1)，末尾 push_back 的均摊时间为 O(1)：偶尔扩容需要搬动整批数据，但连续进行很多次 push_back，总成本与操作次数同阶。在中间插入或删除通常要移动后面的元素，为 O(n)。

### 链表：顺序由连接关系决定

假设名单顺序是 2→5→3。链表不用“编号相邻”表示顺序，而是记录每个元素的前一个、后一个是谁：

```text
next[2]=5，next[5]=3
pre[5]=2，pre[3]=5
```

编号可以跳着连接，因此在**已经知道位置**时，插入和删除不需要整体搬动后面的数据。

可以用两个数组模拟双向链表。约定 0 为头、n+1 为尾，都是占位的哨兵，先连接头尾；以下片段演示把新编号 x 插到现有编号 k 的右边：

```text
int y = nxt[k];
nxt[k] = x;
pre[x] = k;
nxt[x] = y;
pre[y] = x;
```

原来 k→y，改为 k→x→y；pre 同步记录反向关系。删去已有的 x：

```text
nxt[pre[x]] = nxt[x];
pre[nxt[x]] = pre[x];
```

这两步把 x 的左右邻居接起来。0、n+1 也要分配数组空间；哨兵不作为普通学生删除。同一编号可能被重复删除时，用标记判断是否仍在链表中。

数组模拟链表的单次连接修改是 O(1)，从头走到第 k 个位置仍要 O(k)。题目名称里有“队列”两个字，也要先看操作规则：如果允许在任意指定同学旁插入，普通 queue 就不合适。
