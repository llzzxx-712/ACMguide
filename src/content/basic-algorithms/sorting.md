## 排序能帮我们做什么

假设分数是 80、95、70、95。按从高到低排好后，得到 95、95、80、70，前面的元素就是排名靠前者。

不同题目对顺序有不同要求：

| 题目要做什么 | 排好后怎样使用 |
| --- | --- |
| 找最小值、最大值 | 升序后的第一个、最后一个元素 |
| 找第 k 小 | 升序后的 a[k−1]，这里使用 0 下标 |
| 选出成绩最好的前几人 | 按题目规则降序，取前几个 |
| 统计每种数出现几次 | 相同数会排在一起，连续统计 |
| 去掉重复值 | 比较相邻元素，只保留每段的一个 |

**先把顺序理清，再顺着这个顺序处理数据。** sort 负责把排列过程完成，我们需要告诉它排哪些数据、按什么规则排，以及排完后做什么。

## sort 的基本写法：从小到大

程序继续使用万能头文件。若 n 个数保存在 a[0] 到 a[n−1]，直接写：

```text
sort(a, a + n);
```

调用后，这 n 个元素就按从小到大排列。例如 4、1、4、2，会变成 1、2、4、4，数组 a 本身的顺序已经改变。

### 排序区间：包含开头，不包含结尾

sort 的两个位置表示一个**左闭右开区间**：从第一个位置开始，一直排到第二个位置之前。

| 数据放在哪里 | sort 的写法 |
| --- | --- |
| a[0] 到 a[n−1] | `sort(a, a + n);` |
| a[1] 到 a[n] | `sort(a + 1, a + n + 1);` |
| a[left] 到 a[right]，两端都要排 | `sort(a + left, a + right + 1);` |

例如 `sort(a + 1, a + 4);` 只排下标 1、2、3，其他位置不动。第二个参数写的是“待排区间最后一个元素之后的位置”。

> **排序前，核对存储范围与排序范围。**
>
> 如果数据放在 a[0] 到 a[n−1]，就使用 `sort(a, a + n);`。把结尾写成 a+n−1，会漏排最后一个数。
>
> 按实际读入的 n 个数排序，不要把整个数组容量中没有读入的数据一起排进去。

## 从大到小：给 sort 一个比较函数

比较函数用来回答：**在我们的排序规则中，a 是否应该排在 b 前面？**

```text
bool cmp(int a, int b) {
    return a > b;
}
```

a 比 b 大时返回 true，让更大的数排前面。调用时，把函数名放在第三个参数：

```text
sort(a, a + n, cmp);
```

这里写 cmp，不写 `cmp()`。我们把这条比较规则交给 sort，由它在排序过程中反复调用。

### 亲手观察升序与降序

下面是一个本地演示：读入 n 个整数，第一行输出升序，第二行输出降序。约定 `1 <= n <= 1000`，每个数在 int 范围内。

```cpp
#include<bits/stdc++.h>
using namespace std;

bool cmp(int a, int b) {
    return a > b;
}

int main() {
    int n;
    cin >> n;
    int a[1005];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    sort(a, a + n);
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << ' ';
        cout << a[i];
    }
    cout << '\n';

    sort(a, a + n, cmp);
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << ' ';
        cout << a[i];
    }
    cout << '\n';
    return 0;
}
```

输入：

```text
4
4 1 4 2
```

输出：

```text
1 2 4 4
4 4 2 1
```

第二次 sort 直接处理第一次排好的数组。无论原来是什么顺序，它都会按这次指定的规则重新排列。

> **比较函数要表达“严格排在前面”。**
>
> 升序用 `a < b`，降序用 `a > b`，不要写成 `<=` 或 `>=`。相等的两个数，比较函数应返回 false。
>
> 比较规则还要前后一致：如果 a 应在 b 前，b 应在 c 前，那么 a 也应在 c 前。多条件排序时，按优先级逐层判断，就容易把规则写清楚。

## 结构体排序：把题目的优先级写进 cmp

给学生排名时，只比较总分可能还不够。题目可能要求：

1. 总分不同，总分高者在前。
2. 总分相同，语文高者在前。
3. 前两项都相同，学号小者在前。

比较函数就按照这个顺序判断。**只有前一项相等时，才轮到后一项。**

不要把不同优先级的比较直接用“或者”连起来。例如“总分更高，或者语文更高”会让低总分、高语文的人也可能排到高总分的人前面，不符合题目的优先级。

下面用一道完整题目把这件事做一遍。

## 例题精讲：P1093 · 奖学金

**原题：** [P1093 · 奖学金](https://www.luogu.com.cn/problem/P1093)。

**题意简述：** 输入 n 名学生的语文、数学、英语成绩，按总分降序、语文降序、学号升序排名，输出前 5 人的学号和总分。学号按输入顺序从 1 开始，`5 <= n <= 300`，每科成绩在 0 到 100 之间。

### 先保存排序后仍要使用的信息

用结构体保存三项信息：

- id：学号，输出时还要知道是谁。
- chinese：语文分数，用于总分相同后的比较。
- total：三科总分，作为第一排序条件。

排序会改变数组里记录的位置，但每条记录里的学号会跟着这位学生一起移动。因此要在读入时保存 id，不能把“排序后的数组下标加 1”当作原学号。

### 手算一次排名

例如有 6 位学生：

| 学号 | 语文 | 数学 | 英语 | 总分 |
| --- | --- | --- | --- | --- |
| 1 | 90 | 90 | 90 | 270 |
| 2 | 95 | 85 | 90 | 270 |
| 3 | 90 | 95 | 85 | 270 |
| 4 | 100 | 90 | 90 | 280 |
| 5 | 80 | 80 | 80 | 240 |
| 6 | 85 | 95 | 95 | 275 |

4 号总分最高，6 号其次。总分都是 270 的三人中，2 号语文更高，所以排前面；1 号与 3 号总分、语文都相同，学号更小的 1 号排前面。

最终顺序是 **4、6、2、1、3、5**，输出其中前 5 人。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

struct Student {
    int id, chinese, total;
};

bool cmp(Student a, Student b) {
    if (a.total != b.total) {
        return a.total > b.total;
    }
    if (a.chinese != b.chinese) {
        return a.chinese > b.chinese;
    }
    return a.id < b.id;
}

int main() {
    int n;
    cin >> n;
    Student students[305];
    for (int i = 0; i < n; i++) {
        int math, english;
        cin >> students[i].chinese >> math >> english;
        students[i].id = i + 1;
        students[i].total = students[i].chinese + math + english;
    }

    sort(students, students + n, cmp);
    for (int i = 0; i < 5; i++) {
        printf("%d %d\n", students[i].id, students[i].total);
    }
    return 0;
}
```

输入：

```text
6
90 90 90
95 85 90
90 95 85
100 90 90
80 80 80
85 95 95
```

输出：

```text
4 280
6 275
2 270
1 270
3 270
```

看 cmp 的执行过程：只要总分不相同，第一条 return 就已经给出结果，后面的条件不会再执行；只有总分相同，才会比较语文。这与我们手算的优先级一致。

读入与保存记录是 O(n)，排序是 O(n log n)，输出前 5 人是固定次数，所以整体时间复杂度为 **O(n log n)**。保存 n 名学生的数组需要 O(n) 空间。

## 排序之后，怎样统计与去重

以序列 3、1、3、2、2 为例。升序后是：

```text
1 2 2 3 3
```

相同的数现在挨在一起。遇到一个与前一个不同的数，就表示开始了新的一段。因此，n 至少为 1 时，可以这样统计不同数的个数：

```text
int different = 1;
for (int i = 1; i < n; i++) {
    if (a[i] != a[i - 1]) {
        different++;
    }
}
```

上面这组数得到 different=3。若要输出去重结果，也可以先输出第一个数，再只输出“与前一个不同”的数。

这里 i 从 1 开始，所以访问 a[i−1] 时，下标至少为 0。**排序把相同值聚集起来，后续判断就可以围绕相邻元素展开。** 这正是排序在题目里的常见用途。
