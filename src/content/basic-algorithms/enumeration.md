## 两天怎么安排

- **第 15 天：** 确定枚举对象、范围和判断条件，用鸡兔同笼理解“不漏、不重”。
- **第 16 天：** 学减少枚举变量、提前排除和预处理，精讲统计方形，再独立完成练习。

当答案的可能情况不多时，可以把候选情况依次试一遍，检查哪些符合题目要求。这就是枚举。关键是先选好“枚举什么”，再估算总共要试多少次。

> **AI 伴学提示词**
>
> 为我讲解暴力枚举、减少枚举变量、提前排除和预处理，用具体数据带我推导统计方形，并引导我对可能不理解的内容进行提问。

## 先确定三个问题

1. **枚举对象是什么？** 一个数、一对数、一个起点，还是一种长宽组合？
2. **对象的范围是什么？** 从哪里开始，到哪里结束，为什么所有答案都在里面？
3. **怎样判断或统计？** 满足条件就输出、答案加一，还是一次加入一批情况？

写循环之前，先用自然语言回答这三个问题。这样循环变量、上下界和循环体才有明确分工。

### 从枚举思路确定循环

“枚举”先是一种解题过程：把候选情况逐个试过。for 是实现这个过程的一种工具。先决定候选是什么，再决定循环变量；先说明所有候选在哪里，再写上下界；先说明怎样判断合法，再写循环体中的 if。

例如枚举无序的一对位置，思路是“先选第一个，再从它后面选第二个”，代码才写成外层 i、内层 j=i+1。这个 +1 来自避免重复的要求。

如果以后遇到“要连续做 n 次选择”，而 n 由输入决定，就不能在源代码里固定写好 n 层循环。第六章会用递归实现这样的枚举：每进入一层函数，就处理一层选择。

## 本地演示：鸡兔同笼

给定总头数 heads、总腿数 legs，求鸡和兔各有多少只。每只鸡 2 条腿，每只兔 4 条腿；本演示约定 `0 <= heads <= 1000`、`0 <= legs <= 4000`，无解时输出 −1。

如果一共有 5 个头，那么鸡可能有 0、1、2、3、4、5 只。每确定一种鸡的数量，兔的数量就已经确定：

```text
rabbits = heads - chickens;
```

因此，我们只需要枚举鸡的数量，计算兔的数量，再检查腿数。

| 鸡 | 兔 | 总腿数 | 是否符合 14 条腿 |
| --- | --- | --- | --- |
| 0 | 5 | 20 | 否 |
| 1 | 4 | 18 | 否 |
| 2 | 3 | 16 | 否 |
| 3 | 2 | 14 | 是 |
| 4 | 1 | 12 | 否 |
| 5 | 0 | 10 | 否 |

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int heads, legs;
    cin >> heads >> legs;
    bool found = false;

    for (int chickens = 0; chickens <= heads; chickens++) {
        int rabbits = heads - chickens;
        if (2 * chickens + 4 * rabbits == legs) {
            printf("%d %d\n", chickens, rabbits);
            found = true;
        }
    }
    if (!found) {
        cout << -1 << '\n';
    }
    return 0;
}
```

输入 `5 14`，输出 `3 2`。枚举了全部可能的鸡数量，因此不会漏解；每种鸡数量只检查一次，配对的兔数量也唯一，因此不会重复输出同一种方案。

### 已经能算出的量，不必再枚举

如果鸡和兔都从 0 到 heads 枚举，会检查大约 (heads+1)² 对数量。现在用头数关系计算兔，只检查 heads+1 次。

这就是**减少枚举变量**。当 heads=1000 时，候选数量从约一百万对，降到 1001 次。题意中的等式不仅用于最后检验，还能直接帮我们缩小枚举空间。

## 优化前，先数一数候选情况

- 枚举一个 1 到 n 的数，约有 n 种。
- 枚举两个各自从 1 到 n 的数，约有 n² 种。
- 从 n 个对象中取两个不同对象，用 `i < j`，共有 n(n−1)/2 对。
- 枚举矩阵中每个起点，再检查长度为 k 的一段，计算量约为 O(nmk)。

判断方案时，把这些候选数量乘上每次检查的代价。若计算量太大，再寻找题意中的约束，看看能否减少变量、缩小范围，或一次统计一批情况。

> **枚举范围要同时保证“不漏”和“不重”。**
>
> 例如从 n 个对象中取无序的一对时，令 j 从 i+1 开始，就能排除自己与自己，也不会把 (i,j) 和 (j,i) 重复计数。
>
> 本页后面的方形统计，也需要说明为什么每个图形恰好被统计一次。

## 例题精讲：P2241 · 统计方形

**原题：** [P2241 · 统计方形（数据加强版）](https://www.luogu.com.cn/problem/P2241)。

**题意简述：** 给定 n 行 m 列的小方格棋盘，统计所有沿方格线组成的正方形与长方形，长方形的统计中不包含正方形。`1 <= n,m <= 5000`，输出正方形数、长方形数。

### 先想：一个图形需要确定什么

一种直接的想法是枚举上、下、左、右四条边。这样每个图形都能确定，但计算量达到 O(n²m²)，最大规模下候选非常多。

换个角度：**先确定图形的高和宽，再统计它能放在多少个位置。**

同样大小的图形，放置位置的数量可以直接计算，就不需要把每个位置再单独枚举出来。

### 固定高和宽后，能放多少个

假设棋盘 n=2、m=3，选一个高为 1、宽为 2 的长方形：

- 上边可以从第 1 行或第 2 行开始，有 2 种。
- 左边可以从第 1 列或第 2 列开始，有 2 种。
- 一共 2×2=4 个。

一般情况下：

```text
可以选择的起始行数 = n - height + 1
可以选择的起始列数 = m - width + 1
这一种长宽的图形数量 = 起始行数 × 起始列数
```

例如宽为 width 的图形，最右端必须留在棋盘内，所以起始列只有 m−width+1 种。这一处的“+1”可以用宽度恰好等于整块棋盘来检查：此时只能放 1 个位置。

### 枚举所有长宽组合

对于 2×3 的棋盘：

| 高 | 宽 | 放置数量 | 加到哪一类 |
| --- | --- | --- | --- |
| 1 | 1 | 2×3=6 | 正方形 |
| 1 | 2 | 2×2=4 | 长方形 |
| 1 | 3 | 2×1=2 | 长方形 |
| 2 | 1 | 1×3=3 | 长方形 |
| 2 | 2 | 1×2=2 | 正方形 |
| 2 | 3 | 1×1=1 | 长方形 |

正方形一共 6+2=8 个，其余长方形一共 4+2+3+1=10 个。

每个图形都有唯一的高、宽和起始位置。我们枚举它的高与宽，再把所有起始位置的数量加入一次，因此既不会漏掉，也不会重复。

### 完整代码

先对照这几件事：外层 height 决定图形的高，内层 width 决定宽；rowChoices 和 colChoices 实现刚才推导的放置数量；height==width 判断应加入正方形还是其他长方形的计数。两层循环是在枚举“长宽组合”，每次累加则一次性统计该大小的所有位置。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    long long squares = 0, rectangles = 0;

    for (int height = 1; height <= n; height++) {
        for (int width = 1; width <= m; width++) {
            long long rowChoices = n - height + 1;
            long long colChoices = m - width + 1;
            long long ways = rowChoices * colChoices;
            if (height == width) {
                squares += ways;
            } else {
                rectangles += ways;
            }
        }
    }

    printf("%lld %lld\n", squares, rectangles);
    return 0;
}
```

输入：

```text
2 3
```

输出：

```text
8 10
```

两个循环分别枚举 height 和 width，高等于宽时加入正方形，否则加入长方形。因为题目要求长方形不含正方形，这两个分支分别累计。

> **数量统计要看最终答案的范围。**
>
> 棋盘边长只有 5000，但图形总数会超过 int 的约 21 亿上限，所以 squares、rectangles、ways 使用 long long。
>
> 起始行数和起始列数也先存入 long long，再进行乘法；输出两个 long long 时，printf 对应使用两个 `%lld`。

### 这次优化省掉了什么

现在只枚举 n×m 种长宽，每种做固定次数的计算，时间复杂度为 **O(nm)**，额外空间为 **O(1)**。

n=m=5000 时，有 25000000 种长宽组合。我们用乘法一次统计同一长宽的全部位置，省掉了对起始位置的重复枚举。

这种思考方式以后会经常用到：**找到一批具有共同特征的对象，用一次计算得到这一批的数量。**

## 另外两种常见优化思路

### 提前排除已经不可能的情况

鸡兔同笼的总腿数一定是偶数，而且在 `2 * heads` 到 `4 * heads` 之间。若读入的数据已经违反这些条件，就能直接判断无解，后面的枚举可以结束。

这种在继续尝试之前就排除不可能情况的做法，常叫作**剪枝**。写判断时，要能解释为什么被排除的情况不可能产生答案。

### 把反复用到的结果提前算好

如果在两层枚举中反复计算“某个数需要多少根火柴”，可以先把范围内每个数的火柴用量算好，保存在 cost[x]，枚举时直接查表。

这叫作**预处理**。我们把同一项计算集中完成一次，之后通过数组下标重复使用结果。类似地，第一章的 count[x] 也可以让我们直接查到某个值出现了几次。

## 两天验收

- 能说清枚举对象、范围与判断条件。

- 能比较优化前后的计算量，并为较大的计数答案选择 long long。
