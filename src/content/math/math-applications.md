## 进制：同一个数的不同写法

十进制 253 的意思是：

```text
253 = 2 × 10² + 5 × 10 + 3
```

二进制每一位只用 `0、1`，位权依次是 `1、2、4、8`……例如：

```text
(1101)₂ = 1 × 2³ + 1 × 2² + 0 × 2 + 1 = 13
```

$b$ 进制每一位的数码取 $0$ 到 $b-1$，每向左一位，位权乘 $b$。十六进制用 `A B C D E F` 表示 $10$ 到 $15$，例如 $(1A)_{16}=1\times16+10=26$。

### 从左往右读：已有结果乘进制，再加新数码

计算十进制 253，不一定要显式计算每个幂：

```text
初始 value = 0
读到 2：value = 0 × 10 + 2 = 2
读到 5：value = 2 × 10 + 5 = 25
读到 3：value = 25 × 10 + 3 = 253
```

换成 $b$ 进制，过程不变：`value = value * b + digit`。这里的赋值是在实现“旧数的每一位左移一位，再填上最后一位”。

### 从十进制转出去：不断除以目标进制

把 13 转成二进制：

| 当前数 | 除以 2 的商 | 余数 |
| --- | --- | --- |
| 13 | 6 | 1 |
| 6 | 3 | 0 |
| 3 | 1 | 1 |
| 1 | 0 | 1 |

余数依次是最低位、次低位……所以要**倒过来读**，得到 `1101`。程序可以把余数转成字符放进 `string`，最后调用 `reverse`。

## 例题精讲：P1143 · 进制转换

**原题：** [P1143 · 进制转换](https://www.luogu.com.cn/problem/P1143)。

**题意简述：** 给出原进制 $n$、一个 $n$ 进制数、目标进制 $m$，输出转换后的表示。$2\le n,m\le16$，字母使用大写，原数的十进制值不超过 $10^9$。

思路分成两段：先把字符串解读成整数，再把整数写成目标进制。我们并没有改变数值，只是在改变它的写法。

输入：

```text
16
1A
2
```

输出：

```text
11010
```

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    string s;
    cin >> n >> s >> m;

    long long value = 0;
    int length = s.size();
    for (int i = 0; i < length; i++) {
        int digit;
        if (s[i] >= '0' && s[i] <= '9') digit = s[i] - '0';
        else digit = s[i] - 'A' + 10;
        value = value * n + digit;
    }

    string digits = "0123456789ABCDEF";
    string ans;
    if (value == 0) ans = "0";
    while (value > 0) {
        int remainder = value % m;
        ans += digits[remainder];
        value /= m;
    }
    reverse(ans.begin(), ans.end());
    cout << ans << '\n';
    return 0;
}
```

字符 `'7'` 与数值 7 不同，所以先减 `'0'`；字符 `'A'` 减 `'A'` 得 0，再加 10 得到十六进制数码值。反过来，把余数当成 $\mathrm{digits}$ 的下标，就能得到输出字符。这也再次用到了“下标可以成为计算流程的一部分”。

`reverse` 的两个参数表示 `string` 从开头到结尾之后的位置，与 `sort` 的区间习惯相同。数值为 0 时循环一次也不会执行，因此单独写入字符 0。

设输入、输出的位数分别为 $L$、$K$，时间 $\mathcal{O}(L+K)$，保存答案需要 $\mathcal{O}(K)$ 空间。

## 取模：只保存题目需要的余数

有些题的方案数非常大，但只要求答案除以 $M$ 的余数。可以每一步都取模，让保存的数值保持较小。

对非负整数 $a$、$b$ 和正整数 $M$：

```text
(a + b) % M = ((a % M) + (b % M)) % M
(a * b) % M = ((a % M) * (b % M)) % M
```

例如要求一个乘积对 7 的余数，可以每乘一个数就执行 `value %= 7`，不需要先算出整个巨大乘积。这些等式成立，是因为 $a$、$b$ 各自都可以写成“7 的整数倍 + 余数”；相加、相乘后，那些含 7 的整数倍部分不影响最终余数。

### 三个需要直接弄清的细节

1. **取模也不能挽救已经发生的溢出。** 计算 $(a\cdot b)\bmod M$ 时先算乘法。如果 $a$、$b$ 都是 `int`，即使最终赋给 `long long`，也可能先在 `int` 中溢出；可以用 `long long` 保存乘数，或写 `long long value = 1LL * a * b % M;`。
2. **减法可能得到负数。** C++ 中 `int remainder = -1 % 5;` 得到 $-1$。若要得到 $0$ 到 $M-1$ 的代表值，可用 `x = (x % M + M) % M;`；这里 $x$、$M$ 使用能容纳中间结果的 `long long`。
3. **不能把普通除法直接搬进取模。** 例如 $(6/2)\bmod5=3$，但 $\lfloor(6\bmod5)/2\rfloor=0$。遇到组合数时，我们会用递推，避免先算阶乘再除。

常用 $M=1000000007$。两个小于 $M$ 的非负数相乘小于约 $10^{18}$，能够放入 `long long`；但不能因此认为任何 `long long` 的乘积都不会溢出。

## 快速幂：把很多次乘法合并起来

计算 $a^b$，最直接的方法是乘 $b$ 次。如果 $b$ 达到十亿，循环也要跑十亿次。

但平方可以快速得到很大的指数：

```text
a² = a × a
a⁴ = a² × a²
a⁸ = a⁴ × a⁴
a¹⁶ = a⁸ × a⁸
```

而 $13=8+4+1$，所以 $a^{13}=a^8\cdot a^4\cdot a$。我们只需要准备这些不断平方的幂，并选出需要的部分。

### 让“剩余指数”每次减半

用 $\mathrm{result}$ 保存已经选中的乘积，$\mathrm{base}$ 保存当前可以选的幂，$e$ 保存还没有处理的指数：

```text
result = 1，base = a，e = b
如果 e 是奇数：把一份 base 乘进 result
base 平方
e 整除 2
重复，直到 e = 0
```

计算 $2^{13}$ 时，不取模的过程如下：

| 本轮 $e$ | 本轮 $\mathrm{base}$ | 是否乘入 $\mathrm{result}$ | 更新后的 $\mathrm{result}$ |
| --- | --- | --- | --- |
| 13 | 2 | 奇数，乘入 | 2 |
| 6 | 4 | 偶数，不乘 | 2 |
| 3 | 16 | 奇数，乘入 | 32 |
| 1 | 256 | 奇数，乘入 | 8192 |

从数学上看，过程中始终有 $\mathrm{result}\cdot\mathrm{base}^e=a^b$，即“已选乘积乘当前幂的剩余次数，仍等于原来的幂”。奇数时取走一份 $\mathrm{base}$，再把剩下的偶数份两两合并，就对应平方与减半。

### 例题精讲：P1226 · 快速幂

**原题：** [P1226 · 快速幂](https://www.luogu.com.cn/problem/P1226)。

**题意简述：** 给出 $a$、$b$、$p$，求 $a^b$ 除以 $p$ 的余数，按指定格式输出。$0\le a,b<2^{31}$、$a+b>0$，$2\le p<2^{31}$。

输入：

```text
2 10 9
```

输出：

```text
2^10 mod 9=7
```

1024 除以 9 余 7。程序每次乘法后立即取模，避免真正生成 $a^b$。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    long long a, b, p;
    cin >> a >> b >> p;
    long long base = a % p;
    long long e = b;
    long long result = 1 % p;

    while (e > 0) {
        if (e % 2 == 1) result = result * base % p;
        base = base * base % p;
        e /= 2;
    }

    printf("%lld^%lld mod %lld=%lld\n", a, b, p, result);
    return 0;
}
```

保留 $a$、$b$ 不修改，是为了最后输出原始输入；循环操作的是 $\mathrm{base}$、$e$。$b=0$ 时循环不执行，结果为 1，符合非零数满足 $a^0=1$。

因为 $p<2^{31}$，取模后两个数的乘积小于 $2^{62}$，`long long` 能容纳。时间 $\mathcal{O}(\log(b+1))$，额外空间 $\mathcal{O}(1)$。这里不是换了一个难记的模板，而是用“不断平方、按需取用”的思路减少乘法次数。

## 基础计数：先判断是分类，还是分步骤

### 加法原理：互不重叠的类别相加

要选一门活动，数学类有 3 门、编程类有 4 门，并且没有同一门活动同时出现在两个列表中，则共有 $3+4=7$ 种选择。

分类时要做到不重不漏。如果同一个方案被分到两类，直接相加就重复了。例如 1 到 10 中，2 的倍数有 5 个、3 的倍数有 3 个，但 6 被两边都算到，所以总数是 $5+3-1=7$。

### 乘法原理：完成一个方案所需的步骤相乘

有 3 件上衣、2 条裤子，每套穿搭选一件上衣和一条裤子，共 $3\times2=6$ 套。这里的“乘”也可以理解为两层 `for`：外层选上衣，内层选裤子。

如果前面选了什么会影响后面的选择数量，需要把这种影响算进去。例如从 5 个人中选队长、副队长，不能同一个人兼任：先选队长有 5 种，再选副队长只有 4 种，共 $5\times4=20$ 种。

### 排列与组合：交换顺序是否产生新方案

从 5 个人中选队长、副队长，甲乙与乙甲职责不同，顺序有意义，属于排列。

从 5 个人中选 2 人参赛，甲乙与乙甲是同一组，顺序没有意义，属于组合。每组两人被有序选法重复算了 2 次，所以共有 $5\times4/2=10$ 组。

一般地，从 $n$ 个不同元素中选 $k$ 个，不重复且考虑顺序，方案数为 $n(n-1)\cdots(n-k+1)$；不考虑顺序的组合数记作 $\dbinom nk$，还要除以 $k!$。$0!=1$，空选法只有一种，$\dbinom n0=1$。

## 用递推计算组合数

不必真的计算阶乘。固定考察 $n$ 个人中的最后一个人：

- 不选他：从前 $n-1$ 人里选 $k$ 人，有 $\dbinom{n-1}{k}$ 种。
- 选他：从前 $n-1$ 人里再选 $k-1$ 人，有 $\dbinom{n-1}{k-1}$ 种。

两类互不重叠、合起来覆盖所有选法，因此：

```text
C(n,k) = C(n-1,k) + C(n-1,k-1)
C(n,0) = C(n,n) = 1
```

这就是第三章学过的“从更小问题递推”。前几行如下，每行左右两端是 1，中间由上一行相邻两数相加：

```text
n=0：          1
n=1：        1   1
n=2：      1   2   1
n=3：    1   3   3   1
n=4：  1   4   6   4   1
```

### 自编示例：组合数取模

输入 $n$、$k$，$0\le k\le n\le1000$，输出 $\dbinom nk$ 对 $1000000007$ 的余数。例如输入 `5 2`，输出 `10`。

```cpp
#include<bits/stdc++.h>
using namespace std;

const long long MOD = 1000000007;
long long c[1005][1005];

int main() {
    int n, k;
    cin >> n >> k;
    c[0][0] = 1;
    for (int i = 1; i <= n; i++) {
        c[i][0] = c[i][i] = 1;
        for (int j = 1; j < i; j++) {
            c[i][j] = (c[i - 1][j] + c[i - 1][j - 1]) % MOD;
        }
    }
    cout << c[n][k] << '\n';
    return 0;
}
```

数组第一维表示总人数，第二维表示选取人数；每格都在回答一个明确的小问题。先算第 $i-1$ 行，再算第 $i$ 行，保证转移使用的结果已经存在。时间、空间均为 $\mathcal{O}(n^{2})$。

下一章会把这种“定义小问题、保存结果、从旧结果算新结果”的做法进一步推广。

## 二进制还可以逐位运算

C++ 可以直接对整数的二进制位进行运算。先把操作含义与熟悉的逻辑运算分清：

| 操作 | 对单个二进制位的含义 | 示例 |
| --- | --- | --- |
| `a & b` | 都为 1 才得 1 | `6 & 3`：`110` 与 `011` 得 `010`，即 2 |
| `a \| b` | 至少一个为 1 就得 1 | `6\|3` 得 `111`，即 7 |
| `a ^ b` | 两位不同得 1，相同得 0 | `6 ^ 3` 得 `101`，即 5 |
| `a << k` | 位向左移动 $k$ 位，低位补 0 | `3 << 2` 得 12 |
| `a >> k` | 本节对非负数向右移动 $k$ 位 | `13 >> 1` 得 6 |

`&&`、`||` 判断整个表达式真假；`&`、`|` 处理每个二进制位。`^` 是异或，**不是乘方**。涉及位运算比较时，把计算部分用括号括起来，例如 `(x & 1) == 1`。

本节位移处理非负数，移位数小于所用类型的位宽，左移后的结果也要能够表示。若要得到较大的 2 的幂，可以用 `1LL << k`，并确保 $0\le k\le62$，避免在 `int` 上先移出范围。

异或有两个很有用的性质：$x\oplus x=0$，$x\oplus0=x$，而且调整结合顺序、先后顺序不影响结果。因此成对出现的数字全部异或起来会相互抵消，留下唯一落单的数字。这个思路会在练习 P1469 中用到。

## 基础几何：先确定关系，再代入公式

几何计算也遵循“代码是思路的实现”：先画图、标注已知量和所求量，再确定用哪个关系，最后才输入和计算。

- 平面两点 $(x_1,y_1)$、$(x_2,y_2)$ 的距离：$\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$。代码中的平方可以写成 `squared = dx * dx;`，不要用 `squared = dx ^ 2;` 表示平方。
- 圆面积 $\pi r^2$、周长 $2\pi r$。可以用 `double pi = acos(-1.0);` 得到 $\pi$。
- 已知三角形三边时，半周长 $p=(a+b+c)/2$，面积为 $\sqrt{p(p-a)(p-b)(p-c)}$。

这些含小数的量用 `double` 保存，保留一位小数时用 `printf("%.1f\n", area);`。如果原始坐标用 `int`，先把差值存入 `double` 或合适范围的 `long long` 再平方，避免整数乘法溢出。

观察规律的题，可以先列出小规模结果，尝试从“新增一个元素，会多产生什么”推导关系。找到几个样例吻合后，还要解释为什么对所有允许情况都成立；例如 $n$ 条直线最多把平面分成几部分，第 $n$ 条线最多被前面的线分成 $n$ 段，因此最多新增加 $n$ 块区域。这比直接背下一个二次公式更容易实现和检查。
