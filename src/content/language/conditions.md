## if 和 else

先做一个本地演示：读入一个整数，判断它是奇数还是偶数。整数除以 2 的余数为 0，就是偶数。因此条件可以写成 `n % 2 == 0`：

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 2 == 0) {
        cout << "even\n";
    } else {
        cout << "odd\n";
    }
    return 0;
}
```

输入 `6`，输出 `even`；输入 `7`，输出 `odd`。条件为真时执行 `if` 中的大括号，否则执行 `else` 中的大括号。

`else` 可以省略，表示条件不满足时什么也不做。大括号把一个分支要执行的语句圈成一块：条件成立时，执行 if 的这一整块；否则执行 else 的这一整块。即使里面只有一行，也建议保留大括号，后面添加语句时就能直接放进对应分支。

观察代码的缩进：main 里面的语句缩进 4 个空格，if 和 else 里面的输出再多缩进 4 个空格，总共 8 个空格。这样一眼就能看出输出属于哪个分支；每个右大括号都和对应的 if、else 或 main 对齐。

## 比较与逻辑运算

| 运算符 | 含义 | 例子 |
| --- | --- | --- |
| `==`、`!=` | 等于、不等于 | `n == 0` |
| `<`、`<=` | 小于、小于等于 | `n <= 10` |
| `>`、`>=` | 大于、大于等于 | `n >= 1` |
| `&&` | 并且：两边都为真 | `n >= 1 && n <= 10` |
| `\|\|` | 或者：至少一边为真 | `n < 1 \|\| n > 10` |
| `!` | 取反 | `!(n == 0)` |

> **特别注意：`=` 与 `==` 做的是两件事**
>
> `=` 是**赋值**：`n = 3;` 把 3 存进 $n$，$n$ 的值会被修改。
>
> `==` 是**判断相等**：`n == 3` 询问“$n$ 现在是不是 3”，得到真或假，不会修改 $n$。
>
> 所以“如果 $n$ 等于 3”应写成 `if (n == 3)`。写成 `if (n = 3)` 会先把 $n$ 改成 3，随后把非零的 3 当作真，分支就会执行；它不会替你判断原来的 $n$ 是否等于 3。

另外两个容易写错的地方：

- 数学中的 $1\le x\le 10$，在 C++ 中应写成 **`x >= 1 && x <= 10`**。
- `if (条件)` 后面不要随手加一个分号，否则紧随其后的语句块可能不再受条件控制。

## 多种情况依次判断

再做一个本地演示：输入分数 $\mathrm{score}$（0 到 100），90 分及以上输出 `A`，60 到 89 分输出 `B`，其余输出 `C`。先把区间排好，再写代码：

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 90) {
        cout << "A\n";
    } else if (score >= 60) {
        cout << "B\n";
    } else {
        cout << "C\n";
    }
    return 0;
}
```

这是一条 `if / else if / else` 链，只会进入第一个满足条件的分支。执行到第二个条件时，已经知道 `score < 90`，所以不必再写一遍上界。

如果写成几个互不相连的 `if`，则会分别判断，可能同时执行多个分支。比如 95 既满足“大于等于 90”，也满足“大于等于 60”。

## 例题精讲：P5711 · 闰年判断

**原题：** [P5711 · 闰年判断](https://www.luogu.com.cn/problem/P5711)。

**题意简述：** 输入一个 1582 到 2020 之间的年份，是闰年输出 1，否则输出 0。

规则有两种满足方式：能被 400 整除；或者能被 4 整除，但不能被 100 整除。先把中文拆开：

| 中文条件 | C++ 条件 |
| --- | --- |
| 能被 400 整除 | `year % 400 == 0` |
| 能被 4 整除，并且不能被 100 整除 | `year % 4 == 0 && year % 100 != 0` |
| 两种方式至少满足一种 | 用逻辑“或”连接上面的两种条件 |

例如 2000 年是 400 的倍数，应当输出 1；1900 年虽然是 4 的倍数，但既不是 400 的倍数，又是 100 的倍数，应当输出 0。接下来把判断结果存进 `bool leap`，再让分支选择输出：

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int year;
    cin >> year;
    bool leap = (year % 400 == 0) ||
                (year % 4 == 0 && year % 100 != 0);
    if (leap) {
        cout << 1 << '\n';
    } else {
        cout << 0 << '\n';
    }
    return 0;
}
```

这里的 `bool` 变量只存“真”或“假”。条件成立时 $\mathrm{leap}$ 为真，进入输出 1 的分支；否则进入输出 0 的分支。

分别输入 `2000`、`1900`、`2020`、`2019`，输出应依次为 `1`、`0`、`1`、`0`。这四组数据覆盖了“世纪闰年、整百非闰年、普通闰年、普通非闰年”。自己为每个年份说出判断理由，再与程序结果对照。
