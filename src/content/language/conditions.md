## 今天要完成什么

前面的程序总是按同样的顺序执行。今天学习让程序根据条件选择不同的操作：**满足条件做一件事，不满足就做另一件事。**

## if 和 else

读入一个整数，判断它是奇数还是偶数：

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 2 == 0) {
        cout << "even\n";
    } else {
        cout << "odd\n";
    }
    return 0;
}
```

输入 `6`，输出 `even`；输入 `7`，输出 `odd`。条件为真时执行 `if` 中的大括号，否则执行 `else` 中的大括号。

`else` 可以省略，表示条件不满足时什么也不做。刚入门时，即使分支里只有一行，也建议写上大括号，方便以后修改。

## 比较与逻辑运算

| 运算符 | 含义 | 例子 |
| --- | --- | --- |
| `==`、`!=` | 等于、不等于 | `n == 0` |
| `<`、`<=` | 小于、小于等于 | `n <= 10` |
| `>`、`>=` | 大于、大于等于 | `n >= 1` |
| `&&` | 并且：两边都为真 | `n >= 1 && n <= 10` |
| `\|\|` | 或者：至少一边为真 | `n < 1 \|\| n > 10` |
| `!` | 取反 | `!(n == 0)` |

最容易写错的地方：

- 判断相等用 **`==`**，赋值用 `=`。
- 数学中的 `1 <= x <= 10`，在 C++ 中应写成 **`x >= 1 && x <= 10`**。
- `if (条件)` 后面不要随手加一个分号，否则紧随其后的语句块可能不再受条件控制。

## 多种情况依次判断

输入分数 `score`（0 到 100），按三档输出结果：

```cpp
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 90) {
        cout << "A\n";
    } else if (score >= 60) {
        cout << "B\n";
    } else {
        cout << "C\n";
    }
    return 0;
}
```

这是一条 `if / else if / else` 链，只会进入第一个满足条件的分支。执行到第二个条件时，已经知道 `score < 90`，所以不必再写一遍上界。

如果写成几个互不相连的 `if`，则会分别判断，可能同时执行多个分支。比如 95 既满足“大于等于 90”，也满足“大于等于 60”。

## 拿闰年判断练一练

公历闰年规则是：能被 400 整除，或者能被 4 整除但不能被 100 整除。

先把这句话写成条件，再放进程序：

```cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    cin >> year;
    bool leap = (year % 400 == 0) ||
                (year % 4 == 0 && year % 100 != 0);
    if (leap) {
        cout << 1 << '\n';
    } else {
        cout << 0 << '\n';
    }
    return 0;
}
```

分别输入 `2000`、`1900`、`2024`、`2023`，输出应依次为 `1`、`0`、`1`、`0`。这四个例子分别覆盖了不同的分支，比只检查一个普通闰年更有效。
