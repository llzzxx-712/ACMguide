## 二进制：每一位只放 0 或 1

十进制的 $253=2\times 100+5\times 10+3$，二进制也一样，只是每向左一位，位权乘 2。最右侧称为第 0 位，随后是第 `1、2、3` 位，分别对应 `1、2、4、8`：

```text
位编号：3 2 1 0
位  权：8 4 2 1
13    ：1 1 0 1    13 = 8 + 4 + 1
6     ：0 1 1 0     6 = 4 + 2
```

它们仍是整数 `13、6`，只是写法变了。`cin >> x` 默认按十进制读入，`cout << x` 默认按十进制输出，不需要先把输入转换成字符串才能做位运算。

## 逐位计算：与、或、异或、取反

| 写法 | 对同一位置的两个二进制位做什么 | 6 与 3 的例子 |
| --- | --- | --- |
| `a & b` | 两位都是 1，结果才是 1 | `0110 & 0011 = 0010`，即 2 |
| `a \| b` | 至少一位是 1，结果就是 1 | `0110 \| 0011 = 0111`，即 7 |
| `a ^ b` | 两位不同为 1，相同为 0 | `0110 ^ 0011 = 0101`，即 5 |
| `~a` | 把每一位的 `0、1` 互换 | 会翻转整个类型的全部位 |

`~` 不只是翻转纸上写出的四位。例如 `~6` 不能当作四位的 1001 来解释；整数还有更高位。初学时先把它用于下面的“清掉指定一位”，而不是把取反当成求一个四位数。

> **分清 `&` 与 `&&`、`|` 与 `||`。**
>
> `&&`、`||` 判断表达式真假，结果是 `bool`；`&`、`|` 逐位操作整数。例如 `6 && 3` 为 `true`，而 `6 & 3` 为 2。`^` 是异或，不是乘方，平方仍写 `x * x`。比较某一位时加括号，如 `(x & 1) == 1`。

## 移位：把一个 1 放到想要的位置

对非负数，`x << k` 把位向左移 $k$ 位，右边补 0；`x >> k` 把位向右移 $k$ 位。例如 `3 << 2` 是 `0011 → 1100`，得到 12；`13 >> 1` 是 `1101 → 0110`，得到 6。

因此 `1LL << k` 就是一个只有第 $k$ 位为 1 的数。`LL` 让计算从 `long long` 开始，本节取 $0\le k\le 62$，并保证左移结果仍在 `long long` 范围内。移位数不能为负，也不能达到类型的位数；不要用 `1 << 40` 先在 `int` 上移位再赋给 `long long`。

把一位看作一个开关，1 表示开、0 表示关，令 `mask = 1LL << k`：

| 目标 | 代码 | 为什么 |
| --- | --- | --- |
| 检查第 $k$ 位 | `(x >> k) & 1LL` | 先移到最右边，再只留下这一位 |
| 打开第 $k$ 位 | `x = x \| mask` | 与 1 做或，这一位变为 1 |
| 关闭第 $k$ 位 | `x = x & ~mask` | 掩码只有这一位为 0，其余位保留 |
| 翻转第 $k$ 位 | `x = x ^ mask` | 与 1 异或变成相反值，与 0 异或保持原值 |

`x |= mask`、`x &= ~mask`、`x ^= mask` 分别是上面三种赋值的简写，与之前学过的 `sum += value` 一样。

## 例题精讲一：自编 · 开关盒

**题意简述：** 有编号 0 到 19 的 20 个开关，用一个非负整数 $x$ 的低 20 位记录状态。输入初始 $x$、操作数 $q$；随后每行给操作 $\mathrm{op}$ 和编号 $k$。$\mathrm{op}=1$ 打开、2 关闭、3 翻转、4 查询这一位并输出 0 或 1。$0\le x<2^{20}$，$1\le q\le 1000$，$0\le k<20$。

输入：

```text
5 6
4 0
1 1
2 2
3 0
4 0
4 1
```

输出：

```text
1
0
1
```

初始 5 写成二进制是 `0101`，开着第 `0、2` 位。打开第 1 位后是 `0111`，关闭第 2 位后是 `0011`，翻转第 0 位后是 `0010`。代码要实现的正是这几个状态变化：

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    long long x;
    int q;
    cin >> x >> q;
    while (q--) {
        int op, k;
        cin >> op >> k;
        long long mask = 1LL << k;
        if (op == 1) x |= mask;
        else if (op == 2) x &= ~mask;
        else if (op == 3) x ^= mask;
        else cout << ((x >> k) & 1LL) << '\n';
    }
    return 0;
}
```

试着连续打开两次同一个开关：第二次状态不变。连续翻转两次则恢复原样，因为 `x ^ mask ^ mask = x`。异或还满足 `x ^ x = 0`、`x ^ 0 = x`，这会在后面的数学与博弈中继续用到。

位运算让“操作某一位”的思路直接成为代码。现在先理解每个运算做了什么，后面学集合状态、倍增、树状数组时，再看这些位怎样参与解题。

## 例题精讲二：P5728 · 旗鼓相当的对手

**原题：** [P5728 · 旗鼓相当的对手](https://www.luogu.com.cn/problem/P5728)。

**题意简述：** 输入 $N$ 名学生的语文、数学、英语成绩，统计有多少对学生满足：每科分差都不超过 5，且总分分差不超过 10。$N$ 在 2 到 1000 之间，每科成绩在 0 到 150 之间。

### 先把题意拆成几个小任务

1. 一位学生有三科成绩，用结构体；多位学生，用结构体数组。
2. 判断两人是否符合条件，写成返回 `bool` 的函数。
3. 每一对学生都要检查，用两层循环。
4. 找到符合条件的一对，答案加 1。

分差不能直接用 $a-b$ 比较，因为它可能是负数。使用 `abs(a - b)` 取绝对值，才表示两人相差多少。

枚举时令第二个人 $j$ 从 $i+1$ 开始。这样既不会让一个人与自己比较，也不会把“第 1 人与第 2 人”和“第 2 人与第 1 人”重复算两次。

```cpp
#include<bits/stdc++.h>
using namespace std;

struct Student {
    int chinese, math, english;
};

int total(Student s) {
    return s.chinese + s.math + s.english;
}

bool closeEnough(Student a, Student b) {
    return abs(a.chinese - b.chinese) <= 5
        && abs(a.math - b.math) <= 5
        && abs(a.english - b.english) <= 5
        && abs(total(a) - total(b)) <= 10;
}

int main() {
    int n;
    cin >> n;
    Student students[1000];
    for (int i = 0; i < n; i++) {
        cin >> students[i].chinese
            >> students[i].math
            >> students[i].english;
    }
    int answer = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (closeEnough(students[i], students[j])) {
                answer++;
            }
        }
    }
    cout << answer << '\n';
    return 0;
}
```

输入：

```text
3
100 100 100
104 103 102
105 105 105
```

输出：

```text
2
```

第一人与第二人每科分差是 `4 3 2`，总分相差 9，符合条件。第一人与第三人每科都只差 5，但总分差 15，不符合。第二人与第三人符合，所以共 2 对。

这里四个条件用 `&&` 连接，要求同时成立。程序最多检查 $1000\times 999/2=499500$ 对，每对只做固定次数的计算；不需要再对全班重复统计同一对。

## 如何看待评测结果

| 结果 | 常见含义 | 下一步做什么 |
| --- | --- | --- |
| AC | 已通过该题当前测试 | 确认能解释思路，复查边界和复杂度 |
| WA | 输出答案不符合要求 | 手算小数据，核对题意、边界和格式 |
| CE | 编译失败 | 先看第一条报错，再查对应代码附近 |
| RE | 运行异常 | 检查越界、除零、递归深度等问题 |
| TLE | 超出时间限制 | 检查死循环与算法计算量 |
| MLE | 超出内存限制 | 检查数组规模及内存使用 |

不同平台的提示名称可能有差异。**结果告诉你症状，定位错误仍然需要检查代码。**

## 遇到错误时按这个顺序查

1. **重读输入输出。** 输入是否先给 $n$？还是读到某个结束标记？输出是否有固定格式？
2. **只用一组小数据。** 先在纸上算出答案，再看程序每轮变量如何变化。
3. **检查最容易漏的边界。** 只有一个元素、恰好等于分界值、全相同、全为负数或最大范围。
4. **添加临时输出。** 在本地观察中间值，定位后删除这些输出，再提交。
5. **一次改一个原因。** 不要凭感觉同时改十处；否则即使通过，也不清楚错在哪里。

向别人提问时，可以附上“题目链接、完整代码、失败输入、预期输出、实际输出、尝试过什么”。这比只说“为什么不对”更容易得到有效帮助。
