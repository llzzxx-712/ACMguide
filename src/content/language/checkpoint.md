## 例题精讲：P5728 · 旗鼓相当的对手

**原题：** [P5728 · 旗鼓相当的对手](https://www.luogu.com.cn/problem/P5728)。

**题意简述：** 输入 N 名学生的语文、数学、英语成绩，统计有多少对学生满足：每科分差都不超过 5，且总分分差不超过 10。N 在 2 到 1000 之间，每科成绩在 0 到 150 之间。

### 先把题意拆成几个小任务

1. 一位学生有三科成绩，用结构体；多位学生，用结构体数组。
2. 判断两人是否符合条件，写成返回 bool 的函数。
3. 每一对学生都要检查，用两层循环。
4. 找到符合条件的一对，答案加 1。

分差不能直接用 a−b 比较，因为它可能是负数。使用 `<cstdlib>` 中的 `abs(a - b)` 取绝对值，才表示两人相差多少。

枚举时令第二个人 j 从 i+1 开始。这样既不会让一个人与自己比较，也不会把“第 1 人与第 2 人”和“第 2 人与第 1 人”重复算两次。

```cpp
#include <iostream>
#include <cstdlib>
using namespace std;

struct Student {
    int chinese, math, english;
};

int total(Student s) {
    return s.chinese + s.math + s.english;
}

bool closeEnough(Student a, Student b) {
    return abs(a.chinese - b.chinese) <= 5
        && abs(a.math - b.math) <= 5
        && abs(a.english - b.english) <= 5
        && abs(total(a) - total(b)) <= 10;
}

int main() {
    int n;
    cin >> n;
    Student students[1000];
    for (int i = 0; i < n; i++) {
        cin >> students[i].chinese
            >> students[i].math
            >> students[i].english;
    }
    int answer = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (closeEnough(students[i], students[j])) {
                answer++;
            }
        }
    }
    cout << answer << '\n';
    return 0;
}
```

输入：

```text
3
100 100 100
104 103 102
105 105 105
```

输出：

```text
2
```

第一人与第二人每科分差是 4、3、2，总分相差 9，符合条件。第一人与第三人每科都只差 5，但总分差 15，不符合。第二人与第三人符合，所以共 2 对。

这里四个条件用 && 连接，要求同时成立。程序最多检查 `1000 × 999 / 2 = 499500` 对，每对只做固定次数的计算；不需要再对全班重复统计同一对。

## 推荐必做：两道小测

### A · 成绩统计

输入正整数 `n`，再输入 `n` 个分数。输出总分和及格人数，60 分及以上视为及格，两个结果用空格隔开。

范围：`1 <= n <= 1000`，每个分数为 0 到 100 的整数。

输入：

```text
5
59 60 90 0 100
```

输出：

```text
309 3
```

检查点：能否组合输入输出、累加、条件判断和循环？再测试所有人不及格、所有人都及格和只有一个人的情况。

### B · 回文单词

输入一个只包含小写英文字母的非空字符串。如果从左向右和从右向左读完全相同，输出 `YES`，否则输出 `NO`。

范围：长度为 1 到 1000。

输入 `level`，输出 `YES`；输入 `acm`，输出 `NO`。

检查点：能否找到左右位置之间的对应关系？分别测试单字符、偶数长度、奇数长度以及只有中间附近不相同的情况。

## 选做：需要继续巩固时练习

### C · 选出最优选手

输入正整数 `n`，然后每行输入一位选手的姓名和三项成绩。输出总分最高者的姓名与总分；如果同分，输出最先输入的那位。

范围：`1 <= n <= 100`，姓名为不带空格的英文字母串，每项成绩为 0 到 100 的整数。

输入：

```text
3
Alice 80 90 100
Bob 100 80 90
Carol 90 95 100
```

输出：

```text
Carol 285
```

检查点：能否使用结构体整理数据，是否正确处理“同分保留最早者”？尝试把总分计算或比较逻辑写成一个函数。

### D · 矩阵列和

输入正整数 n、m，再输入 n 行 m 列的整数矩阵。输出 m 个整数，分别表示每一列的总和，用空格隔开。

范围：`1 <= n,m <= 20`，矩阵元素为 0 到 1000 的整数。

输入：

```text
2 3
1 2 3
4 5 6
```

输出：

```text
5 7 9
```

检查点：能否分清行下标和列下标？先固定一列，再遍历每一行。测试只有一行、只有一列和元素全为 0 的情况。

## 如何看待评测结果

| 结果 | 常见含义 | 下一步做什么 |
| --- | --- | --- |
| AC | 已通过该题当前测试 | 确认能解释思路，复查边界和复杂度 |
| WA | 输出答案不符合要求 | 手算小数据，核对题意、边界和格式 |
| CE | 编译失败 | 先看第一条报错，再查对应代码附近 |
| RE | 运行异常 | 检查越界、除零、递归深度等问题 |
| TLE | 超出时间限制 | 检查死循环与算法计算量 |
| MLE | 超出内存限制 | 检查数组规模及内存使用 |

不同平台的提示名称可能有差异。**结果告诉你症状，定位错误仍然需要检查代码。**

## 遇到错误时按这个顺序查

1. **重读输入输出。** 输入是否先给 `n`？还是读到某个结束标记？输出是否有固定格式？
2. **只用一组小数据。** 先在纸上算出答案，再看程序每轮变量如何变化。
3. **检查最容易漏的边界。** 只有一个元素、恰好等于分界值、全相同、全为负数或最大范围。
4. **添加临时输出。** 在本地观察中间值，定位后删除这些输出，再提交。
5. **一次改一个原因。** 不要凭感觉同时改十处；否则即使通过，也不清楚错在哪里。

向别人提问时，可以附上“题目链接、完整代码、失败输入、预期输出、实际输出、尝试过什么”。这比只说“为什么不对”更容易得到有效帮助。
