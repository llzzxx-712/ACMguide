## 字符与字符串

- `'A'` 是一个字符，使用**单引号**，类型通常是 `char`。
- `"ACM"` 是字符串字面量，使用**双引号**，可以用来初始化 `string`。
- `string s = "ACM";` 让 `s` 存下这三个字符。

使用 `string` 时引入头文件 `<string>`。`s.size()` 返回长度，`s[i]` 访问下标为 `i` 的字符。合法字符下标为 `0` 到 `s.size() - 1`；空字符串没有可读写的字符位置。

和数组一样，**字符串也要检查边界**。`s.size()` 返回的是无符号类型，初学阶段需要倒序循环时，可先把长度转成 `int`，在本章的小规模字符串范围内使用。

## 读取一个单词

先做一个本地演示：输入一个不带空格的单词，把它倒序输出。和数组倒序一样，先找到最后一个字符的下标：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = static_cast<int>(s.size());
    for (int i = n - 1; i >= 0; i--) {
        cout << s[i];
    }
    cout << '\n';
    return 0;
}
```

输入 `ACM`，输出 `MCA`。这里用 `static_cast<int>` 把字符串长度转为 int，方便写下标循环。`cin >> s` 会跳过前面的空白，再读到下一个空白为止，所以它不能一次读入带空格的完整句子。

## 读取一整行

`getline(cin, s)` 会读取一行，可以保留其中的空格，遇到行尾时结束，并取走换行符。

再做一个本地演示：读入一行文字，统计里面有多少个英文字母。这里处理英文、数字和普通标点组成的文本。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);
    int letters = 0;
    for (char c : s) {
        if ((c >= 'a' && c <= 'z') ||
            (c >= 'A' && c <= 'Z')) {
            letters++;
        }
    }
    cout << letters << '\n';
    return 0;
}
```

输入 `I love ACM 2026!`，输出 `8`。这里的 `for (char c : s)` 是范围循环：依次把每个字符取出来，放进本轮的 `c` 中。

在这里，字符按 ASCII 编码排列。`'a'` 到 `'z'` 连续，`'A'` 到 `'Z'` 也连续。因此可以通过区间判断识别字母，通过它在字母表里的位置完成大小写转换。

## cin 和 getline 混用

先用 `cin >> n` 读整数时，行末的换行通常还留在输入中。紧接着调用 `getline`，它就可能读到一个空行。

如果题目规定“第一行是一个整数，第二行是完整文本”，可以在读整数后使用 `cin.ignore(numeric_limits<streamsize>::max(), '\n');` 丢弃当前行的剩余内容，再 `getline`。使用这句时需要引入 `<limits>`。

另一种常见写法是 `getline(cin >> ws, s)`，但 `ws` 会跳过所有前导空白，因此**不适合需要保留行首空格或空行的题目**。按照题目输入格式选择，不要机械套用。

## 常用操作先学这些

| 操作 | 含义 |
| --- | --- |
| `s.size()` | 字符串长度 |
| `s.empty()` | 是否为空 |
| `s + t` | 连接两个字符串 |
| `s += c` | 在末尾追加字符或字符串 |
| `s.substr(pos, len)` | 从 `pos` 开始取一段；注意起点合法 |
| `s.insert(pos, t)` | 在下标 pos 处插入字符串 t；pos 可以等于长度，表示接在末尾 |
| `s.find(t)` | 查找 t 第一次出现的位置；没有找到时返回 `string::npos` |
| `s == t` | 内容是否相同 |

字符 `'0'` 和整数 `0` 不是同一个东西。如果已经确认 `c` 是数字字符，可以用 `c - '0'` 得到对应的整数数字。

普通字符数组也能存放文本，但 C 风格字符串还要为结尾的 `\0` 留位置。本阶段主要用 `string`；读到字符数组写法时，记住结尾标记和容量要求。

例如 `s = "acm"`，`s.substr(1, 2)` 得到 `"cm"`。调用 `s.insert(1, "X")` 后，s 变成 `"aXcm"`。查找时先保存 `auto pos = s.find("X");`，判断是否等于 `string::npos`，找到后再使用这个位置。可以在本地逐个尝试这些操作，观察字符串发生了什么变化。

## 例题精讲：P5733 · 自动修正

**原题：** [P5733 · 自动修正](https://www.luogu.com.cn/problem/P5733)。

**题意简述：** 读入一个长度不超过 100、没有空格的字符串，把其中的小写字母改成大写字母，其余字符保持原样，输出修改后的字符串。

### 从一个字符开始想

假设读到了小写字母 `'c'`。它比 `'a'` 往后 2 个位置，所以 `'c' - 'a'` 得到 2。把这个位置加到 `'A'` 上，就得到大写的 `'C'`。一般写法是 `c - 'a' + 'A'`。

但数字 `'3'` 不需要改，已经大写的 `'M'` 也不需要改。因此先判断是否在 `'a'` 到 `'z'` 之间，满足才转换。最后把这个步骤对字符串每个下标都做一次。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = static_cast<int>(s.size());
    for (int i = 0; i < n; i++) {
        if (s[i] >= 'a' && s[i] <= 'z') {
            s[i] = s[i] - 'a' + 'A';
        }
    }
    cout << s << '\n';
    return 0;
}
```

输入 `aCm123`，输出 `ACM123`。`static_cast<int>` 把长度转换成我们熟悉的 int，方便在本节不超过 100 个字符的范围内使用下标循环。

循环里的 `s[i] = ...` 直接修改原字符串对应位置，所以循环结束后一次输出 s 即可。试试输入 `AZ09`，它应当保持不变；输入 `az`，应当得到 `AZ`。
