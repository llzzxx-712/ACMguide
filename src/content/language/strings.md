## char：存下一个字符

`char` 用来存一个字符，字符常量写在**单引号**里：

```text
char c = 'a';
char digit = '3';
char space = ' ';
```

这里分别存下字母 a、数字字符 3 和一个空格。注意 `'3'` 是一个字符，整数 `3` 是一个数，它们表达的含义不同。

读取和输出字符，可以使用 `cin >> c;`、`cout << c;`。如果输入 `b`，c 就存下这个字母；之后使用 c，取到的就是这次读入的字符。

## ASCII：字符也有编号

计算机通过编号表示字符。我们先认识 **ASCII 编码**中常见的字母和数字：

| 字符 | ASCII 编码 |
| --- | --- |
| `'A'` | 65 |
| `'Z'` | 90 |
| `'a'` | 97 |
| `'z'` | 122 |
| `'0'` | 48 |
| `'9'` | 57 |

不需要把整张编码表背下来，先记住：**大写字母、小写字母、数字字符，各自在编码中连续排列。**

例如 `'b'` 比 `'a'` 往后一个位置，因此 `'b' - 'a'` 得到整数 1；`'5' - '0'` 得到整数 5。字符参与运算时，可以利用它们的编码计算。

想在本地观察字符与编号，可以先定义 `char c = 'a';`，再执行 `printf("%c %d\n", c, c);`，会显示 `a 97`：`%c` 按字符输出，`%d` 按整数输出。两种显示使用的是同一个 c。

## 用字符运算转换大小写

假设 c 存着小写字母 `'c'`。它在小写字母中的位置是：

```text
'c' - 'a' = 2
```

大写字母也连续排列，因此在 `'A'` 后面走两个位置，就得到 `'C'`。合起来就是：

```text
c = c - 'a' + 'A';
```

先用 `c - 'a'` 算出它在字母表里的位置，再加上大写字母的起点 `'A'`。把结果赋给 `char` 变量 c 时，会自动完成类型转换，c 就存下了对应的大写字符。

下面是一个本地演示：输入一个字符，如果是小写字母就改成大写，再输出。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    char c;
    cin >> c;
    if (c >= 'a' && c <= 'z') {
        c = c - 'a' + 'A';
    }
    cout << c << '\n';
    return 0;
}
```

输入 `b`，输出 `B`；输入 `3`，仍然输出 `3`。先判断小写范围，是因为数字、标点和已经大写的字母不需要转换。

反过来，如果已经确认 c 是大写字母，可以用 `c = c - 'A' + 'a';` 转为小写。确认是数字字符后，则可以用 `int x = c - '0';` 得到它表示的整数。

## string：存下一串字符

一个名字或一句话通常包含多个字符。`string` 就用来保存这样一串按顺序排列的字符：

```text
char c = 'A';
string s = "ACM";
```

`'A'` 使用单引号，表示一个字符；`"ACM"` 使用双引号，表示一串文字。`string s = "A";` 也可以，只是这个字符串恰好只有一个字符。

程序开头继续使用 `#include<bits/stdc++.h>`，就可以直接使用 `string`。接下来我们要学会问它有多长、在末尾接上文字，以及取出指定位置的字符。

## 常用操作先学这些

### size：字符串有多长

`s.size()` 返回字符串长度。要在后面的循环中使用长度，直接写：

```text
string s = "ACM";
int n = s.size();
```

此时 n 为 3。长度赋给 `int` 时会自动完成类型转换，我们直接使用这个写法。

### +=：在末尾拼接

`s += ...;` 会把右侧的字符或字符串接在 s 的末尾，修改 s 本身：

```text
string s = "AC";
s += 'M';
s += " team";
```

执行第一条拼接后，s 变成 `"ACM"`；再拼接后，变成 `"ACM team"`，长度为 8。`+=` 右侧既可以是一个字符，也可以是一段字符串。

如果已经有字符串 s 和 t，`s + t` 会得到它们连接后的字符串；想把拼接结果保存在 s 中，就可以写 `s += t;`。

### 用下标获取和修改字符

字符串也像数组一样从 0 开始编号。对于 `string s = "ACM";`：

| 下标 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 字符 | A | C | M |

`s[0]` 取到 `'A'`，`s[2]` 取到 `'M'`。执行 `s[0] = 'a';` 后，s 就变成 `"aCM"`。

若长度为 n，可访问的字符下标是 0 到 n−1。遍历时用 `i < n`，不是 `i <= n`；空字符串没有可取出的字符位置。

### 其他常用操作查表

| 操作 | 含义 |
| --- | --- |
| `s.empty()` | 判断字符串是否为空 |
| `s.substr(pos, len)` | 从下标 pos 开始取 len 个字符 |
| `s.insert(pos, t)` | 在下标 pos 处插入字符串 t |
| `s.find(t)` | 查找 t 第一次出现的位置；没找到时返回 `string::npos` |
| `s == t` | 判断两个字符串内容是否相同 |

例如 s 是 `"acm"`，`s.substr(1, 2)` 得到 `"cm"`；执行 `s.insert(1, "X")` 后，s 变成 `"aXcm"`。

查找时，可以用 `auto pos = s.find("X");` 保存结果，再判断 pos 是否等于 `string::npos`。这里 auto 让编译器根据右边的结果确定变量类型。找到后再使用这个位置，没找到则单独处理。可以在本地逐项尝试，观察字符串的变化。

## 读取一个单词

`cin >> s;` 会读取一个不带空格的单词。先做一个本地演示：把读入的单词倒序输出。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.size();
    for (int i = n - 1; i >= 0; i--) {
        cout << s[i];
    }
    cout << '\n';
    return 0;
}
```

输入 `ACM`，输出 `MCA`。先用 n 记录长度，再从最后一个下标 n−1 开始向前访问，一直到 0。

`cin` 读取字符串时会跳过开头的空白，并在下一个空格或换行处停止。因此，输入 `I love ACM` 时，一次 `cin >> s;` 只会读到 `I`。想读下整句话，就需要下面的 `getline`。

## 读取一整行：getline

`getline(cin, s);` 读取一整行，可以保留行内的空格，遇到行尾时结束。行末的换行符不会存进 s。

下面做一个本地演示：读入一行文字，统计里面有多少个英文字母。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin, s);
    int n = s.size();
    int letters = 0;
    for (int i = 0; i < n; i++) {
        char c = s[i];
        if ((c >= 'a' && c <= 'z') ||
            (c >= 'A' && c <= 'Z')) {
            letters++;
        }
    }
    cout << letters << '\n';
    return 0;
}
```

输入 `I love ACM 2026!`，输出 `8`。每轮先用下标取出一个字符，存到 c，再利用刚学过的字符区间判断它是不是字母；是字母就让 letters 加 1。空格、数字和标点都不会计入。

这个例子把前面的方法串了起来：**`getline` 读整行 → size 获取长度 → 下标遍历 → `char` 保存当前字符 → 条件判断与计数。**

## 例题精讲：P5733 · 自动修正

**原题：** [P5733 · 自动修正](https://www.luogu.com.cn/problem/P5733)。

**题意简述：** 读入一个长度不超过 100、没有空格的字符串，把其中的小写字母改成大写字母，其余字符保持原样，输出修改后的字符串。

### 把一个字符的转换，推广到整串字符

前面已经能把字符 c 从小写改成大写。现在只是把 c 换成每个位置上的 `s[i]`：

1. 读取字符串，用 `int n = s.size();` 得到长度。
2. i 从 0 遍历到 n−1，依次检查每个字符。
3. 如果 `s[i]` 是小写字母，就执行 `s[i] = s[i] - 'a' + 'A';`。
4. 全部处理完，再输出修改后的 s。

例如输入 `aCm123`：a 改成 A，C 保持不变，m 改成 M，三个数字保持不变，最后得到 `ACM123`。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.size();
    for (int i = 0; i < n; i++) {
        if (s[i] >= 'a' && s[i] <= 'z') {
            s[i] = s[i] - 'a' + 'A';
        }
    }
    cout << s << '\n';
    return 0;
}
```

这里直接修改 s 对应位置上的字符，所以循环结束后一次输出整个字符串即可。再试 `AZ09`，它应保持不变；输入 `az`，应得到 `AZ`。
