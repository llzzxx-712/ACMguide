## for：次数或范围比较明确

先做一个最简单的本地演示：输入正整数 n（不超过 1000），按顺序输出 1 到 n，每行一个数。其中 `i++` 表示让 i 加 1。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cout << i << '\n';
    }
    return 0;
}
```

输入 `3`，输出：

```text
1
2
3
```

大括号里的 `cout` 是每轮都要执行的**循环体**。这条语句缩进在 for 里面，可以直接看出它要跟着循环重复执行。

### for 的执行顺序

`for (int i = 1; i <= n; i++)` 的三个位置分别是“初始化、继续条件、每轮后的更新”。执行顺序是：

1. `int i = 1`：设置起点，只执行一次。
2. `i <= n`：判断是否继续；为假就退出。
3. 执行大括号里的循环体。
4. `i++`：更新变量，再回到第 2 步。

例如 n 为 3 时，循环体执行时 i 依次为 1、2、3。第三轮后 i 变成 4，条件不满足，循环结束。它不是“看到 3 就立即停”，而是先完成 i 为 3 的那一轮。

## while：满足条件就继续

while 也先检查条件，满足才执行一轮。把刚才“输出 1 到 n”的程序换成 while，完整代码如下：

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int i = 1;
    while (i <= n) {
        cout << i << '\n';
        i++;
    }
    return 0;
}
```

输入 `3`，仍然依次输出 1、2、3，每个数占一行。这里先在 while 前准备 i，再在大括号里“输出当前值、让 i 加 1”。循环体中的两条语句都执行完，才回到条件判断。

对照两张图，两种写法都经历“判断 → 输出 → 更新 → 再判断”。for 把初始化、条件、更新集中写在一行；while 在括号里写条件，初始化放在前面，更新放在循环体里。若第一次判断就为假，两种循环都不会执行循环体。

### 再用 while 处理位数统计

下面是另一个本地演示任务：输入一个非负整数，计算它有几位。思路是反复除以 10，每除一次就去掉末位。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    long long n;
    cin >> n;
    int digits = 0;
    if (n == 0) {
        digits = 1;
    }
    while (n > 0) {
        digits++;
        n /= 10;
    }
    cout << digits << '\n';
    return 0;
}
```

输入 `2030` 时，n 依次变成 203、20、2、0，一共做了 4 次，所以输出 4。输入 `0` 时，它本身有一位，却不会进入循环，所以单独令 digits 为 1。

`n /= 10` 就是 `n = n / 10`。如果漏掉它，正数 n 会一直大于 0，循环就不会结束。每写一个循环，都想一想：**哪一步让它朝结束靠近？**

`do ... while` 的区别是先执行一次，再判断条件，因此至少执行一轮。

## 多重循环：一层负责行，一层负责列

下面的本地演示读入 `1 <= n <= 20`，输出 n 行星号，第 i 行有 i 个星号：

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            cout << '*';
        }
        cout << '\n';
    }
    return 0;
}
```

输入 3，输出：

```text
*
**
***
```

外层 i 决定“现在第几行”；内层 j 决定“这一行打几个星号”。一整行打印完才换行，所以换行在内层循环外面。

必做题会把星号换成两位数字。使用 `printf("%02d", x);`：宽度至少为 2，不足两位在前面补 0，例如 3 输出为 03。换行可以写 `printf("\n");`。

## break 和 continue

- `break`：立即结束当前最内层循环，继续执行循环后面的代码。
- `continue`：跳过本轮剩余语句，进入下一轮。在 for 中仍然会执行更新部分。

例如只想处理一串数字中第一个 0 之前的内容，读到 0 就可以 break。若只想跳过负数、继续处理后面的数，可以在负数分支里 continue。

在 while 中，如果更新变量的语句被 continue 跳过，就可能一直停在同一个值。写完后用小数据走一遍执行顺序。

## 循环里的三个常见任务

**计数：** 先令 count 为 0，每遇到一个满足条件的对象就加 1。例如统计及格人数。

**累加：** 先令 sum 为 0，每轮加入一个值。`sum += x` 相当于 `sum = sum + x`。总和较大时使用 long long。

**最值：** 先用第一个真实数据初始化，再与后续数据比较。比如从 5、8、3 中找最小值：先认定最小值为 5，比较 8 后不变，比较 3 后更新为 3。若一开始随手设成 0，最后就可能错误地得到输入中根本没有的 0。

## 例题精讲：P5722 · 数列求和

**原题：** [P5722 · 数列求和](https://www.luogu.com.cn/problem/P5722)。

**题意简述：** 输入 `1 <= n <= 100`，用循环计算 `1 + 2 + … + n`，输出总和。

先手算 n 为 3 的情况。我们不是一下子得到 6，而是在已有结果上继续加：

| 本轮 i | 加之前的 sum | 加之后的 sum |
| --- | --- | --- |
| 1 | 0 | 1 |
| 2 | 1 | 3 |
| 3 | 3 | 6 |

因此，循环开始前设置 `sum = 0`；每轮执行 `sum += i`；循环结束后，sum 就是答案。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    cout << sum << '\n';
    return 0;
}
```

输入 `5`，输出 `15`。注意输出在循环外：题目要的是最终总和，不是每次累加的中间结果。

再试 n 为 1，应该只执行一轮，输出 1。把条件误写成 `i < n` 会漏掉最后的 n，这组数据就能发现错误。
