## 一维数组：名字相同，位置不同

`int a[5] = {};` 定义了 5 个整数，全部初始化为 0。访问时用 `a[下标]`：

| 下标 | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 刚初始化时的值 | 0 | 0 | 0 | 0 | 0 |
| 执行 `a[2] = 7` 后 | 0 | 0 | 7 | 0 | 0 |

**下标从 0 开始。** 第一个数在 `a[0]`，第三个数在 `a[2]`，最后一个数在 `a[4]`。定义中的 5 是总容量，不代表存在 `a[5]`。

如果已经知道有 $n$ 个数，就可以让 $i$ 从 0 走到 $n-1$，每轮用 `cin >> a[i];` 读入一个数。之后再遍历相同下标，就能重新取出这些值。

## 用下标表示类别：计数与标记

下标除了表示“第几个”，还可以表示“哪一种值”。

例如输入值都在 0 到 9 之间，定义 `int count[10] = {};`。每读到一个 $x$，就执行 `count[x]++;`。若依次读到 `3 1 3`，最后 `count[3]` 就是 2，表示数字 3 出现两次。

另一种用法是标记：用 0 表示“还没有出现”，用 1 表示“已经出现”。重复遇到同一个值仍然标为 1，就能避免重复计算。

用数组做计数或标记前，先看题目值域，保证每个可能出现的 $x$ 都能作为合法下标。例如要表示位置 0 到 10000，就需要至少 10001 个位置。

## 二维数组：行与列

`int a[20][20] = {};` 可以看成 20 行、20 列。`a[i][j]` 表示第 $i$ 行、$j$ 列，行列下标都从 0 开始。

做一个本地演示：输入 $n$ 行 $m$ 列的矩阵，输出每一行的和。这里约定 $1\le n,m\le 20$，每个数绝对值不超过 $10^9$。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    int a[20][20] = {};
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }
    for (int i = 0; i < n; i++) {
        long long sum = 0;
        for (int j = 0; j < m; j++) {
            sum += a[i][j];
        }
        cout << sum << '\n';
    }
    return 0;
}
```

输入：

```text
2 3
1 2 3
4 5 6
```

输出：

```text
6
15
```

外层 $i$ 选定一行，内层 $j$ 依次取出这一行的每个数。$\mathrm{sum}$ 放在外层循环里面，因此每换一行都会重新从 0 开始。每个数虽然放得进 `int`，一行的总和却可能超过 `int`，所以 $\mathrm{sum}$ 使用 `long long`。

## 访问之前先检查边界

> **数组大小与越界：写题时重点检查边界**
>
> `int a[1000];` 只能使用 `a[0]` 到 `a[999]`，`a[1000]` 和 `a[-1]` 都越界。数组要按题目的最大数据规模开够；如果 $n$ 最大为 1000，而你打算使用下标 1 到 $n$，就至少要开 `int a[1001];`。
>
> 使用 0 下标保存 $n$ 个数时，循环条件写 $i<n$，最后一个有效位置是 $n-1$。访问 `a[i + 1]` 前检查 $i+1<n$，访问 `a[i - 1]` 前检查 $i>0$。只有一个元素时，左右都没有相邻元素。
>
> 二维数组的行、列都要分别检查。例如 $n$ 行 $m$ 列的数据，要同时满足 $0\le\mathrm{row}<n$、$0\le\mathrm{col}<m$。
>
> **数组越界是 RE（Runtime Error，运行时错误）的常见原因。** 越界也可能不立刻报错，而是产生错误结果；所以写完程序要主动检查边界，不能只看样例是否正常运行。

本章先用固定容量数组，例如 `int a[1000];`，实际存了多少个数就另外记录为 $n$。不要把容量 1000 和实际个数 $n$ 混在一起；倒序输出应从 $n-1$ 开始，而不是从 999 开始。

## 例题精讲：P1427 · 小鱼的数字游戏

**原题：** [P1427 · 小鱼的数字游戏](https://www.luogu.com.cn/problem/P1427)。

**题意简述：** 输入一串整数，最后用 0 表示结束。把 0 之前的数字倒序输出，数字之间用空格隔开，结束标记 0 不输出。原题数字个数不超过 100。

### 为什么要先存下来

例如输入：

```text
2 4 6 8 10 0
```

要求输出：

```text
10 8 6 4 2
```

读到第一个 2 时，我们还不能马上输出它，因为它最终要排在最后。因此先把所有有效数字存入数组，读完再倒序取出。

### 读入时同时记录个数

用 $n$ 表示“已经存了几个数”。初始 $n$ 为 0。每读到一个非零的 $x$，就把它放到 `a[n]`，再让 $n$ 加 1：

| 刚读到的 $x$ | 存到哪里 | 存完后的 $n$ |
| --- | --- | --- |
| 2 | `a[0]` | 1 |
| 4 | `a[1]` | 2 |
| 6 | `a[2]` | 3 |

读到 0 就停止，不能先把 0 放进数组。最后有效下标为 0 到 $n-1$，输出时从 $n-1$ 递减到 0。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int a[100] = {};
    int n = 0;
    int x;
    cin >> x;
    while (x != 0) {
        a[n] = x;
        n++;
        cin >> x;
    }
    for (int i = n - 1; i >= 0; i--) {
        if (i != n - 1) cout << ' ';
        cout << a[i];
    }
    cout << '\n';
    return 0;
}
```

while 的最后一行会读取下一个数字，因此条件检查的值会不断更新。输出部分只有在“不是第一个输出的数”时才先加空格，这样数字之间有空格，行首没有多余空格。

再输入 `7 0`，应输出 7。观察整个程序：**本题并没有先输入一个 $n$，$n$ 是我们在读入时自己统计的。**

## 进阶例题精讲：P2615 · 神奇的幻方

**原题：** [P2615 · 神奇的幻方](https://www.luogu.com.cn/problem/P2615)。

**题意简述：** 给定一个奇数 $N$，把 1 到 $N^2$ 填入 $N$ 行 $N$ 列的方格，使每行、每列和两条对角线的和都相等。题目已经给出填写方法，我们需要用程序按规则构造并输出这个方阵。范围是 $1\le N\le 39$，$N$ 为奇数。

这道题把数组的两件事联系了起来：**保存每个格子里的数，以及在运行过程中计算下一次要访问哪个格子。**

### 为什么一串 $\mathrm{a1}$、$\mathrm{a2}$、$\mathrm{a3}$ 不方便

假设把每个格子都写成单独的变量，光是 $N=3$ 就要准备九个名字，$N$ 变大后还要继续增加。接下来，题目会不断要求我们访问“当前位置的右上方”“当前位置的正下方”。

这些位置需要根据当前情况计算，不能在写代码时就把所有访问都固定成某几个变量名。例如 $\mathrm{row}$ 和 $\mathrm{col}$ 在运行时才确定，我们需要直接访问 `a[row][col]`，并在下一步使用 `a[row - 1][col + 1]`。

**数组下标可以是变量，也可以是表达式。** 程序每次执行到 `a[row][col]`，都会先取 $\mathrm{row}$ 和 $\mathrm{col}$ 当前的值，再访问对应格子。同一行代码，随着下标变化，就能操作不同位置。

### 先准备方格，再记录当前坐标

用 `int a[40][40] = {};` 准备方格，初始值全部为 0。因为要填的数从 1 开始，**0 就可以表示“这个格子还没填过”**。

本例继续使用 0 下标：

- 行号从上到下是 `0` 到 `n - 1`；列号从左到右也是 `0` 到 `n - 1`。
- $\mathrm{row}$、$\mathrm{col}$ 记录上一个数所在的行、列。
- 向上一格，行号减 1；向下一格，行号加 1；向右一格，列号加 1。
- 第一个数 1 放在第一行中间，即 `a[0][n / 2]`。例如 $n=3$ 时，中间列的下标是 1。

读到这里，可以先画一个 $3\times 3$ 方格，把行列下标写在边上，再把 1 放进去。

### 把题目的四种规则翻译成下标操作

接下来依次填写 $k=2,3,\ldots,n^2$。每次根据上一个数的位置，决定 $k$ 放在哪里：

| 上一个数的位置 | 下一步的位置 | 下标怎样改变 |
| --- | --- | --- |
| 在第一行，但不在最后一列 | 最后一行，向右一列 | `row = n - 1; col++;` |
| 在最后一列，但不在第一行 | 第一列，向上一行 | `row--; col = 0;` |
| 在第一行、最后一列的交点 | 正下方 | `row++;`，$\mathrm{col}$ 不变 |
| 既不在第一行，也不在最后一列 | 右上方为空就去右上方，否则去正下方 | 先检查 `a[row - 1][col + 1]`，再决定怎样更新坐标 |

前两条规则处理“向上或向右走出边界后，从另一边接回来”；第三条单独处理右上角；第四条要查询数组，判断目标格子是否已经有数。

注意，只有进入第四种情况时，才会读取 `a[row - 1][col + 1]`。此时已经知道 $\mathrm{row}>0$、$\mathrm{col}<n-1$，所以这个右上方下标是合法的。

### 用 $N=3$ 跟着走完一遍

每一步先确定坐标，再把当前数字写进去。下面的坐标都是“行下标、列下标”：

| 要填的数 | 放入的位置 | 这一步为什么这样走 |
| --- | --- | --- |
| 1 | $(0,1)$ | 第一行中间 |
| 2 | $(2,2)$ | 1 在第一行，接到最后一行并向右一列 |
| 3 | $(1,0)$ | 2 在最后一列，接到第一列并向上一行 |
| 4 | $(2,0)$ | 3 的右上方 $(0,1)$ 已经有 1，改去正下方 |
| 5 | $(1,1)$ | 4 的右上方为空 |
| 6 | $(0,2)$ | 5 的右上方为空 |
| 7 | $(1,2)$ | 6 在右上角，去正下方 |
| 8 | $(0,0)$ | 7 在最后一列，接到第一列并向上一行 |
| 9 | $(2,1)$ | 8 在第一行，接到最后一行并向右一列 |

在纸上按这个顺序填一次，会得到：

```text
8 1 6
3 5 7
4 9 2
```

试着验证：每行、每列以及两条对角线的和都是 15。尤其观察填写 4 的那一步：程序需要先查看另一个格子的值，才能决定下一步的位置。

### 完整代码：更新坐标，再填写数字

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int a[40][40] = {};
    int row = 0, col = n / 2;
    a[row][col] = 1;

    for (int k = 2; k <= n * n; k++) {
        if (row == 0 && col != n - 1) {
            row = n - 1;
            col++;
        } else if (row != 0 && col == n - 1) {
            row--;
            col = 0;
        } else if (row == 0 && col == n - 1) {
            row++;
        } else {
            if (a[row - 1][col + 1] == 0) {
                row--;
                col++;
            } else {
                row++;
            }
        }
        a[row][col] = k;
    }

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (j > 0) cout << ' ';
            cout << a[i][j];
        }
        cout << '\n';
    }
    return 0;
}
```

输入 `3`，输出就是上面的三行幻方。再输入 `1`，只有一个格子，直接输出 1；填写 2 到 $n^2$ 的循环一次也不会执行。

这段代码可以分成三步理解：

1. **准备：** 清空方格，记录初始坐标，填入 1。
2. **构造：** 每轮按四种规则中的一种更新 $\mathrm{row}$、$\mathrm{col}$，再统一执行 `a[row][col] = k;`。
3. **输出：** 用两层循环按行、列打印整个方阵。

$\mathrm{row}$、$\mathrm{col}$ 表示的是**当前所在位置**，`a[row][col]` 存的是**这个位置上的数字**。每轮结束后，它们会一起成为下一轮判断的依据。

### 这道题希望你感受到什么

> **下标的操作，可以成为解题流程中的一部分。**
>
> 数组下标的值可以在程序运行过程中灵活计算和使用。我们可以根据当前位置、移动规则和格子里的数据，决定下一次访问哪里，再用同一句 `a[row][col] = k;` 完成填写。

普通变量 $\mathrm{a1}$、$\mathrm{a2}$、$\mathrm{a3}$ 的名字在编写代码时就各自确定了；数组用统一的名字配合可变化的下标，把“选中哪个数据”这件事交给了程序里的计算过程。这正是本题中数组的优势。

以后还会遇到很多数组下标的精妙使用，比如**桶排序**。本节前面学过的计数数组已经体现了类似的思路：把数值 $x$ 本身作为下标，用 `count[x]` 记录它出现几次，再从小到大遍历下标，就能按顺序输出这些数。例如 `3 1 3 2` 可以记录成 $\mathrm{count}[1]=1$、$\mathrm{count}[2]=1$、$\mathrm{count}[3]=2$，再依次输出 `1 2 3 3`。
