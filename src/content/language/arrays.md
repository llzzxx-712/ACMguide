如果需要存下 100 个数，定义 100 个不同名字的变量会很麻烦。数组可以用同一个名字，配合不同下标访问它们。

## 数组的下标从 0 开始

`int a[5] = {};` 定义了 5 个整数，全部初始化为 0。合法下标是 **0、1、2、3、4**，没有 `a[5]` 这个元素。

数组越界是 C++ 中非常危险的错误：它不保证立刻报错，也可能看起来“还能运行”，却产生错误结果。不要用“样例没崩”来判断下标正确。

## 一维数组：存下再倒序输出

输入 `n` 和 `n` 个整数，倒序输出。例题约定 `1 <= n <= 1000`。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int a[1000] = {};
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    for (int i = n - 1; i >= 0; i--) {
        if (i != n - 1) cout << ' ';
        cout << a[i];
    }
    cout << '\n';
    return 0;
}
```

输入：

```text
5
2 4 6 8 10
```

输出：

```text
10 8 6 4 2
```

这里只存了 `n` 个数，所以最后一个有效位置是 `n - 1`。倒序循环中的 `i` 使用带符号的 `int`，减到 -1 后退出。

这是一道教师自编的示例。P1427 的输入是以 0 结束的数列，直接提交上面“先读 n”的程序不会符合它的输入格式。

## 用下标表示一种类别

如果输入值只在 0 到 9 之间，可以开一个长度为 10 的计数数组。每读到数字 `x`，执行 `count[x]++`；最后 `count[3]` 就表示数字 3 出现了几次。

使用这种方法前，要确认：

1. 输入值是否真在数组覆盖范围内？
2. 计数数组是否已经初始化为 0？
3. 下标表示的是“第几个位置”，还是“哪一种数值”？

读题时分清这两种下标含义，能避免很多看似莫名其妙的错误。

## 二维数组：行与列

`int a[20][20] = {};` 可以看作 20 行、20 列。访问一个元素时，要同时指定行下标和列下标。

输入 `n` 行 `m` 列的矩阵，求每一行的和。例题约定 `1 <= n,m <= 20`，元素绝对值不超过 10⁹。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    int a[20][20] = {};
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }
    for (int i = 0; i < n; i++) {
        long long sum = 0;
        for (int j = 0; j < m; j++) {
            sum += a[i][j];
        }
        cout << sum << '\n';
    }
    return 0;
}
```

输入两行三列：第一行 `1 2 3`，第二行 `4 5 6`，输出分别是 `6` 和 `15`。注意每换一行，`sum` 都重新从 0 开始。

## 先建立边界习惯

- 对长度为 `n` 的数据，使用 0 下标时遍历 `0 <= i < n`。
- C++ 不支持用 `int a[n];` 作为标准的运行时长度数组写法；部分编译器把它当扩展接受，本教程先使用足够大的固定数组。后面会介绍 `vector`。
- 大数组不要随意放在函数内部，可能超出栈空间；本节的小数组不会遇到这个问题，规模变大时再按需要调整。
- 访问相邻元素时，先判断目标下标是否合法。例如访问 `a[i + 1]` 前，确认 `i + 1 < n`。
