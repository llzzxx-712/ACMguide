## 一维数组：名字相同，位置不同

`int a[5] = {};` 定义了 5 个整数，全部初始化为 0。访问时用 `a[下标]`：

| 下标 | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 刚初始化时的值 | 0 | 0 | 0 | 0 | 0 |
| 执行 a[2] = 7 后 | 0 | 0 | 7 | 0 | 0 |

**下标从 0 开始。** 第一个数在 a[0]，第三个数在 a[2]，最后一个数在 a[4]。定义中的 5 是总容量，不代表存在 a[5]。

如果已经知道有 n 个数，就可以让 i 从 0 走到 n−1，每轮用 `cin >> a[i];` 读入一个数。之后再遍历相同下标，就能重新取出这些值。

## 用下标表示类别：计数与标记

下标除了表示“第几个”，还可以表示“哪一种值”。

例如输入值都在 0 到 9 之间，定义 `int count[10] = {};`。每读到一个 x，就执行 `count[x]++;`。若依次读到 3、1、3，最后 count[3] 就是 2，表示数字 3 出现两次。

另一种用法是标记：用 0 表示“还没有出现”，用 1 表示“已经出现”。重复遇到同一个值仍然标为 1，就能避免重复计算。

用数组做计数或标记前，先看题目值域，保证每个可能出现的 x 都能作为合法下标。例如要表示位置 0 到 10000，就需要至少 10001 个位置。

## 二维数组：行与列

`int a[20][20] = {};` 可以看成 20 行、20 列。`a[i][j]` 表示第 i 行、第 j 列，行列下标都从 0 开始。

做一个本地演示：输入 n 行 m 列的矩阵，输出每一行的和。这里约定 `1 <= n,m <= 20`，每个数绝对值不超过 10⁹。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    int a[20][20] = {};
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }
    for (int i = 0; i < n; i++) {
        long long sum = 0;
        for (int j = 0; j < m; j++) {
            sum += a[i][j];
        }
        cout << sum << '\n';
    }
    return 0;
}
```

输入：

```text
2 3
1 2 3
4 5 6
```

输出：

```text
6
15
```

外层 i 选定一行，内层 j 依次取出这一行的每个数。sum 放在外层循环里面，因此每换一行都会重新从 0 开始。每个数虽然放得进 int，一行的总和却可能超过 int，所以 sum 使用 long long。

## 访问之前先检查边界

长度为 n 的数据，使用 0 下标时遍历 `0 <= i < n`。若访问 `a[i + 1]`，就先确认 `i + 1 < n`。

数组越界不一定立刻报错，也可能读到无关数据或产生错误结果。因此要根据容量和数据个数检查下标。

本章先用固定容量数组，例如 `int a[1000];`，实际存了多少个数就另外记录为 n。不要把容量 1000 和实际个数 n 混在一起；倒序输出应从 n−1 开始，而不是从 999 开始。

## 例题精讲：P1427 · 小鱼的数字游戏

**原题：** [P1427 · 小鱼的数字游戏](https://www.luogu.com.cn/problem/P1427)。

**题意简述：** 输入一串整数，最后用 0 表示结束。把 0 之前的数字倒序输出，数字之间用空格隔开，结束标记 0 不输出。原题数字个数不超过 100。

### 为什么要先存下来

例如输入：

```text
2 4 6 8 10 0
```

要求输出：

```text
10 8 6 4 2
```

读到第一个 2 时，我们还不能马上输出它，因为它最终要排在最后。因此先把所有有效数字存入数组，读完再倒序取出。

### 读入时同时记录个数

用 n 表示“已经存了几个数”。初始 n 为 0。每读到一个非零的 x，就把它放到 a[n]，再让 n 加 1：

| 刚读到的 x | 存到哪里 | 存完后的 n |
| --- | --- | --- |
| 2 | a[0] | 1 |
| 4 | a[1] | 2 |
| 6 | a[2] | 3 |

读到 0 就停止，不能先把 0 放进数组。最后有效下标为 0 到 n−1，输出时从 n−1 递减到 0。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[100] = {};
    int n = 0;
    int x;
    cin >> x;
    while (x != 0) {
        a[n] = x;
        n++;
        cin >> x;
    }
    for (int i = n - 1; i >= 0; i--) {
        if (i != n - 1) cout << ' ';
        cout << a[i];
    }
    cout << '\n';
    return 0;
}
```

while 的最后一行会读取下一个数字，因此条件检查的值会不断更新。输出部分只有在“不是第一个输出的数”时才先加空格，这样数字之间有空格，行首没有多余空格。

再输入 `7 0`，应输出 7。观察整个程序：**本题并没有先输入一个 n，n 是我们在读入时自己统计的。**
