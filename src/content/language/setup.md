## 今天要完成什么

今天先把工具准备好，不要求理解 C++ 代码。完成后，你应该能打开 Dev-C++、新建并保存一个 `.cpp` 文件，找到“编译并运行”的入口，并确认已经安装编译器。

这份教程统一使用 **C++17 + Dev-C++**。Dev-C++ 是 Windows 上的一套集成开发环境：你可以在里面写代码、调用编译器、运行程序。**编辑器是写代码的地方，编译器负责把代码转换成计算机能执行的程序。**

## 第一步：下载完整安装包

打开 [Embarcadero Dev-C++ 官方发布页](https://github.com/Embarcadero/Dev-Cpp/releases)。本教程以 6.3 系列界面为参考；如果发布页更新，以页面实际提供的文件为准。

1. 找到发布版本下的 **Assets**（附件），展开文件列表。
2. 选择文件名包含 **TDM-GCC** 的完整安装程序，例如带有 `TDM-GCC 9.2`、`Setup`、`.exe` 的文件。
3. 不要下载 `Source code`；那是软件源码。也不要选 `No Compiler`；它没有附带我们需要的编译器。
4. 下载完成后运行安装包，按安装向导保留编辑器和编译器组件。

已核对的 6.3 完整安装包名称为 `Embarcadero_Dev-Cpp_6.3_TDM-GCC_9.2_Setup.exe`。可以在发布页找到它，或使用[官方附件直链](https://github.com/Embarcadero/Dev-Cpp/releases/download/v6.3/Embarcadero_Dev-Cpp_6.3_TDM-GCC_9.2_Setup.exe)。

> 官方发布页提供的是软件作者发布的文件。如果学校已经提供可靠的统一安装包，可以直接使用。已经装好的同学先检查版本和 C++17 支持，不必反复安装。

安装时建议使用简单的英文路径，例如 `C:\Dev-Cpp`。这能减少初学阶段因路径、权限或其他工具兼容性引起的问题。

## 第二步：检查编译器与 C++17

第一次启动后，按提示选择界面语言、字体和主题。中文、英文界面都可以，本教程会尽量使用容易辨认的菜单名称。

在“工具（Tools）→ 编译选项（Compiler Options）”中检查：

- 已选中一个实际可用的 GCC / TDM-GCC 编译器配置。
- 在设置中找到 C++ 语言标准，选择 **ISO C++17 / GNU C++17**。
- 如果版本没有语言标准下拉框，可在“编译时加入以下命令”一类的编译器附加参数处填写 `-std=c++17`。不要把它填进链接器参数，也不要同时保留互相冲突的标准选项。

不同版本的菜单布局可能略有差别。找不到时，先记录版本和当前界面，向学长学姐求助，不要随机修改一大组设置。**第 2 天会通过真正的编译运行确认环境可用。**

## 第三步：建立代码文件夹

在自己的磁盘上建立一个专门放练习的文件夹，例如：

```text
D:\ACM\
  day01\
  day02\
  day03\
```

文件名优先使用英文字母、数字和下划线，如 `hello.cpp`、`p1001.cpp`。一开始不建议把所有程序都叫 `未命名1.cpp`，否则几天以后就很难找到它们。

在 Dev-C++ 中选择“文件 → 新建 → 源代码”，再选择“文件 → 保存”，保存为 `D:\ACM\day01\hello.cpp`。**注意后缀是 `.cpp`，不是 `.c` 或 `.txt`。**

今天可以先保存一个空文件。明天再在里面写第一段代码。

## 第四步：认识三个操作

| 操作 | 它做什么 | 常见结果 |
| --- | --- | --- |
| 保存 | 把编辑器里的内容写入文件 | `.cpp` 文件更新 |
| 编译 | 检查代码并生成可执行程序 | 成功，或显示编译错误 |
| 运行 | 执行已经编译好的程序 | 出现控制台窗口或输出 |

“编译并运行”会依次执行后两步，适合我们入门使用。请先在“运行（Execute）”菜单里找到它；快捷键以你的菜单显示为准。

以后改了代码，要**保存并重新编译**后再运行。如果只运行旧的可执行文件，你看到的仍然是修改前的结果。

## 常见问题

**只有编辑器，没有编译器。** 检查是否下载了 `No Compiler` 版本；回到官方发布页选择带 TDM-GCC 的完整安装包。

**保存后看不到 `.cpp`。** Windows 可能隐藏了文件扩展名。在资源管理器里打开“文件扩展名”的显示，确认实际文件名，避免得到 `hello.cpp.txt`。

**编译器不认识 C++17。** 检查实际选用的是不是新安装的 GCC 配置。旧版 Dev-C++ 附带的老编译器可能不支持 C++17；优先使用本页指定的完整版本。

**我用的是 macOS / Linux。** Dev-C++ 是 Windows 软件，请先用洛谷在线 IDE 等浏览器环境完成后面的 C++ 练习，或在学长学姐帮助下配置本机 C++ 编译器。本章代码不依赖 Windows 专属功能。

## 今日验收

- 能打开 Dev-C++，知道编辑区和编译信息区在哪里。
- 确认安装了编译器，知道 C++17 选项在哪里。
- 能在自己的文件夹中保存一个真正的 `.cpp` 文件。
- 找到了“编译并运行”，知道修改代码后需要重新编译。

完成这些就可以结束第 1 天。下一节，我们会写出并运行第一个程序。
