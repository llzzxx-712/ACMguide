## 今天要完成什么

今天先把工具准备好，再复制一段代码运行。完成后，你应该能打开 Dev-C++、新建并保存一个 `.cpp` 文件，并让屏幕成功显示 `Hello,World!`。

这份教程统一使用 **C++17 + Dev-C++**。Dev-C++ 是 Windows 上的一套集成开发环境：你可以在里面写代码、调用编译器、运行程序。**编辑器是写代码的地方，编译器负责把代码转换成计算机能执行的程序。**

>
> 帮我安装 Dev-C++ 并配置 C++17，安装路径等信息向我询问后再执行。

## 第一步：下载完整安装包

打开 [Dev-C++ 6.3 下载页（SourceForge）](https://sourceforge.net/projects/embarcadero-devcpp/files/v6.3/)，找到下面这个包含编译器的完整安装包：

`Embarcadero_Dev-Cpp_6.3_TDM-GCC_9.2_Setup.exe`

1. 在文件列表中点击这个文件名，进入下载页面。
2. 等待安装包开始下载，下载完成后找到这个 `.exe` 文件。
3. 文件名中的 `TDM-GCC_9.2` 表示附带编译器，`Setup.exe` 表示安装程序。选择这个完整安装包，不选 `No_Compiler` 版本。

## 第二步：安装并设置 C++17

1. 双击下载好的安装程序，按照向导开始安装。
2. 选择安装位置，建议使用简单的英文路径，例如 `C:\Dev-Cpp` 或 `D:\Dev-Cpp`。
3. 在组件选择中保留 **Dev-C++ 编辑器**和 **TDM-GCC 编译器**，然后完成安装。
4. 启动 Dev-C++，按提示选择界面语言、字体和主题。

接下来设置本教程使用的 C++17：

在“工具（Tools）→ 编译选项（Compiler Options）”中检查：

- 已选中一个实际可用的 GCC / TDM-GCC 编译器配置。
- 在设置中找到 C++ 语言标准，选择 **ISO C++17 / GNU C++17**。
- 如果版本没有语言标准下拉框，可在“编译时加入以下命令”一类的编译器附加参数处填写 `-std=c++17`。不要把它填进链接器参数，也不要同时保留互相冲突的标准选项。

找不到设置时，可以把当前界面截图发给 AI，告诉它你正在使用 Dev-C++ 6.3，请它带你找到对应选项。**本节最后会运行一个程序，确认环境可用。**

## 第三步：建立代码文件夹

在自己的磁盘上建立一个专门放练习的文件夹，例如：

```text
D:\ACM\
  day01\
  day02\
  day03\
```

文件名优先使用英文字母、数字和下划线，如 `hello.cpp`、`p1001.cpp`。一开始不建议把所有程序都叫 `未命名1.cpp`，否则几天以后就很难找到它们。

在 Dev-C++ 中选择“文件 → 新建 → 源代码”，再选择“文件 → 保存”，保存为 `D:\ACM\day01\hello.cpp`。**注意后缀是 `.cpp`，不是 `.c` 或 `.txt`。**

先保存好文件，接下来会把验收代码放进这个文件。

## 第四步：认识三个操作

| 操作 | 它做什么 | 常见结果 |
| --- | --- | --- |
| 保存 | 把编辑器里的内容写入文件 | `.cpp` 文件更新 |
| 编译 | 检查代码并生成可执行程序 | 成功，或显示编译错误 |
| 运行 | 执行已经编译好的程序 | 出现控制台窗口或输出 |

“编译并运行”会依次执行后两步，适合我们入门使用。请先在“运行（Execute）”菜单里找到它；快捷键以你的菜单显示为准。

以后改了代码，要**保存并重新编译**后再运行。如果只运行旧的可执行文件，你看到的仍然是修改前的结果。

## 常见问题

**只有编辑器，没有编译器。** 检查是否下载了 `No_Compiler` 版本；回到 SourceForge 下载页，选择上面列出的 `TDM-GCC_9.2_Setup.exe` 完整安装包，安装时保留编译器组件。

**保存后看不到 `.cpp`。** Windows 可能隐藏了文件扩展名。在资源管理器里打开“文件扩展名”的显示，确认实际文件名，避免得到 `hello.cpp.txt`。

**编译器不认识 C++17。** 检查实际选用的是不是新安装的 GCC 配置。旧版 Dev-C++ 附带的老编译器可能不支持 C++17；优先使用本页指定的完整版本。

**我用的是 macOS / Linux。** Dev-C++ 是 Windows 软件，请先用洛谷在线 IDE 等浏览器环境完成后面的 C++ 练习，或在学长学姐帮助下配置本机 C++ 编译器。本章代码不依赖 Windows 专属功能。

## 今日验收

- 能打开 Dev-C++，知道编辑区和编译信息区在哪里。
- 确认安装了编译器，知道 C++17 选项在哪里。
- 能在自己的文件夹中保存一个真正的 `.cpp` 文件。

## 最后一步：复制代码，确认安装成功

下面的程序会在屏幕上显示一句话。**今天直接复制粘贴就可以，不需要自己写，也不用先理解每一行。** 下一节我们再一起学习这些代码。

打开刚才保存的 `hello.cpp`，复制下面的全部内容并粘贴进去：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello,World!\n";
    return 0;
}
```

1. 保存文件，点击“编译并运行”。
2. 观察运行窗口，是否成功显示下面这一行：

```text
Hello,World!
```

能看到这行文字，就说明你已经完成了“保存 → 编译 → 运行”的流程，环境准备成功。

**如果出现报错，可以把代码、编译报错区或运行结果截图发给 AI**，告诉它：“我在 Dev-C++ 中运行这段 Hello World 代码时遇到了图中的问题，请带我一步步解决。”解决后重新编译运行，再观察结果。
