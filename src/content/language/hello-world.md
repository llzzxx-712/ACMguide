## 先认识程序骨架

一个最简单的 C++ 程序有三部分：准备要使用的功能、找到执行入口、在入口里写具体操作。

| 代码 | 现在怎么理解 |
| --- | --- |
| `#include<bits/stdc++.h>` | 引入常用库功能，后面的输入输出、字符串等都可以用 |
| `using namespace std;` | 让我们可以直接写 `cout`、`cin` |
| `int main()` | 程序从 main 函数开始执行 |
| `{` 和 `}` | 标出 main 中这段代码的范围 |
| `return 0;` | 让主函数正常结束 |

普通语句末尾通常有英文分号 `;`。`#include` 行末尾不加分号。双引号、分号、大括号都用英文输入法中的符号。

本教程统一使用万能头文件 `#include<bits/stdc++.h>`。把它放在程序开头，就准备好了我们常用的库功能；后面使用 `cout`、`cin`、`printf`、`string` 时，都沿用这个开头。

## 大括号与缩进：让代码的层次看得见

先只看 main 这一部分：

```text
int main() {
    cout << "Hello,World!\n";
    return 0;
}
```

`{` 表示这一段代码开始，`}` 表示这一段结束，一对大括号把里面的语句组织成一个**代码块**。上面两条语句都在 main 的大括号里，属于 main。后面学习 if 和循环时，也会用大括号圈出“满足条件要做什么”“每轮要重复做什么”。

建议**每进入一层大括号，里面的语句就向右缩进 4 个空格**，结束的右大括号退回到和这一层开头相同的位置。这样一眼就能看出哪些语句属于同一块，嵌套多层时也容易找到配对的大括号。

在 Dev-C++ 中，也可以按一次 **Tab** 完成一层缩进，把编辑器的 Tab 宽度设置为 4 个空格；开启“将 Tab 转为空格”后，按一次 Tab 就会插入 4 个空格。本教程示例统一用 4 个空格缩进。

**大括号决定代码属于哪一块，缩进帮助人看清这个结构。** 即使不缩进，程序也会按大括号的范围执行；我们保持整齐的缩进，是为了方便阅读和检查错误。

## 输出文字与换行

`cout << "I love ACM!";` 会把双引号里的文字显示到屏幕上，双引号本身不会显示。`cout` 中是字母 **o**，不是数字 0。

想让下一次输出从新的一行开始，就在文字末尾加 `\n`，例如 `cout << "I love ACM!\n";`。它是反斜杠和字母 n，不是 `/n`。

多条输出语句会按从上到下的顺序执行。如果没有换行，后面的内容就紧接着前面的内容显示。

## 为字符三角形准备：读入一个字符

必做题会让你用“输入的字符”画图。与其把星号写死在代码中，我们可以先用一个名字保存这次输入的字符：

```text
char c;
cin >> c;
cout << c;
```

`char c;` 准备一个叫 c 的位置，专门存一个字符；`cin >> c;` 等待你输入；`cout << c;` 把输入的字符输出出来。输入 `#` 就显示 `#`，输入 `*` 就显示 `*`。

如果希望同一行显示空格和多个相同字符，可以把输出连起来，例如 `cout << ' ' << c << c << '\n';`。其中 `' '` 是一个空格字符。下一节会进一步学习这些“存数据的位置”，也就是变量。

## 例题精讲：B2002 · Hello,World!

**原题：** [B2002 · Hello,World!](https://www.luogu.com.cn/problem/B2002)。

**题意简述：** 不需要输入，程序直接输出 `Hello,World!`。H 和 W 大写，逗号后**没有空格**。

### 从要求到代码

我们只需要做一次文字输出：在 main 里写输出语句，再正常结束程序。

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello,World!\n";
    return 0;
}
```

保存后选择“编译并运行”，应看到：

```text
Hello,World!
```

注意我们输出的是**题目要求的文字**。如果把字符串改成 `I love ACM!`，程序依然能正常运行，但完成的就不是 B2002 的要求了。

### 自己改一改，观察执行顺序

在本地把 main 里的输出改成两行：

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello,World!\n";
    cout << "I love ACM!\n";
    return 0;
}
```

运行后应显示：

```text
Hello,World!
I love ACM!
```

试着删掉第一条输出中的 `\n`，重新编译运行，观察两句话是否连在了一行。再把换行加回来。这样可以直接看见代码和输出之间的对应关系。

### 在洛谷提交

1. 打开原题，登录洛谷账号，核对它要求的输出。
2. 在提交页面选择 C++17 / GNU++17。
3. 提交只输出 `Hello,World!` 的版本。
4. 查看结果。AC 表示通过；CE 表示编译失败；WA 表示输出不符合题目要求。

在线评测会运行你的程序并检查输出。因此，提交这个题时只输出它要的那句话，不添加本地修改时的第二行。

## 报错时怎么找原因

| 现象 | 先检查什么 |
| --- | --- |
| 编译错误 CE | 从第一条报错开始，检查附近是否漏了分号、引号或大括号 |
| 答案错误 WA | 对照原题检查大小写、空格、换行，是否多输出了文字 |
| 仍然是旧输出 | 保存并重新编译当前文件 |
| 控制台一闪就关了 | 使用 Dev-C++ 的“编译并运行”查看结果，并检查控制台暂停设置 |

看不懂报错时，可以截图询问 AI，再按照它的解释找到对应代码。修改后重新编译运行，确认问题已经解决。
