## 写下第一个程序

打开昨天保存的 `hello.cpp`，输入下面的代码。**第一遍建议自己敲一遍**，注意英文半角符号、大小写和每一行的分号。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello,World!\n";
    return 0;
}
```

保存后，在菜单中选择“编译并运行”。屏幕应显示：

```text
Hello,World!
```

书写习惯中常见 `Hello, World!`（逗号后有空格），但本节为了对接洛谷 B2002，输出采用 **`Hello,World!`，逗号后没有空格**。评测题要求输出什么，就按题目要求写什么。

## 这几行分别在做什么

| 代码 | 现在怎么理解 |
| --- | --- |
| `#include <iostream>` | 引入输入输出功能 |
| `using namespace std;` | 让我们可以直接写 `cout`，不用每次加 `std::` |
| `int main()` | 程序从 `main` 函数开始执行 |
| `{` 和 `}` | 标出这一段代码的范围 |
| `cout << "...";` | 把引号里的内容输出到屏幕 |
| `\n` | 换行；它是一个反斜杠和字母 n，不是斜杠 `/n` |
| `return 0;` | 让主函数正常结束 |

普通语句末尾通常有英文分号 `;`。`#include` 行不是普通语句，末尾不要照着加分号。

`cout` 中是字母 **o**，不是数字 0。双引号、分号和大括号都要用英文输入法中的符号。

5. 查看评测结果。得到 AC 后，回头想一想：本地运行与在线提交，分别检查了什么？

在线评测会自动运行你的程序，并比较程序输出与题目要求。不要额外输出“我的答案是：”之类的提示；本题没有输入，也不需要等待用户键入任何内容。

## 报错并不可怕

| 现象 | 先检查什么 |
| --- | --- |
| 编译错误 CE | 第一条错误指向哪一行？附近是否漏了分号、引号或大括号？ |
| 答案错误 WA | 输出内容是否完全符合题目？是否多了第二行？ |
| 看起来一直是旧输出 | 是否保存并重新编译了当前文件？ |
| 控制台一闪就关了 | 使用 IDE 的“编译并运行”查看结果；检查控制台暂停设置 |

初学时，不要靠加入 `system("pause")` 来完成在线评测题；它不属于算法需要的代码。
