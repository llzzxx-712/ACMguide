## 变量：给数据一个名字

可以把变量理解成一个带名字的存储位置。定义时要告诉 C++，里面存的是哪种数据。

| 类型 | 用途 | 本阶段要记住什么 |
| --- | --- | --- |
| `int` | 常用整数 | 常见评测环境中通常为 32 位，范围约为正负 21 亿 |
| `long long` | 更大的整数 | 通常为 64 位，范围约为正负 9×10¹⁸ |
| `double` | 带小数的数 | 可以做实数运算，但存在浮点误差 |
| `char` | 单个字符 | 例如 `'A'`，使用单引号 |
| `bool` | 真假 | 值为 `true` 或 `false` |

刚定义的局部变量不一定有可用的初值。**在参与计算之前，先给它赋值或读入数据。**

`=` 表示赋值：`int score = 100;` 是把 100 存进 `score`，不是数学中的方程。

## 输入、计算、输出

下面的程序读取两个整数，输出它们的和：

```cpp
#include <iostream>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    cout << a + b << '\n';
    return 0;
}
```

输入：

```text
3 5
```

输出：

```text
8
```

`cin >> a >> b` 会依次读入两个数，空格或换行都可以把它们隔开。在本地输入完数字后按回车，让输入送到程序中。程序运行后暂时没有输出，可能只是还在等你输入。

如果要在同一行输出两个数，可以写 `cout << a << ' ' << b << '\n';`。其中 `' '` 是一个空格字符。

## 五种常用运算

| 运算符 | 含义 | 例子 |
| --- | --- | --- |
| `+` | 加法 | `7 + 3` 得到 10 |
| `-` | 减法 | `7 - 3` 得到 4 |
| `*` | 乘法 | `7 * 3` 得到 21 |
| `/` | 除法 | 整数 `7 / 3` 得到 2 |
| `%` | 整数取余 | `7 % 3` 得到 1 |

**整数除法不会自动变成小数。** `7 / 3` 的两个操作数都是整数，结果就是整数 2。想做实数除法，可以用 `7.0 / 3` 或把某个操作数转换为 `double`。

乘除优先于加减；不确定时加括号。除数不能是 0。对非负整数来说，除以 10 可以去掉末位，模 10 可以取出末位。

## 小数与格式

假设输入两个整数 `a`、`b`，要求输出它们的平均数，保留两位小数：

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    double average = (a + b) / 2.0;
    cout << fixed << setprecision(2) << average << '\n';
    return 0;
}
```

输入 `3 4`，输出 `3.50`。这里例题约定 `a`、`b` 的绝对值不超过 10⁹，因此求和不会超出 `long long`。

`fixed` 配合 `setprecision(2)` 表示保留小数点后两位。如果只写 `setprecision(2)`，含义并不一样。

## 类型范围与溢出

如果两个 `int` 先相乘，乘法可能在结果存入 `long long` 之前就已经溢出。常用处理方式是让乘法一开始就按 `long long` 进行，例如 `1LL * a * b`，或直接把参与运算的变量定义为 `long long`。

用苹果采购练习：读入单价和数量，输出总价。

```cpp
#include <iostream>
using namespace std;

int main() {
    long long price, count;
    cin >> price >> count;
    cout << price * count << '\n';
    return 0;
}
```

输入 `1000000000 3`，输出 `3000000000`。题目范围再大时，即使 `long long` 也可能放不下；选类型前要先看数据范围。本轮不学习高精度整数。
