## 变量：给数据一个名字

假设需要记录班里有多少名同学，可以写 `int students = 30;`。`int` 说明它是整数，`students` 是我们起的名字，`30` 是存进去的值。以后使用 `students`，就能取到这个数。

`=` 表示赋值。例如 `students = 40;` 会把原来的 30 换成 40。它不是数学中的方程，而是一条“把右边的结果存进左边”的指令。

| 类型 | 适合存什么 | 例子 |
| --- | --- | --- |
| `int` | 常用整数 | 人数、次数、数组下标 |
| `long long` | 更大的整数 | 数量较大时的乘积、总和 |
| `double` | 带小数的数 | 平均数、长度、饮料体积 |
| `char` | 一个字符 | `'A'`、`'3'`，使用单引号 |
| `bool` | 真或假 | `true`、`false`，下一节用来表示条件 |

变量名可由英文字母、数字和下划线组成，不能以数字开头，且区分大小写。先用能说明含义的名字，例如 `students`，不要使用带空格的名字。

刚定义的局部变量要**先赋值或读入，再参与计算**。写下 `int students;` 只准备了存放位置，还没有告诉它人数是多少。

## 用 cin 读取数据，用 cout 输出结果

`cin >> a >> b;` 会依次读入两个数据，分别存进 `a` 和 `b`。空格或换行都可以把两个数隔开。`cout << a;` 则把变量现在存着的值显示出来。

在本地运行时，程序可能先停在输入语句等待你输入。输入数字后按回车，程序才会继续计算。提交洛谷时，评测系统会提供输入，程序只需输出题目要求的结果。

例如输入 `3 5` 后，`a` 存着 3，`b` 存着 5。若执行 `cout << a + b << '\n';`，屏幕就会显示 8。这个要求对应 [P1001 · A+B Problem](https://www.luogu.com.cn/problem/P1001)：读入两个整数，输出它们的和。

## 五种常用运算

| 运算符 | 含义 | 例子 |
| --- | --- | --- |
| `+` | 加法 | 7 + 3 得到 10 |
| `-` | 减法 | 7 - 3 得到 4 |
| `*` | 乘法 | 7 * 3 得到 21 |
| `/` | 除法 | 整数 7 / 3 得到 2 |
| `%` | 整数取余 | 7 % 3 得到 1 |

**整数除法不会自动得到小数。** `7 / 3` 的两个数都是整数，结果就是 2。想得到小数，可以写 `7.0 / 3`，或者让参与除法的一个变量是 `double`。

乘除优先于加减，例如 `2 + 3 * 4` 得到 14；想先加就写 `(2 + 3) * 4`。除数不能为 0。对非负整数，`n / 10` 去掉末位，`n % 10` 取出末位，例如 123 会分别得到 12 和 3。

## 类型范围与溢出：为什么还需要 long long

在本教程使用的 GCC 环境中，`int` 是 32 位整数，范围为 **−2,147,483,648 到 2,147,483,647**，大约是正负 21 亿。它能存 10 亿，却放不下 30 亿。

如果某个计算结果超出了这个范围，就不能继续用 `int` 计算和保存它。比如 `1000000000 * 3` 应当得到 3000000000，这时要换成更大的 `long long`。

64 位 `long long` 的范围为 **−9,223,372,036,854,775,808 到 9,223,372,036,854,775,807**，大约是正负 9×10¹⁸。

不仅要看输入，还要看**中间结果和最终答案**。两个数分别放得进 `int`，它们的乘积也可能放不下。

| 写法 | 计算时发生什么 |
| --- | --- |
| `int a = 1000000000, b = 3; long long answer = a * b;` | 先做 int 乘法，已经超出范围；之后存入大变量也来不及 |
| `int a = 1000000000, b = 3; long long answer = 1LL * a * b;` | 1LL 是 long long 类型的 1，让乘法从一开始就按更大范围进行 |
| `long long a = 1000000000, b = 3;`，再算 `a * b` | 两个变量本身就是 long long，本例的乘法能正确完成 |

刚开始可以直接把可能参与大整数运算的变量定义为 `long long`。选好类型后，再检查结果是否也在它的范围内。

## 小数与格式：统一使用 printf

题目要求“保留两位小数”时，答案 3.5 也应输出为 `3.50`。我们用 `printf` 控制输出格式，需要引入 `<cstdio>`。

下面是一个**本地演示任务**：读入两个绝对值不超过 10⁹ 的整数，输出它们的平均数，保留两位小数。

```cpp
#include <iostream>
#include <cstdio>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    double average = (a + b) / 2.0;
    printf("%.2f\n", average);
    return 0;
}
```

输入 `3 4`，输出 `3.50`。`2.0` 让除法保留小数；如果写成整数 `2`，`3 + 4` 再除以 2 就会先得到整数 3。

`printf("%.2f\n", average);` 的第一个参数是**格式串**：`%.2f` 在这里为一个 double 留位置，并指定小数点后两位；后面的 average 提供要填进去的值；`\n` 表示换行。

| 想输出什么 | printf 的写法 | 结果示例 |
| --- | --- | --- |
| int 整数 x | `printf("%d\n", x);` | 12 |
| long long 整数 x | `printf("%lld\n", x);` | 3000000000 |
| double 小数 x，两位小数 | `printf("%.2f\n", x);` | 3.50 |
| 两个 int，中间有空格 | `printf("%d %d\n", a, b);` | 3 4 |
| int 至少占两位，不足补 0 | `printf("%02d\n", x);` | 03 |

格式符按顺序对应后面的变量，类型要匹配。`%.2f` 中的 2 可以换成 1、3、9，分别表示保留相应位数的小数。本教程保留 cin 读取数据；需要格式化输出时统一使用 printf。

## 例题精讲：P5703 · 苹果采购

**原题：** [P5703 · 苹果采购](https://www.luogu.com.cn/problem/P5703)。

**题意简述：** 每名同学分到固定数量的苹果，已知同学人数，求一共需要多少个苹果。输入两个正整数，依次是**每人分到的数量**和**人数**，输出总苹果数。原题保证输入和答案都在 int 范围内。

### 先在纸上算一遍

假设每人分到 3 个苹果，共有 5 人。我们会算 `3 × 5 = 15`。如果人数换成 8 人，就算 `3 × 8 = 24`。

计算方法没有变，变的是输入的数据。因此不需要为每种人数重新写一份程序，只要把计算流程写下来：

1. 用 apples 记录每人分到几个苹果，用 students 记录人数。
2. 读入两个数。
3. 计算 apples * students，输出乘积。

### 把流程翻译成代码

```cpp
#include <iostream>
using namespace std;

int main() {
    long long apples, students;
    cin >> apples >> students;
    long long total = apples * students;
    cout << total << '\n';
    return 0;
}
```

本题用 int 也能满足范围；这里用刚学过的 long long 练习整数乘法。

输入：

```text
3 5
```

输出：

```text
15
```

现在重新运行，不改代码，把输入换成 `3 8`，观察输出是否变成 24。再试 `2 10`，应当得到 20。

**我们用程序完成的是一个计算流程。** 变量保存本次的数据，输入把这次的数值交给程序，乘法规则负责计算。只要数据在程序能够处理的范围内，不管这次具体输入什么数，它都可以算出对应结果。这就是我们需要变量与输入的原因。
