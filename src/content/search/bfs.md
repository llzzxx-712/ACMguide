## 今天要完成什么

今天用 `queue` 把状态按层处理。你会通过马的遍历理解为什么 BFS 能求最少步数，再用水塘计数练习“从一个格子找出整片相连区域”。

DFS 常常沿一条分支深入；BFS 则先处理离起点近的状态，再处理更远的状态。

## BFS 也在枚举，只是换了处理顺序

上一节的 DFS 把“接下来有哪些选择”逐个试过，先沿一条分支深入。BFS 同样在枚举从当前状态可以走到哪些新状态，但它先处理离起点近的，再处理更远的。

例如马从起点出发：先枚举一步能到的格子，再从这些格子枚举下一步能到哪里。一个格子已经发现过，就不用因为另一条路线再次加入等待队列；我们要保存的是到达这个位置的最少步数。

这里从解题思路自然得到了两项实现要求：用队列安排“先发现的先扩展”，用 dist 记录“哪些状态已经发现，以及最少几步能到”。先理解为什么需要它们，再看代码如何入队、出队和赋值。

## 为什么要一层一层地找

假设你站在一个格子里，每次只能按规则走一步。要找离起点最近的某个位置，可以先试一步能到哪里；还没找到，就试两步、三步……

```text
第 0 层：起点
第 1 层：从起点走 1 步能首次到达的位置
第 2 层：从第 1 层再走 1 步，首次到达的新位置
第 3 层：继续扩展
```

先发现的近处状态，应该先被拿出来扩展；后发现的远处状态，排在后面等。这正是队列的**先进先出**。

### 把位置当作一个状态

一个格子用行号 x、列号 y 表示。可以用结构体装进队列：

```text
struct Point {
    int x, y;
};
queue<Point> q;
q.push({1, 1});       // 将一个 Point 放到队尾
Point now = q.front();
q.pop();
```

`{1, 1}` 依次给 x、y 赋值。取出后，now.x、now.y 就是当前处理的位置。

## BFS 的基本流程

先在纸上说一遍：“把起点放进等待名单；每次拿出最早等待的格子，检查它一步能到的所有格子；新发现的格子记录距离后放到名单末尾。”下面的流程与后面的程序，都是这句话的逐步实现。

用 `dist[x][y]` 同时记录最少步数与是否发现过：

- −1：还没有发现这个格子。
- 0：起点，走 0 步就到。
- 正整数：从起点到这里的最少步数。

```text
将所有 dist 初始化为 -1
dist[起点] = 0
起点入队

while 队列非空：
    取出并删除队首 now
    枚举从 now 能一步到达的 next
    如果 next 合法，且 dist[next] == -1：
        dist[next] = dist[now] + 1
        next 入队
```

### 为什么第一次发现就是最少步数

起点先入队，步数为 0。它扩展出的状态步数为 1，排在后面；处理步数为 1 的状态时，产生步数为 2 的状态，又排在更后面。

因此队列按步数从小到大处理。若一个格子第一次由距离 d 的状态走到，它的距离是 d+1；所有更短的可能来源已经处理过，不会再出现更短的路线。

这里的前提是**每次移动都算一步、代价相同**。后面的马、迷宫和电梯问题都满足这个条件。

> **发现时就标记，也就是入队前标记。**
>
> 写入 dist 后再入队，其他状态就不会把同一个位置重复放进去。若等到出队才标记，同一格可能在等待期间被许多来源重复加入。
>
> 本节求最少步数、统计整片区域时，发现过的状态不需要撤销；这与 DFS 枚举每一条独立路径时的回溯标记不同。

## 例题精讲：P1443 · 马的遍历

**原题：** [P1443 · 马的遍历](https://www.luogu.com.cn/problem/P1443)，来自[自编入门题单](https://www.luogu.com.cn/training/1126196)。

**题意简述：** 在 n×m 棋盘上，一匹马从 (x,y) 出发，每次走一个“日”字。求到每个格子最少走几步，无法到达的格子输出 −1。n、m≤400。

### 先把一步的规则写清楚

马的一步，一维移动 2，另一维移动 1，共有八种：

```text
(-2,-1)  (-2,+1)
(-1,-2)  (-1,+2)
(+1,-2)  (+1,+2)
(+2,-1)  (+2,+1)
```

用两个数组一一对应保存，`dx[k]` 和 `dy[k]` 合在一起才是一种走法。当前为 (x,y)，新位置为：

```text
int nx = x + dx[k];
int ny = y + dy[k];
```

棋盘使用 1 下标，所以需要 1≤nx≤n、1≤ny≤m。先判断范围，再读 `dist[nx][ny]`。

### 手算一块小棋盘

输入：

```text
3 3 1 1
```

输出：

```text
0 3 2
3 -1 1
2 1 4
```

第 0 层只有 (1,1)。它能一步到达 (2,3) 和 (3,2)，距离设为 1、放入队列。再从这两个位置向外扩展，就得到距离为 2 的位置。

中心 (2,2) 无法由棋盘内任何格子走“日”字到达，保持 −1。起点不是走一步到达自己，因此距离为 0。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

struct Point {
    int x, y;
};

int n, m;
int dist[405][405];
int dx[8] = {-2, -2, -1, -1, 1, 1, 2, 2};
int dy[8] = {-1, 1, -2, 2, -2, 2, -1, 1};

void bfs(int sx, int sy) {
    queue<Point> q;
    dist[sx][sy] = 0;
    q.push({sx, sy});

    while (!q.empty()) {
        Point now = q.front();
        q.pop();

        for (int k = 0; k < 8; k++) {
            int nx = now.x + dx[k];
            int ny = now.y + dy[k];
            if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
            if (dist[nx][ny] != -1) continue;

            dist[nx][ny] = dist[now.x][now.y] + 1;
            q.push({nx, ny});
        }
    }
}

int main() {
    int sx, sy;
    cin >> n >> m >> sx >> sy;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            dist[i][j] = -1;
        }
    }

    bfs(sx, sy);
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (j > 1) printf(" ");
            printf("%d", dist[i][j]);
        }
        printf("\n");
    }
    return 0;
}
```

### 对照队列，读懂这四行

这四行分别对应“轮到谁处理、从等待名单拿走、记录新发现的位置、安排后续处理”。移动数组则负责列出本题一步有哪些走法。换成电梯问题时，队列仍在安排处理顺序，枚举对象从八种坐标增量变成“向上或向下”两种楼层变化。

```text
Point now = q.front();                  // 保存当前状态
q.pop();                               // 从等待队列删除
dist[nx][ny] = dist[now.x][now.y] + 1;  // 首次发现新状态
q.push({nx, ny});                       // 排到队尾，等待扩展
```

now 是从队首复制出来的结构体，pop 后仍可使用。dist 在入队之前就赋值，因此同一位置不会被重复加入。

本题要求所有格子的距离，所以一直处理到队列为空。若只求一个目标的最少步数，第一次发现目标时就已经确定答案；起点恰好等于目标时，答案直接为 0。

### 时间、空间与输出

每个格子至多入队一次、出队一次，每次检查 8 个方向，总时间 $\mathcal{O}(8nm)$=$\mathcal{O}(nm)$。最大 400×400=160000 个格子，约 128 万次方向检查。

距离数组和队列最坏占 $\mathcal{O}(nm)$ 空间。这里不递归调用 bfs，因此不会因为一条很长的路径形成很深的递归栈。

输出每个格子的整数，同行用空格分隔即可。代码统一用 `printf` 输出；本题当前不要求固定场宽。

## 再做一个应用：P1596 · 水塘计数

**原题：** [P1596 · 水塘计数](https://www.luogu.com.cn/problem/P1596)，来自[自编入门题单](https://www.luogu.com.cn/training/1126196)。

**题意简述：** n×m 的田地中，W 表示水，. 表示干地。上下、左右、斜向相邻的水格属于同一片水塘，求水塘数量。n、m≤100。

这一次不求最少步数，而是想从一个水格出发，找出整片水塘。BFS 也能完成这种逐步扩展的任务。

### 找到一个新起点，就找到一片新水塘

从左到右、从上到下扫描：

1. 读到干地，跳过。
2. 读到已经标记过的水格，它所在的水塘已统计过，跳过。
3. 读到没有标记过的水格，答案加 1，从这里 BFS，把整片相连的水格都标记。

不能只把相邻水格数量当成水塘数。一片很长的水塘可能由许多格子组成；我们要给**整片区域**一次性做标记。

例如：

```text
W.
.W
```

这两个 W 斜向相邻，算同一片。马的八种走法与本题的八方向也不同：本题每个坐标增量只能取 −1、0、1，并排除 (0,0)。

### 输入输出示例

输入：

```text
4 5
W...W
.W..W
.....
W....
```

输出：

```text
3
```

左上两个斜接的水格一片，右上两个竖接的水格一片，左下单独一个水格一片。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

struct Point {
    int x, y;
};

int n, m;
char field[105][105];
bool vis[105][105];

void bfs(int sx, int sy) {
    queue<Point> q;
    vis[sx][sy] = true;
    q.push({sx, sy});

    while (!q.empty()) {
        Point now = q.front();
        q.pop();
        for (int dx = -1; dx <= 1; dx++) {
            for (int dy = -1; dy <= 1; dy++) {
                if (dx == 0 && dy == 0) continue;
                int nx = now.x + dx;
                int ny = now.y + dy;
                if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
                if (field[nx][ny] != 'W' || vis[nx][ny]) continue;

                vis[nx][ny] = true;
                q.push({nx, ny});
            }
        }
    }
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cin >> field[i][j];
        }
    }

    int ans = 0;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (field[i][j] == 'W' && !vis[i][j]) {
                ans++;
                bfs(i, j);
            }
        }
    }
    cout << ans << '\n';
    return 0;
}
```

### 为什么多次 BFS 仍然是 O(nm)

外层扫描所有格子一次。每次 BFS 的确有自己的循环，但所有 BFS 加在一起，每个水格仍只入队一次，所以总时间 $\mathcal{O}(nm)$，空间 $\mathcal{O}(nm)$。

vis 保留到整道题结束，不在两次 BFS 之间清空。否则同一片水塘会被再次发现、重复统计。

## DFS 与 BFS，该怎么选

| 任务 | 从哪里开始考虑 | 标记怎样处理 |
| --- | --- | --- |
| 枚举排列、组合、合法方案 | DFS，沿着选择往下走 | 当前方案的共享标记，返回时恢复 |
| 每次移动代价相同，求最少步数 | BFS，用队列按层处理 | 首次发现就记录距离，不撤销 |
| 统计一片相连区域 | DFS 或 BFS 都可以 | 整道题保留访问标记，不撤销 |

不是看到 DFS 就一定撤销，也不是看到网格就一定 BFS。先判断自己是在枚举每种方案、求最少步数，还是只想知道哪些位置能到达。
