## 从固定层数的循环，到深度优先搜索

从 1、2、3 中选两个不同的数，选出的顺序不重要。手算得到：

```text
1、2
1、3
2、3
```

若只选两个数，可以写两层循环；题目改成选 k 个数，循环层数由输入决定，就适合让函数递归地“再选一个”。

把过程画成一棵树，每个节点记录已经做过的选择：

```text
还没选
├─ 先选 1
│  ├─ 再选 2 → 得到 {1,2}
│  └─ 再选 3 → 得到 {1,3}
└─ 先选 2
   └─ 再选 3 → 得到 {2,3}
```

DFS 先走完 {1,2}，返回“先选 1”的位置，再走 {1,3}；这一支走完后，才返回起点尝试“先选 2”。

函数调用像一个栈：后调用的函数先返回。你在第三章学过的递归，现在用来系统地尝试选择。

### 写 DFS 前，先回答四个问题

| 问题 | 本次选两个数的回答 |
| --- | --- |
| 状态：已经进行到哪里？ | 已选多少个、下一个从哪里选 |
| 选择：这一步能做什么？ | 选一个编号更大的数 |
| 出口：什么时候处理答案？ | 已经选满两个 |
| 返回后：什么需要恢复？ | 取决于是否修改了共享数组或标记 |

DFS 不是每道题都套同一组参数。先说清楚状态，再把这些量写进函数。

## 例题精讲：P1036 · 选数

**原题：** [P1036 · 选数](https://www.luogu.com.cn/problem/P1036)，来自[自编入门题单](https://www.luogu.com.cn/training/1126196)。

**题意简述：** 从 n 个正整数中选出 k 个，统计有多少种选择的和是质数。选择与顺序无关，每个位置最多选一次。n≤20，k<n，每个数不超过 5×10⁶。

### 输入输出与手算

输入：

```text
4 3
3 7 12 19
```

四种选择的和分别是：

| 选择 | 和 | 是否为质数 |
| --- | --- | --- |
| 3、7、12 | 22 | 否 |
| 3、7、19 | 29 | 是 |
| 3、12、19 | 34 | 否 |
| 7、12、19 | 38 | 否 |

输出：

```text
1
```

题目要的是选择方案的数量，不是输出这些和；即使不同位置上的数相等，选择的下标不同仍是不同方案。

### 用三个参数描述当前进度

定义 `dfs(start, chosen, sum)`：

- start：接下来允许选择的最小下标。
- chosen：已经选了多少个数。
- sum：已经选出的数的总和。

最开始没有选数，从第 1 个数开始，因此调用 `dfs(1, 0, 0)`。

如果本轮选 a[i]，下一层就变成：

```text
dfs(i + 1, chosen + 1, sum + a[i]);
```

### 为什么下一层从 i+1 开始

这样选出的下标总是递增。例如选择了下标 1、2、4，就不会再用 2、1、4 的顺序重复统计同一组数，也不会重复选择同一个位置。

对本题不需要 used 数组：**递增的 start 已经规定了哪些位置还能选。** 如果题目要求排列、不同顺序算不同答案，就需要换一种状态设计。

### 选满后，怎样判断质数

质数是大于 1、只有 1 和自身两个正因子的整数。例如 2、3、5、7 是质数，1 不是。

如果 v 有一个非平凡因子，它和另一个因子的乘积为 v，其中至少有一个不超过 √v。因此检查 d=2 到 d×d≤v 即可；发现整除就返回 false。

先把这个判断函数作为本题的一个工具，第七章会继续学习质数与筛法。

### 再加一个提前结束的条件

还需要 k−chosen 个数，但从 start 到 n 只剩 n−start+1 个。如果剩余个数不够，这一支不可能成功，可以直接 return。这叫**剪枝**：提前停止没有希望的分支。

检查和的范围：最多选 20 个、每个不超过 5×10⁶，总和不超过 10⁸，int 可以保存。本题最多从 20 个位置中选一组，方案数量也在 int 范围内。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int n, k;
int a[25];
int ans = 0;

bool isPrime(int v) {
    if (v < 2) return false;
    for (int d = 2; d * d <= v; d++) {
        if (v % d == 0) return false;
    }
    return true;
}

void dfs(int start, int chosen, int sum) {
    if (chosen == k) {
        if (isPrime(sum)) ans++;
        return;
    }
    if (n - start + 1 < k - chosen) return;

    for (int i = start; i <= n; i++) {
        dfs(i + 1, chosen + 1, sum + a[i]);
    }
}

int main() {
    cin >> n >> k;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    dfs(1, 0, 0);
    cout << ans << '\n';
    return 0;
}
```

### 这里为什么没有 sum-=a[i]

sum 是函数的普通参数，每次调用获得自己的值。把 sum+a[i] 传给下一层，不会修改当前层的 sum。函数返回后，当前层仍拿着原来的参数，继续尝试下一个 i。

如果改为对一个全局 sum 执行 `sum += a[i]`，那么返回后就需要 `sum -= a[i]` 恢复。**要恢复的是被修改的共享状态，普通参数不会自动变成共享变量。**

### 计算量与递归深度

合法组合个数是 C(n,k)，表示“从 n 个位置中选 k 个”的数量；n≤20 时最大为 C(20,10)=184756。枚举中间节点的数量不超过所有子集数量的同阶，即 O(2ⁿ)。

设和的上限为 S，判断一次质数最坏 O(√S)，总时间上界可写成 O(2ⁿ+C(n,k)√S)。实际判断中，遇到第一个因子就会退出，不会每次都检查到平方根。

递归每层多选一个数，深度至多 k+1，调用栈空间 O(k)，加上输入数组，总空间 O(n)。

## 排列与组合：先判断顺序是否重要

如果题目要求输出 1 到 n 的全排列，1、2 与 2、1 是不同的排列，就不能继续用“下一次只选更大下标”的限制。

这时用 used[x] 表示数字 x 是否已经放进当前排列。假设 path[1..pos−1] 已经填好：

```text
void dfs(int pos) {
    if (pos == n + 1) {
        // 输出 path[1] 到 path[n]
        return;
    }
    for (int x = 1; x <= n; x++) {
        if (used[x]) continue;
        used[x] = true;
        path[pos] = x;
        dfs(pos + 1);
        used[x] = false;
    }
}
```

这里 used 是共享数组，离开这一支时必须恢复。path[pos] 下一次会被直接覆盖，不要求清零；而 used[x] 会影响后续分支能否选择 x，因此一定要撤销。

> **做选择 → 递归 → 撤销共享状态。**
>
> 这是回溯的基本顺序。used 表示“当前方案里使用过”，不是“整道题里曾经见过”。如果一个分支用完 x 后不恢复，其他分支就无法正常使用 x。

## 进阶例题精讲：P1219 · 八皇后

**原题：** [P1219 · 八皇后](https://www.luogu.com.cn/problem/P1219)，来自[自编入门题单](https://www.luogu.com.cn/training/1126196)。

**题意简述：** 在 n×n 棋盘上放 n 个皇后，每行、每列恰好一个，同一条斜线上最多一个。按字典序输出前三种方案，再输出方案总数；每个方案用“第 i 行放在哪一列”表示。6≤n≤13。

### 每一层只安排一行

定义 dfs(row)：准备在第 row 行放皇后。因为每层只放一行，行冲突已经被消除了；只需要检查列和两种斜线。

- col[c]：第 c 列是否已经有皇后。
- diag1[row+c]：这条 row+c 相同的斜线是否被占用。
- diag2[row−c+n]：这条 row−c 相同的斜线是否被占用；加 n 让下标变成正数。

例如 (1,2) 和 (2,1) 的行列和都为 3，位于同一条斜线；(1,1) 和 (2,2) 的行列差都为 0，位于另一方向的同一条斜线。

又一次，数组下标直接表达了题目的关系：不用每次回头扫描所有皇后，查询三个标记就知道能不能放。

### 何时撤销、何时统计

某列可放时，同时标记列和两条斜线，记录 path[row]=c，再递归下一行。返回后同时撤销三个标记，让其他方案可以使用。

row=n+1 说明 n 行全部放完，这是一个完整方案。方案总数加 1，若是前三种就输出。**输出第三种后仍要继续搜索**，因为最后还要求总数。

每一行按列号从小到大尝试，整个搜索自然按字典序得到方案：先比较第一行的列号，相同才比较第二行，依此类推。

### 输入输出示例

输入 6，输出：

```text
2 4 6 1 3 5
3 6 2 5 1 4
4 1 5 2 6 3
4
```

前面三行是前三种方案，最后的 4 是总方案数。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int n, ans = 0;
int path[20];
bool col[20], diag1[40], diag2[40];

void dfs(int row) {
    if (row == n + 1) {
        ans++;
        if (ans <= 3) {
            for (int i = 1; i <= n; i++) {
                if (i > 1) cout << ' ';
                cout << path[i];
            }
            cout << '\n';
        }
        return;
    }

    for (int c = 1; c <= n; c++) {
        int d1 = row + c;
        int d2 = row - c + n;
        if (col[c] || diag1[d1] || diag2[d2]) continue;

        path[row] = c;
        col[c] = diag1[d1] = diag2[d2] = true;
        dfs(row + 1);
        col[c] = diag1[d1] = diag2[d2] = false;
    }
}

int main() {
    cin >> n;
    dfs(1);
    cout << ans << '\n';
    return 0;
}
```

### 检查数组与复杂度

n≤13，row+c 最大为 26，row−c+n 在 1 到 25 之间，数组留到 40 足够。只有 row≤n 时才计算、访问这些下标。

剪枝前若只禁止重复列，完整摆法有 n! 种，搜索节点数量为 O(n!)，每个节点至多检查 n 列，粗略时间上界 O(n·n!)；斜线冲突会提前排除大量分支。搜索类题要把“每步能选多少、哪些分支会提前停止”一起考虑，不能用 n² 个格子就断言只做 n² 次操作。

递归深度 O(n)，列、斜线和方案数组也是 O(n) 空间。
