## 搜索：一种特殊的暴力枚举

在第二章，我们用循环把候选情况逐个试过；搜索也在做这件事。区别在于，搜索会根据当前已经做出的选择，继续枚举下一步。

例如 $N$ 皇后：第 1 行放在哪一列？确定后，第 2 行又放在哪一列？再决定第 3 行……每一种完整摆法，都是这些选择依次组合出来的。

**搜索是一种特殊的暴力枚举。** 先理解我们准备按什么顺序枚举哪些情况，再选择合适的代码来实现它。本节的 DFS 用递归组织枚举；下一节的 BFS 用队列组织按层枚举。

## 从两层 for，到由输入决定的层数

先做一个自编小实验：有 $n$ 行、每行 $\mathrm{cols}$ 列，每行放一枚棋子，暂时允许棋子同列，也不检查是否相互攻击。输出所有摆法，每个数表示对应行选择的列号。

如果固定有两行、每行两列，两层循环就够了：

```text
for (int c1 = 1; c1 <= 2; c1++) {
    for (int c2 = 1; c2 <= 2; c2++) {
        cout << c1 << ' ' << c2 << '\n';
    }
}
```

得到四种摆法：`1 1`、`1 2`、`2 1`、`2 2`。外层确定第一行，内层在这次选择下枚举第二行。

变成三行，就需要三层：

```text
for (int c1 = 1; c1 <= 2; c1++) {
    for (int c2 = 1; c2 <= 2; c2++) {
        for (int c3 = 1; c3 <= 2; c3++) {
            // 输出 c1、c2、c3
        }
    }
}
```

三行各有两种选择，共 $2^3=8$ 种。$N$ 皇后同样需要对每行做一次选择，只是每行有 $N$ 列，而且摆法必须符合不互相攻击的规则。

如果 $N$ 由输入给出，编写程序时不能按本次输入手动写好 $N$ 层 `for`。我们需要一种写法，让程序运行时决定要深入几层。

## 用递归实现“动态层数的 for 循环”

把重复的工作提炼成一句话：**处理第 $\mathrm{row}$ 行，枚举它放哪一列，然后让同一个函数去处理下一行。**

于是定义 `dfs(row)`：

1. 如果 `row = n + 1`，说明前 $n$ 行已经放好，输出当前摆法。
2. 否则，用一个 `for` 枚举这一行的列号 $c$。
3. 把选择记进 `path[row]`。
4. 调用 `dfs(row + 1)`，枚举后面各行的所有放法。
5. 下一层枚举完返回，本层 for 再试下一列。

### 与多层 for 一一对应

| 多层 for 中的含义 | 递归中怎样表达 |
| --- | --- |
| 第几层循环，负责第几行 | 参数 $\mathrm{row}$ |
| 本层选哪一列 | 当前调用里的局部变量 $c$ |
| 把这一层选好的值留给内层 | `path[row] = c` |
| 再进入一层循环 | `dfs(row + 1)` |
| 已做完 $n$ 次选择 | `row == n + 1` |
| 内层全部结束，外层继续下一个值 | 函数返回后，本层 `for` 执行 `c++` |

源代码里虽然只写了一个 for，每次递归调用都会有自己的 $\mathrm{row}$ 和 $c$。它们依次嵌套起来，就完成了层数由 $n$ 决定的枚举。

### 调用时暂停，返回后接着往下走

例如当前第一行选了 1，程序调用 `dfs(2)`。`dfs(1)` 会停在调用处，自己的 $c$ 仍然是 1；`dfs(2)` 用另一个 $c$，从 1 开始枚举第二行。

`dfs(2)` 的所有选择都处理完后才返回。回到 `dfs(1)`，接下来执行它这一层的 `c++`，变成 2，再去枚举“第一行选 2”时后面有哪些摆法。

递归调用不会让外层从头再跑，也不会让所有层共用一个 $c$。**每层负责自己的选择，返回意味着这一层交出去的任务已经完成。**

## 动图：枚举怎样发生，递归怎样实现它

先选“两层”，逐步看完四种摆法；再切换“三层”，观察源码里的 for 没有增加，函数调用却多了一层。

动图同时显示当前选择、函数调用和正在执行的代码。用“下一个完整摆法”可以直接走到一次输出；用“下一次返回”观察内层结束后，外层停在哪里、接下来做什么。

四皇后模式在同样的枚举上增加冲突检查：红色表示这个候选与前面的皇后冲突，跳过这一支；绿色表示找到一个完整解。四皇后是本指南用来缩小演示规模的例子，后面原题的范围为 $6\le n\le 13$。

### 与前两种模式对应的完整程序

本地演示约定 $1\le n,\mathrm{cols}\le 4$。输入行数和列数，输出所有摆法：

```cpp
#include<bits/stdc++.h>
using namespace std;

int n, cols;
int path[10];

void dfs(int row) {
    if (row == n + 1) {
        for (int i = 1; i <= n; i++) {
            if (i > 1) cout << ' ';
            cout << path[i];
        }
        cout << '\n';
        return;
    }

    for (int c = 1; c <= cols; c++) {
        path[row] = c;
        dfs(row + 1);
    }
}

int main() {
    cin >> n >> cols;
    dfs(1);
    return 0;
}
```

输入 `2 2`，输出：

```text
1 1
1 2
2 1
2 2
```

输入改成 `3 2`，会依次输出 `1 1 1`、`1 1 2`、`1 2 1`、`1 2 2`、`2 1 1`、`2 1 2`、`2 2 1`、`2 2 2`。这就是三层循环会得到的八种结果。

### 为什么这里没有把 `path[row]` 清零

$\mathrm{path}$ 只负责记录当前选择，下一次尝试时会覆盖同一格。输出只在前 $n$ 行都重新选好之后进行，因此旧值不会混进一个完整摆法。

返回到 `dfs(row)` 后，当前固定的前缀是前 $\mathrm{row}-1$ 行；更深位置留下的旧数值，已经不属于当前固定的选择。动图会把这些未固定的位置留空，而不是声称程序真的执行了清零。

### 搜索树，就是把暴力枚举的过程画出来

两层、每层两列的搜索树如下。边表示一次选择，根到叶子的整条路径表示一种完整摆法：

```text
尚未选择
├─ 第一行选 1
│  ├─ 第二行选 1 → 输出 1 1
│  └─ 第二行选 2 → 输出 1 2
└─ 第一行选 2
   ├─ 第二行选 1 → 输出 2 1
   └─ 第二行选 2 → 输出 2 2
```

DFS 先沿一个分支深入，走到完整摆法后返回，再尝试旁边的分支，所以叫**深度优先搜索**。没有冲突限制的这个小实验，会枚举全部 $\mathrm{cols}^n$ 种摆法；递归帮助我们组织枚举，计算量仍取决于实际试了多少种情况。

> **代码是思路的实现，在搜索中也一样。**
>
> 先说明“当前已经选了什么、下一步枚举什么、何时得到答案”，再把它们写成参数、循环和出口。要修改代码时，也先问解题过程需要怎样改变。

### 写 DFS 前，先回答四个问题

| 问题 | 棋子摆放实验中的回答 |
| --- | --- |
| 状态：已经进行到哪里？ | 准备处理第 $\mathrm{row}$ 行，前 $\mathrm{row}-1$ 行已经选好 |
| 选择：这一步能做什么？ | 枚举当前行的每一列 |
| 出口：什么时候处理答案？ | `row = n + 1`，所有行都选好了 |
| 返回后：什么需要恢复？ | $\mathrm{path}$ 会被覆盖；若另外修改了占用标记，则需要撤销 |

接下来把这套思路用于真正的题目。选数要求“选 $k$ 个、顺序不重要”，就改变状态与枚举范围；$N$ 皇后要求不互相攻击，就增加合法性检查与占用标记。

## 例题精讲：P1036 · 选数

**原题：** [P1036 · 选数](https://www.luogu.com.cn/problem/P1036)，来自[自编入门题单](https://www.luogu.com.cn/training/1126196)。

**题意简述：** 从 $n$ 个正整数中选出 $k$ 个，统计有多少种选择的和是质数。选择与顺序无关，每个位置最多选一次。$n\le 20$，$k<n$，每个数不超过 $5\times 10^6$。

### 输入输出与手算

输入：

```text
4 3
3 7 12 19
```

四种选择的和分别是：

| 选择 | 和 | 是否为质数 |
| --- | --- | --- |
| `3 7 12` | 22 | 否 |
| `3 7 19` | 29 | 是 |
| `3 12 19` | 34 | 否 |
| `7 12 19` | 38 | 否 |

输出：

```text
1
```

题目要的是选择方案的数量，不是输出这些和；即使不同位置上的数相等，选择的下标不同仍是不同方案。

### 用三个参数描述当前进度

定义 `dfs(start, chosen, sum)`：

- $\mathrm{start}$：接下来允许选择的最小下标。
- $\mathrm{chosen}$：已经选了多少个数。
- $\mathrm{sum}$：已经选出的数的总和。

最开始没有选数，从第 1 个数开始，因此调用 `dfs(1, 0, 0)`。

如果本轮选 `a[i]`，下一层就变成：

```text
dfs(i + 1, chosen + 1, sum + a[i]);
```

### 为什么下一层从 $i+1$ 开始

这样选出的下标总是递增。例如选择了下标 `1 2 4`，就不会再用 `2 1 4` 的顺序重复统计同一组数，也不会重复选择同一个位置。

对本题不需要 used 数组：**递增的 $\mathrm{start}$ 已经规定了哪些位置还能选。** 如果题目要求排列、不同顺序算不同答案，就需要换一种状态设计。

### 选满后，怎样判断质数

质数是大于 1、只有 1 和自身两个正因子的整数。例如 `2 3 5 7` 是质数，1 不是。

如果 $v$ 有一个非平凡因子，它和另一个因子的乘积为 $v$，其中至少有一个不超过 $\sqrt v$。因此检查 $d=2$ 到 $d\times d\le v$ 即可；发现整除就返回 `false`。

先把这个判断函数作为本题的一个工具，第七章会继续学习质数与筛法。

### 再加一个提前结束的条件

还需要 $k-\mathrm{chosen}$ 个数，但从 $\mathrm{start}$ 到 $n$ 只剩 $n-\mathrm{start}+1$ 个。如果剩余个数不够，这一支不可能成功，可以直接 `return`。这叫**剪枝**：提前停止没有希望的分支。

检查和的范围：最多选 20 个、每个不超过 $5\times 10^6$，总和不超过 $10^8$，`int` 可以保存。本题最多从 20 个位置中选一组，方案数量也在 `int` 范围内。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int n, k;
int a[25];
int ans = 0;

bool isPrime(int v) {
    if (v < 2) return false;
    for (int d = 2; d * d <= v; d++) {
        if (v % d == 0) return false;
    }
    return true;
}

void dfs(int start, int chosen, int sum) {
    if (chosen == k) {
        if (isPrime(sum)) ans++;
        return;
    }
    if (n - start + 1 < k - chosen) return;

    for (int i = start; i <= n; i++) {
        dfs(i + 1, chosen + 1, sum + a[i]);
    }
}

int main() {
    cin >> n >> k;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    dfs(1, 0, 0);
    cout << ans << '\n';
    return 0;
}
```

### 这里为什么没有 `sum -= a[i]`

$\mathrm{sum}$ 是函数的普通参数，每次调用获得自己的值。把 $\mathrm{sum}+a[i]$ 传给下一层，不会修改当前层的 $\mathrm{sum}$。函数返回后，当前层仍拿着原来的参数，继续尝试下一个 $i$。

如果改为对一个全局 $\mathrm{sum}$ 执行 `sum += a[i]`，那么返回后就需要 `sum -= a[i]` 恢复。**要恢复的是被修改的共享状态，普通参数不会自动变成共享变量。**

### 计算量与递归深度

合法组合个数是 $\binom{n}{k}$，表示“从 $n$ 个位置中选 $k$ 个”的数量；$n\le 20$ 时最大为 $\binom{20}{10}=184756$。枚举中间节点的数量不超过所有子集数量的同阶，即 $\mathcal{O}(2^{n})$。

设和的上限为 $S$，判断一次质数最坏 $\mathcal{O}(\sqrt{S})$，总时间上界可写成 $\mathcal{O}(2^n+\binom{n}{k}\sqrt S)$。实际判断中，遇到第一个因子就会退出，不会每次都检查到平方根。

递归每层多选一个数，深度至多 $k+1$，调用栈空间 $\mathcal{O}(k)$，加上输入数组，总空间 $\mathcal{O}(n)$。

## 排列与组合：先判断顺序是否重要

如果题目要求输出 1 到 $n$ 的全排列，`1 2` 与 `2 1` 是不同的排列，就不能继续用“下一次只选更大下标”的限制。

这时用 `used[x]` 表示数字 $x$ 是否已经放进当前排列。假设 `path[1..pos - 1]` 已经填好：

```text
void dfs(int pos) {
    if (pos == n + 1) {
        // 输出 path[1] 到 path[n]
        return;
    }
    for (int x = 1; x <= n; x++) {
        if (used[x]) continue;
        used[x] = true;
        path[pos] = x;
        dfs(pos + 1);
        used[x] = false;
    }
}
```

这里 used 是共享数组，离开这一支时必须恢复。`path[pos]` 下一次会被直接覆盖，不要求清零；而 `used[x]` 会影响后续分支能否选择 $x$，因此一定要撤销。

> **做选择 → 递归 → 撤销共享状态。**
>
> 这是回溯的基本顺序。$\mathrm{used}$ 表示“当前方案里使用过”，不是“整道题里曾经见过”。如果一个分支用完 $x$ 后不恢复，其他分支就无法正常使用 $x$。

## 进阶例题精讲：P1219 · 八皇后

**原题：** [P1219 · 八皇后](https://www.luogu.com.cn/problem/P1219)，来自[自编入门题单](https://www.luogu.com.cn/training/1126196)。

**题意简述：** 在 $n\times n$ 棋盘上放 $n$ 个皇后，每行、每列恰好一个，同一条斜线上最多一个。按字典序输出前三种方案，再输出方案总数；每个方案用“第 $i$ 行放在哪一列”表示。$6\le n\le 13$。

### 每一层只安排一行

定义 `dfs(row)`：准备在第 $\mathrm{row}$ 行放皇后。因为每层只放一行，行冲突已经被消除了；只需要检查列和两种斜线。

- `col[c]`：第 $c$ 列是否已经有皇后。
- `diag1[row + c]`：这条 $\mathrm{row}+c$ 相同的斜线是否被占用。
- `diag2[row - c + n]`：这条 $\mathrm{row}-c$ 相同的斜线是否被占用；加 $n$ 让下标变成正数。

例如 $(1,2)$ 和 $(2,1)$ 的行列和都为 3，位于同一条斜线；$(1,1)$ 和 $(2,2)$ 的行列差都为 0，位于另一方向的同一条斜线。

又一次，数组下标直接表达了题目的关系：不用每次回头扫描所有皇后，查询三个标记就知道能不能放。

### 从枚举所有摆法，到提前跳过不合法的分支

如果先不管冲突，每行都可以选 $n$ 列，完整摆法有 $n^n$ 种，正如前面纯枚举动图的放大版本。

现在假设前两行的皇后已经相互攻击，无论后面怎么放，这种摆法都不会成为合法答案。因此可以在放下当前皇后之前检查：列、斜线被占用就 continue，不再进入这一支的下一层。

这就是剪枝。我们仍在枚举可能的摆法，只是把已经能够判定不合法的一整批后续情况提前排除了。动图中的四皇后模式展示的正是这个过程：当前列冲突就试下一列；本行所有列都试完，就返回上一行，改变上一行的选择。

| 解题过程里的动作 | 完整代码中的实现 |
| --- | --- |
| 现在给第 $\mathrm{row}$ 行选位置 | `dfs(row)` |
| 逐个尝试这一行的列 | `for` 中的 $c=1$ 到 $n$ |
| 这列会冲突，整支都不必继续 | 查询 $\mathrm{col}$、$\mathrm{diag1}$、$\mathrm{diag2}$，冲突则 `continue` |
| 暂时采用这次选择 | `path[row] = c`，并把三个占用标记设为 true |
| 枚举剩下各行的摆法 | `dfs(row + 1)` |
| 这一次选择的后续已枚举完，准备换一种 | 把三个占用标记恢复为 false |

先把这些动作说清楚，完整程序就是按顺序实现它们。数组名可以换，动作的先后和含义必须一致。

### 何时撤销、何时统计

某列可放时，同时标记列和两条斜线，记录 `path[row] = c`，再递归下一行。返回后同时撤销三个标记，让其他方案可以使用。

`row = n + 1` 说明 $n$ 行全部放完，这是一个完整方案。方案总数加 1，若是前三种就输出。**输出第三种后仍要继续搜索**，因为最后还要求总数。

每一行按列号从小到大尝试，整个搜索自然按字典序得到方案：先比较第一行的列号，相同才比较第二行，依此类推。

### 输入输出示例

输入 6，输出：

```text
2 4 6 1 3 5
3 6 2 5 1 4
4 1 5 2 6 3
4
```

前面三行是前三种方案，最后的 4 是总方案数。

### 完整代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int n, ans = 0;
int path[20];
bool col[20], diag1[40], diag2[40];

void dfs(int row) {
    if (row == n + 1) {
        ans++;
        if (ans <= 3) {
            for (int i = 1; i <= n; i++) {
                if (i > 1) cout << ' ';
                cout << path[i];
            }
            cout << '\n';
        }
        return;
    }

    for (int c = 1; c <= n; c++) {
        int d1 = row + c;
        int d2 = row - c + n;
        if (col[c] || diag1[d1] || diag2[d2]) continue;

        path[row] = c;
        col[c] = diag1[d1] = diag2[d2] = true;
        dfs(row + 1);
        col[c] = diag1[d1] = diag2[d2] = false;
    }
}

int main() {
    cin >> n;
    dfs(1);
    cout << ans << '\n';
    return 0;
}
```

### 检查数组与复杂度

$n\le 13$，$\mathrm{row}+c$ 最大为 26，$\mathrm{row}-c+n$ 在 1 到 25 之间，数组留到 40 足够。只有 $\mathrm{row}\le n$ 时才计算、访问这些下标。

剪枝前若只禁止重复列，完整摆法有 $n!$ 种，搜索节点数量为 $\mathcal{O}(n!)$，每个节点至多检查 $n$ 列，粗略时间上界 $\mathcal{O}(n\cdot n!)$；斜线冲突会提前排除大量分支。搜索类题要把“每步能选多少、哪些分支会提前停止”一起考虑，不能用 $n^2$ 个格子就断言只做 $n^2$ 次操作。

递归深度 $\mathcal{O}(n)$，列、斜线和方案数组也是 $\mathcal{O}(n)$ 空间。
