闭区间二分 · 找第一次出现的位置

找到就记进 ans，再继续向左找

目标 x
le = 1 r = 7 mid = — ans = -1

先把整个 [1,7] 放入待查范围，ans=-1 表示还没找到。

while (le <= r) {    int mid = le + (r - le) / 2;    if (a[mid] == x) { ans = mid; r = mid - 1; }    else if (a[mid] < x) le = mid + 1;    else r = mid - 1;} // 结束后，直接返回 ans
